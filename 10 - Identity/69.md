درواقع Cookie برای **Web Applications سنتی** بهتر است.

مثال:
```markdown

ASP.NET MVC
Razor Pages
Blazor Server

```
چرا؟

- امنیت بهتر در Browser
- HttpOnly Cookie
- مدیریت Session راحت

---

### مثال Login با Cookie
```csharp

await HttpContext.SignInAsync(
    CookieAuthenticationDefaults.AuthenticationScheme,
    new ClaimsPrincipal(claimsIdentity));

```
---

### مثال واقعی

وبسایت:
```markdown

amazon.com

```
وقتی لاگین می‌کنی:
```markdown

Browser Cookie

```
نگه می‌دارد.
