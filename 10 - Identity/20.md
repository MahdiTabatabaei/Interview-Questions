تعریف **Refresh Token** توکنی است که برای گرفتن دوباره‌ی Access Token استفاده می‌شود، بدون نیاز به دوباره لاگین کردن.

چون Access Token عمر کوتاهی دارد.

ولی Refresh Token عمر زیادتری دارد (مثلاً چند روز).

📘 **مثال واقعی:**

تو کارت بانکی داری (Refresh Token) و با آن چند رمز یک‌بار مصرف (Access Token) می‌گیری. وقتی رمزت باطل شد، از کارت اصلی دوباره رمز جدید می‌سازی.

🧩 مثال C#:
```csharp

var refreshToken = Guid.NewGuid().ToString();
SaveRefreshToken(user.Id, refreshToken);

// وقتی Access توکن منقضی شد:
if (IsValid(refreshToken))
    var newAccessToken = GenerateJwtToken(user);

```
