ویژگی **Client** در IdentityServer یعنی **یک برنامه یا اپلیکیشن که می‌خواهد از IdentityServer توکن بگیرد** تا به API دسترسی پیدا کند.

هر Client می‌تواند باشد:

- Web App
- Mobile App
- SPA
- Backend Service

و IdentityServer برای هر Client مشخص می‌کند:

- چه Grant Type مجاز است
- چه Scopeهایی می‌تواند بگیرد
- آدرس Redirect کجاست
- آیا Secret دارد یا نه

مثال واقعی:

یک اپ موبایل بانک که از سرور احراز هویت توکن می‌گیرد.

مثال C#:
```csharp

new Client
{
    ClientId = "web_app",
    ClientSecrets = { new Secret("secret".Sha256()) },

    AllowedGrantTypes = GrantTypes.Code,

    RedirectUris = { "https://localhost:5002/signin-oidc" },

    AllowedScopes =
    {
        "openid",
        "profile",
        "api1"
    }
}

```
