تعریف **Token Theft** یعنی **دزدیده‌شدن توکن‌های احراز هویت** یک کاربر توسط مهاجم.  
به زبان ساده:

> اگر مهاجم توکنِ کاربر (مثل JWT یا Refresh Token) را به‌دست بیاورد، می‌تواند خودش را جای آن کاربر جا بزند.

توکن‌ها همان چیزی هستند که هویت کاربر را اثبات می‌کنند،  
بنابراین اگر کسی آن‌ها را بدزدد یعنی هویت شما را دزدیده است.

---

# Token Theft دقیقاً چگونه اتفاق می‌افتد؟

## 1. XSS (رایج‌ترین)
اگر توکن در LocalStorage یا SessionStorage ذخیره شود،  
و مهاجم بتواند جاوااسکریپت تزریق کند:

```
let token = localStorage.getItem("token");
sendToHacker(token);
```

تمام!

---

## 2. سرقت از کوکی‌ها
اگر توکن داخل Cookie ذخیره شود و:

- HttpOnly نباشد  
- Secure نباشد  
- SameSite درست تنظیم نشده باشد  

مهاجم می‌تواند آن را سرقت کند یا با CSRF سوءاستفاده کند.

---

## 3. سرقت از شبکه (MITM Attack)
وقتی درخواست‌ها بدون HTTPS ارسال شوند،  
هکر می‌تواند درخواست را شنود و توکن را بردارد.

---

## 4. سرقت Refresh Token
حتی اگر Access Token عمر کوتاه داشته باشد،  
اگر Refresh Token دزدیده شود، مهاجم می‌تواند توکن جدید بسازد.

---

## 5. سرقت از حافظه کلاینت یا برنامه
مثلاً یک بدافزار روی موبایل یا سیستم کاربر،  
که به فایل‌ها یا حافظه دسترسی دارد.

---

## 6. حمله Replay Attack
مهاجم یک توکن معتبر را از هر طریقی به‌دست می‌آورد  
و چند بار از آن برای دسترسی استفاده می‌کند.

---

# چرا Token Theft خطرناک است؟

چون مهاجم با داشتن توکن:

- بدون نیاز به رمز عبور
- بدون نیاز به دوباره لاگین
- حتی بدون نیاز به داشتن دستگاه کاربر

می‌تواند **مستقیماً به API یا سرویس‌ها دسترسی کامل بگیرد**.

توکن = بلیت دسترسی → اگر دزدیده شود، مهاجم همان دسترسی کاربر اصلی را دارد.

---

## 2. استفاده از HTTPS  
اجباری.

## 3. استفاده از Access Token کوتاه‌مدت (۵ تا ۱۰ دقیقه)

## 4. محافظت از Refresh Token

- one-time-use

- CSP Headers  
- جلوگیری از ارجاع مستقیم به innerHTML

## 7. بررسی IP / Device / Fingerprint در سمت سرور

# خلاصه کوتاه

**Token Theft = سرقت توکن → مهاجم دسترسی کامل کاربر را به‌دست می‌آورد.**

دلایل:
- XSS  
- دزدیدن LocalStorage  
- کوکی امن نبودن  
- شبکه HTTP  
- بدافزار  

راهکار:
- HttpOnly Cookies  
- HTTPS  
- Token Rotation  
- XSS Protection
