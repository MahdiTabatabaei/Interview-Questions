ابزار IdentityServer از **Entity Framework** پشتیبانی می‌کند.

مثال:
```csharp

builder.Services.AddIdentityServer()
    .AddConfigurationStore(options =>
    {
        options.ConfigureDbContext = b =>
            b.UseSqlServer(connectionString);
    });

```
این باعث می‌شود:
```markdown

Clients
ApiResources
ApiScopes
IdentityResources

```
در دیتابیس ذخیره شوند.
