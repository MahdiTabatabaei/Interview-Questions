ویژگی **ASP.NET Identity** یک فریم‌ورک عضویت (Membership System) است که وظیفه‌ی مدیریت:

- کاربران
- نقش‌ها
- رمز عبور
- تأیید ایمیل
- ورود چندمرحله‌ای

و … را بر عهده دارد.

✅ **مشکلی که حل می‌کند:**

قبلاً در Membership قدیمی فقط Username/Password نگهداری می‌شد و توسعه سخت بود.

ویژگی ASP.NET Identity انعطاف‌پذیر است، از Claims پشتیبانی می‌کند، و با Entity Framework مجتمع است.

📘 **مثال:**
```csharp

var user = new ApplicationUser { UserName = "Ali", Email = "ali@example.com" };
var result = await _userManager.CreateAsync(user, "Pa$$w0rd");

```
