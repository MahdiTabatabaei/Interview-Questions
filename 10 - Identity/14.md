1. هنگام ساخت کاربر، سیستم یک **توکن تأیید ایمیل** ایجاد می‌کند.
2. لینک فعال‌سازی با آن توکن ساخته و برای کاربر ایمیل می‌شود.
3. کاربر روی لینک کلیک می‌کند ← ایمیل تأیید می‌شود.

🧩 مثال:
```csharp

var token = await _userManager.GenerateEmailConfirmationTokenAsync(user);
var confirmationLink = Url.Action("ConfirmEmail", "Account", new { userId = user.Id, token }, Request.Scheme);
await _emailSender.SendEmailAsync(user.Email, "Confirm your email", confirmationLink);

```
در اکشن تأیید:
```csharp

await _userManager.ConfirmEmailAsync(user, token);

```
