تعریف Identity Resource نشان‌دهنده‌ی **اطلاعات هویتی کاربر** است که در **ID Token** برمی‌گردد.

مثال:
```markdown

openid
profile
email

```
مثال واقعی:

وقتی با Google Login وارد می‌شوی و سایت نام و ایمیل تو را دریافت می‌کند.

مثال C#:
```csharp

new IdentityResource(
    name: "profile",
    displayName: "User profile",
    userClaims: new[] { "name", "family_name" }
)

```
