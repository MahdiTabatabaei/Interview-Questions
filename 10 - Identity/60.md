معماری معمول:
```markdown

Users
   ↓
Identity Server
   ↓
Access Token
   ↓
API Gateway
   ↓
Microservices

```
مراحل:

1. کاربر login می‌کند
2. IdentityServer توکن صادر می‌کند
3. کلاینت توکن را به API می‌فرستد
4. API توکن را validate می‌کند

مثال در API:
```csharp

[Authorize]
[HttpGet]
public IActionResult GetProfile()
{
    return Ok(User.Identity.Name);
}

```
