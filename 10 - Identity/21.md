📘 **مثال واقعی:**

وقتی وارد سیستم بانکی می‌شی، کارت بانکی (Access Token) برای انجام تراکنش استفاده می‌شود، اما کارت ملی (ID Token) هویت تو را اثبات می‌کند.

🧩 **مثال C#:**
```csharp

// Access Token برای دسترسی به API استفاده می‌شود
client.DefaultRequestHeaders.Authorization = 
    new AuthenticationHeaderValue("Bearer", accessToken);

// ID Token برای شناسایی در کلاینت به کار می‌رود
var handler = new JwtSecurityTokenHandler();
var idTokenData = handler.ReadJwtToken(idToken);
Console.WriteLine(idTokenData.Claims.First(c => c.Type == "name").Value);

```
