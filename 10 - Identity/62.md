تعریف **Multi-Tenant** یعنی یک سیستم که چندین سازمان مختلف از آن استفاده می‌کنند.

مثال واقعی:

یک SaaS مانند:
```markdown

Company A
Company B
Company C

```
هر شرکت کاربران خودش را دارد.

روش‌های پیاده‌سازی:

### روش 1 — Tenant در Claim

و Token شامل TenantId می‌شود.

مثال:
```markdown

tenant_id = companyA

```
افزودن Claim
```csharp

context.IssuedClaims.Add(new Claim("tenant_id", "companyA"));

```
بررسی در API
```csharp

var tenant = User.FindFirst("tenant_id")?.Value;

```
---

### روش 2 — Database per Tenant

هر Tenant دیتابیس جدا دارد.
```markdown

TenantA_DB
TenantB_DB
TenantC_DB

```

---
روش 3 — Tenant در URL

```markdown

companyA.myapp.com
companyB.myapp.com

```
