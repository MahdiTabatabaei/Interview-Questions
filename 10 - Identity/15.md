1. کاربر درخواست ریست رمز می‌دهد.
2. سیستم یک **توکن بازنشانی رمز** تولید می‌کند.
3. لینک حاوی این توکن ارسال می‌شود.
4. کاربر با لینک به صفحه‌ی تعیین رمز جدید هدایت می‌شود.

🧩 مثال:
```csharp

var token = await _userManager.GeneratePasswordResetTokenAsync(user);
var link = Url.Action("ResetPassword", "Account", new { token, email = user.Email }, Request.Scheme);
await _emailSender.SendEmailAsync(user.Email, "Reset Password", link);

```
در ادامه:
```csharp

await _userManager.ResetPasswordAsync(user, token, "NewPassword123!");

```
