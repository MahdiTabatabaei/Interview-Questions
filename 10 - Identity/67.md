هر دو **IdentityServer** و **Keycloak** نقش یک چیز را دارند:  
یک **Identity Provider / Authorization Server** برای پیاده‌سازی **OAuth2 ،OpenID Connect و SSO**.  
اما از نظر معماری، اکوسیستم و نحوه استفاده تفاوت‌های مهمی دارند.

---

# تفاوت IdentityServer و Keycloak

## 1. تکنولوژی و پلتفرم

### IdentityServer
- مخصوص **.NET**
- به صورت **کتابخانه داخل برنامه ASP.NET Core** استفاده می‌شود
- معمولاً داخل همان solution پروژه پیاده‌سازی می‌شود

### Keycloak
- یک **سیستم مستقل (Standalone Server)** است
- نوشته شده با **Java**
- به صورت سرویس جدا اجرا می‌شود (Docker / Server)

نتیجه:  
IdentityServer بیشتر **embedded در اپلیکیشن** است،  
Keycloak **یک سرویس جداگانه Identity** است.

---

## 2. رابط مدیریتی (Admin UI)

### IdentityServer
- به صورت پیش‌فرض **Admin Panel ندارد**
- باید خودت UI مدیریت بسازی یا ابزار جانبی استفاده کنی

### Keycloak
- **Admin Console کامل** دارد
- از طریق UI می‌توانی:
  - کاربران
  - Role
  - Client
  - Realm
  - Policy
  - Identity Provider

را مدیریت کنی.

نتیجه:  
Keycloak از نظر مدیریت **خیلی آماده‌تر** است.

---

## 3. مدیریت کاربران

### IdentityServer
خودش User Store ندارد.  
معمولاً با این ترکیب استفاده می‌شود:

```
IdentityServer + ASP.NET Identity
```

### Keycloak
خودش:
- User Database
- Role
- Group
- Permission

را دارد.

حتی می‌تواند به:
- LDAP
- Active Directory

وصل شود.

---

## 4. Single Sign-On

هر دو پشتیبانی می‌کنند، اما:

### IdentityServer
نیاز به **پیاده‌سازی بیشتر توسط توسعه‌دهنده**

### Keycloak
SSO **به صورت آماده** وجود دارد.

---

## 5. Federation

### Keycloak
می‌تواند Login از سرویس‌های دیگر بگیرد:

- Google
- Facebook
- GitHub
- Azure AD
- SAML providers

### IdentityServer
امکان‌پذیر است ولی **پیاده‌سازی دستی بیشتری لازم دارد**.

---

## 6. هزینه و لایسنس

### IdentityServer
نسخه جدید (**Duende IdentityServer**)  
برای استفاده production **لایسنس پولی** دارد.

### Keycloak
- کاملاً **Open Source**
- رایگان

---

## 7. معماری در سیستم‌های بزرگ

### IdentityServer
بیشتر مناسب:

- پروژه‌های **.NET-centric**
- کنترل کامل در کد
- Customization زیاد

### Keycloak
بیشتر مناسب:

- **Microservice architectures**
- سیستم‌های چند زبان
- سازمان‌های بزرگ

---

# مقایسه خلاصه

IdentityServer

- مخصوص .NET
- embedded داخل اپ
- admin panel ندارد
- نیاز به ASP.NET Identity برای user
- customization بالا
- نسخه production پولی

Keycloak

- Java based
- standalone server
- admin UI کامل
- user management داخلی
- federation آماده
- open source

---

- React Web App

   |

### با Keycloak

   |

# نتیجه عملی

اگر پروژه‌ات:

**کاملاً .NET است و customization زیادی می‌خواهی**
→ IdentityServer

اگر می‌خواهی:

- یک **Identity Server آماده**
- با **Admin UI**
- **SSO سریع**
- **بدون کدنویسی زیاد**

→ Keycloak
