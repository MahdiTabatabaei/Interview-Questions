مفهوم **PKCE (Proof Key for Code Exchange)** برای جلوگیری از حمله “Code Interception” استفاده می‌شود.

در واقع SPA‌ها چون فقط در مرورگرند، Secret ندارند → PKCE کمک می‌کند امنیت با “code_verifier” و “code_challenge” برقرار شود.

🧩 در C#:
```csharp

string verifier = CryptoRandom.CreateUniqueId(32);
string challenge = Base64Url.Encode(SHA256(verifier));

```

📘 مثال واقعی:

مثل رمز دوم پیامکی که فقط با گوشی خودت می‌توانی ثابت کنی صاحب حسابی.
