در ASP.NET Identity از الگوریتم امن **PBKDF2** برای هش کردن رمز عبور استفاده می‌کند.

این کار خودکار هنگام ثبت کاربر انجام می‌شود.

🧩 مثال:
```csharp

var user = new ApplicationUser { UserName = "Ali" };
await _userManager.CreateAsync(user, "MySecurePass!123");

```
رمز در دیتابیس به شکل هش ذخیره می‌شود، نه به صورت متنی (plain text):
```markdown

AQAAAAEAACcQAAAAEJf7x...

```
