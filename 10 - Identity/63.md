مراحل معمول:

1️⃣ ساخت Docker Image

2️⃣ Push به Registry

3️⃣ Deploy در Kubernetes

### Dockerfile مثال
```yaml

FROM mcr.microsoft.com/dotnet/aspnet:8.0

WORKDIR /app
COPY . .

ENTRYPOINT ["dotnet", "IdentityServer.dll"]

```
ساخت Image
```markdown

docker build -t identityserver .

```
---

### Kubernetes Deployment
```yaml

apiVersion: apps/v1
kind: Deployment
metadata:
  name: identityserver
spec:
  replicas: 3
  template:
    spec:
      containers:
      - name: identityserver
        image: identityserver:latest
        ports:
        - containerPort: 80

```
