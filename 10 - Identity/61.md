در معماری مدرن معمولاً **یک Authorization Server (Identity Provider)** وجود دارد و چندین API به آن اعتماد می‌کنند.

معماری:
```markdown

Client
   ↓
Identity Provider (IdentityServer)
   ↓
Access Token (JWT)
   ↓
API1
API2
API3

```
مراحل:

1. کاربر در **Identity Provider** لاگین می‌کند
2. یک **Access Token** دریافت می‌کند
3. Client همان Token را برای هر API ارسال می‌کند
4. هر API Token را **Validate** می‌کند

مثال واقعی:

یک سیستم فروش:
```markdown

User API
Orders API
Payment API

```
همه با یک Identity Server محافظت می‌شوند.

### تعریف Scope ها در IdentityServer
```csharp

public static IEnumerable<ApiScope> ApiScopes =>
    new List<ApiScope>
    {
        new ApiScope("orders.read"),
        new ApiScope("payments.read"),
        new ApiScope("users.read")
    };

```
تعریف Client
```csharp

new Client
{
    ClientId = "web_client",
    AllowedGrantTypes = GrantTypes.Code,

    RedirectUris = { "https://localhost:5002/signin-oidc" },

    AllowedScopes =
    {
        "openid",
        "profile",
        "orders.read",
        "payments.read"
    }
}

```
محافظت از API
```csharp

builder.Services.AddAuthentication("Bearer")
.AddJwtBearer("Bearer", options =>
{
    options.Authority = "https://localhost:5001";
    options.Audience = "orders_api";
});

```
