مفهوم **API Resource** نماینده‌ی **یک API محافظت‌شده** است که فقط با Access Token قابل دسترسی است.

مثال:
```markdown

Orders API
Payment API
User API

```
مثال واقعی:

در یک شرکت چند سرویس وجود دارد:

- سرویس سفارش
- سرویس پرداخت

هر کدام یک API Resource هستند.

مثال C#:
```csharp

new ApiResource("orders_api", "Orders API")
{
    Scopes = { "orders.read", "orders.write" }
}

```
