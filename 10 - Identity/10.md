### UserManager

کلاسی برای انجام عملیات کاربری، مثل:

- ایجاد کاربر
- حذف کاربر
- تغییر رمز
- تأیید ایمیل
- اضافه کردن نقش

🧩 مثال:
```csharp

await _userManager.CreateAsync(user, "Password123!");
await _userManager.AddToRoleAsync(user, "Admin");

```
### SignInManager

کلاسی برای مدیریت فرآیند ورود، خروج و احراز هویت (Authentication):

🧩 مثال:
```csharp

var result = await _signInManager.PasswordSignInAsync("Ali", "Password123!", false, false);
if (result.Succeeded)
    Console.WriteLine("Login successful");

```
