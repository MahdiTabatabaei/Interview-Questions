هر Token (Access یا ID) **زمان انقضا دارد** تا در صورت لو رفتن امنیت حفظ شود.

مدیریت معمول:

- Access Token = چند دقیقه
- Refresh Token = چند روز

🧩 **در C#:**
```csharp

new JwtSecurityToken(
    expires: DateTime.UtcNow.AddMinutes(15)
);

```
📘 **مثال واقعی:**

بلیط سینما فقط تا انتهای سانس اعتبار دارد. بعد از آن باطل می‌شود.
