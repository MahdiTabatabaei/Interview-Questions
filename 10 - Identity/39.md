تعریف **IdentityServer** (مانند IdentityServer4 یا Duende IdentityServer) یک فریم‌ورک قدرتمند برای **پیاده‌سازی OAuth 2.0 و OIDC** در .NET است.

🎯 نقش‌ها:

- صدور Access و ID Token
- مدیریت کاربران و سیاست‌ها
- نقطه مرکزی احراز هویت برای همه سرویس‌ها

📘 مثال معماری:
```markdown

[Client App] → [IdentityServer] → [Resource API]

```
