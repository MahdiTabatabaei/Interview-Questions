اعتبارسنجی API باید:

1. امضای Token را بررسی کند
2. زمان انقضا را بررسی کند
3. و issuer را بررسی کند
4. همچنین scope را بررسی کند

مثال:
```csharp

builder.Services.AddAuthentication("Bearer")
.AddJwtBearer(options =>
{
    options.Authority = "https://localhost:5001";
    options.Audience = "orders_api";
});

```
