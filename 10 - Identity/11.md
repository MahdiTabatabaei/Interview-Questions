ویژگی **RoleManager** برای مدیریت نقش‌ها استفاده می‌شود:

- تعریف نقش جدید
- حذف نقش
- بررسی اینکه نقش وجود دارد یا نه

🧩 مثال:
```csharp

if (!await _roleManager.RoleExistsAsync("Admin"))
{
    await _roleManager.CreateAsync(new IdentityRole("Admin"));
}

```
📘 **مثال دنیای واقعی:**

در یک شرکت، HR نقش “مدیر مالی” ایجاد می‌کند تا فقط آن افراد به اطلاعات مالی دسترسی داشته باشند.
