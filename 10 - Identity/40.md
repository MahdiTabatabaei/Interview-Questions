ابزار IdentityServer با ایجاد endpointهای استاندارد زیر:

- `/connect/authorize`
- `/connect/token`
- `/connect/userinfo`
- `/.well-known/openid-configuration`

و با تعریف **Clients, Scopes, Resources** در کانفیگ خودش کل پروتکل‌های OAuth/OIDC را اجرا می‌کند.

🧩 مثال تنظیم کلاینت در C#:
```csharp

new Client
{
    ClientId = "mvc_client",
    AllowedGrantTypes = GrantTypes.Code,
    RedirectUris = { "https://localhost:5002/signin-oidc" },
    AllowedScopes = { "openid", "profile", "api1" }
};

```
📘 مثال واقعی:

ابزار IdentityServer مثل “دروازه‌بان” بین تمام اپ‌ها و کاربران است — هر درخواست ورود یا دسترسی ابتدا از او تأیید می‌گیرد.
