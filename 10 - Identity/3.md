در واقع **Authorization** یعنی:

> تعیین اینکه کاربر چه کارهایی اجازه انجام دارد.

مثلا:

- کاربر عادی → فقط مشاهده
- مدیر → حذف و ویرایش

---

### انواع Authorization

1️⃣ Role Based

بر اساس **نقش کاربر**

2️⃣ Claim Based

بر اساس **اطلاعات (Claims)**

3️⃣ Policy Based

ترکیبی از چند شرط

---

### مثال C#
```csharp

[Authorize(Roles = "Admin")]
public IActionResult DeleteUser()
{
    return View();
}

```
فقط Admin می‌تواند این متد را اجرا کند.
