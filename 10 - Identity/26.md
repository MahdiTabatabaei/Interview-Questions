1. نقش **Resource Owner:** شخصی که داده را دارد (کاربر)
2. و **Client:** اپلیکیشنی که می‌خواهد به داده دسترسی داشته باشد
3. و **Resource Server:** سرور داده‌ها (API)
4. و **Authorization Server:** سرور صادرکننده توکن

📘 مثال واقعی:

- تو (Resource Owner)
- اپ موبایل (Client)
- Instagram API (Resource Server)
- Facebook Auth Server (Authorization Server)
