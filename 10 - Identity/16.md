پیاده سازی Two-Factor Authentication (2FA) یعنی بعد از وارد کردن رمز، مرحله‌ی دومی برای تأیید استفاده شود (مثل SMS یا Email Code یا Authenticator App).

🧩 مثال:
```csharp

var user = await _userManager.FindByNameAsync("Ali");
var is2faRequired = await _userManager.GetTwoFactorEnabledAsync(user);

var token = await _userManager.GenerateTwoFactorTokenAsync(user, "Email");
await _emailSender.SendEmailAsync(user.Email, "2FA Code", token);

```
در مرحله ورود:
```csharp

var result = await _signInManager.TwoFactorSignInAsync("Email", token, false, false);

```
📘 **مثال واقعی:**

بعد از وارد کردن رمز در Gmail، باید کد ارسال‌شده به گوشی‌ات را هم وارد کنی.
