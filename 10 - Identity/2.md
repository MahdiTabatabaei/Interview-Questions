
در واقع **Authentication** یعنی:

> فرآیند تایید اینکه کاربر همان کسی است که ادعا می‌کند.

مثلا کاربر می‌گوید من **Ali هستم** → سیستم باید بررسی کند.

---

### مکانیزم‌های Authentication

1️⃣ Username + Password

2️⃣ OTP (رمز یکبار مصرف)

3️⃣ Biometric

- اثر انگشت
- تشخیص چهره

4️⃣ Two-Factor Authentication

5️⃣ OAuth Login

مثل:

- Google Login
- Facebook Login

---

### مثال #C
```csharp

public bool Authenticate(string username, string password)
{
    if(username == "admin" && password == "1234")
        return true;

    return false;
}

```
در اینجا سیستم بررسی می‌کند آیا اطلاعات صحیح است یا نه.
