مفهوم Aggregate مجموعه‌ای از Entities و Value Objects است که:

- یک Root دارد (Aggregate Root)
- فقط از طریق Root قابل تغییر است
- قوانین این مجموعه را محافظت می‌کند (Consistency Boundary)

مثال C#:

```csharp

public class Order
{
    private List<OrderItem> _items = new();
    public void AddItem(string product, int qty) =>
        _items.Add(new OrderItem(product, qty));
}

```
