معماری SOA مجموعه‌ای از **سرویس‌های بزرگ‌تر و قابل استفاده مجدد** است که معمولاً با ESB (Enterprise Service Bus) ارتباط دارند.

خود Microservices نسخه تکامل‌یافته SOA است.


Service Oriented Architecture (SOA)

---

برای **SOA (Service Oriented Architecture)** در .NET و ویژوال استودیو، تصویر ذهنی این است که سیستم از **چند سرویس مستقل** تشکیل شده که معمولاً از طریق یک **مرکز ارتباطی (ESB یا Service Bus)** با هم صحبت می‌کنند.

---

# تصویر ذهنی ساده SOA

```
          Client Applications
      (Web / Mobile / Desktop)
                 │
                 │
           API / Service Layer
                 │
        ┌────────┴────────┐
        │     ESB / Bus   │
        │  (Service Bus)  │
        └────────┬────────┘
                 │
     ┌───────────┼────────────┐
     │           │            │
 User Service  Order Service  Payment Service
     │           │            │
    DB          DB           DB
```

---

# چیدمان معمول در Solution ویژوال استودیو

در SOA معمولاً **چند سرویس مختلف** در Solution وجود دارد و هر سرویس خودش چند لایه دارد.

```
EnterpriseSystem.sln
│
├── Gateway.API
│
├── Services
│   ├── UserService
│   │   ├── UserService.API
│   │   ├── UserService.Business
│   │   ├── UserService.Data
│   │   └── UserService.Contracts
│   │
│   ├── OrderService
│   │   ├── OrderService.API
│   │   ├── OrderService.Business
│   │   ├── OrderService.Data
│   │   └── OrderService.Contracts
│   │
│   └── PaymentService
│       ├── PaymentService.API
│       ├── PaymentService.Business
│       ├── PaymentService.Data
│       └── PaymentService.Contracts
│
└── SharedLibraries
```

---

# تصویر ذهنی لایه‌ها داخل هر سرویس

هر سرویس خودش شبیه یک **Mini Layered Architecture** است:

```
Service API
     │
Business Logic
     │
Data Access
     │
Database
```

---

# تفاوت ذهنی سریع

**Monolithic**

```
یک برنامه بزرگ
```

**SOA**

```
   چند سرویس
      │
     ESB
```

**Microservices**

```
چند سرویس کوچک
بدون ESB سنگین
```

---

خلاصه تصویر ذهنی SOA:

```
Clients
   │
Service Layer
   │
ESB / Service Bus
   │
Multiple Services
   │
Databases
```

---

اگر بخواهی می‌توانم یک **نمودار خیلی واضح از تکامل معماری‌ها** هم نشان بدهم که مسیر تاریخی این‌ها را می‌فهمی:

```
Monolithic
   ↓
Layered
   ↓
  SOA
   ↓
Microservices
```

که در معماری نرم‌افزار خیلی مهم است.
