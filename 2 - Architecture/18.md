Anemic Model:

- فقط getter/setter
- بدون رفتار
- قوانین کسب‌وکار بیرون از مدل

Domain Model:

- دارای رفتار
- قوانین داخل خود مدل
- غنی و واقعی‌تر

مثال Anemic (بد):
```csharp

public class Order { public int Qty { get; set; } }

```
مثال Domain Model (خوب):
```csharp

public class Order
{
    private int _qty;
    public void Increase(int value)
    {
        if(value <= 0) throw new Exception();
        _qty += value;
    }
}

```
