معماری Clean Architecture می‌گوید:

حرکت **Dependency باید فقط به مرکز یعنی Domain باشد.**

ساختار لایه‌ها:

- Entities (Core Domain)
- Use Cases
- Interface Adapters
- Frameworks & Drivers

مزیت:

- تست‌پذیری بالا
- استقلال از دیتابیس، UI، Framework

مثال C#:
```csharp

public class PlaceOrder : IUseCase
{
    private readonly IOrderRepository _repo;
    public PlaceOrder(IOrderRepository repo) => _repo = repo;
    public void Execute(Order order) => _repo.Add(order);
}

```
