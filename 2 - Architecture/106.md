# مفهوم High-Level یعنی چه؟

درواقع High-Level یعنی **در سطح بالا نگاه کردن**؛ یعنی روی _ایده‌ها، مفاهیم کلی، معماری و رفتار کلی_ تمرکز داشتن، نه روی جزئیات فنی یا نحوه پیاده‌سازی.

ویژگی‌ها:

- کلیات را توضیح می‌دهد
- از جزئیات ریز عبور می‌کند
- فهم و ارتباط آسان است
- بیشتر روی _What_ (چه چیزی؟) تمرکز دارد نه _How_ (چطور؟)

مثال‌ها:

- معماری سیستم (Microservices vs Monolith)
- طراحی UI با wireframe
- توضیح اینکه «کاربر ثبت‌نام می‌کند و یک ایمیل تأیید می‌گیرد»
- قرارداد API Contract بدون توضیح جزئیات دیتابیس

نمونه High-Level Code:
```markdown

sendEmailToUser(user)

```
(مهم نیست چطور ایمیل ارسال می‌شود)

# مفهوم Low-Level یعنی چه؟

درواقع Low-Level یعنی **رفتن به عمق جزئیات فنی و نحوه رفتار سیستم**.

اینجا مهم است _پیاده‌سازی دقیق چطور انجام می‌شود_.

ویژگی‌ها:

- جزئیات دقیق و تکنیکی
- تعریف رفتارها، الگوریتم‌ها، ساختار داده
- بیشتر روی _How_ تمرکز دارد
- سخت‌تر و تخصصی‌تر است

مثال‌ها:

- نحوه ذخیره‌سازی داده در دیتابیس
- پروتکل شبکه دقیق
- ساختار یک کلاس و متدهای آن
- پیاده‌سازی الگوریتم‌ها

نمونه Low-Level Code:
```markdown

smtp = SMTP('smtp.example.com')
smtp.login(username, password)
smtp.sendmail(sender, recipient, message)
smtp.quit()

```

# تفاوت High-Level و Low-Level در سه حیطه مختلف

### 1) در معماری نرم‌افزار

- High-Level: انتخاب معماری، سرویس‌ها، جریان داده، وابستگی‌ها
- Low-Level: کلاس‌ها، توابع، جداول دیتابیس، کوئری‌ها

### 2) در برنامه‌نویسی

- High-Level Code: استفاده از abstraction مثل ORM، Framework، API
- Low-Level Code: کار با memory، pointer، socket، file descriptor

### 3) در زبان‌های برنامه‌نویسی

- High-Level Languages: Python, Java, C#, JavaScriptنزدیک‌تر به انسان، دورتر از سخت‌افزار
- Low-Level Languages: C, Assemblyنزدیک به سخت‌افزار، کنترل کامل

# مثال ساده برای فهم بهتر

فرض کن می‌خواهی یک ماشین بسازی:

### High-Level توضیح:

- ماشین باید 4 چرخ داشته باشد.
- یک موتور داشته باشد.
- با بنزین کار کند.
- وقتی گاز می‌دهیم سرعت زیاد می‌شود.

### Low-Level توضیح:

- قطر چرخ‌ها چقدر باشد؟
- سیستم احتراق داخلی چطور کار کند؟
- ECU چه الگوریتمی برای تزریق سوخت اجرا می‌کند؟
- نسبت دنده گیربکس چیست؟

# خلاصه خیلی کوتاه

High-Level:

- عمومی
- مفهومی
- نزدیک به مسئله
- کمتر فنی

Low-Level:

- جزئی
- فنی
- نزدیک به ماشین
- دقیق و عملیاتی
