در Event Sourcing به جای ذخیره **وضعیت نهایی**، همه **Eventها** ذخیره می‌شوند.

به جای:
```markdown

Order:
Status = Paid

```
ما ذخیره می‌کنیم:
```markdown

OrderCreated
OrderPaid
OrderShipped

```
و وضعیت با **بازپخش eventها** ساخته می‌شود.

### مثال #C#

```csharp

public void Apply(OrderCreated evt)
{
    Id = evt.OrderId;
}

public void Apply(OrderPaid evt)
{
    Status = "Paid";
}

```
