مصرف‌کننده‌ای که اگر یک پیام **چند بار** مصرف شد، فقط یک بار اثر بگذارد.

### مثال C#

مثلاً در Outbox، اگر رویداد دوباره رسید:
```csharp

if (_db.ProcessedMessages.Any(m => m.MessageId == msg.Id))
    return; // دوباره پردازش نکن

// پردازش اصلی
ProcessOrder(msg);

_db.ProcessedMessages.Add(msg.Id);
_db.SaveChanges();

```
