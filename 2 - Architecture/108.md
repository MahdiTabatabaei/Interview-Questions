# روش ساده و رایج (IEnumerable)

فرض کنید این Interface را داریم:
```csharp

public interface IHandler
{
    Task HandleAsync(Context context);
}

```
چند implementation:
```csharp

public class HandlerA : IHandler
{
    public Task HandleAsync(Context context)
    {
        // logic A
    }
}

public class HandlerB : IHandler
{
    public Task HandleAsync(Context context)
    {
        // logic B
    }
}
```
ثبت در DI
```csharp

services.AddTransient<IHandler, HandlerA>();
services.AddTransient<IHandler, HandlerB>();
services.AddTransient<IHandler, HandlerC>();

```
---

### استفاده
```csharp

public class Processor
{
    private readonly IEnumerable<IHandler> _handlers;

    public Processor(IEnumerable<IHandler> handlers)
    {
        _handlers = handlers;
    }

    public async Task Execute(Context context)
    {
        foreach (var handler in _handlers)
        {
            await handler.HandleAsync(context);
        }
    }
}

```
✅ در DI تمام handlerها را inject می‌کند.

---

# ترتیب اجرا

ترتیب همان **ترتیب registration در DI** است.
```csharp

services.AddTransient<IHandler, HandlerA>();
services.AddTransient<IHandler, HandlerB>();

```
---

# اگر ترتیب مهم باشد (Pipeline Pattern)

می‌توان Order اضافه کرد.
```csharp

public interface IHandler
{
    int Order { get; }
    Task HandleAsync(Context context);
}

```
استفاده:
```csharp

foreach (var handler in _handlers.OrderBy(x => x.Order))
{
    await handler.HandleAsync(context);
}

```
---

# روش پیشرفته‌تر (Chain of Responsibility)

گاهی handlerها تصمیم می‌گیرند ادامه دهند یا نه.
```csharp

public interface IHandler
{
    Task<bool> HandleAsync(Context context);
}

```

```csharp

foreach (var handler in _handlers)
{
    var handled = await handler.HandleAsync(context);

    if (handled)
        break;
}

```

---
پاسخ کوتاه مناسب 

**چند Handler برای یک Interface داریم و می‌خواهیم همه اجرا شوند.**

پاسخ:

> در ASP.NET Core می‌توان چند implementation برای یک interface در DI ثبت کرد. سپس با inject کردن `IEnumerable<IHandler>` تمام handlerها دریافت می‌شوند و می‌توان روی آن‌ها iterate کرد و اجراشان کرد. ترتیب اجرا نیز همان ترتیب registration در DI است.
