معنای **On‑prem** مخفف **On‑Premises** است.

یعنی:

> سیستم‌ها و سرورها داخل دیتاسنتر یا ساختمان خودِ سازمان نصب و مدیریت می‌شوند، نه روی Cloud عمومی.

خیلی ساده 👇

- ✅ **On‑prem** = سرورها توی شرکت خودت هستند  
- ✅ **Cloud** = سرورها توی دیتاسنتر AWS / Azure / Google هستند

مثال:

اگر Kubernetes را روی سرورهای داخل شرکتت نصب کرده‌ای → این می‌شود **On‑prem**  
اگر روی Azure AKS یا AWS EKS اجرا می‌کنی → این می‌شود **Cloud**

خلاصه:  
معنای **On‑prem یعنی زیرساخت داخل محل سازمان، نه روی سرویس ابری.**
