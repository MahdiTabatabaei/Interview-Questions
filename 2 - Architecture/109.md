چند راه برای این طراحی وجود دارد، اما پاسخ خوب معمولاً یکی از **Strategy Pattern + DI** یا **Factory Pattern** است. هدف این است که از `if/else` یا `switch` بزرگ جلوگیری کنیم.

---

# روش تمیز: Strategy Pattern

فرض کنید نوع درخواست متفاوت است:
```markdown

OnlinePayment
CashPayment
CryptoPayment

```
1️⃣ تعریف Interface
```csharp

public interface IPaymentStrategy
{
    bool CanHandle(PaymentRequest request);
    Task ProcessAsync(PaymentRequest request);
}

```
---

## 2️⃣ پیاده‌سازی‌ها
```csharp

public class OnlinePaymentStrategy : IPaymentStrategy
{
    public bool CanHandle(PaymentRequest request)
        => request.Type == PaymentType.Online;

    public Task ProcessAsync(PaymentRequest request)
    {
        // online logic
    }
}

```

```csharp

public class CashPaymentStrategy : IPaymentStrategy
{
    public bool CanHandle(PaymentRequest request)
        => request.Type == PaymentType.Cash;

    public Task ProcessAsync(PaymentRequest request)
    {
        // cash logic
    }
}

```
---

## 3️⃣ ثبت در DI
```csharp

services.AddTransient<IPaymentStrategy, OnlinePaymentStrategy>();
services.AddTransient<IPaymentStrategy, CashPaymentStrategy>();

```

---

## 4️⃣ سرویس اصلی
```csharp

public class PaymentService
{
    private readonly IEnumerable<IPaymentStrategy> _strategies;

    public PaymentService(IEnumerable<IPaymentStrategy> strategies)
    {
        _strategies = strategies;
    }

    public async Task Process(PaymentRequest request)
    {
        var strategy = _strategies.First(x => x.CanHandle(request));

        await strategy.ProcessAsync(request);
    }
}

```
---

# مزایا

- اصول Open/Closed Principle رعایت می‌شود
- اضافه کردن نوع جدید بدون تغییر کد قبلی
- تست راحت‌تر
- حذف `switch` یا `if` بزرگ
---

# پاسخ کوتاه 


> معمولاً از Strategy Pattern استفاده می‌کنم. برای هر نوع رفتار یک implementation از یک interface تعریف می‌کنم، همه آن‌ها را در DI ثبت می‌کنم و سپس در سرویس اصلی `IEnumerable<IStrategy>` را inject می‌کنم. بر اساس نوع request، strategy مناسب انتخاب و اجرا می‌شود. این کار باعث کاهش coupling و رعایت Open/Closed Principle می‌شود.
