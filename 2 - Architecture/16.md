Entity:

- شناسه دارد
- تغییرپذیر است
- هویت مهم‌تر از مقدار است

Value Object:

- بدون شناسه
- ویژگی [[196 | Immutable]]
- مقدار معیار تشخیص است

مثال C#:
```csharp

// Value Object
public record Money(decimal Amount, string Currency);

// Entity
public class Customer
{
    public Guid Id { get; init; }
    public string Name { get; set; }
}

```
