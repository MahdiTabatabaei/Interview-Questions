معماری نرم‌افزار **ساختار کلی سیستم** است؛ یعنی تصمیمات سطح بالا درباره اینکه اجزای یک سیستم چه هستند، چگونه با هم تعامل می‌کنند، و چه محدودیت‌ها و استانداردهایی باید رعایت شود.

معماری شامل این موارد است:

- ساختار کلی سیستم
- اجزاء اصلی (Modules, Services, Layers)
- نحوه تعامل اجزا
- تصمیمات سخت‌تغییر (Non‑Functional Requirements) مثل Performance، Scalability، Security

مثال دنیای واقعی:

معماری = نقشه مهندسی ساختمان

کد = اجرای آجر به آجر
