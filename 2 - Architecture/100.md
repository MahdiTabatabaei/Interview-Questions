وقتی یک سرویس خراب می‌شود، سیستم **با قابلیت کمتر ولی قابل استفاده** باقی می‌ماند.

مثال فروشگاه آنلاین:

اگر recommendation service خراب شود:
```markdown

site still works
but no recommendations

```

مثال C#
```csharp

try
{
    var rec = await recommendationService.GetProducts();
}
catch
{
    rec = new List<Product>();
}

```
