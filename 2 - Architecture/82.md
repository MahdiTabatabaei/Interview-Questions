در واقع Rate Limiting تعداد درخواست‌های مجاز در یک بازه زمانی را محدود می‌کند.

مثال:
```markdown

100 request per minute

```
### الگوریتم‌های رایج

1. Token Bucket
2. Leaky Bucket
3. Fixed Window
4. Sliding Window

### مثال C# ASP.NET 
```csharp

builder.Services.AddRateLimiter(options =>
{
    options.AddFixedWindowLimiter("api", opt =>
    {
        opt.PermitLimit = 100;
        opt.Window = TimeSpan.FromMinutes(1);
    });
});

```
