رویکرد Event Storming یک ورکشاپ گروهی برای **کشف دامنه، Bounded Contextها و جریان رویدادها** است.

مراحل کار:

1. ابتدا**Domain Events را پیدا می‌کنیم.**مثل: OrderPlaced، PaymentCompleted، CartEmptied
2. سپس **Command ها را تعیین می‌کنیم.**“PlaceOrder” → منجر به “OrderPlaced”
3. بعد **Actors (کاربر/سیستم)** را مشخص می‌کنیم.
4. و **Aggregates** را شناسایی می‌کنیم.
5. و همچنین **Policy ها** را تعریف می‌کنیم (اگر این Event رخ داد، آن Command اجرا شود).
6. در نهایت **Bounded Context ها** به‌وضوح از دل جریان رویدادها بیرون می‌آیند.

مثال تصویری ساده:

OrderPlaced → triggers → SendEmailCommand → EmailSent

مثال دنیای واقعی:

در یک فروشگاه، اتفاقاتی مثل “کالا به سبد اضافه شد” هدف اصلی ما هستند.
