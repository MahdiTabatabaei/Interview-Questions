یک شناسه که یک request را در تمام سرویس‌ها دنبال می‌کند.

مثال:
```markdown

X-Correlation-ID

```
مثال C#
```csharp

var correlationId = Guid.NewGuid().ToString();
httpClient.DefaultRequestHeaders.Add("X-Correlation-ID", correlationId);

```
در log:
```markdown

[CorrelationId:123]
Order created

```
