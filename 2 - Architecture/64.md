CQRS = Command Query Responsibility Segregation

جدا کردن:
```markdown

Write Model
Read Model

```
معماری
```markdown

Client
  |
Command API
  |
Write Model
  |
Event Store
  |
Projection
  |
Read Database

```
### مزایا

- دارای performance بالا
- قابلیت read scaling
- مدل ساده‌تر برای read

### چالش‌ها

- حالت eventual consistency
- پیچیدگی بیشتر
- نیاز به sync event
