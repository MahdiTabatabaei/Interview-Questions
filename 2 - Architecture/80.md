### JWT

یک **token format** است.

ساختار:
```markdown

header.payload.signature

```
مثال payload:
```markdown

userId
roles
expiration

```
### OAuth2

یک **authorization framework** است.

مراحل:
```markdown

client
authorization server
resource server

```
در OAuth2 اغلب از **JWT به عنوان access token** استفاده می‌کند.
