### Authentication

پاسخ به سوال:

```markdown
تو کی هستی؟

```
مثال:

- login
- JWT validation

### Authorization

پاسخ به سوال:

### Authentication vs Authorization در API

این دو مفهوم پشت سر هم استفاده می‌شوند اما وظیفه متفاوت دارند.

## تعریف Authentication (احراز هویت)

معنای Authentication یعنی **مشخص کردن اینکه کاربر چه کسی است**.

سیستم بررسی می‌کند که درخواست واقعاً از طرف یک کاربر معتبر آمده است یا نه.  
معمولاً با این روش‌ها انجام می‌شود:

- Username / Password
- JWT Token
- API Key
- OAuth

یعنی پاسخ به سؤال:  
**"کاربر کیست؟"**

### مثال C# (ASP.NET Core – JWT Authentication)

ابتدا احراز هویت را در برنامه فعال می‌کنیم:

```csharp
builder.Services.AddAuthentication("Bearer")
    .AddJwtBearer("Bearer", options =>
    {
        options.Authority = "https://authserver.com";
        options.Audience = "myapi";
    });
```

در Controller:

```csharp
[Authorize]
[HttpGet("profile")]
public IActionResult GetProfile()
{
    return Ok("User authenticated");
}
```

اگر توکن معتبر باشد → کاربر **Authenticated** است.

---

## تعریف Authorization (مجوز دسترسی)

معنای Authorization یعنی **مشخص کردن اینکه کاربر چه کاری اجازه دارد انجام دهد**.

یعنی پاسخ به سؤال:  
**"کاربر چه دسترسی‌هایی دارد؟"**

مثال:
- شخص Admin می‌تواند کاربر حذف کند
- و User معمولی نمی‌تواند

### مثال C# (Role-based Authorization)

```csharp
[Authorize(Roles = "Admin")]
[HttpDelete("users/{id}")]
public IActionResult DeleteUser(int id)
{
    return Ok("User deleted");
}
```

در اینجا:

- اگر کاربر **Admin** باشد → دسترسی دارد  
- اگر نباشد → خطای **403 Forbidden**

---

## تفاوت اصلی

- **Authentication:** تشخیص هویت کاربر (Who are you?)
- **Authorization:** تعیین سطح دسترسی کاربر (What can you do?)

---

## ترتیب در API

1. اول **Authentication** انجام می‌شود (بررسی هویت)
2. اگر موفق بود → **Authorization** بررسی می‌شود (بررسی دسترسی)

مثال واقعی:

- کاربر با **JWT Token** وارد API می‌شود → Authentication  
- و API بررسی می‌کند آیا Role او **Admin** است → Authorization.
### مثال #C#

```csharp

[Authorize(Roles = "Admin")]
public IActionResult DeleteUser()
{
    return Ok();
}

```
