Architecture:

- تصمیمات کلان سطح بالا
- ساختار کل سیستم
- تعیین لایه‌ها، سرویس‌ها، ارتباطات، تکنولوژی‌ها
- تغییرش هزینه‌بر است

Design Pattern:

- الگوهای تکرارپذیر برای حل مشکلات کوچک‌تر در سطح کد
- تصمیمات سطح پایین
- بسیار قابل جایگزینی

مثال:

- Architecture = Clean Architecture
- Design Pattern = Repository Pattern, Strategy, Singleton
