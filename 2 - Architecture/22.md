ابزار API Gateway یک نقطه ورودی واحد برای همه درخواست‌های کلاینت به سیستم Microservices است.

وظایف:

- Routing
- Aggregation
- Authentication
- Rate Limiting
- Caching
- Logging

مزایا:

- کاهش پیچیدگی برای کلاینت
- امنیت و کنترل مرکزی
- پنهان کردن ساختار داخلی سرویس‌ها

مثال واقعی:

مثل یک **گیشه‌ مرکزی** در بانک که شما را به بخش‌های مختلف هدایت می‌کند.
