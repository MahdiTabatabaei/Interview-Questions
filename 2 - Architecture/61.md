در سیستم‌های Messaging این دو مفهوم شبیه‌اند ولی هدف متفاوتی دارند.

### Message

یک **درخواست یا دستور** است که برای انجام کاری ارسال می‌شود.

مثال:
```markdown

CreateOrder
SendEmail
ProcessPayment

```
یعنی فرستنده انتظار دارد **گیرنده کاری انجام دهد**.

### Event

یک **اتفاقی است که قبلاً رخ داده** و فقط اطلاع‌رسانی می‌کند.

مثال:
```markdown

OrderCreated
PaymentCompleted
EmailSent

```
هیچکس مجبور نیست واکنش نشان دهد.

### تفاوت اصلی

Message → command

Event → notification

### مثال #C#
```csharp

public class CreateOrderCommand
{
    public Guid UserId { get; set; }
}

```
Event:
```csharp

public class OrderCreatedEvent
{
    public Guid OrderId { get; set; }
}

```
