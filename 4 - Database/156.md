**توابع اگریگیت (Aggregate Functions)** در SQL توابعی هستند که بر روی مجموعه‌ای از مقادیر (یک ستون از چندین سطر) محاسباتی انجام می‌دهند و در نهایت **فقط یک مقدار واحد** را به عنوان نتیجه برمی‌گردانند.

این توابع معمولاً برای گزارش‌گیری و خلاصه کردن داده‌ها استفاده می‌شوند.

### ۵ تابع اصلی Aggregate

#### ۱. `()COUNT`

تعداد سطرها یا مقادیر غیر NULL را می‌شمارد.

- **مثال:** تعداد کل محصولات چقدر است؟
```sql

SELECT COUNT(*) AS TotalProducts FROM Products;
-- خروجی: 5

```
#### ۲. `()SUM`

مجموع مقادیر یک ستون عددی را محاسبه می‌کند.

- **مثال:** مجموع قیمت تمام محصولات موجود در انبار چقدر است؟
```sql

SELECT SUM(Price) AS TotalPrice FROM Products;
-- خروجی: 1720

```
#### ۳. `()AVG`

میانگین مقادیر یک ستون عددی را محاسبه می‌کند.

- **مثال:** میانگین قیمت محصولات چقدر است؟
```sql

SELECT AVG(Price) AS AveragePrice FROM Products;
-- خروجی: 344

```
#### ۴. `()MIN`

کمترین مقدار را در یک ستون پیدا می‌کند.

- **مثال:** ارزان‌ترین محصول چه قیمتی دارد؟
```sql

SELECT MIN(Price) AS CheapestPrice FROM Products;
-- خروجی: 25

```
#### ۵. `()MAX`

بیشترین مقدار را در یک ستون پیدا می‌کند.

- **مثال:** گران‌ترین محصول چه قیمتی دارد؟
```sql

SELECT MAX(Price) AS MostExpensive FROM Products;
-- خروجی: 1200

```

### استفاده ترکیبی با `GROUP BY`

توابع اگریگیت زمانی بسیار قدرتمند می‌شوند که با دستور `GROUP BY` ترکیب شوند. این کار باعث می‌شود محاسبات **به تفکیک گروه‌ها** انجام شود.

- **مثال:** میانگین قیمت محصولات **در هر دسته‌بندی** چقدر است؟
```sql

SELECT Category, AVG(Price) AS AvgPrice
FROM Products
GROUP BY Category;

```

### فیلتر کردن نتایج با `HAVING`

اگر بخواهید روی نتیجه یک تابع اگریگیت فیلتر بگذارید، نمی‌توانید از `WHERE` استفاده کنید؛ باید از `HAVING` استفاده کنید.

- **مثال:** دسته‌بندی‌هایی را نشان بده که مجموع موجودی (Stock) آن‌ها بیشتر از ۱۰ عدد است:
```sql

SELECT Category, SUM(Stock) AS TotalStock
FROM Products
GROUP BY Category
HAVING SUM(Stock) > 10;

```

---
### نکات مهم:

1. **مقادیر NULL:** توابع اگریگیت (به جز `COUNT(*)`) معمولاً مقادیر `NULL` را نادیده می‌گیرند و در محاسبات دخالت نمی‌دهند.
2. تابع **DISTINCT:** می‌توانید داخل این توابع از کلمه کلیدی `DISTINCT` استفاده کنید تا فقط مقادیر غیرتکراری محاسبه شوند.

- مثال: `SELECT COUNT(DISTINCT Category) FROM Products;` (تعداد دسته‌بندی‌های منحصربه‌فرد را برمی‌گرداند).
