قابلیت Window Functionها به شما اجازه می‌دهند **بدون گروه‌بندی داده‌ها** بتوانید محاسبات ردیف به ردیف انجام دهید، اما هم‌زمان بتوانید روی کل مجموعه داده دسترسی داشته باشید.

کاربردها:

- محاسبه رتبه‌بندی (Ranking)
- محاسبه مجموع تجمعی (Running Total)
- میانگین (Moving Average)
- مقایسه ردیف فعلی با ردیف قبلی یا بعدی
- ایجاد شماره ردیف بدون حذف جزئیات هر ردیف

مثال:
```sql

SELECT 
    EmployeeID,
    Salary,
    SUM(Salary) OVER(ORDER BY EmployeeID) AS RunningSalary
FROM Employees;

```

مثال واقعی:

مثل اینکه در فهرست حقوق کارکنان، همزمان حقوق هر نفر و مجموع حقوق تا آن لحظه را ببینی.

---

ساختار کلی **Window Function** در SQL Server به این شکل است:

```sql
function_name (expression)
OVER (
    [PARTITION BY column_list]
    [ORDER BY column_list]
)
```

### اجزای اصلی

**1. function_name**  
تابعی که روی داده‌ها اجرا می‌شود. مثل:
- `ROW_NUMBER()`
- `RANK()`
- `SUM()`
- `AVG()`
- `LAG()`
- `LEAD()`

**2. OVER**  
کلمه کلیدی که مشخص می‌کند تابع به صورت **Window (روی مجموعه‌ای از ردیف‌ها)** اجرا شود.

**3. PARTITION BY (اختیاری)**  
داده‌ها را به **گروه‌های جدا** تقسیم می‌کند.  
شبیه `GROUP BY` است ولی ردیف‌ها حذف نمی‌شوند.

**4. ORDER BY (اختیاری ولی برای بعضی توابع لازم)**  
ترتیب ردیف‌ها در هر پنجره را مشخص می‌کند.

---

### مثال 1: شماره‌گذاری ردیف‌ها

```sql
SELECT 
    Name,
    ROW_NUMBER() OVER (ORDER BY Salary DESC) AS RowNum
FROM Employees;
```

به هر ردیف یک شماره بر اساس حقوق می‌دهد.

---

### مثال 2: استفاده از PARTITION

```sql
SELECT 
    DepartmentId,
    Name,
    ROW_NUMBER() OVER (PARTITION BY DepartmentId ORDER BY Salary DESC) AS RowNum
FROM Employees;
```

در هر **دپارتمان جداگانه** شماره‌گذاری انجام می‌شود.

---

### مثال 3: محاسبه مجموع در هر گروه

```sql
SELECT 
    DepartmentId,
    Salary,
    SUM(Salary) OVER (PARTITION BY DepartmentId) AS TotalSalary
FROM Employees;
```

مجموع حقوق هر دپارتمان را در کنار هر ردیف نشان می‌دهد بدون اینکه ردیف‌ها گروه‌بندی شوند.

---

### ساختار کامل‌تر (با Window Frame)

گاهی بخش دیگری هم اضافه می‌شود:

```sql
function_name(expression)
OVER (
    PARTITION BY column
    ORDER BY column
    ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
)
```

این بخش تعیین می‌کند **پنجره دقیقاً شامل کدام ردیف‌ها باشد**.

---

یک مثال ساده:

فرض کنید جدول **Employees** داریم:

| Id | Name | Department | Salary |
|----|------|------------|--------|
|1|Ali|IT|5000|
|2|Sara|IT|6000|
|3|Reza|HR|4000|
|4|Mina|HR|4500|

می‌خواهیم **حقوق هر کارمند و مجموع حقوق دپارتمانش** را کنار هم ببینیم.

```sql
SELECT 
    Name,
    Department,
    Salary,
    SUM(Salary) OVER (PARTITION BY Department) AS TotalDepartmentSalary
FROM Employees;
```

خروجی:

| Name | Department | Salary | TotalDepartmentSalary |
|-----|-----------|-------|-----------------------|
|Ali|IT|5000|11000|
|Sara|IT|6000|11000|
|Reza|HR|4000|8500|
|Mina|HR|4500|8500|

توضیح:  
درواقع `PARTITION BY Department` باعث می‌شود مجموع حقوق **برای هر دپارتمان جداگانه** محاسبه شود، ولی برخلاف `GROUP BY` ردیف‌ها حذف نمی‌شوند و اطلاعات هر کارمند همچنان نمایش داده می‌شود.
