[[Bottleneck]]
مراحل:

1. بررسی CPU → اگر بالاست، Queryهای سنگین
2. بررسی Memory → اگر کم است، Page Life Expectancy پایین خواهد بود
3. بررسی I/O → اگر Latency بالا باشد، دیسک مقصر است
4. بررسی Wait Stats → نشان می‌دهد گلوگاه چیست
    - CXPACKET = parallelism
    - PAGEIOLATCH = disk
    - LCK_M_X = locking
    - SOS_SCHEDULER_YIELD = CPU
