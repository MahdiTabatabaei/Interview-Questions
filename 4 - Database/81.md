در واقع **Hash Join** یکی از روش‌های ترکیب (Join) بین دو جدول در Query Execution Plan است.

**کارکرد ساده:**

در SQL Server یکی از جداول (Table کوچک‌تر معمولاً) را به‌صورت **Hash Table** در حافظه می‌سازد.

سپس جدول بزرگ‌تر را می‌خواند و هر رکورد را بر اساس کلید Join در آن Hash Table جست‌وجو می‌کند.

**مناسب برای:**

وقتی هر دو جدول بزرگ هستند و ایندکس مناسبی ندارند.

**مثال SQL:**
```sql

SELECT *
FROM Orders o
JOIN Customers c ON o.CustomerID = c.CustomerID

```
اگر هیچ ایندکسی روی `CustomerID` وجود نداشته باشد، SQL Server احتمالاً **Hash Join** را انتخاب می‌کند.

**مثال از زندگی:**

فرض کن لیست مشتریان داری، و لیست سفارشات.

لیست کوچکتر (مشتریان) را مرور می‌کنی و شماره‌ملی هر مشتری را در دفتر یادداشت می‌کنی (Hash Table).

حالا سفارشات را نگاه می‌کنی، هر سفارش را با دفترت چک می‌کنی.
