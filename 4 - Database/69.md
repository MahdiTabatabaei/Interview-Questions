ابزار SQL Server برای `OR` باید هر دو شرط را بررسی کند.

اگر روی یکی از ستون‌ها Index نباشد، کل Query به اسکن تبدیل می‌شود.

مثال
```sql

WHERE Name = 'Ali' OR City = 'Tehran'

```
اگر فقط روی City Index باشد → Seek برای City، Scan برای Name

در نهایت Plan ممکن است تبدیل به **Scan کامل** شود.

مثل اینکه بگویی:
