خیر. در `UNION` نمی‌توان ستون‌های نابرابر داشت.

برای استفاده از `UNION` باید چند شرط رعایت شود:

- **تعداد ستون‌ها در هر دو Query برابر باشد**
- **ترتیب ستون‌ها یکسان باشد**
- **نوع داده ستون‌های متناظر سازگار (Compatible) باشد**

مثال صحیح:
```sql

SELECT Id, Name
FROM Users

UNION

SELECT Id, Name
FROM Customers

```
هر دو Query **۲ ستون** دارند.

---

### مثال نادرست (ستون‌ها نابرابر)
```sql

SELECT Id, Name
FROM Users

UNION

SELECT Id, Name, Age
FROM Customers

```
اینجا خطا رخ می‌دهد چون:

- Query اول → 2 ستون
- Query دوم → 3 ستون

---

### راه‌حل

باید تعداد ستون‌ها را برابر کنید، مثلاً با `NULL`:
```sql

SELECT Id, Name, NULL AS Age
FROM Users

UNION

SELECT Id, Name, Age
FROM Customers

```
---

✅ خلاصه:

در `UNION` تعداد ستون‌ها باید **برابر** باشد، اما **نام ستون‌ها لازم نیست یکسان باشد**؛ فقط **ترتیب و نوع داده باید سازگار باشند**.
