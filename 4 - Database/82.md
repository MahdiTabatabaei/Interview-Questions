روش  **Merge Join** زمانی استفاده می‌شود که **هر دو ورودی مرتب** (Sorted) بر اساس ستون Join باشند.

**کارکرد:**

به‌صورت دو لیست مرتب جلو می‌رویم — هر ردیف را با دیگری مقایسه می‌کنیم و فقط در صورت مساوی بودن، در خروجی می‌نویسیم.

**خیلی سریع است** چون sort انجام شده است.

**پیش‌شرط:**

هر دو ورودی باید **Sorted** باشند (مثلاً از روی ایندکس Clustered).

**مثال SQL:**
```sql

SELECT * 
FROM Orders o
JOIN Customers c ON o.CustomerID = c.CustomerID

```

اگر هر دو جدول روی `CustomerID` Clustered Index داشته باشند، SQL Server از **Merge Join** استفاده می‌کند.

**مثال از زندگی:**

دو دفتر داری: یکی لیست مشتری‌ها، یکی لیست سفارشات.

هر دو بر اساس کد مشتری مرتب هستند.

با دو انگشت در هر دو دفتر جلو می‌روی و وقتی کد یکی شد، تطبیق می‌دهی. خیلی سریع.
