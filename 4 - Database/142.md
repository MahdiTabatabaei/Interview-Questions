MongoDB:

- Document Database
- داده‌ها به شکل JSON
- schema flexible
- مناسب اپلیکیشن‌ها

مثال:
```markdown

{
 name: "Ali",
 age: 25
}

```

Cassandra:

- Wide Column Database
- طراحی شده برای **Big Data**
- بسیار scalable
- مناسب سیستم‌های distributed

مثال استفاده:

MongoDB:

- CMS
- اپلیکیشن وب

Cassandra:

- Netflix
- Uber
- Apple

خلاصه:

MongoDB → flexible

Cassandra → massively scalable
