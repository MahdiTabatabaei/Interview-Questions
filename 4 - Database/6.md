هر دو برای **حذف تکراری‌ها** استفاده می‌شوند، اما هدف و کاربردشان متفاوت است.

## DISTINCT
برای **نمایش مقادیر یکتای یک یا چند ستون** استفاده می‌شود.

مثال:

```sql
SELECT DISTINCT city
FROM customers;
```

اگر در جدول چند مشتری از یک شهر باشند، `DISTINCT` باعث می‌شود هر شهر فقط **یک بار** نمایش داده شود.

ویژگی مهم:
- فقط **تکراری‌ها را حذف می‌کند**.
- معمولاً همراه با **توابع تجمعی استفاده نمی‌شود**.

---

## GROUP BY
برای **گروه‌بندی داده‌ها** استفاده می‌شود، معمولاً همراه با **توابع تجمعی** مثل:

- `COUNT`
- `SUM`
- `AVG`
- `MAX`
- `MIN`

مثال:

```sql
SELECT city, COUNT(*) AS total_customers
FROM customers
GROUP BY city;
```

اینجا داده‌ها بر اساس `city` گروه‌بندی می‌شوند و تعداد مشتری‌های هر شهر محاسبه می‌شود.

---

## تفاوت اصلی

- `DISTINCT` → فقط **حذف مقادیر تکراری**
- `GROUP BY` → **گروه‌بندی داده‌ها برای انجام محاسبات**

---

## مثال مقایسه‌ای

### با DISTINCT
```sql
SELECT DISTINCT city
FROM customers;
```

خروجی:
```
Tehran
Shiraz
Tabriz
```

### با GROUP BY
```sql
SELECT city, COUNT(*)
FROM customers
GROUP BY city;
```

خروجی:
```
Tehran   5
Shiraz   3
Tabriz   2
```

---

نکته جالب:  
اگر فقط یک ستون را بدون تابع تجمعی بنویسید، نتیجهٔ `GROUP BY` تقریباً شبیه `DISTINCT` می‌شود:

```sql
SELECT city
FROM customers
GROUP BY city;
```

اما **هدف واقعی GROUP BY انجام aggregation است**.
