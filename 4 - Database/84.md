تعریف [[Statistics]] یعنی اطلاعات خلاصه‌ای از نحوه‌ی توزیع داده‌ها در ستون‌ها (چند مقدار متفاوت داریم، هر مقدار چند بار تکرار شده و …).


در SQL Server از Statistics استفاده می‌کند تا حدس بزند Query چند ردیف برمی‌گرداند و چه Planی بهتر است.

**اگر [[Statistics]] قدیمی باشند:** Plan اشتباه ساخته می‌شود → Query کند می‌شود.

**مثال واقعی:**

فرض کن فروشگاهت لیست مشتریان سال ۱۴۰۰ را دارد.

اگر با همان اطلاعات بخواهی تصمیم سال ۱۴۰۲ بگیری، پیش‌بینی‌هایت دقیق نیست چون «آمار» قدیمی شده است.
