SARG = Search ARGument

درواقع Queryهایی که SQL Server بتواند با **Index Seek** آن‌ها را اجرا کند.

ویژگی‌ها:

- از توابع روی ستون‌ها استفاده نشده باشد
- و LIKE شروع‌بنیاد باشد (‘abc%’)
- عملیات محاسباتی روی ستون نباشد
- مقایسه مستقیم باشد (=, >, <, BETWEEN, IN)

مثال

SARGable:
```markdown

WHERE Age > 30

```
Non-SARGable:
```markdown

WHERE Age + 1 > 30

```
