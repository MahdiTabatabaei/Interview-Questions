تفاوت Index در **PostgreSQL** و **SQL Server** بیشتر در **انواع ایندکس، نحوه مدیریت و قابلیت‌ها** است. از نظر مفهوم کلی هر دو برای **سریع‌تر کردن جستجو** استفاده می‌شوند، اما امکاناتشان متفاوت است.

---

# 1️⃣ نوع ایندکس پیش‌فرض

### SQL Server
ایندکس پیش‌فرض:

- **B-Tree**

دو نوع اصلی دارد:

- **Clustered Index**
- **Non‑Clustered Index**

در SQL Server معمولاً هر جدول:

- فقط **یک Clustered Index**
- چندین **Non‑Clustered Index**

---

### PostgreSQL

ایندکس پیش‌فرض هم:

- **B‑Tree**

اما PostgreSQL **انواع بیشتری از Index** دارد.

---

# 2️⃣ انواع Index

### SQL Server

انواع مهم:

- Clustered Index
- Non‑Clustered Index
- Columnstore Index
- Filtered Index
- XML Index
- Spatial Index
- Full‑Text Index

---

### PostgreSQL

ابزار PostgreSQL انواع بیشتری دارد:

- **B‑Tree**
- **Hash**
- **GIN**
- **GiST**
- **BRIN**
- **SP‑GiST**

مثال:

```sql
CREATE INDEX idx_data
ON documents
USING GIN (content);
```

این برای **جستجوی متن یا JSON** بسیار سریع است.

---

# 3️⃣ Expression Index

ابزار PostgreSQL در این زمینه بسیار قوی است.

مثال:

```sql
CREATE INDEX idx_lower_email
ON users (LOWER(email));
```

این یعنی روی **نتیجه یک expression** ایندکس ساخته می‌شود.

در SQL Server معمولاً باید:

- **Computed Column** بسازی
- بعد روی آن index بزنی.

---

# 4️⃣ Partial Index vs Filtered Index

### PostgreSQL

**Partial Index**

```sql
CREATE INDEX idx_active_users
ON users (email)
WHERE active = true;
```

---

### SQL Server

مشابه آن:

**Filtered Index**

```sql
CREATE INDEX idx_active_users
ON users(email)
WHERE active = 1;
```

هر دو مشابه هستند.

---

# 5️⃣ Clustered Index

### SQL Server

مفهوم بسیار مهم:

- داده‌ها **فیزیکی مرتب** می‌شوند.

یعنی:

```
Table = Clustered Index
```

---

### PostgreSQL

در PostgreSQL:

- جدول **به طور پیش‌فرض heap** است.
- ایندکس‌ها جدا هستند.

اگر بخواهی مرتب شود باید:

```
CLUSTER
```

استفاده کنی.

---

# 6️⃣ Index Maintenance

### SQL Server

دارای ابزارهای قوی:

- Index Rebuild
- Index Reorganize
- Fragmentation monitoring

---

### PostgreSQL

از این‌ها استفاده می‌کند:

- `VACUUM`
- `ANALYZE`
- `REINDEX`

به خاطر **MVCC** نیاز به Vacuum دارد.

---

# 7️⃣ JSON Indexing

ابزار PostgreSQL برای JSON بسیار قوی است.

مثال:

```sql
CREATE INDEX idx_json
ON products
USING GIN (data);
```

برای JSONB بسیار سریع است.

در SQL Server JSON وجود دارد ولی **Indexing آن محدودتر است**.

---

# خلاصه تفاوت اصلی

| ویژگی | SQL Server | PostgreSQL |
|------|------------|------------|
| Clustered Index | دارد و مهم است | به‌صورت پیش‌فرض ندارد |
| انواع Index | کمتر | بسیار بیشتر |
| JSON Index | محدودتر | بسیار قوی |
| Expression Index | غیرمستقیم | مستقیم |
| Maintenance | Rebuild / Reorganize | Vacuum / Analyze |
| ساختار جدول | Clustered | Heap |

---

✅ **خلاصه **

ابزار SQL Server بیشتر روی **Clustered / Non‑Clustered Index** تمرکز دارد،  
اما PostgreSQL **انواع Index بیشتری** مثل **GIN, GiST, BRIN** دارد و برای **JSON و Full‑Text و داده‌های پیچیده قوی‌تر است**.
