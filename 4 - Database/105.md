دستور MERGE اجازه می‌دهد در یک دستور:

- INSERT
- UPDATE
- DELETE

را همزمان روی دو مجموعه داده انجام دهی.

مثال:
```sql

MERGE Target AS T
USING Source AS S
ON T.ID = S.ID
WHEN MATCHED THEN UPDATE SET ...
WHEN NOT MATCHED THEN INSERT ...

```
مثال واقعی:

مثل این است که فهرست مشتریان قدیمی را با لیست جدید مقایسه کنی و بگویی:

- اگر وجود دارد → بروزش کن
- اگر نیست → اضافه کن
- اگر حذف شده → پاک کن
