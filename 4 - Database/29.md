تعریف **Stored Procedure** مجموعه‌ای از دستورات SQL است که به صورت **از پیش کامپایل شده** در دیتابیس ذخیره می‌شود.

- **قابلیت‌ها:**
- می‌تواند پارامتر ورودی و خروجی داشته باشد.
- می‌تواند منطق پیچیده، شرط‌ها (IF/ELSE)، حلقه‌ها (WHILE)، تراکنش‌ها را اجرا کند.
- چندین دستور SQL را در یک واحد اجرا می‌کند.
- **مزایا:**
- **کاهش ترافیک شبکه:** دستورات در سرور اجرا می‌شوند.
- **افزایش امنیت:** دسترسی به دیتابیس را می‌توان به Stored Procedure محدود کرد.
- **افزایش کارایی:** چون از پیش کامپایل شده است.
- **قابلیت استفاده مجدد:** یک بار نوشته شده و بارها فراخوانی می‌شود.

**مثال:**

یک Stored Procedure برای “پردازش سفارش”:

1. بررسی موجودی کالا.
2. کاهش موجودی.
3. ایجاد رکورد در جدول سفارشات.
4. اگر موجودی کم بود، یک ایمیل هشدار ارسال شود.
