تفاوت اصلی در **نحوهٔ اتصال سطرها** است.

## INNER JOIN
فقط سطرهایی را برمی‌گرداند که **شرط اتصال (ON)** بین دو جدول برقرار باشد.

مثال:

```sql
SELECT c.name, o.order_id
FROM customers c
INNER JOIN orders o
ON c.id = o.customer_id;
```

نتیجه:
- فقط مشتری‌هایی نمایش داده می‌شوند که **سفارش دارند**.
- اتصال بر اساس شرط `ON` انجام می‌شود.

---

## CROSS JOIN
تمام سطرهای دو جدول را با هم **ترکیب ضربی (Cartesian Product)** می‌کند و **هیچ شرطی ندارد**.

مثال:

```sql
SELECT c.name, p.product_name
FROM customers c
CROSS JOIN products p;
```

نتیجه:
- هر مشتری با **تمام محصولات** ترکیب می‌شود.

اگر:
- 10 مشتری داشته باشیم
- 5 محصول داشته باشیم

خروجی:

```
10 × 5 = 50 rows
```

---

## تفاوت اصلی

- **INNER JOIN**
  - شرط اتصال دارد (`ON`)
  - فقط رکوردهای مرتبط را برمی‌گرداند

- **CROSS JOIN**
  - شرط ندارد
  - تمام ترکیب‌های ممکن از دو جدول را می‌سازد

---

✅ مثال ساده:

Table A  
```
1
2
```

Table B  
```
X
Y
```

**CROSS JOIN**

```
1 X
1 Y
2 X
2 Y
```

اما **INNER JOIN** فقط رکوردهایی را می‌دهد که شرطشان برقرار باشد.
