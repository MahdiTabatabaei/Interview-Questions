درواقع CTE که خودش را صدا می‌زند و برای ساخت **ساختارهای سلسله‌مراتبی** استفاده می‌شود.

مثال:

درخت مدیران و کارمندان.
```sql

WITH c AS (
   SELECT EmpID, ManagerID FROM Emp WHERE ManagerID IS NULL
   UNION ALL
   SELECT e.EmpID, e.ManagerID FROM Emp e JOIN c ON e.ManagerID = c.EmpID
)
SELECT * FROM c;

```
