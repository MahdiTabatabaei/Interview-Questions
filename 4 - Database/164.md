تعیین نوع قفل در پایگاه داده معمولاً **به‌صورت خودکار توسط سیستم مدیریت پایگاه داده (DBMS)** انجام می‌شود. یعنی برنامه‌نویس معمولاً مستقیماً نوع قفل را تعیین نمی‌کند؛ بلکه **نوع عملیات، سطح ایزولیشن و ساختار Query** باعث می‌شود دیتابیس تصمیم بگیرد چه قفلی اعمال کند.

در واقع دیتابیس با توجه به چند عامل نوع قفل را انتخاب می‌کند.

---

## 1. نوع عملیات (Operation)

مهم‌ترین عامل، **نوع دستوری است که اجرا می‌شود**.

- `SELECT` → معمولاً **Shared Lock**
- `UPDATE` → **Exclusive Lock**
- `DELETE` → **Exclusive Lock**
- `INSERT` → **Exclusive Lock**

مثال:
```sql

SELECT * FROM Users

```
دیتابیس برای خواندن داده‌ها **Shared Lock** می‌گیرد.

اما:
```sql

UPDATE Users
SET Name = 'Ali'
WHERE Id = 1

```
دیتابیس **Exclusive Lock** می‌گیرد چون داده تغییر می‌کند.

---

## 2. سطح ایزولیشن (Isolation Level)

سطح ایزولیشن تعیین می‌کند **قفل‌ها چقدر سخت‌گیرانه باشند و چه مدت نگه داشته شوند**.

مثلاً:

- `READ COMMITTED` → قفل خواندن سریع آزاد می‌شود
- `REPEATABLE READ` → قفل تا پایان تراکنش نگه داشته می‌شود
- `SERIALIZABLE` → قفل‌های بیشتری گرفته می‌شود

مثال:
```sql

SET TRANSACTION ISOLATION LEVEL SERIALIZABLE

```
در این حالت دیتابیس قفل‌های شدیدتری اعمال می‌کند.

---

## 3. محدوده داده (Granularity)

دیتابیس تصمیم می‌گیرد قفل روی چه سطحی اعمال شود:

- **Row Lock** → یک ردیف
- **Page Lock** → یک صفحه داده
- **Table Lock** → کل جدول

مثلاً اگر تعداد زیادی ردیف تغییر کند، دیتابیس ممکن است **قفل را از Row به Table ارتقا دهد**.

این فرآیند را می‌گویند:

**Lock Escalation**

---

## 4. استفاده از Hint ها در Query

برنامه‌نویس می‌تواند در بعضی موارد **به صورت دستی نوع قفل را پیشنهاد دهد**.

مثال در SQL Server:
```sql

SELECT * FROM Users WITH (NOLOCK)

```
این دستور باعث می‌شود **Shared Lock گرفته نشود** و حتی داده‌های Commit نشده هم خوانده شوند.

یا:
```sql

SELECT * FROM Users WITH (UPDLOCK)

```
این Hint باعث می‌شود **Update Lock** گرفته شود.

---

## جمع‌بندی

نوع قفل در دیتابیس معمولاً بر اساس این عوامل تعیین می‌شود:

1. نوع دستور SQL (SELECT / UPDATE / DELETE / INSERT)
2. سطح ایزولیشن تراکنش
3. اندازه داده و سطح قفل (Row / Page / Table)
4. استفاده از Hintهای مشخص شده در Query

در حالت عادی **DBMS خودش بهترین نوع قفل را انتخاب می‌کند** و برنامه‌نویس فقط در شرایط خاص آن را کنترل می‌کند.
