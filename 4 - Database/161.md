درواقع **Table Type** در SQL Server یک **نوع داده سفارشی (User-Defined Table Type)** است که به شما اجازه می‌دهد **یک جدول را به عنوان پارامتر به Stored Procedure یا Function ارسال کنید**.

به زبان ساده:

به جای ارسال **یک مقدار** مثل `int` یا `varchar`، می‌توانید **چندین ردیف داده (یک جدول کامل)** را به یک procedure بدهید.

---

## چرا Table Type استفاده می‌شود؟

گاهی لازم است **چندین رکورد را یک‌جا به دیتابیس ارسال کنیم**.

بدون Table Type معمولاً مجبور می‌شویم:

- چندین بار Stored Procedure را صدا بزنیم
- یا داده‌ها را به صورت رشته (مثلاً CSV) ارسال کنیم

اما با **Table Type** می‌توانیم **چند ردیف را یک‌جا ارسال کنیم**.

---

# مثال

## 1️⃣ ساخت Table Type
```sql

CREATE TYPE ProductTableType AS TABLE
(
    Id INT,
    Name NVARCHAR(100),
    Price DECIMAL(10,2)
);

```
اینجا یک نوع داده جدید ساختیم که شبیه یک جدول است.

---

## 2️⃣ استفاده در Stored Procedure
```sql

CREATE PROCEDURE InsertProducts
    @Products ProductTableType READONLY
AS
BEGIN
    INSERT INTO Products (Id, Name, Price)
    SELECT Id, Name, Price
    FROM @Products
END
```

نکته مهم:

پارامتر Table Type باید **READONLY** باشد.

---

## 3️⃣ ارسال داده به Procedure

```sql

DECLARE @ProductList ProductTableType;

INSERT INTO @ProductList
VALUES (1,'Laptop',2000),
       (2,'Phone',1000),
       (3,'Tablet',800);

EXEC InsertProducts @ProductList;

```

در اینجا **چند ردیف داده را یکجا ارسال کردیم**.

---

# مزایای Table Type

- ارسال **چندین رکورد به صورت یکجا**
- کاهش تعداد **Round Trip** بین برنامه و دیتابیس
- کد **تمیزتر و خواناتر**
- عملکرد بهتر نسبت به ارسال داده به صورت رشته

---

# کاربردهای رایج

Table Type معمولاً در این موارد استفاده می‌شود:

- **Bulk Insert از برنامه**
- ارسال لیست آیتم‌ها
- ذخیره لیست سفارش‌ها
- ارسال چند ID برای فیلتر

مثال واقعی:
```markdown

لیست محصولات یک سفارش
لیست کاربران
لیست شناسه‌ها

```
