درواقع `JOIN` و `SUBQUERY` هر دو برای استفاده از داده‌های چند جدول به کار می‌روند، اما روش کارشان متفاوت است.

## JOIN
درواقع `JOIN` چند جدول را **مستقیماً به هم متصل می‌کند** و یک نتیجهٔ ترکیبی می‌سازد.

مثال:

```sql
SELECT c.name, o.order_id
FROM customers c
JOIN orders o ON c.id = o.customer_id;
```

اینجا:
- جدول `customers` و `orders` به هم وصل می‌شوند.
- خروجی شامل ستون‌هایی از **هر دو جدول** است.

ویژگی‌ها:
- معمولاً **سریع‌تر** است.
- برای نمایش داده از چند جدول خیلی رایج است.
- انواع مختلف دارد: `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, `FULL JOIN`.

---

## SUBQUERY
تعریف `SUBQUERY` یک **کوئری داخل کوئری دیگر** است که نتیجه‌اش به کوئری اصلی داده می‌شود.

مثال:

```sql
SELECT name
FROM customers
WHERE id IN (
    SELECT customer_id
    FROM orders
);
```

اینجا:
- ابتدا Subquery اجرا می‌شود.
- نتیجهٔ آن به کوئری اصلی داده می‌شود.

ویژگی‌ها:
- خوانایی بعضی مواقع بهتر است.
- می‌تواند در `SELECT`, `WHERE`, `FROM` استفاده شود.
- گاهی نسبت به `JOIN` **کندتر** است.

---

## تفاوت اصلی

- کلمهٔ کلیدی`JOIN` → **ترکیب جدول‌ها**  
- ساختار یا عبارت`SUBQUERY` → **استفاده از نتیجهٔ یک کوئری داخل کوئری دیگر**

---

## مثال مقایسه‌ای

### با JOIN

```sql
SELECT c.name
FROM customers c
JOIN orders o ON c.id = o.customer_id;
```

### با SUBQUERY

```sql
SELECT name
FROM customers
WHERE id IN (
    SELECT customer_id
    FROM orders
);
```

هر دو مشتری‌هایی را نشان می‌دهند که سفارش دارند، اما روش انجام کار متفاوت است.

---

✅ در عمل:
- برای **کار با چند جدول و گزارش‌گیری** → معمولاً `JOIN` بهتر است.  
- برای **فیلتر کردن بر اساس نتیجهٔ یک کوئری دیگر** → `SUBQUERY` مناسب است.
