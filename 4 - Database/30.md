تعریف **View** یک جدول مجازی است که بر اساس نتیجه یک Query SQL ساخته می‌شود.

- **قابلیت‌ها:**
- داده واقعی را ذخیره نمی‌کند، بلکه یک Query ذخیره شده است.
- می‌تواند شامل داده‌های ترکیب شده از چند جدول باشد.
- می‌تواند ستون‌های انتخاب شده را فیلتر کند.
- **مزایا:**
- **سادگی:** پیچیدگی Queryها را مخفی می‌کند.
- **امنیت:** دسترسی به داده‌های خاص را محدود می‌کند.
- **سازگاری:** اگر ساختار جداول پایه تغییر کند، می‌توان View را طوری تغییر داد که Queryهای اصلی دست نخورده باقی بمانند.
- **معایب:**
- گاهی اوقات ممکن است کندتر از Query مستقیم باشد.
- قابلیت Update کردن آن محدود است.

**مثال:**

یک View به نام `ActiveCustomers` که فقط مشتریان فعال را از جدول `Customers` نشان می‌دهد:

`CREATE VIEW ActiveCustomers AS SELECT CustomerID, Name, Email FROM Customers WHERE IsActive = 1;`
