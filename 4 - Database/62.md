ابزار SQL Server دارای **Query Optimizer** است که:

1. ابتدا Query را تحلیل می‌کند
2. و Planهای مختلف را تولید می‌کند
3. بر اساس هزینه (Cost) بهترین Plan را انتخاب می‌کند
4. و Plan را Cache می‌کند
5. دفعه بعد همان Plan را استفاده می‌کند

مثال

مثل اینکه مسیریابی Google Maps چند مسیر را مقایسه می‌کند و بهترین را انتخاب می‌کند.
