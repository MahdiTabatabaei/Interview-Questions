درواقع `NEWSEQUENTIALID` یک تابع در **SQL Server** است که برای تولید **GUID (شناسه یکتای جهانی)** استفاده می‌شود، اما برخلاف `NEWID()`، مقادیر را به صورت **ترتیبی (sequential)** تولید می‌کند.

### تعریف

درواقع `NEWSEQUENTIALID()` تابعی است که **GUIDهای افزایشی و مرتب** ایجاد می‌کند تا کارایی ایندکس‌ها در جدول‌هایی که از ستون `uniqueidentifier` استفاده می‌کنند بهتر شود.

### نحوه استفاده

این تابع فقط می‌تواند به عنوان **مقدار پیش‌فرض (DEFAULT)** برای یک ستون استفاده شود.

مثال:

```sql
CREATE TABLE Users (
    Id uniqueidentifier DEFAULT NEWSEQUENTIALID() PRIMARY KEY,
    Name NVARCHAR(100)
);
```

وقتی رکورد جدید درج شود، SQL Server به طور خودکار یک GUID ترتیبی تولید می‌کند.

### تفاوت با `NEWID()`

- تابع `NEWID()`
  - مقدار GUID کاملاً تصادفی تولید می‌کند.
  - باعث **fragmentation زیاد در ایندکس‌ها** می‌شود.

- تابع `NEWSEQUENTIALID()`
  - مقدار GUIDها تقریباً **به صورت افزایشی** تولید می‌شوند.
  - باعث **fragmentation کمتر** و عملکرد بهتر در ایندکس‌های clustered دارد.

### مزایا

- کاهش fragmentation در ایندکس‌ها  
- بهبود سرعت درج داده‌ها در جدول‌های بزرگ  
- مناسب برای ستون‌های `PRIMARY KEY` از نوع GUID

### محدودیت

- فقط در **DEFAULT constraint** قابل استفاده است و نمی‌توان آن را مستقیم در `SELECT` یا `INSERT` فراخوانی کرد.
