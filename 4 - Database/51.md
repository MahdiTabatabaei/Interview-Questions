**Shared Lock (S)**

برای خواندن (SELECT)

دیگران هم می‌توانند S Lock بگیرند

اما نمی‌توانند بنویسند

**Exclusive Lock (X)**

برای نوشتن (INSERT/UPDATE/DELETE)

هیچ خواننده یا نویسنده دیگری اجازه ندارد

مثال

در Shared Lock = چند نفر یک کتاب را همزمان می‌خوانند

در Exclusive Lock = یک نفر کتاب را برداشته و اجازه نمی‌دهد کسی نزدیک شود

----

در SQL Server قفل‌ها تعیین می‌کنند چه کسی می‌تواند **بخواند** یا **بنویسد**. دو قفل پایه‌ای:

- **Shared Lock (S)**
- **Exclusive Lock (X)**

---

# تعریف Shared Lock چیست؟

وقتی یک کوئری **SELECT** اجرا می‌شود، معمولاً SQL Server روی داده‌ها **Shared Lock** می‌گیرد.

ویژگی‌ها:

- چندین تراکنش می‌توانند همزمان **Shared Lock** داشته باشند.
- یعنی چند نفر می‌توانند همزمان **بخوانند**.
- اما وقتی Shared Lock وجود دارد، **نوشتن (UPDATE / DELETE / INSERT)** روی همان داده ممکن نیست.

### مثال

```
SELECT *
FROM Customers
WHERE CustomerID = 1
```

در این حالت SQL Server روی آن ردیف **Shared Lock** می‌گیرد.

اگر همزمان یک کوئری دیگر هم اجرا شود:

```
SELECT *
FROM Customers
WHERE CustomerID = 1
```

مشکلی نیست. هر دو می‌توانند بخوانند.

اما اگر همزمان این اجرا شود:

```
UPDATE Customers
SET Name = 'Ali'
WHERE CustomerID = 1
```

این دستور باید **صبر کند** تا Shared Lock آزاد شود.

---

# تعریف Exclusive Lock چیست؟

وقتی داده **تغییر می‌کند**، SQL Server **Exclusive Lock** می‌گیرد.

ویژگی‌ها:

- فقط **یک تراکنش** می‌تواند Exclusive Lock داشته باشد.
- وقتی X Lock وجود دارد:
  - هیچ **SELECT**
  - هیچ **UPDATE**
  - هیچ **DELETE**

نمی‌تواند روی آن داده اجرا شود.

### مثال

```
UPDATE Customers
SET Name = 'Ali'
WHERE CustomerID = 1
```

SQL Server روی این ردیف **Exclusive Lock** می‌گیرد.

حالا اگر همزمان اجرا شود:

```
SELECT *
FROM Customers
WHERE CustomerID = 1
```

این کوئری **منتظر می‌ماند** تا UPDATE تمام شود.

---

# تفاوت اصلی

| ویژگی | Shared Lock | Exclusive Lock |
|------|-------------|---------------|
| برای چه عملیاتی | خواندن | نوشتن |
| چند تراکنش همزمان | بله | خیر |
| اجازه SELECT دیگر | بله | خیر |
| اجازه UPDATE | خیر | خیر |

---

# مثال واقعی Blocking

فرض کن این اجرا شود:

### Session 1

```
BEGIN TRAN

UPDATE Products
SET Price = 200
WHERE ID = 10
```

اینجا **Exclusive Lock** گرفته می‌شود.

---

### Session 2

```
SELECT *
FROM Products
WHERE ID = 10
```

این کوئری **منتظر می‌ماند** چون X Lock وجود دارد.

---

# خلاصه خیلی کوتاه

- **Shared Lock** → فقط خواندن، چند نفر همزمان می‌توانند داشته باشند.  
- **Exclusive Lock** → برای تغییر داده، فقط یک نفر می‌تواند داشته باشد.
