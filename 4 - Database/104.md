## تعریف Temp Table چیست؟

درواقع **Temp Table** یک جدول موقت در SQL Server است که برای نگهداری موقت داده‌ها در طول اجرای یک **Session یا Stored Procedure** استفاده می‌شود. این جدول در دیتابیس **tempdb** ساخته می‌شود.

ساختار:

```sql
CREATE TABLE #TempEmployees
(
    ID INT,
    Name NVARCHAR(50)
)
```

یا

```sql
SELECT *
INTO #TempEmployees
FROM Employees
```

ویژگی‌ها:
- در **tempdb** ذخیره می‌شود
- تا پایان **Session** یا **Connection** باقی می‌ماند
- می‌توان روی آن **Index** ایجاد کرد
- برای حجم داده زیاد مناسب است

---

## تعریف Table Variable چیست؟

درواقع **Table Variable** یک متغیر از نوع جدول است که برای نگهداری داده موقت در داخل یک **Batch / Procedure / Function** استفاده می‌شود.

ساختار:

```sql
DECLARE @Employees TABLE
(
    ID INT,
    Name NVARCHAR(50)
)
```

استفاده:

```sql
INSERT INTO @Employees
VALUES (1,'Ali')
```

ویژگی‌ها:
- دامنه آن محدود به **Batch یا Procedure** است
- معمولاً برای **حجم داده کم** استفاده می‌شود
- در بسیاری موارد آمار (Statistics) ندارد

---

# تفاوت Temp Table و Table Variable

### 1️⃣ محل ذخیره
هر دو در **tempdb** ذخیره می‌شوند، ولی:

- Temp Table بیشتر شبیه جدول واقعی مدیریت می‌شود
- Table Variable سبک‌تر مدیریت می‌شود

---

### 2️⃣ حجم داده

Table Variable → مناسب برای داده کم  
Temp Table → مناسب برای داده زیاد

---

### 3️⃣ Statistics

Temp Table → Statistics دارد  
Table Variable → معمولاً Statistics ندارد

به همین دلیل **Execution Plan برای Temp Table بهتر است**.

---

### 4️⃣ Index

Temp Table:

```sql
CREATE INDEX IX_Test ON #TempEmployees(ID)
```

Table Variable:

فقط هنگام تعریف می‌توان Index ساخت:

```sql
DECLARE @Employees TABLE
(
    ID INT PRIMARY KEY,
    Name NVARCHAR(50)
)
```

---

### 5️⃣ Scope

Temp Table:

- در کل **Session** قابل دسترسی است
- حتی در **Stored Procedureهای داخلی** هم قابل استفاده است

Table Variable:

- فقط در همان **Batch / Procedure** قابل استفاده است

---

✅ **خلاصه مهم**

| ویژگی | Temp Table | Table Variable |
|------|-------------|---------------|
| محل ذخیره | tempdb | tempdb |
| حجم داده مناسب | زیاد | کم |
| Statistics | دارد | معمولاً ندارد |
| Performance | بهتر برای داده زیاد | بهتر برای داده کم |
| Scope | Session | Batch / Procedure |

---

✅ **قانونی که اکثر DBAها استفاده می‌کنند**

- اگر داده **کم (مثلاً کمتر از چند صد یا هزار رکورد)** → `Table Variable`
- اگر داده **زیاد یا Query پیچیده** → `Temp Table`
