درواقع **CTE (Common Table Expression)** یک **result set موقت** است که داخل یک کوئری تعریف می‌شود و فقط در همان کوئری قابل استفاده است. هدفش این است که **کوئری‌ها خواناتر و قابل مدیریت‌تر شوند**.

ساختار کلی:

```sql
WITH CTE_Name AS
(
    SELECT ...
)
SELECT *
FROM CTE_Name;
```

---

## کاربردهای اصلی CTE

### 1️⃣ ساده کردن Queryهای پیچیده
وقتی یک Query خیلی بزرگ باشد، می‌توان آن را به چند بخش تقسیم کرد.

```sql
WITH HighSalaryEmployees AS
(
    SELECT *
    FROM Employees
    WHERE Salary > 5000
)
SELECT Name, Salary
FROM HighSalaryEmployees;
```

---

### 2️⃣ جایگزین Subquery
به‌جای نوشتن Subqueryهای پیچیده، می‌توان از CTE استفاده کرد.

بدون CTE:

```sql
SELECT *
FROM (
    SELECT CustomerID, COUNT(*) OrderCount
    FROM Orders
    GROUP BY CustomerID
) t
WHERE OrderCount > 5;
```

با CTE:

```sql
WITH CustomerOrders AS
(
    SELECT CustomerID, COUNT(*) AS OrderCount
    FROM Orders
    GROUP BY CustomerID
)
SELECT *
FROM CustomerOrders
WHERE OrderCount > 5;
```

خواناتر و قابل فهم‌تر است.

---

### 3️⃣ استفاده چندباره از یک Result
می‌توان یک Result را چند بار در همان Query استفاده کرد.

---

### 4️⃣ Recursive Queries (کاربرد بسیار مهم)
CTE برای **ساختارهای سلسله‌مراتبی** استفاده می‌شود مثل:

- درخت سازمانی
- Category tree
- Parent / Child data

مثال:

```sql
WITH EmployeeHierarchy AS
(
    SELECT EmployeeID, ManagerID, Name
    FROM Employees
    WHERE ManagerID IS NULL

    UNION ALL

    SELECT e.EmployeeID, e.ManagerID, e.Name
    FROM Employees e
    JOIN EmployeeHierarchy eh
        ON e.ManagerID = eh.EmployeeID
)
SELECT *
FROM EmployeeHierarchy;
```

این کوئری کل **سلسله‌مراتب کارمندان** را برمی‌گرداند.

---

✅ **خلاصه**

کاربردهای مهم CTE:

- ساده کردن Queryهای پیچیده
- جایگزین Subquery
- خواناتر شدن کد SQL
- انجام **Recursive Query**
- کار با داده‌های سلسله‌مراتبی
