درواقع `SELF JOIN` حالتی از `JOIN` است که در آن **یک جدول با خودش Join می‌شود**.

یعنی همان جدول را **دو بار با نام مستعار (alias)** در کوئری استفاده می‌کنیم تا بتوانیم رکوردهای آن را با رکوردهای دیگر همان جدول مقایسه کنیم.

## مثال
فرض کنید جدول `employees` داریم:

```
id | name   | manager_id
1  | Ali    | NULL
2  | Sara   | 1
3  | Reza   | 1
4  | Mina   | 2
```

می‌خواهیم نام کارمند و مدیرش را ببینیم.

```sql
SELECT e.name AS employee, m.name AS manager
FROM employees e
LEFT JOIN employees m
ON e.manager_id = m.id;
```

اینجا:
- `employees e` → جدول کارمندان
- `employees m` → همان جدول ولی به عنوان مدیران

پس جدول با **خودش Join شده است**.

خروجی مثال:

```
employee | manager
Ali      | NULL
Sara     | Ali
Reza     | Ali
Mina     | Sara
```

## نکته مهم
در `SELF JOIN` حتماً باید از **Alias** استفاده کنیم، وگرنه دیتابیس نمی‌تواند تشخیص دهد کدام ستون مربوط به کدام نسخهٔ جدول است.

## خلاصه
- `SELF JOIN` یعنی **اتصال یک جدول به خودش**
- برای نمایش **روابط درون همان جدول** استفاده می‌شود (مثل کارمند و مدیر، دسته‌بندی‌های درختی، و …).
