مثال:

حقوق‌ها: 10000, 9000, 9000, 8000

**RANK:**

1, 2, 2, 4

**DENSE_RANK:**

1, 2, 2, 3

مثال زندگی:

برای RANK مثل مسابقه دو است: اگر دو نفر دوم شوند، نفر بعدی چهارم است.

برای DENSE_RANK مثل نمره مدرسه است: دو نفر اول شوند، بعدی دوم است نه سوم.

---
### تعریف RANK

درواقع `RANK()` یک **Window Function** است که به هر ردیف بر اساس ترتیب مشخص‌شده یک **رتبه (Rank)** می‌دهد. اگر چند ردیف مقدار مساوی داشته باشند، **رتبه یکسان می‌گیرند** و در رتبه‌های بعدی **پرش ایجاد می‌شود**.

سینتکس:
```sql
RANK() OVER (ORDER BY column)
```

---

### تعریف DENSE_RANK

درواقع `DENSE_RANK()` هم رتبه‌بندی انجام می‌دهد، اما اگر چند مقدار مساوی باشند **رتبه بعدی حذف نمی‌شود** و رتبه‌ها **پیوسته** باقی می‌مانند.

سینتکس:
```sql
DENSE_RANK() OVER (ORDER BY column)
```

---

### مثال

جدول Employees:

| Name | Salary |
|-----|-------|
|Ali|7000|
|Sara|6000|
|Reza|6000|
|Mina|5000|

کوئری:

```sql
SELECT 
    Name,
    Salary,
    RANK() OVER (ORDER BY Salary DESC) AS RankValue,
    DENSE_RANK() OVER (ORDER BY Salary DESC) AS DenseRankValue
FROM Employees;
```

خروجی:

|Name|Salary|RANK|DENSE_RANK|
|----|------|----|----------|
|Ali|7000|1|1|
|Sara|6000|2|2|
|Reza|6000|2|2|
|Mina|5000|4|3|

---

### تفاوت اصلی
- در **RANK:** اگر رتبه تکراری باشد، **شماره بعدی پرش می‌کند**.  
- در **DENSE_RANK:** رتبه‌ها **بدون پرش** ادامه پیدا می‌کنند.
---

چند کاربرد رایج `RANK` و `DENSE_RANK` با مثال ساده:

---

## 1. رتبه‌بندی کارمندان بر اساس حقوق

می‌خواهیم ببینیم هر کارمند چندمین حقوق بالاتر را دارد.

```sql
SELECT 
    Name,
    Salary,
    RANK() OVER (ORDER BY Salary DESC) AS RankSalary
FROM Employees;
```

مثال خروجی:

|Name|Salary|Rank|
|---|---|---|
|Ali|7000|1|
|Sara|6000|2|
|Reza|6000|2|
|Mina|5000|4|

کاربرد: گزارش رتبه حقوق کارمندان.

---

## 2. پیدا کردن 3 حقوق بالاتر شرکت

در اینجا `DENSE_RANK` بهتر است چون رتبه‌ها حذف نمی‌شوند.

```sql
WITH T AS (
SELECT 
    Name,
    Salary,
    DENSE_RANK() OVER (ORDER BY Salary DESC) AS r
FROM Employees
)
SELECT *
FROM T
WHERE r <= 3;
```

کاربرد: پیدا کردن **Top N** (مثلاً ۳ فروشنده برتر).

---

## 3. پیدا کردن بهترین کارمند هر دپارتمان

با `PARTITION BY` رتبه‌بندی داخل هر گروه انجام می‌شود.

```sql
SELECT *
FROM (
    SELECT 
        Name,
        Department,
        Salary,
        RANK() OVER (
            PARTITION BY Department 
            ORDER BY Salary DESC
        ) AS r
    FROM Employees
) t
WHERE r = 1;
```

کاربرد:  
- بهترین فروشنده هر شهر  
- بیشترین نمره هر کلاس  
- بالاترین حقوق هر دپارتمان

---

## 4. رتبه‌بندی فروش محصولات
فرض کنید جدول فروش داریم:

```sql
SELECT 
    ProductName,
    TotalSales,
    DENSE_RANK() OVER (ORDER BY TotalSales DESC) AS SalesRank
FROM Products;
```

کاربرد: مشخص کردن **پرفروش‌ترین محصولات**.
