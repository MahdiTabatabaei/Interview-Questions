راه‌حل‌های کلی برای رفع این مشکل:

1. **OPTION (RECOMPILE)** → هر بار Plan جدید ساخته می‌شود.
2. **استفاده از Local Variable در SP** (جلوگیری از sniffing مستقیم).
3. **OPTIMIZE FOR UNKNOWN** → Plan عمومی می‌سازد.
4. **OPTIMIZE FOR specific value** → به SQL Server می‌گوییم برای چه مقداری Plan بسازد.
5. **بهبود Index و Statistics** تا Plan پایدار شود.
6. **تقسیم SPها** برای سناریوهای مختلف داده.
