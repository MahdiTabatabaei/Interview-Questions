برای بررسی عملکرد SQL Server باید ۴ بخش را چک کنیم:

1. بررسی Query

- Execution Plan
- Duration, Reads, CPU
- Missing Indexes
- Parameter Sniffing

2. بررسی Server

- CPU usage
- Memory grants
- Disk I/O latency
- Wait statistics

3. بررسی Locks & Blocking

- استفاده از DMVs`sys.dm_exec_requests`, `sys.dm_tran_locks`, `sys.dm_os_waiting_tasks`

4. بررسی Storage

- Fragmentation
- File growth
- TempDB pressure

مثال واقعی

مثل بررسی کندی یک خودرو: موتور (CPU)، فشار باد چرخ‌ها (Disk)، کیفیت بنزین (Query Plan)، وزن بار (Memory).
