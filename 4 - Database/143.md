هر دو **in-memory cache** هستند.

Redis:

- دیتاستراکت‌های پیچیده
- persistence دارد
- replication دارد
- pub/sub دارد

پشتیبانی از:

- List
- Set
- Hash
- Sorted Set

Memcached:

- ساده‌تر
- فقط key-value
- سریع ولی امکانات کمتر

مثال:

Redis:
```markdown

user:1 -> {name:Ali}

```
Memcached:
```markdown

user1 -> "Ali"

```
خلاصه:

Memcached → ساده و سریع

Redis → قدرتمندتر
