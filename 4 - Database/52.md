نوعی قفل بین Shared و Exclusive.

زمانی استفاده می‌شود که SQL Server مطمئن نیست نیاز به Update دارد یا نه، ولی می‌خواهد جلوی Deadlock را بگیرد.

مزیت:

Shared Lockها را بلاک نمی‌کند

ولی چند Update همزمان را هم اجازه نمی‌دهد
