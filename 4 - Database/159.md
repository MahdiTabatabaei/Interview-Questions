کلمه کلیدی**PIVOT** برای **تبدیل ردیف‌ها (Rows) به ستون‌ها (Columns)** استفاده می‌شود.

معمولاً وقتی کاربرد دارد که بخواهیم **داده‌ها را به شکل گزارش یا جدول خلاصه‌شده نمایش دهیم**.

به زبان ساده:

>درواقع PIVOT داده‌های عمودی را به **ساختار افقی** تبدیل می‌کند.

---

## مثال ساده

فرض کنید جدول فروش داریم:

### Sales
![[17_Product_Month_Amount.png]]
این جدول **ماه‌ها را به صورت ردیف** دارد.

---

## استفاده از PIVOT

می‌خواهیم **ماه‌ها ستون شوند**.
```sql

SELECT *
FROM
(
    SELECT Product, Month, Amount
    FROM Sales
) AS SourceTable
PIVOT
(
    SUM(Amount)
    FOR Month IN ([Jan], [Feb], [Mar])
) AS PivotTable;

```
نتیجه
![[18_Product_Jan_Feb_Mar.png]]

حالا داده‌ها برای **گزارش‌گیری خواناتر** شده‌اند.

---

## اجزای PIVOT

در دستور بالا سه بخش مهم داریم:

1️⃣ **تابع تجمیعی (Aggregate Function)**

مثل:
```markdown

SUM()
AVG()
COUNT()

```
چون ممکن است چند مقدار برای یک خانه وجود داشته باشد.

---

2️⃣ **ستونی که قرار است تبدیل به ستون شود**

```markdown

FOR Month

```
---

3️⃣ **مقادیر ستون جدید**
```markdown

IN ([Jan], [Feb], [Mar])

```
یعنی این مقادیر تبدیل به ستون می‌شوند.

---

# تابع UNPIVOT چیست؟

درواقع **UNPIVOT دقیقاً برعکس PIVOT است.**

یعنی:

> ستون‌ها را تبدیل به **ردیف‌ها** می‌کند.

به بیان ساده:

- **PIVOT:** Rows → Columns
- **UNPIVOT:** Columns → Rows

---

## مثال

فرض کنید این جدول را داریم:
![[19_Product_UNPIVOT.png]]
می‌خواهیم دوباره آن را به حالت قبلی تبدیل کنیم.

---

## استفاده از UNPIVOT
```sql

SELECT Product, Month, Amount
FROM SalesPivot
UNPIVOT
(
    Amount FOR Month IN (Jan, Feb, Mar)
) AS UnpivotTable;

```

# کاربردهای واقعی PIVOT
معمولاً در **گزارش‌گیری و تحلیل داده** استفاده می‌شود:

- گزارش فروش ماهانه
- گزارش حضور و غیاب
- گزارش درآمد سالانه
- گزارش امتیاز کاربران
- داشبوردهای مدیریتی

مثال واقعی:
```markdown

کارمند | فروردین | اردیبهشت | خرداد

```
