چون Query را **Non-SARGable** می‌کند.

و SQL Server مجبور می‌شود اسکن انجام دهد.

مثال بد:
```markdown

WHERE YEAR(OrderDate) = 2024

```
بهینه:
```markdown

WHERE OrderDate >= '2024-01-01' AND OrderDate < '2025-01-01'

```
مثال واقعی

مثل اینکه به جای پرسیدن “ماشینی که پلاکش 11 داره” بپرسی “کدوم ماشین‌ها پلاکشون دو رقمیه و یکی از رقم‌ها 1 هست؟” → جستجو سخت‌تر می‌شود.
