این دستورات در SQL برای **ترکیب یا مقایسه نتایج چند Query** استفاده می‌شوند. به آن‌ها معمولاً **Set Operators** گفته می‌شود.

سه دستور مهم: **UNION ، INTERSECT ، MINUS (یا EXCEPT)**

ابتدا یک مثال ساده در نظر بگیریم.

### جدول Students
```markdown

ID | Name
1  | Ali
2  | Sara
3  | Reza
4  | Mina

```

جدول Graduates
```markdown

ID | Name
2  | Sara
3  | Reza
5  | Nima

```

---
# 1. UNION

دستور **UNION** نتایج دو Query را **با هم ترکیب می‌کند** و **مقادیر تکراری را حذف می‌کند**.

### مثال
```sql

SELECT Name FROM Students
UNION
SELECT Name FROM Graduates;

```
نتیجه
```markdown

Ali
Sara
Reza
Mina
Nima

```
ویژگی مهم:

- رکوردهای تکراری حذف می‌شوند.

اگر بخواهیم تکراری‌ها حذف نشوند از **UNION ALL** استفاده می‌کنیم:
```sql

SELECT Name FROM Students
UNION ALL
SELECT Name FROM Graduates;

```
---

# 2. INTERSECT

دستور **INTERSECT** فقط رکوردهایی را برمی‌گرداند که **در هر دو Query مشترک باشند**.

### مثال
```sql

SELECT Name FROM Students
INTERSECT
SELECT Name FROM Graduates;

```
نتیجه
```markdown

Sara
Reza

```
یعنی کسانی که هم در Students هستند هم در Graduates.

---

# 3. MINUS (یا EXCEPT)

دستور **MINUS** رکوردهایی را برمی‌گرداند که در **Query اول هستند اما در Query دوم نیستند**.

در بعضی دیتابیس‌ها مثل SQL Server اسم آن **EXCEPT** است.

### مثال

```sql

SELECT Name FROM Students
MINUS
SELECT Name FROM Graduates;

```
نتیجه

```markdown

Ali
Mina

```
یعنی دانشجوهایی که فارغ‌التحصیل نشده‌اند.

در SQL Server:
```sql

SELECT Name FROM Students
EXCEPT
SELECT Name FROM Graduates;

```
---

# تفاوت خیلی خلاصه

UNION

ترکیب دو نتیجه (بدون تکراری)

INTERSECT

اشتراک دو نتیجه

MINUS / EXCEPT

موارد موجود در Query اول ولی نه در Query دوم

---

# یک نکته مهم در استفاده

برای استفاده از این دستورات:

1. تعداد ستون‌ها در دو Query باید **برابر باشد**
2. نوع داده ستون‌ها باید **سازگار باشد**
3. ترتیب ستون‌ها باید **یکسان باشد**

مثال صحیح:
```sql

SELECT id, name FROM table1
UNION
SELECT id, name FROM table2

```
