### Self Join

درواقع **Self Join** زمانی استفاده می‌شود که یک جدول را با **خود همان جدول** Join کنیم.

مثال: فرض کنید جدول `Employees` داریم که هر کارمند یک مدیر دارد.
```markdown

Employees
---------
Id | Name | ManagerId
1  | Ali  | NULL
2  | Reza | 1
3  | Sara | 1
4  | Mina | 2

```
می‌خواهیم نام کارمند و مدیرش را ببینیم.
```sql

SELECT 
E.Name AS Employee,
M.Name AS Manager
FROM Employees E
LEFT JOIN Employees M
ON E.ManagerId = M.Id;

```
نتیجه:
```markdown

Employee | Manager
Ali      | NULL
Reza     | Ali
Sara     | Ali
Mina     | Reza

```
در اینجا جدول `Employees` **با خودش Join شده است**.

### Cross Join

درواقع **Cross Join** ضرب کارتزین (Cartesian Product) دو جدول را ایجاد می‌کند.

یعنی **هر ردیف از جدول اول با تمام ردیف‌های جدول دوم ترکیب می‌شود**.

فرض کنید دو جدول داریم:
```markdown

Colors
------
Red
Blue

```

```markdown

Sizes
------
S
M
L

```
Query:
```sql

SELECT *
FROM Colors
CROSS JOIN Sizes;

```
نتیجه:
```markdown

Color | Size
Red   | S
Red   | M
Red   | L
Blue  | S
Blue  | M
Blue  | L

```
اگر جدول اول 2 ردیف و جدول دوم 3 ردیف داشته باشد:
```markdown

2 × 3 = 6 rows

```

---

✅ خلاصه:

- تعریف **Self Join:** Join یک جدول با خودش (مثلاً کارمند و مدیر).
- تعریف **Cross Join:** ترکیب همه ردیف‌های دو جدول با هم (Cartesian Product).
