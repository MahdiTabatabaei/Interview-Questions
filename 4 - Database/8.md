هر دو برای مقایسه یک مقدار با نتیجهٔ یک **Subquery** استفاده می‌شوند، اما نحوهٔ بررسی و عملکردشان فرق دارد.

## IN
درواقع `IN` بررسی می‌کند که آیا یک مقدار **در لیستی از مقادیر** وجود دارد یا نه.

مثال:

```sql
SELECT name
FROM customers
WHERE id IN (
    SELECT customer_id
    FROM orders
);
```

یعنی: مشتری‌هایی را نشان بده که `id` آن‌ها در لیست `customer_id` جدول `orders` وجود دارد.

ویژگی‌ها:
- زیرکوئری معمولاً **یک لیست از مقادیر** برمی‌گرداند.
- اگر نتیجهٔ زیرکوئری بزرگ باشد ممکن است **کندتر شود**.

---

## EXISTS
درواقع `EXISTS` فقط بررسی می‌کند که آیا **حداقل یک رکورد** در زیرکوئری وجود دارد یا نه.

مثال:

```sql
SELECT name
FROM customers c
WHERE EXISTS (
    SELECT 1
    FROM orders o
    WHERE o.customer_id = c.id
);
```

یعنی: اگر برای آن مشتری حداقل یک سفارش وجود داشته باشد، آن مشتری نمایش داده می‌شود.

ویژگی‌ها:
- به **وجود رکورد** توجه می‌کند، نه مقدار آن.
- معمولاً با **Subquery وابسته (correlated subquery)** استفاده می‌شود.
- در داده‌های بزرگ اغلب **سریع‌تر** است چون با پیدا شدن اولین رکورد متوقف می‌شود.

---

## تفاوت اصلی

- عملگر `IN` → مقایسه با **لیستی از مقادیر**
- عملگر `EXISTS` → بررسی **وجود حداقل یک رکورد**

---

## تفاوت در عملکرد

- عملگر `IN` معمولاً ابتدا نتیجهٔ Subquery را می‌سازد.
- عملگر `EXISTS` برای هر رکورد بررسی می‌کند که آیا رکورد مرتبطی وجود دارد یا نه و با اولین تطابق **متوقف می‌شود**.

---

✅ یک نکتهٔ مهم دربارهٔ `NULL`:

اگر در زیرکوئری `NULL` وجود داشته باشد، `IN` ممکن است نتایج غیرمنتظره بدهد، اما `EXISTS` این مشکل را ندارد.
