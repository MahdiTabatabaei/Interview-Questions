تفاوت اصلی در **حذف یا نگه داشتن داده‌های تکراری** است.

## UNION
نتایج دو کوئری را با هم **ترکیب می‌کند و مقادیر تکراری را حذف می‌کند**.

مثال:

```sql
SELECT city FROM customers
UNION
SELECT city FROM suppliers;
```

اگر یک شهر در هر دو جدول باشد، در خروجی فقط **یک بار** نمایش داده می‌شود.

ویژگی‌ها:
- تکراری‌ها حذف می‌شوند
- به خاطر عملیات حذف تکراری‌ها معمولاً **کندتر** است

---

## UNION ALL
نتایج دو کوئری را **بدون حذف تکراری‌ها** ترکیب می‌کند.

```sql
SELECT city FROM customers
UNION ALL
SELECT city FROM suppliers;
```

اگر یک شهر در هر دو جدول باشد، **چند بار** در خروجی ظاهر می‌شود.

ویژگی‌ها:
- تکراری‌ها حذف نمی‌شوند
- معمولاً **سریع‌تر** است چون عملیات حذف تکراری انجام نمی‌دهد

---

## مثال

فرض کنید نتایج دو کوئری این‌ها باشد:

Query1
```
Tehran
Shiraz
Tabriz
```

Query2
```
Tehran
Mashhad
```

### با UNION
```
Tehran
Shiraz
Tabriz
Mashhad
```

### با UNION ALL
```
Tehran
Shiraz
Tabriz
Tehran
Mashhad
```

---

✅ نکته مهم:  
برای استفاده از `UNION` یا `UNION ALL`:

- تعداد ستون‌ها باید **برابر** باشد  
- نوع دادهٔ ستون‌ها باید **سازگار** باشد
