- درواقع SQL Server به‌صورت خودکار [[Statistics]] را آپدیت می‌کند (Auto Update).

- ولی در دیتابیس‌های بزرگ، باید دستی هم تنظیم شود (Scheduled Job).

**استراتژی‌ها:**

- اجرا با دستور `UPDATE STATISTICS` به‌صورت هفتگی یا روزانه.
- تنظیم **FULLSCAN** برای دقت بالا در جداول بحرانی.
- استفاده از Maintenance Plan اختصاصی.

**چرا حیاتی؟**

چون Planهای Query بر اساس آمار تصمیم می‌گیرند. آمار غلط = Plan اشتباه = کندی شدید.
