ویژگی Logging provider مشخص می‌کند **لاگ‌ها کجا ذخیره شوند**.

---

## Console

لاگ در ترمینال چاپ می‌شود.

### مثال
```csharp

builder.Logging.AddConsole();

```
خروجی:
```markdown

info: User created

```
مناسب:

- development

---

## Seq

یک **log server** با UI عالی.

ویژگی‌ها:

- structured logs
- search
- filtering

---

### مثال
```csharp

builder.Logging.AddSeq("http://localhost:5341");

```
---

## Elastic Stack (ELK)

سیستم بزرگ برای لاگ‌ها.

اجزا:

- Elasticsearch
- Logstash
- Kibana

مناسب:

- سیستم‌های بزرگ
- microservices

---

## Application Insights

سرویس Microsoft Azure.

ویژگی‌ها:

- distributed tracing
- performance monitoring
- error tracking

---

### مثال
```csharp

builder.Services.AddApplicationInsightsTelemetry();

```
