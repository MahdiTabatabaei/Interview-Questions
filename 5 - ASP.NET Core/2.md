در ASP.NET Core، Lifecycle به چرخه حیات اشیاء و سرویس‌های مختلف اشاره دارد که در طول پردازش یک درخواست HTTP دخیل هستند. مهم‌ترین جنبه Lifecycle در ASP.NET Core مربوط به **Dependency Injection (DI)** است. DI در ASP.NET Core از سه Scope اصلی پشتیبانی می‌کند:

- در **Singleton:** یک نمونه از سرویس در طول عمر برنامه (Application Lifetime) ایجاد و استفاده می‌شود. هر بار که سرویس درخواست شود، همان نمونه قبلی برگردانده می‌شود.
- در **Scoped:** یک نمونه از سرویس در طول عمر یک درخواست HTTP (Request Lifetime) ایجاد و استفاده می‌شود. هر درخواست HTTP جدید، یک نمونه جدید از سرویس را دریافت می‌کند.
- در **Transient:** هر بار که سرویس درخواست شود، یک نمونه جدید از آن ایجاد می‌شود (Object Lifetime).

این Scopeها نحوه مدیریت و طول عمر اشیائی که برنامه شما به آن‌ها وابسته است را تعیین می‌کنند.

**مثال:**

فرض کنید یک سرویس `IMyScopedService` داریم که می‌خواهیم در طول یک درخواست، فقط یک نمونه از آن استفاده شود.
```csharp

// Startup.cs (یا Program.cs)
services.AddScoped<IMyScopedService, MyScopedService>(); // ثبت سرویس به صورت Scoped

// Controller
public class MyController : ControllerBase
{
    private readonly IMyScopedService _scopedService1;
    private readonly IMyScopedService _scopedService2;

    public MyController(IMyScopedService scopedService1, IMyScopedService scopedService2)
    {
        _scopedService1 = scopedService1;
        _scopedService2 = scopedService2;
    }

    [HttpGet]
    public IActionResult Get()
    {
        // در طول یک درخواست، _scopedService1 و _scopedService2 به یک نمونه اشاره خواهند کرد.
        bool areSameInstance = object.ReferenceEquals(_scopedService1, _scopedService2);
        return Ok(areSameInstance); // خروجی: true
    }
}

// MyScopedService.cs
public interface IMyScopedService { }
public class MyScopedService : IMyScopedService { }

```
