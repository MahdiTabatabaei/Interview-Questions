ویژگی Model Validation در ASP.NET Core فرآیندی است که بررسی می‌کند آیا داده‌های ورودی کاربر (که توسط Model Binding به یک مدل نگاشت شده‌اند) با قوانین تعریف شده برای آن مدل مطابقت دارند یا خیر. این کار به جلوگیری از ورود داده‌های نامعتبر به برنامه و افزایش امنیت کمک می‌کند.

**نحوه انجام:**

1. **استفاده از Data Annotations:** رایج‌ترین روش، استفاده از Attributeهای اعتبارسنجی (Validation Attributes) از Namespace `System.ComponentModel.DataAnnotations` است که مستقیماً روی پراپرتی‌های مدل اعمال می‌شوند. مثال‌ها:

- `[Required]`: فیلد نباید خالی باشد.
- `[StringLength(int maxLength, int minLength)]`: طول رشته باید در محدوده مشخصی باشد.
- `[EmailAddress]`: مقدار باید فرمت ایمیل معتبر داشته باشد.
- `[Range(int min, int max)]`: مقدار عددی باید در محدوده مشخصی باشد.
- `[RegularExpression(string pattern)]`: مقدار باید با الگوی Regex مطابقت داشته باشد.
- `[Compare("OtherPropertyName")]`: مقدار باید با پراپرتی دیگر مطابقت داشته باشد.

2. **اعتبارسنجی خودکار در Controller/API:**

- هنگامی که یک مدل به عنوان پارامتر اکشن متد در Controller یا Minimal API استفاده می‌شود، ASP.NET Core به طور پیش‌فرض اعتبارسنجی را انجام می‌دهد.
- می‌توانید با چک کردن `ModelState.IsValid` قبل از پردازش مدل، بررسی کنید که آیا اعتبارسنجی موفق بوده است یا خیر.
- اگر از `[ApiController]` Attribute در Controller استفاده کنید، ASP.NET Core به طور خودکار در صورت نامعتبر بودن مدل، یک پاسخ `BadRequest` با جزئیات خطا برمی‌گرداند.

3. **اعتبارسنجی سفارشی (Custom Validation):**

- می‌توانید با ارث‌بری از `ValidationAttribute`، قوانین اعتبارسنجی سفارشی خود را ایجاد کنید.
- می‌توانید از Interface `IValidatableObject` در مدل استفاده کنید تا منطق اعتبارسنجی پیچیده‌تری را پیاده‌سازی کنید.

**مثال:**
```csharp

// RegistrationViewModel.cs
public class RegistrationViewModel
{
    [Required(ErrorMessage = "نام الزامی است.")]
    [StringLength(50, MinimumLength = 2, ErrorMessage = "نام باید بین ۲ تا ۵۰ کاراکتر باشد.")]
    public string FirstName { get; set; }

    [Required(ErrorMessage = "نام خانوادگی الزامی است.")]
    [StringLength(50, MinimumLength = 2, ErrorMessage = "نام خانوادگی باید بین ۲ تا ۵۰ کاراکتر باشد.")]
    public string LastName { get; set; }

    [Required(ErrorMessage = "سن الزامی است.")]
    [Range(18, 99, ErrorMessage = "سن باید بین ۱۸ تا ۹۹ باشد.")]
    public int Age { get; set; }

    [Required(ErrorMessage = "ایمیل الزامی است.")]
    [EmailAddress(ErrorMessage = "فرمت ایمیل نامعتبر است.")]
    public string Email { get; set; }
}

// RegistrationController.cs
[ApiController] // فعال کردن اعتبارسنجی خودکار و بازگرداندن BadRequest
[Route("api/[controller]")]
public class RegistrationController : ControllerBase
{
    [HttpPost]
    public IActionResult Register(RegistrationViewModel model)
    {
        // اگر از [ApiController] استفاده شده باشد، این بررسی خودکار انجام می‌شود
        // if (!ModelState.IsValid)
        // {
        //     return BadRequest(ModelState); // بازگرداندن خطاها
        // }

        // اگر مدل معتبر بود، پردازش را ادامه دهید
        // ... ثبت کاربر در پایگاه داده ...

        return Ok(new { Message = "ثبت نام موفقیت آمیز بود." });
    }
}

```
در سمت کلاینت (HTML با استفاده از jQuery Validate):

اگر از Tag Helpers یا JavaScriptهای اعتبارسنجی استفاده کنید، این اعتبارسنجی‌ها در مرورگر نیز قابل نمایش هستند و کاربر را راهنمایی می‌کنند.
