# Response Caching

وابسته به **HTTP headers** است.

بیشتر برای **browser و proxy caching**.

---

### مثال
```csharp

[ResponseCache(Duration = 60)]
public IActionResult GetData()
{
    return Ok(DateTime.Now);
}

```
### رفتار

اگر 60 ثانیه گذشته نباشد:

در این حالت Response از cache برگردانده می‌شود.

---

# Output Caching (.NET 7+)

یک سیستم caching جدید و قوی‌تر است.

ویژگی‌ها:

- server side
- policy based
- memory cache

---

### مثال

فعال سازی
```csharp

builder.Services.AddOutputCache();

```
middleware
```csharp

app.UseOutputCache();

```
endpoint
```csharp

app.MapGet("/time", () => DateTime.Now)
   .CacheOutput();

```
