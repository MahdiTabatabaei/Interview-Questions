از Filters (فیلترها) در ASP.NET Core به شما امکان می‌دهند تا کدها یا منطق‌های از پیش تعریف شده‌ای را قبل یا بعد از اجرای Action Methodها (در MVC و API) یا در مراحل مختلف Pipeline درخواست-پاسخ اجرا کنید. فیلترها برای پیاده‌سازی قابلیت‌هایی مانند:

- **احراز هویت (Authentication):** بررسی هویت کاربر.
- **مجوز دسترسی (Authorization):** بررسی اینکه آیا کاربر اجازه دسترسی به منبع را دارد یا خیر.
- **مدیریت خطا (Exception Handling):** گرفتن و مدیریت خطاها.
- **لاگینگ (Logging):** ثبت اطلاعات درخواست و پاسخ.
- **اعتبارسنجی مدل (Model Validation):** خودکار کردن اعتبارسنجی مدل قبل از اجرای اکشن.
- **کش کردن (Caching):** مدیریت پاسخ‌های کش شده.

**انواع فیلترها:**

- `IActionFilter`: قبل و بعد از اجرای Action Method اجرا می‌شود.
- `IResultFilter`: قبل و بعد از اجرای نتیجه Action Method (قبل از ارسال پاسخ) اجرا می‌شود.
- `IExceptionFilter`: زمانی که یک Exception در طول پردازش رخ دهد، اجرا می‌شود.
- `IAuthorizationFilter`: قبل از اجرای Action Method، برای بررسی مجوز دسترسی اجرا می‌شود.
- `IAsyncActionFilter`: نسخه ناهمزمان `IActionFilter`.

**نحوه استفاده:**

فیلترها را می‌توان به صورت **سراسری (Global)** در Pipeline (با `app.UseMvc(...)` یا `app.UseEndpoints(...)`) یا به صورت **موضعی (Local)** روی Controllerها یا Action Methodهای خاص با استفاده از Attributeها اعمال کرد.

**مثال (فیلتر سفارشی برای لاگ کردن):**
```csharp

// ActionLoggingFilter.cs
public class ActionLoggingFilter : IActionFilter
{
    private readonly ILogger<ActionLoggingFilter> _logger;

    public ActionLoggingFilter(ILogger<ActionLoggingFilter> logger)
    {
        _logger = logger;
    }

    public void OnActionExecuting(ActionExecutingContext context)
    {
        // قبل از اجرای اکشن
        _logger.LogInformation($"Executing action: {context.ActionDescriptor.DisplayName}");
    }

    public void OnActionExecuted(ActionExecutedContext context)
    {
        // بعد از اجرای اکشن
        _logger.LogInformation($"Executed action: {context.ActionDescriptor.DisplayName}");
    }
}

// ProductsController.cs
[ServiceFilter(typeof(ActionLoggingFilter))] // اعمال فیلتر به صورت موضعی روی Controller
public class ProductsController : Controller
{
    public IActionResult Index()
    {
        return View();
    }
}

// Startup.cs (یا Program.cs) - ثبت فیلتر برای استفاده موضعی
services.AddScoped<ActionLoggingFilter>(); // یا AddTransient بسته به نیاز

```
