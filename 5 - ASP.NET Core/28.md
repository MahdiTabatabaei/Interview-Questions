در `IHttpClientFactory` دو روش رایج برای پیکربندی و استفاده از `HttpClient` وجود دارد: **Named Client** و **Typed Client**. تفاوت اصلی آن‌ها در **نحوه دسترسی، ساختار کد و میزان type-safety** است.

---

# 1. Named Client

در این روش یک **نام (string)** برای تنظیمات HttpClient تعریف می‌کنیم و هنگام استفاده با همان نام آن را می‌گیریم.

### ثبت در DI

```csharp
builder.Services.AddHttpClient("github", client =>
{
    client.BaseAddress = new Uri("https://api.github.com/");
});
```

### استفاده

```csharp
public class MyService
{
    private readonly IHttpClientFactory _factory;

    public MyService(IHttpClientFactory factory)
    {
        _factory = factory;
    }

    public async Task GetData()
    {
        var client = _factory.CreateClient("github");
        var result = await client.GetAsync("/users");
    }
}
```

### ویژگی‌ها

- استفاده از **string name**
- نیاز به `IHttpClientFactory`
- تنظیمات در `AddHttpClient("name")`
- احتمال **خطای تایپی در نام**

---

# 2. Typed Client

در این روش یک **کلاس strongly‑typed** برای ارتباط با API تعریف می‌کنیم و `HttpClient` مستقیماً در آن inject می‌شود.

### تعریف Typed Client

```csharp
public class GithubService
{
    private readonly HttpClient _client;

    public GithubService(HttpClient client)
    {
        _client = client;
    }

    public async Task<string> GetUsers()
    {
        return await _client.GetStringAsync("/users");
    }
}
```

### ثبت در DI

```csharp
builder.Services.AddHttpClient<GithubService>(client =>
{
    client.BaseAddress = new Uri("https://api.github.com/");
});
```

### استفاده

```csharp
public class MyController : ControllerBase
{
    private readonly GithubService _service;

    public MyController(GithubService service)
    {
        _service = service;
    }
}
```

### ویژگی‌ها

- **Strongly Typed**
- بدون string
- خواناتر و maintainable تر
- مناسب برای **Service Layer**

---

# تفاوت اصلی

| ویژگی | Named Client | Typed Client |
|------|--------------|-------------|
| نوع دسترسی | با نام (string) | با کلاس |
| Type Safety | ندارد | دارد |
| نیاز به IHttpClientFactory | بله | نه مستقیم |
| ساختار کد | ساده‌تر | تمیزتر و معماری بهتر |
| مناسب برای | چند تنظیم ساده | ارتباط با API مشخص |

---

# جمع‌بندی

- **Named Client** → وقتی فقط چند تنظیم مختلف برای HttpClient نیاز دارید.  
- **Typed Client** → وقتی برای یک API خارجی **یک سرویس مشخص** می‌سازید (بهترین روش در پروژه‌های واقعی).

---

یک نکته جالب که خیلی‌ها نمی‌دانند:  
در واقع **Typed Client در پشت صحنه خودش یک Named Client می‌سازد** و روی آن یک wrapper کلاس قرار می‌دهد.
