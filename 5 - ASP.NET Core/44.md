در واقع Authentication باید **قبل از Authorization** باشد.

چرا؟

چون Authorization نیاز دارد بداند **کاربر کیست**.

---

### مثال اشتباه
```csharp

app.UseAuthorization();
app.UseAuthentication();

```
در این حالت:

Authorization اجرا می‌شود ولی کاربر هنوز authenticate نشده.

نتیجه:
```markdown

403 Forbidden

```
---

### مثال درست
```csharp

app.UseAuthentication();
app.UseAuthorization();

```
---

### مثال Controller
```csharp

[Authorize]
[HttpGet]
public IActionResult GetSecret()
{
    return Ok("secret data");
}

```
اگر ترتیب middleware اشتباه باشد این endpoint همیشه fail می‌شود.
