برای سفارشی‌سازی خروجی **JSON** در ASP.NET Core Health Checks باید از `HealthCheckOptions` و مخصوصاً **ResponseWriter** استفاده کنیم. این امکان می‌دهد خروجی را دقیقاً مطابق نیاز خودمان بسازیم (ساختار، فیلدها، زمان، exception‑ها و …).

در ادامه یک نمونه **کاملاً حرفه‌ای** قرار می‌دهم.

---

# 1️⃣ تعریف ResponseWriter سفارشی

همه چیز در `HealthCheckOptions.ResponseWriter` اتفاق می‌افتد.

```csharp
using System.Text.Json;

static Task CustomHealthWriter(HttpContext context, HealthReport report)
{
    context.Response.ContentType = "application/json; charset=utf-8";

    var result = new
    {
        status = report.Status.ToString(),
        duration = report.TotalDuration.TotalMilliseconds + " ms",
        timestamp = DateTime.UtcNow,
        entries = report.Entries.Select(e => new
        {
            name = e.Key,
            status = e.Value.Status.ToString(),
            description = e.Value.Description,
            duration = e.Value.Duration.TotalMilliseconds + " ms",
            error = e.Value.Exception?.Message,
            data = e.Value.Data
        })
    };

    var json = JsonSerializer.Serialize(result, new JsonSerializerOptions
    {
        WriteIndented = true
    });

    return context.Response.WriteAsync(json);
}
```

این خروجی شامل موارد زیر است:

- وضعیت کلی سیستم  
- زمان اجرا  
- جزئیات هر Health Check  
- مدت زمان هر check  
- exception (اگر وجود داشته باشد)  
- داده‌های custom

---

# 2️⃣ استفاده از ResponseWriter در endpoint

ساده:

```csharp
app.MapHealthChecks("/health", new HealthCheckOptions
{
    ResponseWriter = CustomHealthWriter
});
```

---

# 3️⃣ نسخه حرفه‌ای با فیلتر tag (مثلاً readiness)

```csharp
app.MapHealthChecks("/health/ready", new HealthCheckOptions
{
    Predicate = check => check.Tags.Contains("ready"),
    ResponseWriter = CustomHealthWriter
});
```

# 5️⃣ توضیح: حذف فیلدهای اضافی یا تغییر ساختار

مثلاً اگر فقط وضعیت کلی بخواهیم:

```csharp
var result = new { status = report.Status.ToString() };
```

یا اگر خروجی سازگار با Kubernetes بخواهیم:

```csharp
var result = new { status = report.Status == HealthStatus.Healthy ? "ok" : "failed" };
```

# 6️⃣ افزودن Metadata اختصاصی در Check سفارشی

در health check سفارشی می‌توانیم داده اضافه کنیم:

```csharp
var data = new Dictionary<string, object>
{
    { "version", "1.0.3" },
    { "region", "eu-west" }
};

return HealthCheckResult.Healthy("Database ok", data);
```

بعد در JSON هم ظاهر می‌شود.

---

# 7️⃣ بهترین Practiceها

- همیشه `WriteIndented = true` برای خوانایی  
- حتماً `application/json; charset=utf-8` برای سازگاری  
- زمان اجرای هر Check → کمک عالی برای Performance debugging  
- اضافه کردن timestamp برای log aggregation  
- اضافه کردن metadata اگر روی dashboards استفاده می‌شود (Grafana / Kibana)
