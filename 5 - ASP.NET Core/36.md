پیاده‌سازی IHealthCheck
```csharp

public class DatabaseHealthCheck : IHealthCheck
{
    public Task<HealthCheckResult> CheckHealthAsync(
        HealthCheckContext context,
        CancellationToken token = default)
    {
        bool dbIsUp = true;

        if(dbIsUp)
            return Task.FromResult(HealthCheckResult.Healthy());

        return Task.FromResult(HealthCheckResult.Unhealthy());
    }
}

```
ثبت:
```csharp

builder.Services.AddHealthChecks()
    .AddCheck<DatabaseHealthCheck>("database");

```

این کد یک **Custom Health Check** در ASP.NET Core می‌سازد تا سلامت یک وابستگی (مثلاً دیتابیس) بررسی شود.

بیایید قسمت به قسمت ببینیم چه اتفاقی می‌افتد.

---

# 1. ساخت کلاس Health Check

```csharp
public class DatabaseHealthCheck : IHealthCheck
```

اینجا یک کلاس ساخته شده که اینترفیس `IHealthCheck` را پیاده‌سازی می‌کند.

اینترفیس `IHealthCheck` از namespace زیر می‌آید:

```csharp
Microsoft.Extensions.Diagnostics.HealthChecks
```

هر کلاسی که این interface را پیاده‌سازی کند می‌تواند به عنوان **Health Check سفارشی** در سیستم ثبت شود.

---

# 2. متد اصلی Health Check

```csharp
public Task<HealthCheckResult> CheckHealthAsync(
    HealthCheckContext context,
    CancellationToken token = default)
```

این متد توسط ASP.NET Core هنگام اجرای health check فراخوانی می‌شود.

پارامترها:

- `HealthCheckContext`  
  شامل اطلاعاتی درباره health check جاری است (نام، تنظیمات و ...)

- `CancellationToken`  
  اگر درخواست health check cancel شود، می‌توان عملیات را متوقف کرد.

خروجی متد:

```
Task<HealthCheckResult>
```

یعنی نتیجه بررسی سلامت سیستم.

---

# 3. بررسی وضعیت دیتابیس

```csharp
bool dbIsUp = true;
```

در این مثال فقط یک متغیر فرضی تعریف شده است.

در پروژه واقعی اینجا معمولاً یکی از این کارها انجام می‌شود:

- باز کردن connection به دیتابیس
- اجرای یک query ساده
- ping کردن database

مثال واقعی:

```csharp
var connection = new SqlConnection(connectionString);
await connection.OpenAsync();
```

---

# 4. بازگرداندن نتیجه

اگر دیتابیس سالم باشد:

```csharp
return Task.FromResult(HealthCheckResult.Healthy());
```

و اگر مشکل داشته باشد:

```csharp
return Task.FromResult(HealthCheckResult.Unhealthy());
```

وضعیت‌های ممکن در HealthCheckResult:

- `Healthy` → سیستم سالم است
- `Degraded` → سیستم کار می‌کند ولی مشکل دارد
- `Unhealthy` → سیستم مشکل جدی دارد

مثال پیشرفته‌تر:

```csharp
return HealthCheckResult.Degraded("Database response is slow");
```

---

# 5. ثبت Health Check در DI

```csharp
builder.Services.AddHealthChecks()
    .AddCheck<DatabaseHealthCheck>("database");
```

اینجا دو کار انجام می‌شود.

### 1️⃣ فعال کردن سیستم Health Checks

```
AddHealthChecks()
```

### 2️⃣ ثبت Health Check سفارشی

```
AddCheck<DatabaseHealthCheck>("database");
```

یعنی:

- از کلاس `DatabaseHealthCheck` استفاده کن
- نام این health check را `database` بگذار

# نسخه واقعی‌تر Database Health Check

مثال حرفه‌ای‌تر:

```csharp
public class DatabaseHealthCheck : IHealthCheck
{
    private readonly string _connectionString;

    public DatabaseHealthCheck(IConfiguration config)
    {
        _connectionString = config.GetConnectionString("DefaultConnection");
    }

    public async Task<HealthCheckResult> CheckHealthAsync(
        HealthCheckContext context,
        CancellationToken token = default)
    {
        try
        {
            using var connection = new SqlConnection(_connectionString);
            await connection.OpenAsync(token);

            return HealthCheckResult.Healthy("Database is reachable");
        }
        catch (Exception ex)
        {
            return HealthCheckResult.Unhealthy("Database connection failed", ex);
        }
    }
}
```

---

✅ خلاصه مفهوم کد :

- یک **Health Check سفارشی** ساخته شده
- وظیفه‌اش بررسی **سلامت دیتابیس** است
- با `AddCheck` در سیستم HealthCheck ثبت می‌شود
- هنگام درخواست `/health` اجرا می‌شود
