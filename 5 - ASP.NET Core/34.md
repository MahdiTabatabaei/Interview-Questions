در **ASP.NET Core** برای اضافه کردن Health Check از دو بخش اصلی استفاده می‌شود:

- ثبت سرویس‌ها با `AddHealthChecks()`
- تعریف endpoint با `MapHealthChecks()`

درواقع Health Check معمولاً برای مانیتورینگ وضعیت اپلیکیشن (مثلاً توسط Docker, Kubernetes, Load Balancer) استفاده می‌شود تا مشخص شود برنامه **Healthy / Unhealthy** است.

---

# 1️⃣ اضافه کردن Health Checks در Service Container

در فایل `Program.cs` یا `Startup.cs` باید سرویس HealthCheck را ثبت کنید:

```csharp
var builder = WebApplication.CreateBuilder(args);

builder.Services.AddHealthChecks();

var app = builder.Build();
```

---

# 2️⃣ ایجاد Endpoint برای Health Check

بعد از build شدن اپلیکیشن باید یک endpoint برای آن تعریف کنید:

```csharp
app.MapHealthChecks("/health");

app.Run();
```

اکنون اگر آدرس زیر را باز کنید:

```
https://localhost:5001/health
```

اگر برنامه سالم باشد پاسخ می‌گیرید:

```
Healthy
```

---

# 3️⃣ اضافه کردن Health Check برای سرویس‌ها (مثلاً Database)

می‌توانید بررسی‌های واقعی مثل دیتابیس هم اضافه کنید:

```csharp
builder.Services.AddHealthChecks()
    .AddSqlServer(
        connectionString: builder.Configuration.GetConnectionString("DefaultConnection"),
        name: "sql",
        failureStatus: Microsoft.Extensions.Diagnostics.HealthChecks.HealthStatus.Unhealthy);
```

---

# 4️⃣ تنظیم خروجی JSON (اختیاری)

اگر بخواهید خروجی قابل مانیتورینگ باشد:

```csharp
app.MapHealthChecks("/health", new HealthCheckOptions
{
    ResponseWriter = async (context, report) =>
    {
        context.Response.ContentType = "application/json";

        var result = JsonSerializer.Serialize(new
        {
            status = report.Status.ToString(),
            checks = report.Entries.Select(e => new {
                name = e.Key,
                status = e.Value.Status.ToString()
            })
        });

        await context.Response.WriteAsync(result);
    }
});
```

نمونه خروجی:

```json
{
  "status": "Healthy",
  "checks": [
    { "name": "sql", "status": "Healthy" }
  ]
}
```

---

# 5️⃣ مثال کامل Program.cs

```csharp
var builder = WebApplication.CreateBuilder(args);

builder.Services.AddHealthChecks();

var app = builder.Build();

app.MapHealthChecks("/health");

app.Run();
```

---

✅ خلاصه:

- `AddHealthChecks()` → ثبت سرویس HealthCheck  
- `MapHealthChecks()` → ایجاد endpoint برای بررسی سلامت  

- قابل اتصال به سرویس‌هایی مثل **SQL Server, Redis, API, Disk, Memory**
