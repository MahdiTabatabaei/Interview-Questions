در C# (به‌ویژه در  ASP.NET MVC یا ASP.NET Core، **Anti‑Forgery Token** یک **توکن امنیتی** است که برای جلوگیری از حملات **CSRF (Cross‑Site Request Forgery)** استفاده می‌شود.

---

### ⚙️ توضیح ساده:

وقتی فرم HTML در سمت سرور تولید می‌شود، یک **توکن مخفی (hidden field)** در آن قرار داده می‌شود و هم‌زمان یک **کوکی** حاوی همان توکن نیز برای مرورگر ارسال می‌شود.

هنگام ارسال فرم، هر دو توکن (مخفی + کوکی) به سرور بازگردانده می‌شوند.

سرور بررسی می‌کند که این دو مقدار با هم **سازگار و معتبر** باشند. اگر کسی از سایت دیگری تلاش کند فرم را بفرستد، چون توکن معتبر ندارد، درخواست رد می‌شود.

---

### 🧩 مثال در ASP.NET Core MVC:
```csharp

@Html.AntiForgeryToken()

```
و در اکشن کنترلر:
```csharp

[ValidateAntiForgeryToken]
public IActionResult Submit(FormModel model)
{
    // فقط اگر توکن معتبر بود، به اینجا می‌رسد
}

```
### 🔐 خلاصه:

**هدف:** جلوگیری از جعل درخواست‌های کاربر (CSRF).

**کاربرد:** تولید و اعتبارسنجی توکن منحصربه‌فرد برای هر فرم یا درخواست POST.
