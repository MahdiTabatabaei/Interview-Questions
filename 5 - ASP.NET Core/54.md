درواقع **Attribute Routing** روشی برای تعریف مسیرهای (Routes) در Web API یا ASP.NETT Core است که در آن **مسیرها با استفاده از Attributeها مستقیماً روی Controller یا Action نوشته می‌شوند**.

یعنی به جای تعریف route در یک فایل مرکزی، آن را **کنار متد مربوطه** مشخص می‌کنیم.

## مثال
```csharp

[ApiController]
[Route("api/products")]
public class ProductsController : ControllerBase
{
    [HttpGet]
    public IActionResult GetAll()
    {
        return Ok();
    }

    [HttpGet("{id}")]
    public IActionResult GetById(int id)
    {
        return Ok(id);
    }

    [HttpPost]
    public IActionResult Create(Product product)
    {
        return Ok();
    }
}

```
در این مثال:

- `GET /api/products` → متد `GetAll`
- `GET /api/products/5` → متد `GetById`
- `POST /api/products` → متد `Create`

## Attributeهای رایج

- `Route`
- `HttpGet`
- `HttpPost`
- `HttpPut`
- `HttpDelete`
- `HttpPatch`

مثال:
```csharp

[HttpGet("active")]

```
Route:
```markdown

GET /api/products/active

```
## مزیت‌ها

- خوانایی بیشتر (route کنار متد است)
- کنترل دقیق روی مسیرها
- مناسب برای REST API

## تفاوت با Conventional Routing

نوع **Conventional Routing**

درواقع Route در یک جای مرکزی تعریف می‌شود:
```csharp

app.MapControllerRoute(
    name: "default",
    pattern: "{controller}/{action}/{id?}");

```
**Attribute Routing**

درواقع Route مستقیماً روی controller یا action نوشته می‌شود.

✅ خلاصه:

مفهوم **Attribute Routing یعنی تعریف routeهای API با استفاده از Attributeها روی Controller یا Action به جای تعریف مرکزی.**
