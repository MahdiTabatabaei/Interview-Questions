این سه مفهوم مکمل هم هستند اما **هدف‌های متفاوتی دارند**.

### 1️⃣ Health Check

بررسی می‌کند آیا **سرویس سالم و آماده کار است یا نه**.

معمولاً توسط:

- Kubernetes
- Load Balancer
- Monitoring systems

استفاده می‌شود.

مثال:

- آیا دیتابیس وصل است؟
- آیا Redis در دسترس است؟

### مثال #C
```csharp

builder.Services.AddHealthChecks()
    .AddSqlServer(builder.Configuration.GetConnectionString("Default"));

app.MapHealthChecks("/health");

```
درخواست:

```markdown

GET /health

```
خروجی:
```markdown

Healthy

```
---

### 2️⃣ Monitoring

Monitoring یعنی **جمع‌آوری مداوم متریک‌ها و وضعیت سیستم**.

مثال متریک‌ها:

- CPU usage
- Memory
- Request count
- Response time

ابزارها:

- Prometheus
- Grafana
- Application Insights

---

### مثال زندگی واقعی
Health Check مثل:

✅ چک کردن اینکه **ماشین روشن می‌شود یا نه**

Monitoring مثل:

📊 دیدن

- سرعت
- مصرف سوخت
- دمای موتور

---

### 3️⃣ Logging

Logging یعنی **ثبت اتفاقاتی که در سیستم رخ می‌دهد**.

مثال:

- خطاها
- درخواست‌ها
- عملیات کاربران

---

### مثال #C 
```csharp

public class UserService
{
    private readonly ILogger<UserService> _logger;

    public UserService(ILogger<UserService> logger)
    {
        _logger = logger;
    }

    public void CreateUser(string name)
    {
        _logger.LogInformation("User created: {name}", name);
    }
}

```
