بستگی به **DI Container** دارد، اما در اغلب فریم‌ورک‌ها (مثل **.NET Dependency Injection**) رفتار به این شکل است:

### حالت ۱: Resolve کردن یک نمونه

اگر یک Interface چند بار ثبت شود و شما **یک نمونه** بخواهید:
```csharp

services.AddTransient<IService, ServiceA>();
services.AddTransient<IService, ServiceB>();

```
و سپس:
```csharp

var service = provider.GetService<IService>();

```
✅ **آخرین registration استفاده می‌شود**

یعنی `ServiceB`.

---

### حالت ۲: گرفتن همه پیاده‌سازی‌ها

اگر از **IEnumerable** استفاده کنید:
```csharp

IEnumerable<IService> services

```
✅ **تمام پیاده‌سازی‌ها برگردانده می‌شوند**:
```csharp

ServiceA
ServiceB

```
و می‌توانید روی آن‌ها loop بزنید.

---

### مثال
```csharp

public class HandlerA : IHandler {}
public class HandlerB : IHandler {}

services.AddTransient<IHandler, HandlerA>();
services.AddTransient<IHandler, HandlerB>();

```
استفاده:
```csharp

public MyService(IEnumerable<IHandler> handlers)
{
    // handlers = [HandlerA, HandlerB]
}

```
✅ **خلاصه**

- چند بار register → مشکلی ندارد
- Resolve یک instance → **آخرین ثبت شده استفاده می‌شود**
- Resolve `IEnumerable<T>` → **همه implementationها برمی‌گردند**
