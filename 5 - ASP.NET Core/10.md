در واقع **JWT (JSON Web Token):** یک استاندارد باز (RFC 7519) است که روشی فشرده و خودکفا برای انتقال امن اطلاعات بین طرفین به صورت JSON Object را تعریف می‌کند. این اطلاعات می‌توانند به صورت دیجیتال امضا شده و یا رمزگذاری شوند.

و **JWT Authentication:** روشی برای پیاده‌سازی Authentication است که در آن، پس از اینکه کاربر با موفقیت وارد سیستم شد (مثلاً با نام کاربری و رمز عبور)، یک توکن JWT برای او صادر می‌شود. این توکن حاوی اطلاعاتی درباره کاربر (مانند ID، نقش‌ها) و همچنین امضایی برای اطمینان از عدم دستکاری آن است.

**چگونه کار می‌کند:**

1. **ورود و صدور توکن:** کاربر اطلاعات ورود خود را ارسال می‌کند. سرور هویت او را تأیید کرده و یک توکن JWT صادر می‌کند. این توکن معمولاً شامل سه بخش است که با نقطه (`.`) از هم جدا شده‌اند:

- **Header:** اطلاعات مربوط به نوع توکن (JWT) و الگوریتم امضا (مثلاً HS256).
- **Payload:** حاوی “Claims” یا ادعاهایی درباره کاربر (مانند `user_id`, `role`, `exp` - تاریخ انقضا). این بخش قابل خواندن است اما نباید حاوی اطلاعات بسیار حساس باشد زیرا رمزگذاری نشده است.
- **Signature:** برای تأیید صحت توکن. این بخش با استفاده از یک کلید مخفی (Secret Key) و الگوریتم مشخص شده در Header ایجاد می‌شود.

2. **ارسال توکن توسط کلاینت:** کلاینت (مرورگر یا اپلیکیشن موبایل) توکن دریافتی را در درخواست‌های بعدی به سرور، معمولاً در هدر `Authorization` با پیشوند `Bearer` ارسال می‌کند: `Authorization: Bearer <your_jwt_token>`.

3. **تأیید توکن توسط سرور:** سرور (با استفاده از Middleware مربوط به JWT) هدر `Authorization` را بررسی می‌کند.


- توکن را استخراج کرده و امضای آن را با استفاده از همان کلید مخفی که برای صدور توکن استفاده شده بود، تأیید می‌کند.
- اگر امضا معتبر بود و توکن منقضی نشده بود، سرور اطلاعات موجود در Payload را به عنوان هویت کاربر در آن درخواست می‌شناسد (Authentication موفق).
- سپس مرحله Authorization بر اساس Claims موجود در توکن انجام می‌شود.

**مثال (سمت سرور ASP.NET Core):**
```csharp

// Program.cs (تنظیمات JWT Authentication)
builder.Services.AddAuthentication(JwtBearerDefaults.AuthenticationScheme)
    .AddJwtBearer(options =>
    {
        options.TokenValidationParameters = new TokenValidationParameters
        {
            ValidateIssuer = true,
            ValidateAudience = true,
            ValidateLifetime = true,
            ValidateIssuerSigningKey = true,
            ValidIssuer = builder.Configuration["Jwt:Issuer"], // از appsettings.json
            ValidAudience = builder.Configuration["Jwt:Audience"], // از appsettings.json
            IssuerSigningKey = new SymmetricSecurityKey(Encoding.UTF8.GetBytes(builder.Configuration["Jwt:Key"])) // کلید مخفی
        };
    });

builder.Services.AddAuthorization(); // برای استفاده از Authorization

var app = builder.Build();

app.UseAuthentication(); // فعال کردن Middleware احراز هویت
app.UseAuthorization(); // فعال کردن Middleware مجوز دسترسی

// ... Map Endpoints ...

// AuthController.cs (مثال صدور توکن)
[Route("api/[controller]")]
[ApiController]
public class AuthController : ControllerBase
{
    private readonly IConfiguration _configuration;

    public AuthController(IConfiguration configuration)
    {
        _configuration = configuration;
    }

    [HttpPost("login")]
    public IActionResult Login([FromBody] LoginModel model)
    {
        // فرض کنید کاربر با موفقیت احراز هویت شده است
        if (model.Username == "test" && model.Password == "password")
        {
            var issuer = _configuration["Jwt:Issuer"];
            var audience = _configuration["Jwt:Audience"];
            var key = Encoding.UTF8.GetBytes(_configuration["Jwt:Key"]);

            var securityKey = new SymmetricSecurityKey(key);
            var credentials = new SigningCredentials(securityKey, SecurityAlgorithms.HmacSha256);

            var tokenDescriptor = new SecurityTokenDescriptor
            {
                Subject = new ClaimsIdentity(new[]
                {
                    new Claim(ClaimTypes.NameIdentifier, model.Username),
                    new Claim(ClaimTypes.Role, "Admin") // مثال: اضافه کردن نقش
                }),
                Expires = DateTime.UtcNow.AddMinutes(30), // انقضا بعد از 30 دقیقه
                Issuer = issuer,
                Audience = audience,
                SigningCredentials = credentials
            };

            var tokenHandler = new JwtSecurityTokenHandler();
            var token = tokenHandler.CreateToken(tokenDescriptor);
            var jwtToken = tokenHandler.WriteToken(token);

            return Ok(new { token = jwtToken });
        }
        return Unauthorized();
    }
}

```
