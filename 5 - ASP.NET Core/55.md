مفهوم **Middleware** و **Filter** هر دو برای اجرای کد قبل و بعد از پردازش درخواست در ASP.NETET Core استفاده می‌شوند، اما **در سطح و مرحله متفاوتی از pipeline اجرا می‌شوند.**

## Middleware

تغریف Middleware در **HTTP Request Pipeline** اجرا می‌شود و روی **همه درخواست‌ها** قبل از رسیدن به MVC یا endpointها عمل می‌کند.

ویژگی‌ها:

- در سطح کل application
- قبل از رسیدن به Controller
- می‌تواند request را متوقف کند
- به MVC وابسته نیست

مثال:
```csharp

app.Use(async (context, next) =>
{
    Console.WriteLine("Before request");

    await next();

    Console.WriteLine("After request");
});

```
کاربردهای رایج:

- Authentication
- Logging
- Exception handling
- CORS
- Static files

## Filter

ویژگی Filter فقط در **MVC / Web API pipeline** اجرا می‌شود و مربوط به **Controller و Action** است.

ویژگی‌ها:

- بعد از رسیدن درخواست به MVC
- روی controller یا action اعمال می‌شود
- برای منطق مربوط به MVC

انواع Filter:

- Authorization Filter
- Action Filter
- Result Filter
- Exception Filter

مثال:
```csharp

public class LogFilter : IActionFilter
{
    public void OnActionExecuting(ActionExecutingContext context)
    {
        Console.WriteLine("Before action");
    }

    public void OnActionExecuted(ActionExecutedContext context)
    {
        Console.WriteLine("After action");
    }
}

```
استفاده:
```csharp

[ServiceFilter(typeof(LogFilter))]
public IActionResult Get()
{
    return Ok();
}

```
---

## تفاوت‌های اصلی

Middleware

- در **HTTP pipeline**
- قبل از MVC
- روی کل برنامه
- به controller وابسته نیست

Filter

- در **MVC pipeline**
- بعد از routing
- روی controller/action
- مخصوص MVC و Web API
