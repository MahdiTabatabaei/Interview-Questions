ویژگی Endpoint Filter شبیه **Middleware برای Minimal API** است.

قبل یا بعد از اجرای endpoint اجرا می‌شود.

---

### کاربرد

- validation
- logging
- authorization
- caching

---

### مثال
```csharp

app.MapGet("/users", () => "users")
.AddEndpointFilter(async (context, next) =>
{
    Console.WriteLine("before");

    var result = await next(context);

    Console.WriteLine("after");

    return result;
});

```
---
