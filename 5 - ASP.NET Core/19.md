تعریف **Output Caching (کش کردن خروجی):** تکنیکی است که در آن پاسخ‌های HTTP تولید شده توسط سرور برای درخواست‌های معین، ذخیره (کش) می‌شوند. دفعه بعدی که درخواستی با همان مشخصات دریافت شود، سرور به جای پردازش مجدد درخواست و تولید پاسخ از ابتدا، پاسخ کش شده را مستقیماً به کلاینت برمی‌گرداند.

**مزایا:**

- **افزایش عملکرد:** کاهش زمان پاسخ‌دهی سرور.
- **کاهش بار پردازشی:** کاهش بار روی CPU و پایگاه داده.
- **صرفه‌جویی در منابع:** مصرف کمتر منابع سرور.

**موارد استفاده:**

- صفحات یا Endpointهایی که محتوای آن‌ها به ندرت تغییر می‌کند (مانند صفحات اصلی سایت، لیست محصولات، نتایج جستجو).
- و APIهایی که داده‌های استاتیک یا نیمه‌استاتیک را برمی‌گردانند.

**نحوه پیاده‌سازی در ASP.NET Core:**

در ASP.NET Core از Output Caching در سطح Middleware پشتیبانی می‌کند:

1. **فعال کردن سرویس کش:**
```csharp

    builder.Services.AddResponseCaching();

```

2. فعال کردن Middleware کش:
```csharp

    app.UseResponseCaching();

```
3. **اعمال kebijakan کش (Caching Policies):**

- **با استفاده از Attribute:** می‌توانید با استفاده از Attributeهایی مانند `[ResponseCache]` روی Controllerها یا Action Methodها، سیاست‌های کش را تعریف کنید.
- **با استفاده از هدرهای HTTP:** می‌توانید هدرهای استاندارد HTTP مانند `Cache-Control`, `Expires`, `Pragma`, `Vary` را تنظیم کنید.

**مثال (با `[ResponseCache]`):**
```csharp

// ProductsController.cs
[ResponseCache(Duration = 60, VaryByQueryKeys = new[] { "sortOrder" }, Location = ResponseCacheLocation.Any)]
public IActionResult Index(string sortOrder)
{
    // این View یا داده‌ها حداکثر 60 ثانیه کش می‌شوند.
    // اگر پارامتر query string 'sortOrder' تغییر کند، کش معتبر نخواهد بود (VaryByQueryKeys).
    // Location.Any یعنی کش هم در سمت سرور و هم در سمت کلاینت ذخیره شود.
    ViewBag.Message = "Product List";
    return View();
}

// Minimal API Example
app.MapGet("/cached-data", () => $"Hello - {DateTime.Now}")
   .CacheOutput(options =>
   {
       options.SetDurationMs(10000); // 10 ثانیه
       options.SetVaryByQuery("param"); // Vary by query parameter 'param'
       options.SetVaryByHeader("Accept-Language"); // Vary by header
   });

```

```json

```
- `Duration`: مدت زمانی که پاسخ کش می‌شود (بر حسب ثانیه).
- `VaryByQueryKeys`: مشخص می‌کند که اگر این کلیدهای Query String تغییر کنند، پاسخ جدیدی تولید شود (کش معتبر نیست).
- `VaryByHeader`: مشابه `VaryByQueryKeys` اما برای هدرهای HTTP.
- `Location`: تعیین می‌کند که کش در کجا ذخیره شود (`Client`, `Server`, `Any`).
