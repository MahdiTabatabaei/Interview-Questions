قابلیت داخلی برای محدود کردن درخواست‌ها.

---

### مثال
```csharp

builder.Services.AddRateLimiter(options =>
{
    options.AddFixedWindowLimiter("api", opt =>
    {
        opt.PermitLimit = 10;
        opt.Window = TimeSpan.FromSeconds(10);
    });
});

```
---

استفاده
```csharp

app.MapGet("/data", () => "ok")
   .RequireRateLimiting("api");

```
