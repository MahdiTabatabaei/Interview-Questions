مکانیزم **Rate Limiting (محدودسازی نرخ):** مکانیزمی برای کنترل تعداد درخواست‌هایی است که یک کاربر یا کلاینت می‌تواند در یک بازه زمانی مشخص به یک API ارسال کند. هدف اصلی آن جلوگیری از سوء استفاده، حملات DDoS، و اطمینان از توزیع عادلانه منابع سرور بین کاربران است.

**روش‌های پیاده‌سازی در ASP.NET Core:**

1. **استفاده از کتابخانه‌های NuGet:** رایج‌ترین و بهترین روش، استفاده از کتابخانه‌های اختصاصی Rate Limiting است. معروف‌ترین آن‌ها:

- استفاده از **Microsoft.AspNetCore.RateLimiting:** این کتابخانه رسمی مایکروسافت است که از .NET 7 به بعد معرفی شده و از الگوریتم‌های مختلفی مانند Token Bucket و Leaky Bucket پشتیبانی می‌کند.
- و **AspNetCoreRateLimit:** یک کتابخانه محبوب و قوی که قابلیت‌های زیادی از جمله محدودسازی بر اساس IP، کلید API، و … را ارائه می‌دهد.

2. **پیاده‌سازی سفارشی با Middleware:** می‌توانید یک Middleware سفارشی بنویسید که تعداد درخواست‌ها را شمارش کرده و در صورت عبور از حد مجاز، پاسخ مناسب (معمولاً `429 Too Many Requests`) را برگرداند. این روش پیچیده‌تر است و نیاز به مدیریت دقیق وضعیت (مانند ذخیره تعداد درخواست‌ها در حافظه یا پایگاه داده) دارد.

**مثال (با استفاده از Microsoft.AspNetCore.RateLimiting):**

ابتدا پکیج `Microsoft.AspNetCore.RateLimiting` را نصب کنید.
```csharp
// Program.cs
var builder = WebApplication.CreateBuilder(args);

// Register services for Rate Limiting
builder.Services.AddRateLimiter(options =>
{
    options.RejectionStatusCode = StatusCodes.Status429TooManyRequests; // کد وضعیت در صورت عبور از حد مجاز

    // پیکربندی یک سیاست (Policy) به نام "fixed"
    options.AddFixedWindowLimiter(policyName: "fixed", opt =>
    {
        opt.PermitLimit = 5; // حداکثر 5 درخواست مجاز
        opt.Window = TimeSpan.FromSeconds(30); // در بازه زمانی 30 ثانیه
        opt.QueueProcessingOrder = QueueProcessingOrder.OldestFirst; // ترتیب پردازش در صف
        opt.QueueLimit = 0; // 0 یعنی صف نامحدود (یا 10 اگر می‌خواهید محدود کنید)
    });

    // پیکربندی سیاست دیگری به نام "sliding"
    options.AddSlidingWindowLimiter(policyName: "sliding", opt =>
    {
        opt.PermitLimit = 10; // حداکثر 10 درخواست
        opt.Window = TimeSpan.FromMinutes(1); // در بازه زمانی 1 دقیقه
        opt.SegmentsPerWindow = 5; // تقسیم پنجره به 5 بخش برای دقت بیشتر
        opt.QueueLimit = 0;
    });
});

var app = builder.Build();

// فعال کردن Rate Limiting در Pipeline
app.UseRateLimiter();

app.MapGet("/", () => "Hello World!").RequireRateLimiting("fixed"); // اعمال سیاست "fixed" به این Endpoint

app.MapGet("/api/data", () => "Some data")
   .RequireRateLimiting("sliding"); // اعمال سیاست "sliding" به این Endpoint

app.Run();

```

در این مثال:

- برای Endpoint `/`، حداکثر 5 درخواست در هر 30 ثانیه مجاز است.
- برای Endpoint `/api/data`، حداکثر 10 درخواست در هر 1 دقیقه مجاز است.
- اگر کاربری بیش از حد مجاز درخواست ارسال کند، پاسخ `429 Too Many Requests` دریافت خواهد کرد.
