در واقع  Model Binding فرآیندی در ASP.NET Core است که داده‌های ورودی از درخواست HTTP (مانند مقادیر فرم، پارامترهای Query String، داده‌های JSON) را به یک **مدل** (یک کلاس C#) نگاشت می‌کند. این کار باعث می‌شود که بتوانید به این داده‌ها به صورت اشیاء C# دسترسی داشته باشید، به جای اینکه مجبور باشید رشته‌های خام را تجزیه و تحلیل کنید.

**چگونه کار می‌کند:**

1. **شناسایی منبع داده:** Model Binder منابع داده مختلف در درخواست HTTP را شناسایی می‌کند (مانند Form, Route, Query String, Headers, Body).
2. **یافتن مدل:** شما یک مدل (کلاس C#) را به عنوان پارامتر یک اکشن متد (در Controller یا Minimal API) یا به عنوان بدنه (Body) درخواست تعریف می‌کنید.
3. **تطبیق نام:** Model Binder نام پراپرتی‌های مدل را با نام مقادیر موجود در منابع داده مقایسه می‌کند.
4. **تبدیل نوع:** اگر نام‌ها مطابقت داشتند، Model Binder سعی می‌کند مقدار را از نوع منبع داده به نوع پراپرتی مدل تبدیل کند (مثلاً رشته “123” را به عدد صحیح `int`).
5. **پر کردن مدل:** مقدار تبدیل شده به پراپرتی مدل اختصاص داده می‌شود.

**مثال:**

فرض کنید یک فرم ثبت نام داریم و می‌خواهیم داده‌های آن را در یک مدل `UserViewModel` دریافت کنیم.

```csharp

// UserViewModel.cs
public class UserViewModel
{
    public string FirstName { get; set; }
    public string LastName { get; set; }
    public int Age { get; set; }
}

// UserController.cs
public class UserController : Controller
{
    [HttpPost]
    // Model Binding به طور خودکار مقادیر فرم را به پارامتر user می‌نگارد
    public IActionResult Register(UserViewModel user)
    {
        if (ModelState.IsValid) // بررسی اعتبار سنجی مدل
        {
            // حالا می‌توانید از پراپرتی‌های user استفاده کنید
            string message = $"Welcome, {user.FirstName} {user.LastName}! You are {user.Age} years old.";
            return Ok(message);
        }
        // اگر مدل نامعتبر بود، دوباره فرم را نمایش دهید
        return View(user);
    }
}

```

در سمت کلاینت (HTML Form):
```html

<form asp-action="Register" method="post">
    <input type="text" name="FirstName" />
    <input type="text" name="LastName" />
    <input type="number" name="Age" />
    <button type="submit">Register</button>
</form>

```
وقتی فرم ارسال شود، ASP.NET Core به طور خودکار مقادیر `FirstName`, `LastName`, `Age` را در `UserViewModel` قرار می‌دهد.
