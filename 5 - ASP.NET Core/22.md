استفاده از این دو باعث **Deadlock** و **Thread Starvation** می‌شود.

### مشکل

در ASP.NET از **Thread Pool** استفاده می‌کند.

اگر بنویسیم:
```csharp

var result = GetDataAsync().Result;

```
Thread:

1. منتظر می‌ماند
2. block می‌شود
3. Thread pool پر می‌شود

در نتیجه درخواست‌های جدید پردازش نمی‌شوند.

---

### روش صحیح

استفاده از async/await
```csharp

public async Task<IActionResult> Get()
{
    var result = await GetDataAsync();
    return Ok(result);
}

```
---

### مثال زندگی واقعی

فرض کنید رستوران دارید.

**Task.Wait()**

مشتری می‌گوید:

“اینجا می‌نشینم تا غذا آماده شود”

پس میز اشغال می‌شود.

**async/await**

مشتری می‌گوید:

“وقتی آماده شد خبر بده”

پس میز آزاد می‌شود.
