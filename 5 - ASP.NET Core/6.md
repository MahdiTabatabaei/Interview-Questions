در واقع Routing در ASP.NET Core مسئول نگاشت URL درخواستی به یک Endpoint (مانند یک اکشن متد در Controller یا یک کد پردازش مستقیم) است. این فرآیند به طور کلی شامل دو بخش است:

1. بخش اول **Inbound Routing (مسیریابی ورودی):**

- وقتی یک درخواست HTTP به برنامه می‌رسد، موتور مسیریابی ASP.NET Core (معمولاً با استفاده از `UseRouting` Middleware) URL را بررسی می‌کند.
- این URL با الگوهای تعریف شده در مسیریابی تطبیق داده می‌شود. این الگوها می‌توانند به صورت Controller-Action (در MVC)، صفحه (Razor Pages) یا Endpointهای سفارشی (با `MapGet`, `MapPost` و …) تعریف شوند.
- اگر URL با یکی از الگوها مطابقت داشت، موتور مسیریابی اطلاعاتی مانند نام Controller، نام Action، پارامترهای مسیر (Route Parameters) و پارامترهای Query String را استخراج کرده و به `HttpContext.Request` اضافه می‌کند.

1. بخش دوم **Outbound Routing (مسیریابی خروجی):**

- هنگامی که نیاز به تولید URL برای یک Action یا Endpoint دارید (مثلاً در view ها یا هنگام بازگرداندن پاسخ JSON)، از قابلیت URL Generation استفاده می‌کنید.
- این قابلیت با استفاده از اطلاعات موجود در مسیریابی (نام Route، پارامترها) URL صحیح را تولید می‌کند.

**نحوه پیاده‌سازی:**

- **MVC:** با استفاده از Attributeها (`[HttpGet]`, `[Route]`) یا تنظیمات در `Startup.cs`/`Program.cs`.
- **Razor Pages:** مسیریابی بر اساس نام فایل‌ها و پوشه‌ها انجام می‌شود.
- **Minimal APIs:** با استفاده از متدهای `MapGet`, `MapPost`, `MapPut`, `MapDelete` و …

**مثال (MVC):**
```csharp

// Startup.cs (یا Program.cs)
app.UseRouting(); // فعال کردن موتور مسیریابی

app.UseEndpoints(endpoints =>
{
    // تعریف یک مسیر پیش‌فرض برای MVC
    endpoints.MapControllerRoute(
        name: "default",
        pattern: "{controller=Home}/{action=Index}/{id?}");
});

// ProductsController.cs
[Route("api/[controller]")] // مسیر کلی Controller: /api/Products
public class ProductsController : ControllerBase
{
    [HttpGet] // مسیر برای این اکشن: GET /api/Products
    public IActionResult GetAll() { /* ... */ }

    [HttpGet("{id}")] // مسیر برای این اکشن: GET /api/Products/{id}
    public IActionResult GetById(int id) { /* ... */ }
}

```
وقتی کاربر به `/api/Products/123` درخواست GET ارسال کند، Routing تشخیص می‌دهد که باید `GetById` اکشن در `ProductsController` را با `id = 123` فراخوانی کند.
