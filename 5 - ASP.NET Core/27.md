`IHttpClientFactory` یک **Factory در ASP.NET Core برای ساخت و مدیریت HttpClient** است که مشکل‌های رایج استفاده مستقیم از `HttpClient` را حل می‌کند.

قبل از معرفی آن (در .NET Core 2.1)، توسعه‌دهندگان معمولاً این کار را می‌کردند:

```csharp
var client = new HttpClient();
```

یا یک `HttpClient` استاتیک می‌ساختند. هر دو روش مشکلاتی داشت.

---

## مشکل استفاده مستقیم از HttpClient

### 1. Socket Exhaustion
اگر در هر درخواست یک `HttpClient` جدید بسازید:

```
new HttpClient()
```

Connectionها به سرعت مصرف می‌شوند و سیستم به خطای **Socket Exhaustion** می‌رسد.

---

### 2. DNS caching مشکل‌دار
اگر یک HttpClient استاتیک بسازید:

```
static HttpClient client
```

ممکن است تغییرات DNS سرور مقصد دیر اعمال شود.

---

## راه‌حل: IHttpClientFactory

مایکروسافت `IHttpClientFactory` را معرفی کرد تا:

- مدیریت **connection pooling**
- مدیریت **lifetime handler**
- پشتیبانی از **Dependency Injection**
- تنظیمات مرکزی برای HttpClient

را انجام دهد.

---

## ثبت در DI

ابتدا باید آن را ثبت کنیم:

```csharp
builder.Services.AddHttpClient();
```

---

## استفاده ساده

```csharp
public class MyService
{
    private readonly IHttpClientFactory _factory;

    public MyService(IHttpClientFactory factory)
    {
        _factory = factory;
    }

    public async Task GetData()
    {
        var client = _factory.CreateClient();

        var response = await client.GetAsync("https://api.example.com/data");
    }
}
```

در این حالت:

- HttpClientها ساخته می‌شوند
- Handlerها مدیریت می‌شوند
- Connection reuse انجام می‌شود

---

## سه نوع HttpClient در IHttpClientFactory

### 1. Basic Client

```csharp
var client = _factory.CreateClient();
```

ساده‌ترین حالت.

---

### 2. Named Client

می‌توانید تنظیمات خاص تعریف کنید:

```csharp
builder.Services.AddHttpClient("github", client =>
{
    client.BaseAddress = new Uri("https://api.github.com/");
});
```

استفاده:

```csharp
var client = _factory.CreateClient("github");
```

---

### 3. Typed Client (بهترین روش)

یک کلاس اختصاصی برای API می‌سازید.

```csharp
public class GithubService
{
    private readonly HttpClient _client;

    public GithubService(HttpClient client)
    {
        _client = client;
    }

    public async Task<string> GetRepos()
    {
        return await _client.GetStringAsync("/users/octocat/repos");
    }
}
```

ثبت:

```csharp
builder.Services.AddHttpClient<GithubService>(client =>
{
    client.BaseAddress = new Uri("https://api.github.com/");
});
```

---

## مزایای مهم IHttpClientFactory

- جلوگیری از **Socket Exhaustion**
- مدیریت بهتر **DNS updates**
- ادغام با **Dependency Injection**
- امکان اضافه کردن **Delegating Handlers**
- پشتیبانی از **Polly (Retry, Circuit Breaker)**

---

✅ **خلاصه**

`IHttpClientFactory` یک **Factory برای ایجاد و مدیریت HttpClient در ASP.NET Core** است که:

- مشکلات اتصال و DNS را حل می‌کند
- با DI کار می‌کند
- امکان پیکربندی و reuse اتصال‌ها را فراهم می‌کند
