این سه مفهوم، **Scopeهای مدیریت عمر سرویس‌ها** در سیستم Dependency Injection (DI) ASP.NET Core هستند:

- **Singleton:**

- **عمر:** یک نمونه واحد در کل طول عمر برنامه ایجاد می‌شود.

- **کاربرد:** سرویس‌های کلی که وضعیت آن‌ها بین درخواست‌ها مشترک است و تغییر نمی‌کنند (مثلاً یک کلاینت HTTP یا یک سرویس کش).

- **نکته:** باید مراقب وضعیت (state) سرویس‌های Singleton بود، زیرا ممکن است باعث تداخل بین درخواست‌ها شود.

- **Scoped:**

- **عمر:** یک نمونه واحد برای هر درخواست HTTP ایجاد می‌شود.

- **کاربرد:** سرویس‌هایی که وضعیت آن‌ها باید در طول یک درخواست خاص ثابت بماند (مثلاً یک DbContext برای دسترسی به پایگاه داده در یک درخواست).

- **نکته:** این Scope رایج‌ترین Scope برای سرویس‌هایی است که به پایگاه داده یا سرویس‌های دیگر در طول یک درخواست دسترسی دارند.

- **Transient:**

- **عمر:** هر بار که سرویس درخواست می‌شود، یک نمونه جدید ایجاد می‌شود.

- **کاربرد:** سرویس‌هایی که سبک هستند، وضعیت ندارند و یا نیازی به اشتراک‌گذاری نمونه بین بخش‌های مختلف یک درخواست ندارند (مثلاً یک سرویس محاسباتی ساده).

- **نکته:** استفاده بیش از حد از Transient می‌تواند منجر به سربار عملکردی شود.


**مثال (ترکیبی):**

فرض کنید یک سرویس `Logger` (Singleton)، یک سرویس `DbContext` (Scoped) و یک سرویس `Calculator` (Transient) داریم.
```csharp

// Startup.cs (یا Program.cs)
services.AddSingleton<ILogger, Logger>();
services.AddScoped<IDbContext, MyDbContext>();
services.AddTransient<ICalculator, Calculator>();

// Controller
public class MyController : ControllerBase
{
    private readonly ILogger _logger1;
    private readonly ILogger _logger2;
    private readonly IDbContext _dbContext1;
    private readonly IDbContext _dbContext2;
    private readonly ICalculator _calculator1;
    private readonly ICalculator _calculator2;

    public MyController(ILogger logger1, ILogger logger2, IDbContext dbContext1, IDbContext dbContext2, ICalculator calculator1, ICalculator calculator2)
    {
        _logger1 = logger1;
        _logger2 = logger2;
        _dbContext1 = dbContext1;
        _dbContext2 = dbContext2;
        _calculator1 = calculator1;
        _calculator2 = calculator2;
    }

    [HttpGet]
    public IActionResult Get()
    {
        // Singleton
        bool loggersAreSame = object.ReferenceEquals(_logger1, _logger2); // true

        // Scoped
        bool dbContextsAreSame = object.ReferenceEquals(_dbContext1, _dbContext2); // true (در طول یک درخواست)

        // Transient
        bool calculatorsAreSame = object.ReferenceEquals(_calculator1, _calculator2); // false (هر بار نمونه جدید)

        return Ok($"Loggers Same: {loggersAreSame}, DbContexts Same: {dbContextsAreSame}, Calculators Same: {calculatorsAreSame}");
    }
}

// Sample services
public interface ILogger { }
public class Logger : ILogger { }

public interface IDbContext { }
public class MyDbContext : IDbContext { }

public interface ICalculator { }
public class Calculator : ICalculator { }

```
