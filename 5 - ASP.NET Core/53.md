اگر **`IEnumerable<IService>`** را inject کنید، DI Container **همه پیاده‌سازی‌های ثبت‌شده از `IService`** را برمی‌گرداند.

### مثال

فرض کنید چند implementation دارید:
```csharp

public class ServiceA : IService {}
public class ServiceB : IService {}

```
و آن‌ها را register می‌کنید:
```csharp

services.AddTransient<IService, ServiceA>();
services.AddTransient<IService, ServiceB>();

```
حالا اگر این را inject کنید:
```csharp

public class MyClass
{
    public MyClass(IEnumerable<IService> services)
    {
    }
}

```
✅ ابزار Container یک collection شامل **همه implementationها** می‌سازد:
```markdown

[ ServiceA , ServiceB ]

```
### ترتیب عناصر

ترتیب عناصر معمولاً **بر اساس ترتیب registration در DI container** است.

یعنی:
```markdown

AddTransient<IService, ServiceA>()
AddTransient<IService, ServiceB>()

```
نتیجه:
```markdown

ServiceA → ServiceB

```
### اگر هیچ implementation ثبت نشده باشد

در این وضعیت DI یک **collection خالی** می‌دهد، نه `null`.
```markdown

[]

```
### کاربرد رایج

این الگو معمولاً در **Strategy Pattern یا Plugin Architecture** استفاده می‌شود.

مثال:
```csharp

foreach (var service in services)
{
    service.Execute();
}

```
✅ خلاصه:

- درا این حالت`IEnumerable<IService>` → همه implementationها برگردانده می‌شوند
- ترتیب = ترتیب registration
- اگر چیزی ثبت نشده باشد → collection خالی برمی‌گردد.
