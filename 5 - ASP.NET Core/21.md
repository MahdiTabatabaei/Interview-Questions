

در واقع **Kestrel** وب‌سرور پیش‌فرض ASP.NET Core است که توسط مایکروسافت نوشته شده و بسیار **سریع و lightweight** است.

این سرور مسئول **گوش دادن به درخواست‌های HTTP و ارسال آن‌ها به ASP.NET Core pipeline** است.

### معماری

Client → Kestrel → Middleware Pipeline → Controller / Minimal API

### ویژگی‌ها

- بسیار سریع
- قابلیت Cross-platform (Linux / Windows / Mac)
- بصورت built-in در ASP.NET Core
- استفاده از async I/O

### مثال اجرا

در ASP.NET Core :
```csharp

var builder = WebApplication.CreateBuilder(args);

var app = builder.Build();

app.MapGet("/", () => "Hello from Kestrel");

app.Run();

```
وب سرور Kestrel به طور پیش‌فرض روی پورت 5000 اجرا می‌شود.
