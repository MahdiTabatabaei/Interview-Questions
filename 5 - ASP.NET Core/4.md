ثبت Dependency Injection (DI) در ASP.NET Core شامل دو مرحله اصلی است:

1. **رجیستر کردن سرویس‌ها (Registering Services):** شما به فریم‌ورک می‌گویید که چه سرویس‌هایی (کلاس‌ها یا اینترفیس‌ها) در دسترس هستند و چگونه باید نمونه‌سازی شوند (Singleton, Scoped, Transient). این کار معمولاً در متد `ConfigureServices` (در ASP.NET Core < 3.0) یا مستقیماً در `Program.cs` (در ASP.NET Core 3.0+) با استفاده از `IServiceCollection` انجام می‌شود.

2. **استفاده از سرویس‌ها (Consuming Services):** شما سرویس‌های ثبت شده را در Constructor کلاس‌هایی که به آن‌ها نیاز دارند (مانند Controllers, Services, Middlewareها) تزریق می‌کنید. ASP.NET Core به طور خودکار نمونه‌های مناسب را بر اساس Scope تعریف شده، ایجاد و تزریق می‌کند.


**نحوه کار:**

- یک `IServiceCollection` ایجاد می‌شود که لیستی از سرویس‌ها و نحوه رجیستر شدن آن‌ها را نگهداری می‌کند.
- این `IServiceCollection` به یک `ServiceProvider` تبدیل می‌شود. `ServiceProvider` مسئول ایجاد و مدیریت نمونه‌های سرویس‌ها بر اساس Scopeهای تعریف شده است.
- هنگامی که یک کلاس (مثلاً Controller) ساخته می‌شود، ASP.NET Core از `ServiceProvider` برای پیدا کردن و تزریق وابستگی‌های آن کلاس استفاده می‌کند.

**مثال:**
```csharp

// Program.cs (ASP.NET Core 6+)
var builder = WebApplication.CreateBuilder(args);

// 1. Registering Services
builder.Services.AddControllersWithViews(); // رجیستر کردن سرویس‌های لازم برای MVC
builder.Services.AddScoped<IMyService, MyService>(); // رجیستر کردن سرویس سفارشی

var app = builder.Build();

// ... Configure pipeline ...

app.MapControllerRoute(
    name: "default",
    pattern: "{controller=Home}/{action=Index}/{id?}");

app.Run();


// MyController.cs
public class MyController : Controller
{
    private readonly IMyService _myService;

    // 2. Consuming Service via Constructor Injection
    public MyController(IMyService myService)
    {
        _myService = myService;
    }

    public IActionResult Index()
    {
        ViewBag.Message = _myService.GetData();
        return View();
    }
}

// MyService.cs
public interface IMyService
{
    string GetData();
}

public class MyService : IMyService
{
    public string GetData()
    {
        return "Data from MyService!";
    }
}

```
