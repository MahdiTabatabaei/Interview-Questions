تعریف Middleware در ASP.NET Core به پایپ‌لاین (pipeline) درخواست-پاسخ اشاره دارد. این پایپ‌لاین از مجموعه‌ای از کامپوننت‌های نرم‌افزاری تشکیل شده است که هر کدام مسئول انجام بخشی از پردازش درخواست HTTP و تولید پاسخ HTTP هستند. هر کامپوننت می‌تواند:

- یک درخواست را قبل از رسیدن به نقطه نهایی پردازش کند.
- یک درخواست را به کامپوننت بعدی در تیوپ ارسال کند.
- یک پاسخ را قبل از ارسال به کلاینت پردازش کند.
- یک درخواست را به طور کامل پردازش کرده و از ارسال آن به کامپوننت‌های بعدی جلوگیری کند.

تصویر ساده:

```markdown

Request
   ↓
Middleware 1
   ↓
Middleware 2
   ↓
Middleware 3
   ↓
Endpoint / Controller
   ↓
Response
   ↑
Middleware 3
   ↑
Middleware 2
   ↑
Middleware 1

```


**چرا استفاده می‌شود؟**

درواقع Middlewareها به دلایل زیر استفاده می‌شوند:

- **قابلیت استفاده مجدد (Reusability):** منطق مشترک (مانند احراز هویت، لاگینگ، مدیریت خطا) را می‌توان در یک Middleware قرار داد و در پروژه‌های مختلف استفاده کرد.
- **ماژولار بودن (Modularity):** کد برنامه به بخش‌های کوچک‌تر و قابل مدیریت تقسیم می‌شود.
- **پیکربندی آسان (Easy Configuration):** ترتیب اجرای Middlewareها در فایل `Startup.cs` (یا `Program.cs` در .NET 6+) به راحتی قابل تنظیم است.
- **انعطاف‌پذیری (Flexibility):** امکان افزودن، حذف یا تغییر ترتیب Middlewareها بدون تأثیر زیاد بر سایر بخش‌های برنامه وجود دارد.

**مثال:**

فرض کنید می‌خواهیم یک Middleware برای لاگ کردن زمان درخواست‌ها ایجاد کنیم.
```csharp

// Startup.cs (یا Program.cs)
public void Configure(IApplicationBuilder app)
{
    app.UseMiddleware<RequestLoggingMiddleware>(); // اضافه کردن Middleware
    app.UseRouting();
    app.UseEndpoints(endpoints =>
    {
        endpoints.MapGet("/", async context => await context.Response.WriteAsync("Hello World!"));
    });
}

// RequestLoggingMiddleware.cs
public class RequestLoggingMiddleware
{
    private readonly RequestDelegate _next;

    public RequestLoggingMiddleware(RequestDelegate next)
    {
        _next = next;
    }

    public async Task InvokeAsync(HttpContext context)
    {
        // قبل از ارسال درخواست به Middleware بعدی
        var startTime = DateTime.UtcNow;
        Console.WriteLine($"Request received at: {startTime}");

        // ارسال درخواست به Middleware بعدی در تیوپ
        await _next(context);

        // بعد از بازگشت پاسخ از Middleware بعدی
        var endTime = DateTime.UtcNow;
        Console.WriteLine($"Request processed in: {(endTime - startTime).TotalMilliseconds} ms");
    }
}

```
