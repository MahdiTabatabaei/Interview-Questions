الگوی **Visitor** یک الگوی طراحی از نوع **Behavioral** است که اجازه می‌دهد **عملیات جدیدی روی مجموعه‌ای از اشیاء اضافه کنیم بدون اینکه کلاس‌های آن اشیاء را تغییر دهیم**.

به بیان ساده:  
به‌جای اینکه عملیات را داخل کلاس‌ها بنویسیم، آن‌ها را در یک **Visitor** جداگانه قرار می‌دهیم.

---

## مشکل بدون Visitor

فرض کنید چند نوع **Shape** داریم:

- Circle  
- Rectangle  
- Triangle  

و می‌خواهیم عملیات‌های مختلف انجام دهیم:

- محاسبه مساحت  
- رسم شکل  
- Export به JSON  

اگر این عملیات‌ها را داخل کلاس‌ها قرار دهیم، هر بار که عملیات جدید اضافه شود باید **همه کلاس‌ها تغییر کنند**.

Visitor این مشکل را حل می‌کند.

---

# ساختار Visitor Pattern

اجزا:

- **Visitor (interface)** → تعریف عملیات‌ها
- **ConcreteVisitor** → پیاده‌سازی عملیات
- **Element (interface)** → اشیائی که visitor روی آن‌ها اجرا می‌شود
- **ConcreteElement** → پیاده‌سازی element
- **Accept()** → متدی که visitor را می‌پذیرد

---

# مثال C#

فرض کنید سیستم **Shape** داریم.

---

# Visitor Interface

```csharp
public interface IShapeVisitor
{
    void VisitCircle(Circle circle);
    void VisitRectangle(Rectangle rectangle);
}
```

---

# Element Interface

```csharp
public interface IShape
{
    void Accept(IShapeVisitor visitor);
}
```

---

# Concrete Elements

### Circle

```csharp
public class Circle : IShape
{
    public double Radius { get; set; }

    public Circle(double radius)
    {
        Radius = radius;
    }

    public void Accept(IShapeVisitor visitor)
    {
        visitor.VisitCircle(this);
    }
}
```

---

### Rectangle

```csharp
public class Rectangle : IShape
{
    public double Width { get; set; }
    public double Height { get; set; }

    public Rectangle(double width, double height)
    {
        Width = width;
        Height = height;
    }

    public void Accept(IShapeVisitor visitor)
    {
        visitor.VisitRectangle(this);
    }
}
```

---

# Concrete Visitor

مثلاً **محاسبه مساحت**

```csharp
public class AreaCalculator : IShapeVisitor
{
    public void VisitCircle(Circle circle)
    {
        double area = Math.PI * circle.Radius * circle.Radius;
        Console.WriteLine($"Circle Area: {area}");
    }

    public void VisitRectangle(Rectangle rectangle)
    {
        double area = rectangle.Width * rectangle.Height;
        Console.WriteLine($"Rectangle Area: {area}");
    }
}
```

---

# استفاده

```csharp
class Program
{
    static void Main()
    {
        List<IShape> shapes = new List<IShape>
        {
            new Circle(5),
            new Rectangle(4,6)
        };

        IShapeVisitor visitor = new AreaCalculator();

        foreach (var shape in shapes)
        {
            shape.Accept(visitor);
        }
    }
}
```

# مزایا

- اضافه کردن عملیات جدید بدون تغییر کلاس‌ها
- رعایت **Open/Closed Principle**
- جداسازی عملیات از ساختار داده

---

# معایب

- اضافه شدن یک **Element جدید** سخت است (باید همه visitorها تغییر کنند)
- پیچیدگی بیشتر
- coupling بین visitor و element

---

- **Document object models**
