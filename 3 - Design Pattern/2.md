فقط **یک instance** از یک کلاس در کل برنامه وجود دارد.

مثال:

```csharp

public class Logger
{
    private static Logger instance;

    private Logger() { }

    public static Logger Instance
    {
        get
        {
            if (instance == null)
                instance = new Logger();

            return instance;
        }
    }
}


```
