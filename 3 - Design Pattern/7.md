الگوی **Adapter** یک الگوی طراحی از نوع **Structural** است که برای **سازگار کردن دو اینترفیس ناسازگار** استفاده می‌شود تا بتوانند با هم کار کنند.

ایده اصلی:  
وقتی یک کلاس داریم که **اینترفیس آن با چیزی که برنامه انتظار دارد متفاوت است**، یک **Adapter** می‌سازیم که بین این دو واسطه شود.

در واقع Adapter مثل **مبدل برق** عمل می‌کند.

مثال واقعی:  
- پریز برق اروپا  
- دوشاخه آمریکا  
برای اتصال، از **Adapter** استفاده می‌کنیم.

---

# ساختار الگو

اجزای اصلی:

- **Target** → اینترفیس مورد انتظار برنامه  
- **Adaptee** → کلاسی که می‌خواهیم از آن استفاده کنیم ولی اینترفیسش متفاوت است  
- **Adapter** → کلاسی که Adaptee را به Target تبدیل می‌کند  
- **Client** → برنامه‌ای که از Target استفاده می‌کند

---

# مثال در C#

فرض کنید سیستم ما انتظار دارد با این اینترفیس کار کند:

## Target

```csharp
public interface IPaymentProcessor
{
    void Pay(int amount);
}
```

---

اما یک سرویس قدیمی داریم که این متد را دارد:

## Adaptee

```csharp
public class OldPaymentGateway
{
    public void MakePayment(int money)
    {
        Console.WriteLine($"Paid {money} using old gateway");
    }
}
```

مشکل:  
سیستم ما متد `Pay()` می‌خواهد، ولی کلاس قدیمی `MakePayment()` دارد.

---

# Adapter

```csharp
public class PaymentAdapter : IPaymentProcessor
{
    private OldPaymentGateway oldGateway;

    public PaymentAdapter(OldPaymentGateway gateway)
    {
        oldGateway = gateway;
    }

    public void Pay(int amount)
    {
        oldGateway.MakePayment(amount);
    }
}
```

---

# استفاده

```csharp
class Program
{
    static void Main()
    {
        OldPaymentGateway oldGateway = new OldPaymentGateway();

        IPaymentProcessor payment = new PaymentAdapter(oldGateway);

        payment.Pay(100);
    }
}
```

خروجی:

```
Paid 100 using old gateway
```

---

# چه زمانی از Adapter استفاده می‌کنیم؟

وقتی:

- می‌خواهیم از یک **کتابخانه یا کلاس قدیمی** استفاده کنیم
- اینترفیس آن با سیستم ما **سازگار نیست**
- نمی‌خواهیم کد اصلی آن کلاس را تغییر دهیم

---

# انواع Adapter

### 1. Object Adapter (رایج در C#)

از **composition** استفاده می‌کند.

```
Adapter -> has Adaptee
```

مثل مثالی که بالا دیدیم.

---

### 2. Class Adapter

از **inheritance** استفاده می‌کند (در زبان‌هایی که multiple inheritance دارند).
