الگوی Adapter دو interface ناسازگار را به هم وصل می‌کند.

### مثال

یک کتابخانه قدیمی داریم:
```csharp

class OldPayment
{
    public void MakePayment() {}
}

```

ولی سیستم جدید انتظار دارد:

```markdown

IPayment

```

Adapter

```csharp

class PaymentAdapter : IPayment
{
    private OldPayment oldPayment;

    public PaymentAdapter(OldPayment oldPayment)
    {
        this.oldPayment = oldPayment;
    }

    public void Pay()
    {
        oldPayment.MakePayment();
    }
}

```
