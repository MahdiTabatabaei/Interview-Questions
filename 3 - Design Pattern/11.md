الگوی **Facade** یک الگوی طراحی از نوع **Structural** است که یک **رابط ساده و واحد** برای کار با یک **سیستم پیچیده از چند کلاس** فراهم می‌کند.

ایده اصلی:  
به‌جای اینکه Client مستقیماً با چندین کلاس پیچیده کار کند، یک **کلاس واسط (Facade)** ایجاد می‌کنیم که همه عملیات لازم را در یک متد ساده جمع می‌کند.

به بیان ساده:  
Facade مثل یک **درِ ورودی ساده برای یک سیستم پیچیده** عمل می‌کند.

---

## مثال واقعی

فرض کنید برای **روشن کردن سینمای خانگی** باید چند کار انجام شود:

- روشن کردن TV  
- روشن کردن DVD Player  
- روشن کردن Sound System  
- تنظیم صدا  

بدون Facade، کاربر باید همه این‌ها را جداگانه انجام دهد.  
با Facade فقط یک متد صدا می‌زنیم:

```
StartMovie()
```

# مثال در C#

## کلاس‌های سیستم پیچیده

### TV

```csharp
public class TV
{
    public void On()
    {
        Console.WriteLine("TV turned on");
    }
}
```

### DVDPlayer

```csharp
public class DVDPlayer
{
    public void Play()
    {
        Console.WriteLine("DVD is playing");
    }
}
```

### SoundSystem

```csharp
public class SoundSystem
{
    public void SetVolume(int level)
    {
        Console.WriteLine("Sound volume set to " + level);
    }
}
```

---

# Facade

```csharp
public class HomeTheaterFacade
{
    private TV tv;
    private DVDPlayer dvd;
    private SoundSystem sound;

    public HomeTheaterFacade(TV tv, DVDPlayer dvd, SoundSystem sound)
    {
        this.tv = tv;
        this.dvd = dvd;
        this.sound = sound;
    }

    public void WatchMovie()
    {
        tv.On();
        sound.SetVolume(10);
        dvd.Play();
    }
}
```

---

# استفاده

```csharp
class Program
{
    static void Main()
    {
        TV tv = new TV();
        DVDPlayer dvd = new DVDPlayer();
        SoundSystem sound = new SoundSystem();

        HomeTheaterFacade theater = new HomeTheaterFacade(tv, dvd, sound);

        theater.WatchMovie();
    }
}
```

خروجی:

```
TV turned on
Sound volume set to 10
DVD is playing
```

# مزایای Facade

- ساده‌سازی استفاده از سیستم‌های پیچیده  
- کاهش وابستگی Client به کلاس‌های داخلی سیستم  
- خوانایی بهتر کد  
- مدیریت بهتر لایه‌ها در سیستم

# تفاوت Facade با Adapter

**Facade**
- ساده کردن یک سیستم پیچیده
- اینترفیس جدید و ساده ارائه می‌دهد

**Adapter**
- سازگار کردن دو اینترفیس ناسازگار
