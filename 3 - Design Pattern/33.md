وقتی object **پیچیده با تنظیمات زیاد** داریم.

مثال:
```markdown

Car
  engine
  color
  gps
  sunroof

```

مثال C#
```csharp

public class Car
{
    public string Engine { get; set; }
    public string Color { get; set; }
}

```

Builder:
```csharp

public class CarBuilder
{
    private Car car = new Car();

    public CarBuilder SetEngine(string engine)
    {
        car.Engine = engine;
        return this;
    }

    public CarBuilder SetColor(string color)
    {
        car.Color = color;
        return this;
    }

    public Car Build()
    {
        return car;
    }
}

```

استفاده:
```csharp

var car = new CarBuilder()
    .SetEngine("V8")
    .SetColor("Red")
    .Build();

```
