الگوی **Composite** یک الگوی طراحی از نوع **Structural** است که اجازه می‌دهد **اشیاء منفرد (Leaf)** و **گروهی از اشیاء (Composite)** را به **صورت یکسان** مدیریت کنیم.

ایده اصلی:  
ساخت یک **ساختار درختی (Tree Structure)** که در آن:

- **Leaf** → یک شیء تکی  
- **Composite** → مجموعه‌ای از اشیاء  

و هر دو یک **اینترفیس مشترک** دارند.

به این ترتیب Client لازم نیست بداند با **یک شیء** کار می‌کند یا با **یک مجموعه از اشیاء**.

---

# مثال واقعی

ساختار **فایل سیستم**:

```
Folder
 ├── File1
 ├── File2
 └── SubFolder
      ├── File3
      └── File4
```

در اینجا:

- File → Leaf  
- Folder → Composite  

و هر دو می‌توانند عملیات مشترکی مثل **نمایش یا محاسبه حجم** داشته باشند.

---

# مثال در C#

## Component (اینترفیس مشترک)

```csharp
public interface IFileSystemItem
{
    void Display();
}
```

---

# Leaf

```csharp
public class File : IFileSystemItem
{
    private string name;

    public File(string name)
    {
        this.name = name;
    }

    public void Display()
    {
        Console.WriteLine("File: " + name);
    }
}
```

---

# Composite

```csharp
public class Folder : IFileSystemItem
{
    private string name;
    private List<IFileSystemItem> items = new List<IFileSystemItem>();

    public Folder(string name)
    {
        this.name = name;
    }

    public void Add(IFileSystemItem item)
    {
        items.Add(item);
    }

    public void Remove(IFileSystemItem item)
    {
        items.Remove(item);
    }

    public void Display()
    {
        Console.WriteLine("Folder: " + name);

        foreach (var item in items)
        {
            item.Display();
        }
    }
}
```

---

# استفاده

```csharp
class Program
{
    static void Main()
    {
        File file1 = new File("file1.txt");
        File file2 = new File("file2.txt");

        Folder folder = new Folder("Documents");
        folder.Add(file1);
        folder.Add(file2);

        Folder mainFolder = new Folder("Root");
        mainFolder.Add(folder);

        mainFolder.Display();
    }
}
```

خروجی:

```
Folder: Root
Folder: Documents
File: file1.txt
File: file2.txt
```

---

# ساختار الگو

- **Component** → اینترفیس مشترک  
- **Leaf** → عنصر تکی  
- **Composite** → مجموعه‌ای از Component ها  
- **Client** → با Component کار می‌کند

---

# مزایای Composite

- مدیریت **اشیاء تکی و گروهی به شکل یکسان**
- مناسب برای **ساختارهای درختی**
- ساده‌تر شدن کد Client

---

# مثال‌های واقعی

- **File System** (Folder / File)
- **UI Components** (Panel / Button / TextBox)
- **Organization Structure** (Manager / Employee)
- **Menu System** (Menu / MenuItem)
