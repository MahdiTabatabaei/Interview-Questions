الگوی **Interpreter** یک الگوی طراحی از نوع **Behavioral** است که برای **تفسیر (interpret) یک زبان یا گرامر خاص** استفاده می‌شود.

ایده اصلی:  
یک **زبان ساده** تعریف می‌کنیم و سپس برای هر قانون گرامری یک کلاس می‌سازیم که بتواند آن را **تفسیر و اجرا کند**.

به بیان ساده‌تر:  
اگر برنامه‌ای داشته باشیم که باید **عبارات یا دستورات یک زبان خاص را تجزیه و اجرا کند**، از Interpreter استفاده می‌کنیم.

---

## ساختار الگو

اجزای اصلی:

- **AbstractExpression** → اینترفیس تفسیر
- **TerminalExpression** → تفسیر عناصر پایه
- **NonTerminalExpression** → ترکیب چند expression
- **Context** → اطلاعات موردنیاز برای تفسیر
- **Client** → ساخت درخت expression

---

## مثال ساده

فرض کنید می‌خواهیم یک زبان بسیار ساده برای **عبارات منطقی** بسازیم:

```
John AND Mary
```

یعنی بررسی کنیم آیا هر دو در لیست افراد وجود دارند یا نه.

---

## Abstract Expression

```csharp
public interface IExpression
{
    bool Interpret(string context);
}
```

---

## Terminal Expression

```csharp
public class TerminalExpression : IExpression
{
    private string data;

    public TerminalExpression(string data)
    {
        this.data = data;
    }

    public bool Interpret(string context)
    {
        return context.Contains(data);
    }
}
```

---

## Non-Terminal Expression (AND)

```csharp
public class AndExpression : IExpression
{
    private IExpression expr1;
    private IExpression expr2;

    public AndExpression(IExpression expr1, IExpression expr2)
    {
        this.expr1 = expr1;
        this.expr2 = expr2;
    }

    public bool Interpret(string context)
    {
        return expr1.Interpret(context) && expr2.Interpret(context);
    }
}
```

---

## استفاده

```csharp
class Program
{
    static void Main()
    {
        IExpression john = new TerminalExpression("John");
        IExpression mary = new TerminalExpression("Mary");

        IExpression johnAndMary = new AndExpression(john, mary);

        Console.WriteLine(johnAndMary.Interpret("John Mary"));
        Console.WriteLine(johnAndMary.Interpret("John"));
    }
}
```

خروجی:

```
True
False
```

توضیح:

- در `"John Mary"` هر دو وجود دارند → True  
- در `"John"` فقط یکی وجود دارد → False

## چه زمانی استفاده می‌شود؟

وقتی:

- یک **زبان کوچک یا DSL** داریم
- باید **عبارات را تفسیر کنیم**
- قوانین گرامری مشخص داریم

## محدودیت‌ها

این الگو وقتی زبان **بزرگ و پیچیده** شود مناسب نیست، چون:

- تعداد کلاس‌ها بسیار زیاد می‌شود
- نگهداری سخت می‌شود
