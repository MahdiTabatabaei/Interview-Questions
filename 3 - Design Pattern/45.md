تعریف **Active Record** یک الگوی معماری است که در آن **هر مدل (Entity)** هم **دادهٔ خودش** را نگه می‌دارد و هم **عملیات دیتابیسی مربوط به خودش** را انجام می‌دهد (CRUD داخل خود کلاس قرار می‌گیرد).

این الگو ساده است اما باعث **مخلوط شدن منطق دامنه با منطق دیتابیس** می‌شود.

---

# مفهوم Active Record  
هر شیء:

- خودش را **Insert** می‌کند  
- خودش را **Update** می‌کند  
- خودش را **Delete** می‌کند  
- خودش اطلاعات را از DB **Load** می‌کند  

در واقع **Model = Table** و **Object = Row**.

---

# مثال Active Record در C# (ساده)

فرض کنید یک جدول Users داریم.

```csharp
public class User
{
    public int Id { get; set; }
    public string Name { get; set; }

    // شبیه ORM هستند اما در ActiveRecord داخل مدل قرار دارند
    public void Save()
    {
        using var conn = new SqlConnection("connection-string");
        conn.Open();

        if (Id == 0)
        {
            var cmd = new SqlCommand(
                "INSERT INTO Users(Name) VALUES (@Name); SELECT SCOPE_IDENTITY()", conn);
            cmd.Parameters.AddWithValue("@Name", Name);

            Id = Convert.ToInt32(cmd.ExecuteScalar());
        }
        else
        {
            var cmd = new SqlCommand(
                "UPDATE Users SET Name=@Name WHERE Id=@Id", conn);
            cmd.Parameters.AddWithValue("@Name", Name);
            cmd.Parameters.AddWithValue("@Id", Id);

            cmd.ExecuteNonQuery();
        }
    }

    public void Delete()
    {
        using var conn = new SqlConnection("connection-string");
        conn.Open();

        var cmd = new SqlCommand("DELETE FROM Users WHERE Id=@Id", conn);
        cmd.Parameters.AddWithValue("@Id", Id);
        cmd.ExecuteNonQuery();
    }

    public static User Find(int id)
    {
        using var conn = new SqlConnection("connection-string");
        conn.Open();

        var cmd = new SqlCommand("SELECT * FROM Users WHERE Id=@Id", conn);
        cmd.Parameters.AddWithValue("@Id", id);

        using var rdr = cmd.ExecuteReader();
        if (!rdr.Read()) return null;

        return new User
        {
            Id = (int)rdr["Id"],
            Name = (string)rdr["Name"]
        };
    }
}
```

---

# استفاده

```csharp
var user = new User { Name = "Ali" };
user.Save();     // Insert

user.Name = "Ali Reza";
user.Save();     // Update

var loaded = User.Find(1);  // Load user

loaded.Delete();            // Delete
```

# نمونه مشهور Active Record  
در دنیای .NET خیلی کم‌استفاده است، اما در:

- **Ruby on Rails → ActiveRecord**
- **PHP Laravel → Eloquent (تقریباً Active Record)**  

این الگو بسیار رایج است.

---

# مزایا  
- پیاده‌سازی ساده  
- مناسب برای پروژه‌های کوچک  
- مدل‌ها مستقیماً CRUD دارند  
- شی‌گرایی ساده و قابل فهم

---

# معایب  
- **Violation of SRP**: مدل هم داده دارد و هم logic دیتابیس  
- تست‌نویسی سخت  
- مناسب نبودن برای دامنه‌های پیچیده (DDD)  
- وابستگی مدل به DB

---

# خلاصه در یک جمله  

درواقع **Active Record یعنی مدل‌ها مستقیماً مسئول عملیات دیتابیسی خودشان باشند (CRUD داخل مدل).**
