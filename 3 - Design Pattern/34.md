کپی کردن object به جای ساختن آن از صفر.

مناسب زمانی که:
```markdown

object creation expensive

```

مثال C#
```csharp

public class Document : ICloneable
{
    public string Text { get; set; }

    public object Clone()
    {
        return this.MemberwiseClone();
    }
}

```

استفاده:

```csharp

var copy = (Document)original.Clone();

```
