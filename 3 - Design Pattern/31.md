الگوی Singleton در برخی موارد مشکل ایجاد می‌کند.

### مشکلات

**1. Global State**

همه جای سیستم به آن دسترسی دارند.

**2. تست سخت**

درواقع Mock کردن دشوار است.

**3. coupling بالا**

کدها به singleton وابسته می‌شوند.

### مثال مشکل

اگر Logger به DB وصل شود:
```markdown

Singleton Logger → DB

```
در تست‌ها دردسر ایجاد می‌کند.

### راه بهتر

Dependency Injection
```csharp

services.AddSingleton<ILogger, Logger>();

```
