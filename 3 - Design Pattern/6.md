الگوی **Prototype** یک الگوی طراحی از نوع **Creational** است که برای **ساخت اشیاء جدید با کپی کردن (Clone) یک شیء موجود** استفاده می‌شود، به‌جای اینکه از ابتدا با `new` ساخته شوند.

ایده اصلی:  
اگر ساخت یک شیء **هزینه‌بر یا پیچیده** باشد، می‌توان یک نمونه از آن را ساخت و سپس **کپی آن را برای ایجاد اشیاء جدید استفاده کرد**.

---

## ساختار الگو

اجزای اصلی:

- **Prototype** : اینترفیس یا کلاس پایه که متد `Clone()` دارد  
- **ConcretePrototype** : کلاسی که عمل کپی کردن را پیاده‌سازی می‌کند  
- **Client** : از clone برای ساخت شیء جدید استفاده می‌کند

---

# مثال ساده در C#

## Prototype Interface

```csharp
public interface IPrototype
{
    IPrototype Clone();
}
```

---

## Concrete Prototype

```csharp
public class Person : IPrototype
{
    public string Name { get; set; }
    public int Age { get; set; }

    public IPrototype Clone()
    {
        return (IPrototype)this.MemberwiseClone();
    }
}
```

`MemberwiseClone()` یک متد داخلی در C# است که **کپی سطحی (Shallow Copy)** از شیء می‌سازد.

---

# استفاده

```csharp
class Program
{
    static void Main()
    {
        Person p1 = new Person();
        p1.Name = "Ali";
        p1.Age = 30;

        Person p2 = (Person)p1.Clone();
        p2.Name = "Reza";

        Console.WriteLine(p1.Name); // Ali
        Console.WriteLine(p2.Name); // Reza
    }
}
```

در اینجا:
- `p2` یک **کپی از p1** است
- ولی تغییرات روی `p2` روی `p1` تاثیر نمی‌گذارد

---

# Shallow Copy vs Deep Copy

### Shallow Copy
فقط مقادیر سطح اول کپی می‌شوند.

```csharp
MemberwiseClone()
```

اگر شیء شامل reference object باشد، همان reference کپی می‌شود.

---

### Deep Copy
تمام اشیاء داخلی هم کپی می‌شوند.

مثال:

```csharp
public class Address
{
    public string City;
}

public class Person : IPrototype
{
    public string Name;
    public Address Address;

    public IPrototype Clone()
    {
        Person clone = (Person)this.MemberwiseClone();
        clone.Address = new Address { City = this.Address.City };
        return clone;
    }
}
```

# مثال کاربردی

فرض کنید در یک بازی:

- دشمن‌ها تنظیمات پیچیده دارند
- ساخت هر دشمن زمان‌بر است

می‌توان یک **enemy prototype** ساخت و بعد clone کرد.

```csharp
Enemy enemy1 = new Enemy();
Enemy enemy2 = enemy1.Clone();
Enemy enemy3 = enemy1.Clone();
```

---

# مزایای Prototype

- کاهش هزینه ساخت اشیاء پیچیده
- حذف وابستگی به کلاس‌های مشخص
- ساخت سریع نسخه‌های جدید از یک شیء

---

# تفاوت با Factory

- **Factory** → شیء جدید از صفر ساخته می‌شود  
- **Prototype** → شیء با **کپی کردن نمونه موجود** ساخته می‌شود
