درواقع **Repository Pattern** یک الگوی طراحی (معمولاً در لایه Data Access) است که **منطق دسترسی به داده‌ها را از بقیه برنامه جدا می‌کند**.  

به زبان ساده:  
به‌جای اینکه در سرویس‌ها یا کنترلرها مستقیم با **Entity Framework / SQL / Database** کار کنیم، یک **Repository** واسط قرار می‌دهیم که عملیات دیتابیس را انجام می‌دهد.

---

# مشکل بدون Repository

مثلاً در Service مستقیم با DbContext کار می‌کنیم:

```csharp
public class ProductService
{
    private readonly AppDbContext _context;

    public ProductService(AppDbContext context)
    {
        _context = context;
    }

    public List<Product> GetProducts()
    {
        return _context.Products.ToList();
    }
}
```

مشکل‌ها:

- وابستگی مستقیم به **Entity Framework**
- تست کردن سخت می‌شود
- منطق دسترسی به داده در کل پروژه پخش می‌شود

---

# راه‌حل Repository Pattern

یک لایه بین **Business Logic** و **Data Access** قرار می‌دهیم.

ساختار:

```
Controller
   ↓
Service
   ↓
Repository
   ↓
Database
```

---

# ساختار Repository

اجزا:

- **Entity**
- **Repository Interface**
- **Repository Implementation**

---

# مثال کامل در C#

## Entity

```csharp
public class Product
{
    public int Id { get; set; }
    public string Name { get; set; }
    public decimal Price { get; set; }
}
```

---

# Repository Interface

```csharp
public interface IProductRepository
{
    List<Product> GetAll();
    Product GetById(int id);
    void Add(Product product);
    void Delete(int id);
}
```

---

# Repository Implementation

```csharp
public class ProductRepository : IProductRepository
{
    private readonly AppDbContext _context;

    public ProductRepository(AppDbContext context)
    {
        _context = context;
    }

    public List<Product> GetAll()
    {
        return _context.Products.ToList();
    }

    public Product GetById(int id)
    {
        return _context.Products.Find(id);
    }

    public void Add(Product product)
    {
        _context.Products.Add(product);
        _context.SaveChanges();
    }

    public void Delete(int id)
    {
        var product = _context.Products.Find(id);
        if (product != null)
        {
            _context.Products.Remove(product);
            _context.SaveChanges();
        }
    }
}
```

---

# استفاده در Service

```csharp
public class ProductService
{
    private readonly IProductRepository _repository;

    public ProductService(IProductRepository repository)
    {
        _repository = repository;
    }

    public List<Product> GetProducts()
    {
        return _repository.GetAll();
    }
}
```

# Dependency Injection در ASP.NET Core

```csharp
builder.Services.AddScoped<IProductRepository, ProductRepository>();
```
