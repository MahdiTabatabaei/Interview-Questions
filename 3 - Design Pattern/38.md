الگوی Proxy یک **جایگزین برای object اصلی** است.

کاربردها:

- lazy loading
- access control
- caching
- logging

### مثال #C#
```csharp

class ImageProxy : IImage
{
    private RealImage realImage;

    public void Display()
    {
        if(realImage == null)
            realImage = new RealImage();

        realImage.Display();
    }
}

```
