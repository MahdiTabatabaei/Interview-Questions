تعریف **Specification Pattern** الگویی است برای **جدا کردن و ترکیب کردن قوانین (Business Rules / Filters)** به‌صورت قابل استفاده مجدد.

به جای اینکه شرط‌ها را داخل query یا service بنویسیم، آن‌ها را در کلاس‌های **Specification** قرار می‌دهیم.

هدف:
- reusable کردن شرط‌ها  
- ترکیب شرط‌ها (AND / OR / NOT)  
- تمیزتر شدن کد

---

# مثال ساده

فرض کنید می‌خواهیم محصولات را فیلتر کنیم.

```csharp
public class Product
{
    public string Name { get; set; }
    public decimal Price { get; set; }
    public bool InStock { get; set; }
}
```

---

# Interface Specification

```csharp
public interface ISpecification<T>
{
    bool IsSatisfiedBy(T item);
}
```

---

# Specification برای قیمت

```csharp
public class ExpensiveProductSpecification : ISpecification<Product>
{
    public bool IsSatisfiedBy(Product product)
    {
        return product.Price > 100;
    }
}
```

---

# Specification برای موجود بودن

```csharp
public class InStockSpecification : ISpecification<Product>
{
    public bool IsSatisfiedBy(Product product)
    {
        return product.InStock;
    }
}
```

---

# استفاده

```csharp
var products = new List<Product>
{
    new Product { Name = "Laptop", Price = 1500, InStock = true },
    new Product { Name = "Mouse", Price = 20, InStock = true },
    new Product { Name = "Keyboard", Price = 200, InStock = false }
};

var spec = new ExpensiveProductSpecification();

var result = products.Where(p => spec.IsSatisfiedBy(p));
```

---

# ترکیب Specification ها (AND)

می‌توانیم قوانین را ترکیب کنیم.

```csharp
public class AndSpecification<T> : ISpecification<T>
{
    private readonly ISpecification<T> _left;
    private readonly ISpecification<T> _right;

    public AndSpecification(ISpecification<T> left, ISpecification<T> right)
    {
        _left = left;
        _right = right;
    }

    public bool IsSatisfiedBy(T item)
    {
        return _left.IsSatisfiedBy(item) && _right.IsSatisfiedBy(item);
    }
}
```

استفاده:

```csharp
var spec = new AndSpecification<Product>(
    new ExpensiveProductSpecification(),
    new InStockSpecification()
);

var result = products.Where(p => spec.IsSatisfiedBy(p));
```

# مثال واقعی در .NET

در پروژه‌های **Clean Architecture / DDD** این pattern خیلی استفاده می‌شود، مخصوصاً با **EF Core**.

کتابخانه معروف:

```
Ardalis.Specification
```

نمونه:

```csharp
public class ExpensiveProductsSpec : Specification<Product>
{
    public ExpensiveProductsSpec()
    {
        Query.Where(p => p.Price > 100);
    }
}
```
