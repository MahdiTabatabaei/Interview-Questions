الگوی **Null Object** یک الگوی طراحی است که به‌جای استفاده از `null`، یک **شیء واقعی ولی بدون رفتار (do‑nothing)** برمی‌گرداند تا نیاز به بررسی‌های مکرر `null` از بین برود.

به بیان ساده:  
به‌جای اینکه بنویسیم:

```csharp
if (customer != null)
{
    customer.SendNotification();
}
```

یک **NullObject** می‌سازیم که متدها را انجام می‌دهد ولی **هیچ کاری نمی‌کند**.

---

# مشکل بدون Null Object

فرض کنید سیستم **Customer** داریم:

```csharp
public class Customer
{
    public string Name { get; set; }

    public void SendPromotion()
    {
        Console.WriteLine($"Promotion sent to {Name}");
    }
}
```

استفاده:

```csharp
Customer customer = repository.GetCustomer(id);

if (customer != null)
{
    customer.SendPromotion();
}
```

اگر در چندین جا این کار انجام شود، کد پر از **null check** می‌شود.

---

# راه‌حل با Null Object Pattern

یک کلاس می‌سازیم که همان interface یا base class را پیاده‌سازی کند ولی **هیچ کاری انجام ندهد**.

---

# ساختار

اجزا:

- **Abstract / Interface**
- **Real Object**
- **Null Object**

---

# مثال C#

### Interface

```csharp
public interface ICustomer
{
    string Name { get; }
    void SendPromotion();
}
```

---

# Real Object

```csharp
public class RealCustomer : ICustomer
{
    public string Name { get; private set; }

    public RealCustomer(string name)
    {
        Name = name;
    }

    public void SendPromotion()
    {
        Console.WriteLine($"Promotion sent to {Name}");
    }
}
```

---

# Null Object

```csharp
public class NullCustomer : ICustomer
{
    public string Name => "Guest";

    public void SendPromotion()
    {
        // do nothing
    }
}
```

---

# Repository

```csharp
public class CustomerRepository
{
    public ICustomer GetCustomer(int id)
    {
        if (id == 1)
            return new RealCustomer("Ali");

        return new NullCustomer();
    }
}
```

---

# استفاده

```csharp
class Program
{
    static void Main()
    {
        CustomerRepository repo = new CustomerRepository();

        ICustomer customer = repo.GetCustomer(2);

        Console.WriteLine(customer.Name);
        customer.SendPromotion();
    }
}
```

---

# خروجی

```
Guest
```

هیچ خطایی رخ نمی‌دهد و نیازی به `null` check نیست.

---

# مزایا

- حذف `null checks`
- جلوگیری از **NullReferenceException**
- ساده‌تر شدن کد
- رعایت **Polymorphism**

---

# معایب

- ممکن است رفتار silent ایجاد کند (بدون اینکه بفهمیم داده واقعی وجود ندارد)
- تعداد کلاس‌ها بیشتر می‌شود

---

# مثال‌های واقعی

- **Logging systems** (NullLogger)
- **Caching systems**
- **Guest User**
- **Empty collections**
- در .NET:
  
مثلاً:

```csharp
Enumerable.Empty<T>()
```

یک نوع **Null Object** محسوب می‌شود.

---

# تفاوت Null Object و null

| حالت | توضیح |
|---|---|
| null | هیچ شیئی وجود ندارد |
| Null Object | یک شیء واقعی ولی بدون رفتار |
