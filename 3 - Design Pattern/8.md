الگوی **Bridge** یک الگوی طراحی از نوع **Structural** است که برای **جدا کردن Abstraction از Implementation** استفاده می‌شود تا بتوان هر دو را **مستقل از هم تغییر داد**.

ایده اصلی:  
اگر یک کلاس دو بُعد تغییر داشته باشد (مثلاً **نوع دستگاه** و **نوع پیاده‌سازی**)، به‌جای ایجاد تعداد زیادی کلاس با inheritance، آن‌ها را با **Bridge** از هم جدا می‌کنیم.

به‌عبارت ساده:  
Bridge باعث می‌شود **دو سلسله‌مراتب مستقل داشته باشیم که با composition به هم وصل شده‌اند.**

---

# مشکل بدون Bridge

فرض کنید یک سیستم **Remote Control** داریم برای دستگاه‌های مختلف:

- TV
- Radio

و دو نوع ریموت داریم:

- BasicRemote
- AdvancedRemote

اگر از inheritance استفاده کنیم:

```
BasicRemoteTV
AdvancedRemoteTV
BasicRemoteRadio
AdvancedRemoteRadio
```

تعداد کلاس‌ها سریع زیاد می‌شود.

---

# راه‌حل Bridge

دو hierarchy جدا می‌کنیم:

- **Abstraction → Remote**
- **Implementation → Device**

و آن‌ها را با **composition** به هم وصل می‌کنیم.

---

# مثال در C#

## Implementation

```csharp
public interface IDevice
{
    void TurnOn();
    void TurnOff();
}
```

---

## Concrete Implementations

```csharp
public class TV : IDevice
{
    public void TurnOn()
    {
        Console.WriteLine("TV is ON");
    }

    public void TurnOff()
    {
        Console.WriteLine("TV is OFF");
    }
}

public class Radio : IDevice
{
    public void TurnOn()
    {
        Console.WriteLine("Radio is ON");
    }

    public void TurnOff()
    {
        Console.WriteLine("Radio is OFF");
    }
}
```

---

# Abstraction

```csharp
public class RemoteControl
{
    protected IDevice device;

    public RemoteControl(IDevice device)
    {
        this.device = device;
    }

    public void TurnOn()
    {
        device.TurnOn();
    }

    public void TurnOff()
    {
        device.TurnOff();
    }
}
```

---

# Refined Abstraction

```csharp
public class AdvancedRemoteControl : RemoteControl
{
    public AdvancedRemoteControl(IDevice device) : base(device) { }

    public void Mute()
    {
        Console.WriteLine("Device muted");
    }
}
```

---

# استفاده

```csharp
class Program
{
    static void Main()
    {
        IDevice tv = new TV();
        RemoteControl remote = new RemoteControl(tv);

        remote.TurnOn();
        remote.TurnOff();

        IDevice radio = new Radio();
        AdvancedRemoteControl advanced = new AdvancedRemoteControl(radio);

        advanced.TurnOn();
        advanced.Mute();
    }
}
```

خروجی:

```
TV is ON
TV is OFF
Radio is ON
Device muted
```

---

# مزایای Bridge

- جلوگیری از **انفجار تعداد کلاس‌ها**
- **Abstraction و Implementation مستقل تغییر می‌کنند**
- استفاده از **composition به‌جای inheritance**

---

# تفاوت Bridge با Adapter

- **Adapter**  
  برای سازگار کردن **دو اینترفیس ناسازگار** استفاده می‌شود.

- **Bridge**  
  برای **جدا کردن abstraction از implementation** در طراحی سیستم استفاده می‌شود.

---

# مثال واقعی

مثلاً در یک سیستم پرداخت:

Abstraction:
- Payment

Implementation:
- PayPal
- Stripe
- Zarinpal

Bridge اجازه می‌دهد:

```
OnlinePayment + PayPal
OnlinePayment + Stripe
MobilePayment + PayPal
```

بدون ساخت تعداد زیادی کلاس.
