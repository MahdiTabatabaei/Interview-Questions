یک interface ساده برای سیستم پیچیده فراهم می‌کند.

### مثال

پردازش سفارش شامل:

```markdown

PaymentService
InventoryService
ShippingService

```

Facade:
```csharp

class OrderFacade
{
    public void PlaceOrder()
    {
        Payment.Pay();
        Inventory.Reserve();
        Shipping.Ship();
    }
}

```

کاربر فقط:
```markdown

PlaceOrder()

```
