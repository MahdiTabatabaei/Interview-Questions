الگوی Strategy اجازه می‌دهد **الگوریتم را قابل تعویض کنیم**.

### مثال پرداخت

```markdown

CreditCard
Paypal
Crypto

```
C#

```csharp

public interface IPaymentStrategy
{
    void Pay();
}

```

استراتژی‌ها:
```csharp

class CreditCardPayment : IPaymentStrategy
{
    public void Pay() => Console.WriteLine("Pay by card");
}

```

استفاده:
```csharp

class PaymentService
{
    private IPaymentStrategy strategy;

    public PaymentService(IPaymentStrategy strategy)
    {
        this.strategy = strategy;
    }

    public void Pay() => strategy.Pay();
}

```
