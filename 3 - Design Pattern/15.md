الگوی **Command** یک الگوی طراحی از نوع **Behavioral** است که در آن **یک درخواست به‌صورت یک شیء (Command Object)** کپسوله می‌شود.

به زبان ساده:  
به‌جای اینکه یک متد را مستقیم صدا بزنیم، **درخواست را داخل یک شیء قرار می‌دهیم** و بعد آن شیء را اجرا می‌کنیم.

این کار باعث می‌شود بتوانیم:

- درخواست‌ها را صف‌بندی کنیم  
- Undo/Redo داشته باشیم  
- Logging انجام دهیم  
- درخواست‌ها را به‌صورت داینامیک اجرا کنیم

---

# ایده اصلی

به‌جای این:

```
Light.TurnOn();
```

یک **Command** می‌سازیم:

```
TurnOnCommand.Execute();
```

---

# ساختار الگو

اجزا:

- **Command** → اینترفیس اجرای دستور  
- **ConcreteCommand** → پیاده‌سازی دستور  
- **Receiver** → شیء واقعی که کار را انجام می‌دهد  
- **Invoker** → شیئی که دستور را اجرا می‌کند  
- **Client** → سازنده Command

---

# مثال ساده (کنترل روشنایی)

فرض کنید یک **ریموت کنترل** داریم که چراغ را روشن یا خاموش می‌کند.

---

# Receiver

```csharp
public class Light
{
    public void TurnOn()
    {
        Console.WriteLine("Light is ON");
    }

    public void TurnOff()
    {
        Console.WriteLine("Light is OFF");
    }
}
```

---

# Command Interface

```csharp
public interface ICommand
{
    void Execute();
}
```

---

# Concrete Command (روشن کردن)

```csharp
public class TurnOnCommand : ICommand
{
    private Light light;

    public TurnOnCommand(Light light)
    {
        this.light = light;
    }

    public void Execute()
    {
        light.TurnOn();
    }
}
```

---

# Concrete Command (خاموش کردن)

```csharp
public class TurnOffCommand : ICommand
{
    private Light light;

    public TurnOffCommand(Light light)
    {
        this.light = light;
    }

    public void Execute()
    {
        light.TurnOff();
    }
}
```

---

# Invoker (ریموت کنترل)

```csharp
public class RemoteControl
{
    private ICommand command;

    public void SetCommand(ICommand command)
    {
        this.command = command;
    }

    public void PressButton()
    {
        command.Execute();
    }
}
```

---

# استفاده

```csharp
class Program
{
    static void Main()
    {
        Light light = new Light();

        ICommand turnOn = new TurnOnCommand(light);
        ICommand turnOff = new TurnOffCommand(light);

        RemoteControl remote = new RemoteControl();

        remote.SetCommand(turnOn);
        remote.PressButton();

        remote.SetCommand(turnOff);
        remote.PressButton();
    }
}
```

خروجی:

```
Light is ON
Light is OFF
```

# مزایای Command

- **Decoupling** بین فرستنده و گیرنده
- امکان **Undo / Redo**
- امکان **Queue و Scheduling**
- قابل گسترش بودن

# مثال‌های واقعی

این الگو خیلی در سیستم‌های واقعی استفاده می‌شود:

- **Undo/Redo در Text Editor**
- **Menu Actions در UI**
- **Job Queue**
- **Task Scheduler**
