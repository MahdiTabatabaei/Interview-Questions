الگوی **Iterator** یک الگوی طراحی از نوع **Behavioral** است که به ما اجازه می‌دهد **بدون اینکه ساختار داخلی یک مجموعه (Collection) را بدانیم، عناصر آن را یکی‌یکی پیمایش کنیم**.

به بیان ساده:  
Iterator یک **مکانیزم استاندارد برای حرکت روی عناصر یک مجموعه** فراهم می‌کند.

مثلاً بتوانیم روی موارد زیر loop بزنیم بدون اینکه بدانیم داخلشان چگونه ذخیره شده‌اند:

- List  
- Array  
- Tree  
- Stack  
- Custom Collection  

---

## ایده اصلی

به‌جای اینکه Client مستقیماً به ساختار داخلی Collection دسترسی داشته باشد، یک **Iterator** از آن می‌گیریم.

```
Collection → Iterator → Elements
```

---

## ساختار الگو

اجزا:

- **Iterator** → اینترفیس پیمایش
- **ConcreteIterator** → پیاده‌سازی iterator
- **Aggregate** → اینترفیس مجموعه
- **ConcreteAggregate** → مجموعه واقعی
- **Client**

# مثال در C#

فرض کنید یک **کتابخانه کتاب** داریم و می‌خواهیم روی کتاب‌ها حرکت کنیم.

---

## کلاس Book

```csharp
public class Book
{
    public string Title { get; set; }

    public Book(string title)
    {
        Title = title;
    }
}
```

---

## Iterator Interface

```csharp
public interface IIterator
{
    bool HasNext();
    Book Next();
}
```

---

## Concrete Iterator

```csharp
public class BookIterator : IIterator
{
    private List<Book> books;
    private int position = 0;

    public BookIterator(List<Book> books)
    {
        this.books = books;
    }

    public bool HasNext()
    {
        return position < books.Count;
    }

    public Book Next()
    {
        return books[position++];
    }
}
```

---

## Collection

```csharp
public class BookCollection
{
    private List<Book> books = new List<Book>();

    public void AddBook(Book book)
    {
        books.Add(book);
    }

    public IIterator CreateIterator()
    {
        return new BookIterator(books);
    }
}
```

---

# استفاده

```csharp
class Program
{
    static void Main()
    {
        BookCollection collection = new BookCollection();

        collection.AddBook(new Book("Clean Code"));
        collection.AddBook(new Book("Design Patterns"));
        collection.AddBook(new Book("Refactoring"));

        IIterator iterator = collection.CreateIterator();

        while (iterator.HasNext())
        {
            Book book = iterator.Next();
            Console.WriteLine(book.Title);
        }
    }
}
```

خروجی:

```
Clean Code
Design Patterns
Refactoring
```

# مزایای Iterator

- **مخفی کردن ساختار داخلی Collection**
- امکان داشتن **چند نوع traversal**
- ساده شدن کد Client
- رعایت اصل **Single Responsibility**

# مثال واقعی در C#

در .NET این الگو **به‌صورت built-in وجود دارد**.

اینترفیس‌ها:

```
IEnumerable
IEnumerator
```

مثال:

```csharp
List<int> numbers = new List<int> {1,2,3};

foreach(var n in numbers)
{
    Console.WriteLine(n);
}
```

در واقع `foreach` از **Iterator Pattern** استفاده می‌کند.
