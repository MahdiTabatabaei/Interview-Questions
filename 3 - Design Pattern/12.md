الگوی **Flyweight** یک الگوی طراحی از نوع **Structural** است که برای **کاهش مصرف حافظه** در زمانی استفاده می‌شود که تعداد زیادی شیء مشابه در برنامه داریم.

ایده اصلی:  
به‌جای ساختن هزاران شیء مشابه، **بخش‌های مشترک بین اشیاء را به اشتراک می‌گذاریم**.

یعنی:

- داده‌های **مشترک (Shared / Intrinsic State)** یک بار ذخیره می‌شوند.
- داده‌های **متغیر (Extrinsic State)** هنگام استفاده ارسال می‌شوند.

به این شکل حافظه بسیار کمتر مصرف می‌شود.

---

# مثال ساده

فرض کنید در یک بازی جنگی **۱۰۰۰۰ درخت** داریم.

اگر برای هر درخت یک شیء کامل بسازیم:

```
Tree
- type
- texture
- color
- position
```

بخش‌های زیر برای همه درخت‌ها مشترک است:

```
type
texture
color
```

اما این مورد متفاوت است:

```
position
```

در Flyweight:

- اطلاعات مشترک فقط **یک بار** ذخیره می‌شود.
- موقع رسم درخت، **position** به آن داده می‌شود.

---

# ساختار Flyweight

اجزای اصلی:

- **Flyweight** → اینترفیس مشترک
- **ConcreteFlyweight** → داده‌های مشترک
- **FlyweightFactory** → مدیریت و اشتراک اشیاء
- **Client** → ارسال state خارجی

---

# مثال در C#

## Flyweight

```csharp
public class TreeType
{
    private string name;
    private string color;

    public TreeType(string name, string color)
    {
        this.name = name;
        this.color = color;
    }

    public void Draw(int x, int y)
    {
        Console.WriteLine($"Drawing {name} tree in {color} at ({x},{y})");
    }
}
```

---

# Flyweight Factory

```csharp
public class TreeFactory
{
    private static Dictionary<string, TreeType> treeTypes = new Dictionary<string, TreeType>();

    public static TreeType GetTreeType(string name, string color)
    {
        string key = name + color;

        if (!treeTypes.ContainsKey(key))
        {
            treeTypes[key] = new TreeType(name, color);
        }

        return treeTypes[key];
    }
}
```

---

# Context (شیء واقعی در جنگل)

```csharp
public class Tree
{
    private int x;
    private int y;
    private TreeType type;

    public Tree(int x, int y, TreeType type)
    {
        this.x = x;
        this.y = y;
        this.type = type;
    }

    public void Draw()
    {
        type.Draw(x, y);
    }
}
```

---

# استفاده

```csharp
class Program
{
    static void Main()
    {
        List<Tree> forest = new List<Tree>();

        TreeType oak = TreeFactory.GetTreeType("Oak", "Green");

        forest.Add(new Tree(10, 20, oak));
        forest.Add(new Tree(15, 25, oak));
        forest.Add(new Tree(30, 40, oak));

        foreach (var tree in forest)
        {
            tree.Draw();
        }
    }
}
```

خروجی:

```
Drawing Oak tree in Green at (10,20)
Drawing Oak tree in Green at (15,25)
Drawing Oak tree in Green at (30,40)
```

در این مثال:

- فقط **یک شیء TreeType** ساخته شده
- ولی چندین **Tree** از آن استفاده می‌کنند.

---

# مزایای Flyweight

- **کاهش شدید مصرف حافظه**
- مناسب برای سیستم‌هایی با **تعداد زیاد اشیاء**
- بهبود عملکرد

---

# مثال‌های واقعی

- **Game engines** (درخت، سنگ، آبجکت‌های تکراری)
- **Text editors** (حروف مشترک)
- **Icon systems**
- **Caching objects**

---

یک نکته مهم:  
درواقع Flyweight بیشتر در **سیستم‌هایی با میلیون‌ها شیء** کاربرد دارد و در پروژه‌های معمولی خیلی رایج نیست.
