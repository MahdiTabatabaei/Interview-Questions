الگوی **Decorator** یک الگوی طراحی از نوع **Structural** است که برای **اضافه کردن رفتار (Behavior) جدید به یک شیء در زمان اجرا** بدون تغییر کلاس اصلی استفاده می‌شود.

ایده اصلی:  
به‌جای اینکه کلاس را تغییر دهیم یا از inheritance زیاد استفاده کنیم، یک **Wrapper** دور شیء می‌پیچیم و قابلیت جدید اضافه می‌کنیم.

به همین دلیل به آن **Decorator (تزئین‌کننده)** می‌گویند.

---

## مثال ساده واقعی

فرض کنید یک سیستم **قهوه** داریم.

قهوه ساده:

```
Coffee
```

حالا می‌توانیم به آن اضافه کنیم:

```
Coffee + Milk
Coffee + Sugar
Coffee + Milk + Sugar
```

بدون اینکه کلاس Coffee را تغییر دهیم.

---

# ساختار الگو

اجزای اصلی:

- **Component** → اینترفیس مشترک  
- **ConcreteComponent** → شیء اصلی  
- **Decorator** → کلاس پایه برای decorator ها  
- **ConcreteDecorator** → قابلیت‌های جدید

---

# مثال در C#

## Component

```csharp
public interface ICoffee
{
    string GetDescription();
    double GetCost();
}
```

---

# Concrete Component

```csharp
public class SimpleCoffee : ICoffee
{
    public string GetDescription()
    {
        return "Simple Coffee";
    }

    public double GetCost()
    {
        return 5.0;
    }
}
```

---

# Decorator پایه

```csharp
public abstract class CoffeeDecorator : ICoffee
{
    protected ICoffee coffee;

    public CoffeeDecorator(ICoffee coffee)
    {
        this.coffee = coffee;
    }

    public virtual string GetDescription()
    {
        return coffee.GetDescription();
    }

    public virtual double GetCost()
    {
        return coffee.GetCost();
    }
}
```

---

# Decorator اول (Milk)

```csharp
public class MilkDecorator : CoffeeDecorator
{
    public MilkDecorator(ICoffee coffee) : base(coffee) { }

    public override string GetDescription()
    {
        return coffee.GetDescription() + ", Milk";
    }

    public override double GetCost()
    {
        return coffee.GetCost() + 2;
    }
}
```

---

# Decorator دوم (Sugar)

```csharp
public class SugarDecorator : CoffeeDecorator
{
    public SugarDecorator(ICoffee coffee) : base(coffee) { }

    public override string GetDescription()
    {
        return coffee.GetDescription() + ", Sugar";
    }

    public override double GetCost()
    {
        return coffee.GetCost() + 1;
    }
}
```

---

# استفاده

```csharp
class Program
{
    static void Main()
    {
        ICoffee coffee = new SimpleCoffee();

        coffee = new MilkDecorator(coffee);
        coffee = new SugarDecorator(coffee);

        Console.WriteLine(coffee.GetDescription());
        Console.WriteLine(coffee.GetCost());
    }
}
```

خروجی:

```
Simple Coffee, Milk, Sugar
8
```

---

# مزایای Decorator

- اضافه کردن قابلیت بدون تغییر کلاس اصلی  
- جلوگیری از inheritance زیاد  
- انعطاف‌پذیری بالا  
- رعایت **Open/Closed Principle**
