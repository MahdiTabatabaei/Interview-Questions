الگوی **Memento** یک الگوی طراحی از نوع **Behavioral** است که برای **ذخیره و بازیابی وضعیت قبلی یک شیء** استفاده می‌شود، بدون اینکه جزئیات داخلی آن شیء فاش شود.

به بیان ساده:  
این الگو به ما اجازه می‌دهد **یک snapshot از وضعیت یک شیء بگیریم و بعداً آن را restore کنیم**.

---

## مثال ساده از زندگی واقعی

قابلیت **Undo / Redo** در برنامه‌ها.

مثلاً در:

- Word
- Photoshop
- Text Editor

هر بار که تغییری ایجاد می‌کنید، وضعیت قبلی ذخیره می‌شود و می‌توانید به آن برگردید.

---

## ساختار الگو

سه جزء اصلی دارد:

**1. Originator**  
شیء اصلی که وضعیت دارد و می‌تواند آن را ذخیره یا بازیابی کند.

**2. Memento**  
شیء‌ای که snapshot از وضعیت Originator را نگه می‌دارد.

**3. Caretaker**  
مسئول نگهداری mementoها (مثلاً history).

---

# مثال در C#

فرض کنید یک **TextEditor** داریم که می‌خواهیم قابلیت **Undo** داشته باشد.

---

## Memento

```csharp
public class EditorMemento
{
    public string Content { get; }

    public EditorMemento(string content)
    {
        Content = content;
    }
}
```

این کلاس وضعیت ذخیره‌شده را نگه می‌دارد.

---

## Originator

```csharp
public class TextEditor
{
    public string Content { get; set; }

    public EditorMemento Save()
    {
        return new EditorMemento(Content);
    }

    public void Restore(EditorMemento memento)
    {
        Content = memento.Content;
    }
}
```

وظیفه:

- ساخت snapshot
- بازیابی snapshot

---

## Caretaker

```csharp
public class History
{
    private Stack<EditorMemento> history = new Stack<EditorMemento>();

    public void Push(EditorMemento memento)
    {
        history.Push(memento);
    }

    public EditorMemento Pop()
    {
        return history.Pop();
    }
}
```

این کلاس **تاریخچه تغییرات** را نگه می‌دارد.

---

# استفاده

```csharp
class Program
{
    static void Main()
    {
        TextEditor editor = new TextEditor();
        History history = new History();

        editor.Content = "Hello";
        history.Push(editor.Save());

        editor.Content = "Hello World";
        history.Push(editor.Save());

        editor.Content = "Hello World!!!";
        Console.WriteLine(editor.Content);

        editor.Restore(history.Pop());
        Console.WriteLine(editor.Content);

        editor.Restore(history.Pop());
        Console.WriteLine(editor.Content);
    }
}
```
