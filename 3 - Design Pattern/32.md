تفاوت اصلی بین **Factory Method** و **Abstract Factory** در این است که چه چیزی ساخته می‌شود و ساختار کارخانه چگونه است.

- در **Factory Method**: برای ساخت **یک نوع محصول** استفاده می‌شود و تصمیم ساخت به **کلاس‌های فرزند** واگذار می‌شود.  
- در **Abstract Factory**: برای ساخت **یک خانواده از محصولات مرتبط** استفاده می‌شود.

---

# تفاوت مفهومی

**Factory Method**

- یک متد کارخانه دارد
- فقط **یک محصول** می‌سازد
- و subclass مشخص می‌کند چه چیزی ساخته شود

مثال:  
یک سیستم پیام که **Email یا SMS** می‌سازد.

---

**Abstract Factory**

- یک کارخانه شامل **چند متد ساخت** است
- **چند محصول مرتبط** می‌سازد
- هر factory یک **خانواده از محصولات سازگار** می‌سازد

مثال:  
یک سیستم UI که برای **Windows یا Mac** دکمه و چک‌باکس می‌سازد.

---

# مثال Factory Method در C#

```csharp
public interface IMessage
{
    void Send();
}

public class EmailMessage : IMessage
{
    public void Send()
    {
        Console.WriteLine("Email sent");
    }
}

public class SmsMessage : IMessage
{
    public void Send()
    {
        Console.WriteLine("SMS sent");
    }
}

public abstract class MessageFactory
{
    public abstract IMessage CreateMessage();
}

public class EmailFactory : MessageFactory
{
    public override IMessage CreateMessage()
    {
        return new EmailMessage();
    }
}

public class SmsFactory : MessageFactory
{
    public override IMessage CreateMessage()
    {
        return new SmsMessage();
    }
}
```

استفاده:

```csharp
MessageFactory factory = new EmailFactory();
IMessage message = factory.CreateMessage();
message.Send();
```

در اینجا فقط **یک نوع محصول (Message)** ساخته می‌شود.

# مثال Abstract Factory در C#

در اینجا یک کارخانه چند محصول مرتبط می‌سازد.

### Products

```csharp
public interface IButton
{
    void Render();
}

public interface ICheckbox
{
    void Render();
}
```

### Concrete Products

```csharp
public class WindowsButton : IButton
{
    public void Render() => Console.WriteLine("Windows Button");
}

public class WindowsCheckbox : ICheckbox
{
    public void Render() => Console.WriteLine("Windows Checkbox");
}
```

### Abstract Factory

```csharp
public interface IGUIFactory
{
    IButton CreateButton();
    ICheckbox CreateCheckbox();
}
```

### Concrete Factory

```csharp
public class WindowsFactory : IGUIFactory
{
    public IButton CreateButton()
    {
        return new WindowsButton();
    }

    public ICheckbox CreateCheckbox()
    {
        return new WindowsCheckbox();
    }
}
```

استفاده:

```csharp
IGUIFactory factory = new WindowsFactory();

IButton button = factory.CreateButton();
ICheckbox checkbox = factory.CreateCheckbox();
```

در اینجا یک **خانواده از محصولات مرتبط (Button + Checkbox)** ساخته می‌شود.

---

# خلاصه تفاوت‌ها

- **Factory Method**
  - ساخت یک محصول
  - تمرکز روی inheritance
  - درواقع subclass نوع شیء را تعیین می‌کند

- **Abstract Factory**
  - ساخت چند محصول مرتبط
  - تمرکز روی composition
  - یک کارخانه مجموعه‌ای از اشیاء سازگار می‌سازد

---

یک نکته مهم:  
درواقع **Abstract Factory معمولاً داخل خودش از چند Factory Method استفاده می‌کند.**
