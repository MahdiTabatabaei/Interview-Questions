الگوی **Observer** یک الگوی طراحی از نوع **Behavioral** است که در آن **یک شیء (Subject)** تغییرات خود را به مجموعه‌ای از **Observerها (مشاهده‌گرها)** اطلاع می‌دهد.

یعنی وقتی وضعیت Subject تغییر کند، همه Observerهایی که subscribe کرده‌اند **به‌صورت خودکار notification دریافت می‌کنند**.

ایده کلی:

```
Subject → notify → Observer1
                   Observer2
                   Observer3
```

---

## مثال ساده از دنیای واقعی

**سیستم خبرنامه**

- شما در یک سایت subscribe می‌کنید.
- وقتی مقاله جدید منتشر شود:
- به همه مشترکین ایمیل ارسال می‌شود.

در اینجا:

- سایت → Subject  
- کاربران → Observer

---

# ساختار الگو

اجزا:

- **Subject (Publisher)** → نگهداری لیست observerها
- **Observer (Subscriber)** → دریافت notification
- **ConcreteSubject**
- **ConcreteObserver**

---

# مثال در C#

فرض کنید یک **سیستم اطلاع‌رسانی قیمت سهام** داریم.

وقتی قیمت تغییر کند، همه سرمایه‌گذاران باید مطلع شوند.

---

## Observer Interface

```csharp
public interface IObserver
{
    void Update(float price);
}
```

---

## Subject Interface

```csharp
public interface ISubject
{
    void Attach(IObserver observer);
    void Detach(IObserver observer);
    void Notify();
}
```

---

## Concrete Subject

```csharp
public class Stock : ISubject
{
    private List<IObserver> observers = new List<IObserver>();
    private float price;

    public float Price
    {
        get { return price; }
        set
        {
            price = value;
            Notify();
        }
    }

    public void Attach(IObserver observer)
    {
        observers.Add(observer);
    }

    public void Detach(IObserver observer)
    {
        observers.Remove(observer);
    }

    public void Notify()
    {
        foreach (var observer in observers)
        {
            observer.Update(price);
        }
    }
}
```

---

## Concrete Observer

```csharp
public class Investor : IObserver
{
    private string name;

    public Investor(string name)
    {
        this.name = name;
    }

    public void Update(float price)
    {
        Console.WriteLine($"{name} notified. New price: {price}");
    }
}
```

---

# استفاده

```csharp
class Program
{
    static void Main()
    {
        Stock stock = new Stock();

        Investor ali = new Investor("Ali");
        Investor sara = new Investor("Sara");

        stock.Attach(ali);
        stock.Attach(sara);

        stock.Price = 100;
        stock.Price = 120;
    }
}
```

---

## خروجی

```
Ali notified. New price: 100
Sara notified. New price: 100
Ali notified. New price: 120
Sara notified. New price: 120
```

# مزایا

- **Loose Coupling** بین Subject و Observer
- اضافه یا حذف observer بدون تغییر Subject
- مناسب برای **event-driven systems**

---

# معایب

- اگر observerها زیاد شوند ممکن است **performance مشکل پیدا کند**
- ترتیب اجرای observerها مشخص نیست

---

# مثال واقعی در .NET

در .NET این الگو بسیار رایج است.

نمونه معروف:

**Events / Delegates**

مثال:

```csharp
public class Publisher
{
    public event Action OnChange;

    public void DoSomething()
    {
        OnChange?.Invoke();
    }
}
```

Subscriber:

```csharp
publisher.OnChange += () => Console.WriteLine("Changed!");
```
