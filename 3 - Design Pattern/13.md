الگوی **Proxy** یک الگوی طراحی از نوع **Structural** است که در آن یک **شیء واسط (Proxy)** به‌جای شیء واقعی قرار می‌گیرد و **دسترسی به شیء اصلی را کنترل می‌کند**.

به بیان ساده:  
Client به‌جای اینکه مستقیماً با **Real Object** کار کند، با **Proxy** کار می‌کند و Proxy درخواست را به شیء واقعی منتقل می‌کند.

Proxy می‌تواند کارهای اضافی انجام دهد مثل:

- کنترل دسترسی  
- Lazy Loading  
- Logging  
- Caching  
- امنیت

---

# مثال ساده

فرض کنید یک **تصویر بزرگ** داریم که بارگذاری آن از دیسک زمان‌بر است.  
به‌جای اینکه بلافاصله تصویر را لود کنیم، از **Proxy** استفاده می‌کنیم تا فقط وقتی لازم شد تصویر واقعی لود شود.

---

# ساختار الگو

اجزا:

- **Subject** → اینترفیس مشترک  
- **RealSubject** → شیء واقعی  
- **Proxy** → شیء واسط  
- **Client**

---

# مثال در C#

## Subject

```csharp
public interface IImage
{
    void Display();
}
```

---

# Real Subject

```csharp
public class RealImage : IImage
{
    private string fileName;

    public RealImage(string fileName)
    {
        this.fileName = fileName;
        LoadFromDisk();
    }

    private void LoadFromDisk()
    {
        Console.WriteLine("Loading image from disk: " + fileName);
    }

    public void Display()
    {
        Console.WriteLine("Displaying image: " + fileName);
    }
}
```

---

# Proxy

```csharp
public class ImageProxy : IImage
{
    private RealImage realImage;
    private string fileName;

    public ImageProxy(string fileName)
    {
        this.fileName = fileName;
    }

    public void Display()
    {
        if (realImage == null)
        {
            realImage = new RealImage(fileName);
        }

        realImage.Display();
    }
}
```

---

# استفاده

```csharp
class Program
{
    static void Main()
    {
        IImage image = new ImageProxy("photo.jpg");

        image.Display(); // بار اول → تصویر لود می‌شود
        image.Display(); // بار دوم → فقط نمایش
    }
}
```

خروجی:

```
Loading image from disk: photo.jpg
Displaying image: photo.jpg
Displaying image: photo.jpg
```

در اینجا:

- **ImageProxy** کنترل می‌کند که تصویر فقط **یک بار لود شود**.

# انواع Proxy

### 1. Virtual Proxy
برای **Lazy Loading**

مثال: بارگذاری تصویر بزرگ

---

### 2. Protection Proxy
برای **کنترل دسترسی**

مثال: فقط Admin بتواند عملیات خاصی انجام دهد

---

### 3. Remote Proxy
برای دسترسی به **شیء در سرور دیگر**

مثال: RPC یا Web Service

---

### 4. Smart Proxy
اضافه کردن قابلیت‌هایی مثل:

- Logging  
- Caching  
- Reference Counting

---

# مثال‌های واقعی در .NET
