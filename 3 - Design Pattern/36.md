تفاوت اصلی:  
**Inheritance (ارث‌بری)** رفتار را در **زمان کامپایل و به‌صورت ثابت** اضافه می‌کند، اما **Decorator** رفتار را در **زمان اجرا و به‌صورت داینامیک** به یک شیء اضافه می‌کند.

---

## مثال با Inheritance

فرض کنید یک قهوه داریم و می‌خواهیم ویژگی‌های مختلف به آن اضافه کنیم.

```csharp
class Coffee
{
    public virtual string GetDescription()
    {
        return "Coffee";
    }

    public virtual double Cost()
    {
        return 5;
    }
}

class MilkCoffee : Coffee
{
    public override string GetDescription()
    {
        return "Coffee + Milk";
    }

    public override double Cost()
    {
        return 7;
    }
}

class MilkSugarCoffee : Coffee
{
    public override string GetDescription()
    {
        return "Coffee + Milk + Sugar";
    }

    public override double Cost()
    {
        return 8;
    }
}
```

مشکل:  
اگر ترکیب‌ها زیاد شوند باید **کلاس‌های زیادی** بسازیم.

---

## مثال با Decorator

ابتدا یک interface:

```csharp
public interface ICoffee
{
    string GetDescription();
    double Cost();
}
```

کلاس پایه:

```csharp
public class SimpleCoffee : ICoffee
{
    public string GetDescription() => "Coffee";
    public double Cost() => 5;
}
```

Decorator پایه:

```csharp
public abstract class CoffeeDecorator : ICoffee
{
    protected ICoffee _coffee;

    public CoffeeDecorator(ICoffee coffee)
    {
        _coffee = coffee;
    }

    public virtual string GetDescription() => _coffee.GetDescription();
    public virtual double Cost() => _coffee.Cost();
}
```

Decorator برای Milk:

```csharp
public class MilkDecorator : CoffeeDecorator
{
    public MilkDecorator(ICoffee coffee) : base(coffee) { }

    public override string GetDescription()
    {
        return _coffee.GetDescription() + " + Milk";
    }

    public override double Cost()
    {
        return _coffee.Cost() + 2;
    }
}
```

Decorator برای Sugar:

```csharp
public class SugarDecorator : CoffeeDecorator
{
    public SugarDecorator(ICoffee coffee) : base(coffee) { }

    public override string GetDescription()
    {
        return _coffee.GetDescription() + " + Sugar";
    }

    public override double Cost()
    {
        return _coffee.Cost() + 1;
    }
}
```

استفاده:

```csharp
ICoffee coffee = new SimpleCoffee();
coffee = new MilkDecorator(coffee);
coffee = new SugarDecorator(coffee);

Console.WriteLine(coffee.GetDescription());
Console.WriteLine(coffee.Cost());
```

خروجی:

```
Coffee + Milk + Sugar
8
```

---

## خلاصه تفاوت

Inheritance:
- رفتار ثابت
- در زمان کامپایل مشخص می‌شود
- تعداد کلاس‌ها زیاد می‌شود

Decorator:
- رفتار قابل اضافه شدن در زمان اجرا
- انعطاف‌پذیرتر
- بدون انفجار تعداد کلاس‌ها (Class Explosion)
