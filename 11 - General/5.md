ابزار **Dapper** یک **Micro‑ORM** (Object–Relational Mapper سبک و فوق‌سریع) برای **#C** و **.NET** است که توسط تیم StackOverflow ساخته شد. هدف آن این است که **سرعت اجرای کوئری‌های SQL مثل ADO.NET** را حفظ کند، اما نوشتن کد را ساده‌تر و خواناتر کند.

در واقع Dapper یک ORM کامل مثل Entity Framework نیست؛ فقط تبدیل نتایج SQL به آبجکت‌ها را ساده می‌کند.

مزایا: سرعت بسیار بالا، کد کم، کنترل کامل روی SQL.

---

## کاربردهای Dapper

چند مورد اصلی:

- اجرای سریع کوئری‌های SQL (Select, Insert, Update, Delete)
- نگاشت نتیجه کوئری به کلاس‌های #C
- پشتیبانی از Query چندگانه، Stored Procedure، Transaction
- نگاشت چند مدل با یک کوئری (Multi‑Mapping)
- در پروژه‌هایی که EF سنگین است یا کنترل SQL مهم است

---

## مثال ساده: خواندن داده‌ها

### 1. مدل
```csharp
public class User {
    public int Id { get; set; }
    public string Name { get; set; }
}

```

### 2. اجرای یک Select
```csharp

using (var connection = new SqlConnection(connectionString))
{
    var users = connection.Query<User>("SELECT Id, Name FROM Users").ToList();
}

```

دراین _Query_ داده‌ها را خوانده و به لیست User تبدیل می‌کند.

---

## مثال Insert
```csharp

var sql = "INSERT INTO Users (Name) VALUES (@Name)";
connection.Execute(sql, new { Name = "Ali" });

```
---

## مثال Update
```csharp

var sql = "UPDATE Users SET Name = @Name WHERE Id = @Id";
connection.Execute(sql, new { Id = 1, Name = "Updated Name" });

```
---

## مثال Delete
```csharp

var sql = "DELETE FROM Users WHERE Id = @Id";
connection.Execute(sql, new { Id = 5 });

```

---
## مثال Multi‑Mapping 

فرض کنید یک کاربر چند سفارش دارد:
```csharp

var sql = @"SELECT u.Id, u.Name, o.Id, o.Title 
            FROM Users u 
            JOIN Orders o ON u.Id = o.UserId";

var result = connection.Query<User, Order, User>(
    sql,
    (user, order) => { user.Orders.Add(order); return user; },
    splitOn: "Id"
);

```

## چه زمانی Dapper انتخاب بهتری است؟

- پروژه‌هایی که **Performance اولویت بالایی** دارد
- وقتی **SQL را خودتان می‌نویسید**
- سرویس‌های کوچک، Microserviceها
- زمانی که EF سنگین یا کند است یا رفتار خودکارش مطلوب نیست
