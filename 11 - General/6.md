
ابزار **Traefik** یک **Reverse Proxy و Load Balancer مدرن** است که برای معماری‌های **Cloud‑Native، Docker و Kubernetes** طراحی شده.

به زبان ساده:

> ابزار Traefik دروازه ورود ترافیک به سیستم شماست و درخواست‌ها را به سرویس درست هدایت می‌کند.

---

# 🔎 ابزار Traefik دقیقاً چه کاری انجام می‌دهد؟

فرض کن چند میکروسرویس داری:

- user-service  
- order-service  
- payment-service  
- keycloak  

و همه داخل Kubernetes اجرا می‌شوند.

کاربر از بیرون می‌زند:

```
https://api.example.com/orders
```

وظیفه Traefik:

1. درخواست را دریافت می‌کند.
2. بررسی می‌کند مسیر `/orders` متعلق به کدام سرویس است.
3. آن را به `order-service` داخل کلاستر هدایت می‌کند.
4. پاسخ را برمی‌گرداند.

---

# 📦 مفهوم Traefik چه نوع ابزاری است؟

درواقع Traefik یک:

- ✅ Reverse Proxy  
- ✅ Load Balancer  
- ✅ Ingress Controller برای Kubernetes  
- ✅ Edge Router  

است.

---

# 🔄 مفهوم Reverse Proxy یعنی چه؟

کاربر فکر می‌کند با `api.example.com` صحبت می‌کند،  
اما در واقع پشت صحنه:

```
User → Traefik → Microservice
```

کاربر هیچ‌وقت مستقیم به Pod وصل نمی‌شود.

---

# ⚙️ کاربرد Traefik در Kubernetes

در Kubernetes معمولاً Traefik به عنوان:

```
Ingress Controller
```

نصب می‌شود.

درواقع Ingress یعنی تعریف می‌کنی:

```yaml
/orders → order-service
/users → user-service
```

ابزار Traefik این قوانین را می‌خواند و خودش تنظیم می‌شود.

---

# 🎯 ویژگی‌های مهم Traefik

### 1️⃣ Auto Service Discovery
با Kubernetes یا Docker خودش سرویس‌ها را کشف می‌کند.

### 2️⃣ Load Balancing
اگر ۵ تا Pod از order-service داشته باشی، بینشان تقسیم می‌کند.

### 3️⃣ SSL/TLS خودکار
می‌تواند با Let’s Encrypt خودش گواهی HTTPS بگیرد.

### 4️⃣ Middleware
می‌تواند:
- احراز هویت اضافه کند
- قابلیت Rate Limit بگذارد
- مقدار Header تغییر دهد
- و Redirect انجام دهد

# 📊 تفاوت Traefik با Nginx

| ویژگی | Traefik | Nginx |
|--------|----------|--------|
| مناسب Kubernetes | ✅ عالی | نیاز به تنظیم بیشتر |
| Auto Discovery | ✅ بله | ❌ معمولاً دستی |
| Config دینامیک | ✅ | معمولاً ریستارت لازم |
| Cloud Native | ✅ | قدیمی‌تر |

# 🧠 در معماری نمونه

اگر دارید:

- Kubernetes  
- ASP.NET Core microservices  
- Keycloak  
- Traefik  

معماری به این شکل است:

```
Internet
   ↓
Traefik (Ingress)
   ↓
Kubernetes Services
   ↓
Pods (ASP.NET Core APIs)
```

و بین سرویس‌ها:

```
Service Discovery توسط Kubernetes
```

- قابلیت Load Balance انجام می‌دهد
