### Pod

**Pod کوچک‌ترین واحد قابل اجرا در Kubernetes است.**

یک Pod معمولاً شامل:

- یک یا چند **Container**
- شبکه مشترک
- storage مشترک

ویژگی مهم:

تمام کانتینرهای داخل یک Pod:

- یک **IP مشترک**
- یک **network namespace مشترک**
- امکان ارتباط سریع با localhost

مثال:
```markdown

Pod
 ├─ Container (API)
 └─ Container (Logging agent)

```
معمولاً هر Pod **یک container اصلی** دارد.

### Cluster

درواقع **Cluster مجموعه‌ای از چندین سرور (Node) است که توسط Kubernetes مدیریت می‌شوند.**

ساختار ساده:
```markdown

Kubernetes Cluster
     │
 ┌─────────────┐
 │Control Plane│
 └─────────────┘
        │
 ┌────────┬────────┬────────┐
 Node 1   Node 2   Node 3
  │        │        │
 Pods     Pods     Pods

```

اجزای اصلی Cluster:

**Control Plane**

- مدیریت کل سیستم
- تصمیم‌گیری برای scheduling
- API Server
- Scheduler
- Controller Manager

**Worker Nodes**

- جایی که Podها اجرا می‌شوند.
