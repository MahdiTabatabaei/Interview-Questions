مراحل:

1️⃣ Build container
```markdown

docker build

```
2️⃣ Deploy در Kubernetes
```markdown

Deployment
Service

```
3️⃣ استفاده از **HTTP/2 capable ingress**

مثل:

- Envoy
- Istio
- Nginx (HTTP2)

نمونه Deployment:
```yaml

apiVersion: apps/v1
kind: Deployment
metadata:
  name: grpc-service
spec:
  replicas: 3
  template:
    spec:
      containers:
      - name: grpc
        image: grpcapp
        ports:
        - containerPort: 5000


```
