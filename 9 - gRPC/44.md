قوانین مهم:

✅ اضافه کردن فیلد جدید مجاز است

✅ حذف فیلد با reserved

✅ تغییر شماره فیلد ممنوع

✅ تغییر نوع داده خطرناک

مثال:
```markdown

message User {
 int32 id = 1;
 string name = 2;
}

```
نسخه جدید:
```markdown

message User {
 int32 id = 1;
 string name = 2;
 string email = 3;
}

```
