1. API عمومی (public API)
2. مرورگرها (Browser) → پشتیبانی ضعیف
3. انتقال فایل‌های بزرگ → REST بهتر است
4. نیاز به human-readable data → JSON بهتر است
5. نبود پشتیبانی HTTP/2 در شبکه قدیمی

مثال واقعی:

اگر بخواهید API برای تمام برنامه‌نویس‌ها بدهید:
```markdown

https://api.myservice.com/users

```
REST بسیار بهتر است

چون همه زبان‌ها و محیط‌ها از JSON/REST پشتیبانی دارند.
