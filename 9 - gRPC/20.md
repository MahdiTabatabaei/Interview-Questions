هر دو طرف می‌توانند **همزمان پیام بفرستند**.

proto:
```csharp

rpc Chat(stream ChatMessage) returns (stream ChatMessage);

```
C# مثال:
```csharp

var call = client.Chat();

await call.RequestStream.WriteAsync(new ChatMessage{ Text="Hello"});

```
و همزمان response دریافت می‌شود.

مثال واقعی:

- chat system
- realtime game
- live collaboration
