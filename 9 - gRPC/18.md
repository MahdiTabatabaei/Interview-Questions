Client یک request می‌فرستد

Server چند response ارسال می‌کند.

proto:
```csharp

rpc GetOrders(OrderRequest) returns (stream OrderResponse);

```
C#:
```csharp

var call = client.GetOrders(request);

await foreach (var item in call.ResponseStream.ReadAllAsync())
{
    Console.WriteLine(item.Id);
}

```
مثال واقعی:

مشاهده live stock prices.
