Streaming زمانی استفاده می‌شود که:

- حجم داده زیاد است
- پیوسته تولید می‌شود
- باید Real-time منتقل شود
- نمی‌توان همه چیز را در یک request فرستاد

سناریوهای واقعی:

- **Live Chat** → Bidirectional Streaming
- **آپلود فایل Chunk شده** → Client Streaming
- **Stock price realtime** → Server Streaming
- **موقعیت مکانی تاکسی آنلاین** → Bidirectional

مثال C# برای Server Streaming:
```csharp

var call = client.GetPrices(new PriceRequest());

await foreach (var price in call.ResponseStream.ReadAllAsync())
{
    Console.WriteLine(price.Value);
}

```
