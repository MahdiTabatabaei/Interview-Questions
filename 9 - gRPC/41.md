مرورگرها به‌طور مستقیم از **HTTP/2 full-duplex** که gRPC نیاز دارد پشتیبانی کامل ندارند.

مشکلات اصلی:

- Browser اجازه کنترل کامل HTTP/2 را نمی‌دهد
- Streaming کامل (Bidirectional) در Browser محدود است
- Binary framing در مرورگر محدود است

به همین دلیل **gRPC-Web** ساخته شد.

راه‌حل:
```markdown

Browser → gRPC-Web → Proxy (Envoy) → gRPC Server

```
مثال زندگی:

Browser مثل مشتری است که فقط زبان خاصی بلد است،

Envoy مثل مترجم بین Browser و gRPC است.
