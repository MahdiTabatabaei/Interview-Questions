سه بخش observability:

1️⃣ Logs

2️⃣ Metrics

3️⃣ Tracing

در gRPC معمولاً از:

- OpenTelemetry
- Jaeger
- Zipkin
- Prometheus

استفاده می‌شود.

نمونه C#:
```csharp

builder.Services.AddOpenTelemetry()
    .WithTracing(tracing =>
    {
        tracing.AddAspNetCoreInstrumentation();
        tracing.AddGrpcClientInstrumentation();
    });

```
