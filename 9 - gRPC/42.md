gRPC و GraphQL هر دو برای API هستند اما فلسفه متفاوت دارند.

gRPC:

- RPC based
- strongly typed
- سریع
- مناسب microservices داخلی

GraphQL:

- Query based
- client تعیین می‌کند چه داده‌ای می‌خواهد
- مناسب frontend APIs

مثال:

gRPC:
```markdown

GetUser(id)

```
GraphQL:
```markdown

query {
  user(id:1){
    name
    email
  }
}

```
GraphQL اجازه می‌دهد client دقیقاً مشخص کند چه فیلدی می‌خواهد.
