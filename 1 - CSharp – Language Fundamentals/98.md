ویژگی `ValueTask<T>` برای کاهش **Heap allocation** در async متدهایی استفاده می‌شود که معمولاً سریع و بدون `await` هستند.

اما اگر چند بار `await` یا ترکیب Taskها داشته باشید، `Task` بهتر است چون ساده‌تر و پایدارتر است.

### مثال:
```csharp

async ValueTask<int> GetNumberAsync()
{
    return 42; // نتیجه فوری، بدون نیاز به تخصیص Task جدید
}

// ولی اگر متد پیچیده بود:
async Task<int> GetNumberDelayedAsync()
{
    await Task.Delay(100);
    return 42;
}

```
