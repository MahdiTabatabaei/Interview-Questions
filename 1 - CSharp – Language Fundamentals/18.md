## Value Type

مقدار **مستقیماً در متغیر ذخیره می‌شود**.

- مقدار **خودِ داده** نگهداری می‌شود
- معمولاً در **Stack** ذخیره می‌شود
- هنگام assignment یا پاس دادن به متد، **کپی می‌شود**

مثال‌ها:

- int
- double
- bool
- struct
```csharp

int a = 5;
int b = a;

b = 10;

Console.WriteLine(a); // 5

```
کپی مقدار انجام می‌شود.

```csharp

int a = 10;
int b = a;
b = 20;

```

مقدار `a` تغییر نمی‌کند چون `b` کپی شده است.

---

## Reference Type

متغیر **reference به object در Heap** را نگه می‌دارد.

- فقط **آدرس حافظه (reference)** نگهداری می‌شود
- داده اصلی در **Heap** است
- هنگام assignment، فقط reference کپی می‌شود

مثال:
- class
- string
- array
```csharp

Person p1 = new Person();
Person p2 = p1;

```
هر دو به یک object اشاره می‌کنند.


```csharp

class Person
{
    public string Name;
}

Person p1 = new Person();
p1.Name = "Ali";

Person p2 = p1;
p2.Name = "Reza";


```

مقدار `p1.Name` هم تغییر می‌کند چون هر دو به یک object اشاره می‌کنند.
