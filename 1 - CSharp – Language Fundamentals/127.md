### زمانی که:

- وقتی struct **بزرگ** باشد (بیش از 16–24 بایت)
- و mutable باشد → می‌تواند باعث **bugs** شود
- به صورت **by-value** کپی‌های زیادی ایجاد کند → کاهش performance
- در collectionها زیاد جابه‌جا شود

## مثال اشتباه (mutable struct)
```csharp

struct MyStruct
{
    public int X;
    public void Increment() => X++;
}

```
