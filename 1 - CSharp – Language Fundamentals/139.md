### مهم‌ترین تفاوت

ابزار `BlockingCollection` **thread را block می‌کند**

اما

ابزار `Channel` **async-await friendly است**

---

### مثال BlockingCollection

```csharp

var queue = new BlockingCollection<int>();

Task.Run(() =>
{
    queue.Add(1);
    queue.Add(2);
    queue.CompleteAdding();
});

foreach (var item in queue.GetConsumingEnumerable())
{
    Console.WriteLine(item);
}

```

در اینجا thread **block می‌شود**.
