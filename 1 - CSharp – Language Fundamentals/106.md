نسخه‌ی موازی (Parallelized) از LINQ برای استفاده از چند Core CPU در یک زمان.

باعث افزایش سرعت در پردازش سنگین مجموعه‌ها.

### مثال:
```csharp

var numbers = Enumerable.Range(1, 1000000);

var results = numbers.AsParallel()   // اجرای موازی
                     .Where(n => n % 2 == 0)
                     .Select(n => n * n)
                     .ToList();

Console.WriteLine(results.Count);

```
✅ **مزیت:** به‌کارگیری همه Coreهای CPU برای تسریع محاسبات سنگین.
