متغیر `string` یک **Reference Type** است.

اما رفتار آن شبیه Value Type است چون **[[196 | Immutable]]** است.
```csharp

string a = "Ali";
string b = a;

b = "Reza";

Console.WriteLine(a); // Ali

```


### ❗ متغییر string [[196 | Immutable]] است

یعنی:

> بعد از ساخته شدن، **قابل تغییر نیست**

مثال مهم (دام مصاحبه):

```csharp

string s1 = "Hello";
string s2 = s1;

s2 = "World";



```

آیا `s1` تغییر می‌کند؟

**خیر**

چرا؟

- چون string [[196 | Immutable]] است
- یک object جدید در Heap ساخته می‌شود

این کد در واقع چه می‌کند؟

```csharp

s2 = "World";


```

✅ حافظه جدید ساخته می‌شود

✅ مقدار قبلی دست‌نخورده باقی می‌ماند

✅ یک reference جدید به `s2` داده می‌شود
