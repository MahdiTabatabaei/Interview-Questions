### Task.WhenAll:

- منتظر می‌ماند **همه** taskها تمام شوند.
- اگر **یکی** خطا دهد، exception جمعی برمی‌گرداند.

### Task.WhenAny:

- وقتی **اولین** task تمام شود، ادامه می‌دهد.
- بقیه taskها هنوز ممکن است در حال اجرا باشند.

## مثال:
```csharp

await Task.WhenAll(task1, task2); // همه باید تمام شوند

var finished = await Task.WhenAny(task1, task2); // اولی که تمام شد

```

----

نکته **`Task.WhenAny` خودش هیچ Task دیگری را Cancel نمی‌کند.**

درواقع`WhenAny` فقط **منتظر می‌ماند اولین Task تمام شود** و همان Task را برمی‌گرداند. بقیه Taskها **به اجرای خود ادامه می‌دهند** مگر اینکه خودت آن‌ها را cancel کنی.

### مثال

```csharp
var t1 = Task.Delay(1000);
var t2 = Task.Delay(5000);

var first = await Task.WhenAny(t1, t2);

Console.WriteLine("First finished");
```

بعد از 1 ثانیه:

```
t1 تمام می‌شود
WhenAny برمی‌گردد
```

اما:

```
t2 هنوز در حال اجراست
و تا 5 ثانیه ادامه می‌دهد
```

## اگر بخواهیم بقیه Cancel شوند

باید از **CancellationTokenSource** استفاده کنیم.

```csharp
var cts = new CancellationTokenSource();

var t1 = Task.Run(() => Work1(cts.Token));
var t2 = Task.Run(() => Work2(cts.Token));

var first = await Task.WhenAny(t1, t2);

cts.Cancel(); // بقیه را کنسل کن
```

و داخل Taskها:

```csharp
async Task Work1(CancellationToken token)
{
    await Task.Delay(5000, token);
}
```
