در ASP.NET Core دو کلاس مهم در شروع برنامه وجود داشتند: **Program** و **Startup**. این دو کلاس مسئول **راه‌اندازی (Bootstrapping)** و **پیکربندی برنامه** هستند.

البته از **.NET 6 به بعد** ساختار کمی تغییر کرده، ولی ابتدا مدل کلاسیک را توضیح داده می شود. 

---

# 1️⃣ کلاس Program

### تعریف
کلاس **Program** نقطه شروع اجرای برنامه است.  
مثل متد `Main` در برنامه‌های معمولی C#.

وقتی برنامه اجرا می‌شود، ابتدا این کلاس اجرا می‌شود و **Web Host** یا **Web Application** ساخته می‌شود.

### مثال (ASP.NET Core قدیمی)

```csharp
public class Program
{
    public static void Main(string[] args)
    {
        CreateHostBuilder(args).Build().Run();
    }

    public static IHostBuilder CreateHostBuilder(string[] args) =>
        Host.CreateDefaultBuilder(args)
            .ConfigureWebHostDefaults(webBuilder =>
            {
                webBuilder.UseStartup<Startup>();
            });
}
```

### وظایف Program

- نقطه شروع برنامه
- ساخت **Host**
- تنظیم Web Server (مثل Kestrel)
- معرفی کلاس **Startup**
- اجرای برنامه (`Run()`)

---

# 2️⃣ کلاس Startup

کلاس **Startup** مسئول **پیکربندی سرویس‌ها و Pipeline برنامه** است.

دو متد مهم دارد.

---

# 3️⃣ متد ConfigureServices

در این متد **Dependency Injection container** تنظیم می‌شود.

یعنی سرویس‌هایی که برنامه نیاز دارد ثبت می‌شوند.

مثال:

```csharp
public void ConfigureServices(IServiceCollection services)
{
    services.AddControllers();
    services.AddDbContext<AppDbContext>();
    services.AddScoped<IUserService, UserService>();
}
```

کارهایی که معمولاً اینجا انجام می‌شود:

- ثبت سرویس‌ها در DI
- اضافه کردن MVC یا API
- تنظیم Authentication
- تنظیم EF Core
- تنظیم CORS
- تنظیم Swagger

---

# 4️⃣ متد Configure

این متد **HTTP Request Pipeline** را می‌سازد.

Pipeline یعنی ترتیب Middlewareهایی که هر درخواست از آن‌ها عبور می‌کند.

مثال:

```csharp
public void Configure(IApplicationBuilder app, IWebHostEnvironment env)
{
    if (env.IsDevelopment())
    {
        app.UseDeveloperExceptionPage();
    }

    app.UseRouting();

    app.UseAuthentication();
    app.UseAuthorization();

    app.UseEndpoints(endpoints =>
    {
        endpoints.MapControllers();
    });
}
```

---

# 5️⃣ HTTP Pipeline چیست؟

وقتی یک Request به سرور می‌آید، از چند Middleware عبور می‌کند:

```
Request
  ↓
Middleware 1 (Logging)
  ↓
Middleware 2 (Authentication)
  ↓
Middleware 3 (Routing)
  ↓
Controller
  ↓
Response
```

این ترتیب در متد **Configure** تعیین می‌شود.

---

# 6️⃣ تفاوت Program و Startup

| ویژگی | Program | Startup |
|------|------|------|
| نقش | شروع برنامه | پیکربندی برنامه |
| مسئول | ساخت Host | تنظیم سرویس‌ها و Middleware |
| شامل | Main method | ConfigureServices + Configure |

---

# 7️⃣ تغییر در .NET 6+

از .NET 6 به بعد **Startup حذف شد** و همه چیز در Program نوشته می‌شود.

مثال:

```csharp
var builder = WebApplication.CreateBuilder(args);

builder.Services.AddControllers();

var app = builder.Build();

app.UseRouting();
app.UseAuthorization();

app.MapControllers();

app.Run();
```

این مدل را **Minimal Hosting Model** می‌گویند.

---

# 8️⃣ خلاصه ساده

- **Program** → برنامه را شروع می‌کند و Host را می‌سازد  
- **Startup** → سرویس‌ها و HTTP Pipeline را تنظیم می‌کند
