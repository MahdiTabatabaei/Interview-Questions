مثال:
```csharp

using System.Threading;
ReaderWriterLockSlim rwLock = new ReaderWriterLockSlim();

// خواندن داده
rwLock.EnterReadLock();
try { Console.WriteLine(value); }
finally { rwLock.ExitReadLock(); }

// نوشتن داده
rwLock.EnterWriteLock();
try { value = 10; }
finally { rwLock.ExitWriteLock(); }

```
