- کلمه کلیدی **ref:** متغیر **قبل** از ارسال به متد باید مقداردهی اولیه شده باشد. متد می‌تواند آن را تغییر دهد.
- کلمه کلیدی **out:** متغیر لازم نیست قبل از ارسال مقدار داشته باشد، اما متد **مجبور است** قبل از تمام شدن، به آن مقدار بدهد. (معمولاً برای متدهایی با چند خروجی استفاده می‌شود).

## کلمه کلیدی ref: مقدار باید قبل از ارسال مقدار داشته باشد

```csharp

void Increase(ref int x)
{
    x += 10;
}

int number = 5;
Increase(ref number);

Console.WriteLine(number); // 15

```
_ورودی باید مقدار اولیه داشته باشد._

---

## کلمه کلیدی out: ورودی لازم نیست مقدار اولیه داشته باشد، اما متد باید مقداردهی کند

```csharp

void GetFullName(out string name)
{
    name = "John Doe"; // مقداردهی اجباری
}

string fullName;
GetFullName(out fullName);

Console.WriteLine(fullName); // John Doe

```
