تفاوت اصلی در **نوع مقایسه‌ای است که انجام می‌دهند**.

- `IEqualityComparer` → بررسی می‌کند **دو شیء برابر هستند یا نه**
- `IComparer` → تعیین می‌کند **کدام شیء بزرگ‌تر/کوچک‌تر است (ترتیب)**

---

# IEqualityComparer

برای **برابری (Equality)** استفاده می‌شود.

دو متد اصلی دارد:

```csharp
bool Equals(T x, T y)
int GetHashCode(T obj)
```

استفاده در جاهایی مثل:

- `Dictionary`
- `HashSet`
- `Distinct`
- `GroupBy`

چون این ساختارها باید بدانند:

```
آیا این دو کلید یکسان هستند؟
```

مثال:

فرض کن می‌خواهیم مقایسه رشته‌ها **case‑insensitive** باشد.

```csharp
class CaseInsensitiveComparer : IEqualityComparer<string>
{
    public bool Equals(string x, string y)
    {
        return x.ToLower() == y.ToLower();
    }

    public int GetHashCode(string obj)
    {
        return obj.ToLower().GetHashCode();
    }
}
```

استفاده:

```csharp
var dict = new Dictionary<string, int>(new CaseInsensitiveComparer());
```

# IComparer

برای **مرتب‌سازی (Ordering)** استفاده می‌شود.

متد اصلی:

```csharp
int Compare(T x, T y)
```

مقدار بازگشتی:

```
< 0  → x کوچکتر از y
0    → برابر
> 0  → x بزرگتر از y
```

مثال:

مرتب‌سازی افراد بر اساس سن:

```csharp
class AgeComparer : IComparer<Person>
{
    public int Compare(Person x, Person y)
    {
        return x.Age.CompareTo(y.Age);
    }
}
```

استفاده:

```csharp
list.Sort(new AgeComparer());
```

# تفاوت مفهومی

**IEqualityComparer**

```
آیا این دو برابرند؟
true / false
```

استفاده در:

```
HashSet
Dictionary
Distinct
```

---

**IComparer**

```
کدام جلوتر است؟
ترتیب را تعیین می‌کند
```

استفاده در:

```
Sort
OrderBy
SortedSet
SortedDictionary
```

---

# مثال ساده

فرض کن این دو عدد را داریم:

```
5 و 10
```

**IEqualityComparer**

```
آیا 5 == 10 ؟
false
```

**IComparer**

```
5 < 10
```

---

# خلاصه کوتاه 

```
IEqualityComparer → equality comparison (Equals + GetHashCode)

IComparer → ordering comparison (Compare)
```
