یک **کتابخانه استاندارد برای اندازه‌گیری performance در .NET** است.

کاربردها:

- مقایسه الگوریتم‌ها
- بررسی مصرف حافظه
- بررسی سرعت متدها

---

### نصب

```markdown

dotnet add package BenchmarkDotNet

```
---

### مثال
```csharp

using BenchmarkDotNet.Attributes;

public class Test
{
    [Benchmark]
    public void Method1()
    {
        var x = 1 + 1;
    }
}

```
---

### اجرای benchmark
```csharp

BenchmarkRunner.Run<Test>();

```
خروجی شامل:

- Execution time
- Memory allocation
- CPU usage
