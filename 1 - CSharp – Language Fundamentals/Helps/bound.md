کلمه **bound** در انگلیسی در این نوع ترکیب‌ها معمولاً معنی **«محدود شده توسط»** یا **«وابسته به»** می‌دهد.

پس وقتی می‌گویند چیزی **CPU‑bound** است یعنی:

> سرعت اجرای آن کار بیشتر از هر چیز **به قدرت CPU محدود شده است**.

یعنی CPU عامل گلوگاه (bottleneck) است.

---

## مفهوم CPU‑bound یعنی چه؟

یک برنامه **CPU‑bound** برنامه‌ای است که بیشتر زمانش صرف **محاسبات پردازنده** می‌شود.

ویژگی‌ها:

- استفاده CPU نزدیک **100% استفاده** است
- منتظر دیسک یا شبکه نیست
- بیشتر زمان صرف **محاسبات ریاضی یا الگوریتمی** می‌شود

### مثال‌ها

- رمزنگاری
- پردازش تصویر
- رندر سه‌بعدی
- محاسبات علمی
- فشرده‌سازی فایل

مثال ساده:

```csharp
for(int i = 0; i < 1000000000; i++)
{
    result += Math.Sqrt(i);
}
```

اینجا برنامه تقریباً فقط در حال **محاسبه با CPU** است.

---

## برعکس آن: I/O‑bound

مفهوم **I/O-bound** یعنی برنامه بیشتر وقتش را **منتظر عملیات ورودی/خروجی** است.

مثل:

- خواندن از فایل
- درخواست شبکه
- دیتابیس
- فراخوانی API

مثال:

```csharp
var data = await httpClient.GetStringAsync(url);
```

اینجا CPU کار زیادی نمی‌کند، فقط **منتظر پاسخ شبکه** است.

---

## مقایسه سریع

CPU‑bound

- گلوگاه: CPU
- مصرف CPU بالا
- مثال: محاسبات سنگین

I/O‑bound

- گلوگاه: دیسک / شبکه / دیتابیس
- درواقع CPU بیشتر وقت‌ها [[idle]]
- مثال: خواندن فایل یا API

---

## یک مثال واقعی

فرض کن برنامه‌ای داری که:

1. از اینترنت عکس دانلود می‌کند  
2. روی عکس فیلتر سنگین اعمال می‌کند

قسمت‌ها:

- دانلود عکس → **I/O‑bound**
- پردازش عکس → **CPU‑bound**

---

✅ خلاصه خیلی کوتاه:

- معنای **bound = محدود شده توسط**
- معنای **CPU‑bound = سرعت برنامه به CPU محدود است**
- معنای **I/O‑bound = سرعت برنامه به عملیات ورودی/خروجی محدود است**
