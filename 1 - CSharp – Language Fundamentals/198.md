درواقه ر`finally` بخشی از ساختار مدیریت خطا است و **همیشه اجرا می‌شود**، چه exception رخ بدهد چه نه.

مثال:
```csharp

try
{
    Console.WriteLine("Try");
}
catch (Exception ex)
{
    Console.WriteLine("Catch");
}
finally
{
    Console.WriteLine("Finally");
}

```
رفتار:

- اگر خطا رخ دهد → `catch` اجرا می‌شود
- اگر خطا رخ ندهد → `catch` رد می‌شود
- **در هر دو حالت `finally` اجرا می‌شود**

معمولاً برای **آزاد کردن resource ها** استفاده می‌شود.

مثال واقعی:
```csharp

FileStream file = null;

try
{
    file = File.Open("test.txt", FileMode.Open);
}
finally
{
    if (file != null)
        file.Close();
}

```
حتی اگر وسط کار exception رخ بدهد، فایل بسته می‌شود.
