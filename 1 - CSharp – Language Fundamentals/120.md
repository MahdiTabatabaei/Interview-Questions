- متدهای **async void** نمی‌توانند با `await` منتظر پایانشان ماند.
- در صورت خطا، exception به صورت غیرقابل‌پیش‌بینی **در سطح جهانی** پراکنده می‌شود و امکان کنترل ندارد.
- فقط برای **رویدادها (Event Handlers)** کاربرد دارد.

### توصیه:

- همیشه برای متدهای async، از **`async Task`** یا **`async Task<T>`** استفاده کنید.

### مثال:
```csharp

// خطرناک!
async void ButtonClick(object sender, EventArgs e)
{
    await Task.Delay(1000);
    // اگر خطایی پیش بیاید، exception در سطح برنامه پخش می‌شود بدون کنترل
}

```
