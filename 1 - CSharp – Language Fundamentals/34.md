### مثال Dispose:
```csharp

class FileHandler : IDisposable
{
    public void Dispose()
    {
        Console.WriteLine("Dispose called");
    }
}

```

اگر این‌طور استفاده کنی:
```csharp

var f = new FileHandler();

```

و **هیچ‌وقت `Dispose()` را صدا نزنی**، وقتی GC شیء را جمع‌آوری کند:

- متد`Dispose()` اجرا **نمی‌شود**
- فقط حافظه object آزاد می‌شود.

---

## چرا؟

چون **`IDisposable` فقط یک قرارداد (interface)** است.

درواقع CLR یا GC هیچ الزامی برای صدا زدن آن ندارد.

یعنی:
```markdown

GC → حافظه را آزاد می‌کند
Dispose → باید توسط برنامه‌نویس صدا زده شود

```

---

## راه درست استفاده

معمولاً از `using` استفاده می‌کنند تا `Dispose` خودکار صدا زده شود.
```csharp

using (var f = new FileHandler())
{
    // work with file
}

```
در پایان بلاک:
```markdown

Dispose() automatically called

```
در واقع کامپایلر این را تقریباً به این تبدیل می‌کند:
```csharp

var f = new FileHandler();
try
{
}
finally
{
    if (f != null)
        f.Dispose();
}

```

---
## پس Finalizer چه ربطی دارد؟

اگر کلاس **Finalizer** داشته باشد:
```csharp

class FileHandler : IDisposable
{
    ~FileHandler()
    {
        Console.WriteLine("Finalizer");
    }

    public void Dispose()
    {
        Console.WriteLine("Dispose");
    }
}

```
آن وقت:

- اگر `Dispose()` را صدا بزنی → Finalizer معمولاً دیگر اجرا نمی‌شود (با `GC.SuppressFinalize`)
- اگر `Dispose()` صدا زده نشود → **Finalizer هنگام GC اجرا می‌شود**

---

✅ خلاصه مهم:
```markdown

GC → Dispose را صدا نمی‌زند
Dispose → باید دستی یا با using صدا زده شود
Finalizer → توسط GC اجرا می‌شود

```
