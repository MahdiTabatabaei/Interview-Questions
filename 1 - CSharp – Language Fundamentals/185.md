متدهای **GET** و **POST** دو تا از مهم‌ترین HTTP Methodها هستند که برای ارتباط بین **Client (مثل مرورگر)** و **Server (مثل API)** استفاده می‌شوند. تفاوت اصلی آن‌ها در **هدف، نحوه ارسال داده، امنیت، و رفتار در HTTP** است.

---

# تفاوت اصلی GET و POST

### GET
برای **دریافت (Read) داده از سرور** استفاده می‌شود.

مثال:
```
GET /api/products?id=10
```

---

### POST
برای **ارسال داده به سرور و ایجاد resource جدید** استفاده می‌شود.

مثال:
```
POST /api/products
```

body:
```
{
 "name":"Laptop",
 "price":1000
}
```

---

# مقایسه مهم GET و POST

## 1️⃣ هدف استفاده

**GET**
- دریافت اطلاعات
- نباید state سرور را تغییر دهد

**POST**
- ارسال داده
- ایجاد یا تغییر resource

---

## 2️⃣ محل ارسال داده

**GET**

داده داخل **URL** ارسال می‌شود:

```
/users?id=5&name=ali
```

---

**POST**

داده داخل **Body درخواست** ارسال می‌شود:

```
POST /users
Body:
{
 "name":"Ali",
 "age":25
}
```

---

## 3️⃣ محدودیت حجم داده

**GET**

محدود به طول URL است (معمولاً حدود 2000 کاراکتر).

---

**POST**

تقریباً محدودیتی ندارد و می‌تواند داده‌های بزرگ ارسال کند.

---

## 4️⃣ Cache شدن

**GET**

✅ قابل Cache شدن توسط مرورگر و Proxy

---

**POST**

❌ معمولاً Cache نمی‌شود

---

## 5️⃣ امنیت

**GET**

داده در URL دیده می‌شود:

```
example.com/login?password=123
```

پس برای اطلاعات حساس مناسب نیست.

---

**POST**

داده در **Body** ارسال می‌شود و در URL دیده نمی‌شود.  
(البته هنوز باید از **HTTPS** استفاده شود)

---

## 6️⃣ Bookmark و History

**GET**

✅ قابل ذخیره در Bookmark  
✅ در History مرورگر ذخیره می‌شود

---

**POST**

❌ معمولاً ذخیره نمی‌شود

---

## 7️⃣ Idempotent بودن

این یک مفهوم مهم در HTTP است.

### GET
✅ **Idempotent**

یعنی اگر چند بار اجرا شود نتیجه یکسان است.

```
GET /products
```

---

### POST
❌ **Idempotent نیست**

ممکن است هر بار resource جدید ایجاد کند.

```
POST /orders
```

---

# مثال در ASP.NET Core

### GET

```csharp
[HttpGet]
public IActionResult GetProduct(int id)
{
    return Ok(productService.Get(id));
}
```

---

### POST

```csharp
[HttpPost]
public IActionResult CreateProduct(ProductDto product)
{
    productService.Create(product);
    return Ok();
}
```

---

# یک مثال واقعی

### GET

درخواست گرفتن لیست کاربران:

```
GET /api/users
```

---

### POST

ساختن کاربر جدید:

```
POST /api/users
```

body:

```
{
 "name":"Ali",
 "email":"ali@test.com"
}
```

---

# خلاصه خیلی کوتاه

| ویژگی | GET | POST |
|------|-----|------|
| هدف | دریافت داده | ارسال داده |
| محل داده | URL | Body |
| امنیت | کمتر | بیشتر |
| Cache | بله | معمولاً نه |
| Idempotent | بله | نه |
