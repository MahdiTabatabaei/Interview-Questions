
اگر چند Thread همزمان از کد استفاده کنند و **هیچ [[1 - CSharp – Language Fundamentals/61| race condition]]  خطای رخ ندهد**، آن کد thread-safe است.

---

### مثال مشکل

```csharp

int counter = 0;

void Increment()
{
    counter++;
}

```
چند Thread ممکن است مقدار را خراب کنند.

---

### راه‌حل
```csharp

lock(obj)
{
    counter++;
}

```
