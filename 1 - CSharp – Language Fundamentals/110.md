وقتی یک **value type** (مثل `int`, `struct`) در قالب `object` قرار می‌گیرد، عملیات **boxing** انجام می‌شود، یعنی مقدار داخل یک شی on heap قرار می‌گیرد و بعد، اگر برعکس آن است، **unboxing**.

🔸 **مشکل:**

عملیات Boxing و Unboxing هزینه‌بر است، چون عملیات حافظه و پردازش را افزایش می‌دهد، در نتیجه کارایی کاهش می‌یابد.

### راهکارهای کاهش:

- اجتناب از تبدیل‌های unneeded (مثل `object value = 5;`)
- استفاده از **generic types** که عملیات boxing را حذف می‌کند، مانند `List<int>` بجای `ArrayList`
- در موارد حساس، عملیات‌های value type را مستقیماً انجام دهید.

### مثال:
```csharp

int num = 42;
// اینجا boxing صورت می‌گیرد
object obj = num;

```
برای اجتناب:
```csharp

List<int> numbers = new List<int>();
numbers.Add(42); // boxing نمی‌شود

```
