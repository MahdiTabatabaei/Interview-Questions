## var

نوع در **compile time** مشخص می‌شود.
```csharp

var name = "Ali";

```
معادل:
```csharp

string name = "Ali";

```
---

## dynamic

نوع در **runtime** مشخص می‌شود.
```csharp

dynamic x = 10;
x = "Hello";
x = new Person();

```
کامپایلر بررسی نمی‌کند.

---

## object

پایه همه کلاس‌ها.
```csharp

object x = 10;

```
برای استفاده باید cast کنیم.
```csharp

int y = (int)x;

```
