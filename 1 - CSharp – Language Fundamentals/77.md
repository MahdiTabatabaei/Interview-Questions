به Value Typeها (مثل `int`, `bool`, `DateTime`) اجازه می‌دهد مقدار `null` بپذیرند. در دیتابیس‌ها که فیلدها می‌توانند تهی باشند، این بسیار کاربردی است.

**مثال:**
```csharp

int? age = null; // معادل Nullable<int>
if (age.HasValue)
    Console.WriteLine(age.Value);
else
    Console.WriteLine("Age is unknown.");

// استفاده از Null-coalescing
int finalAge = age ?? 18; // اگر null بود، ۱۸ قرار بده

```
