درواقع HashSet یک **ساختار داده** در ‎.NET‎ است که مجموعه‌ای از آیتم‌ها را **بدون تکرار** ذخیره می‌کند و به‌صورت **بسیار سریع** (تقریباً زمان دسترسی O(1)) عمل می‌کند.

خلاصهٔ خیلی ساده:

تعریف **HashSet = مجموعه‌ای از آیتم‌های یکتا + سرعت بسیار بالا برای جستجو و اضافه‌کردن**

---

# مزایا و ویژگی‌ها

## 1) **آیتم تکراری قبول نمی‌کند**

اگر یک مقدار قبلاً داخلش باشد، دوباره اضافه نمی‌شود.

```csharp
var set = new HashSet<int>();
set.Add(5); // true
set.Add(5); // false (قبلاً وجود دارد)
```

---

## 2) **سرعت بسیار بالا**

بر اساس **Hashing** کار می‌کند؛  
پس عملیات‌های زیر تقریباً سریع‌ترین ممکن هستند:

- Add
- Remove
- Contains

زمان عملکرد معمولاً **O(1)** است؛  
برخلاف List که O(n) است.

---

## 3) **ترتیب ندارد**

مثل List ایندکس ندارد و ترتیب ورود آیتم‌ها را حفظ نمی‌کند.

---

## 4) مناسب برای چک‌کردن سریع وجود آیتم

پرکاربردترین سناریو:

- چک‌کردن اینکه آیتم وجود دارد یا نه
- حذف تکراری‌ها
- عملیات مجموعه‌ای (Union, Intersect, Except)

---

# مثال کاربردی

## حذف آیتم‌های تکراری از یک لیست

```csharp
var numbers = new List<int> { 1, 2, 2, 3, 4, 4, 5 };

var unique = new HashSet<int>(numbers);

foreach (var n in unique)
    Console.WriteLine(n);
```

---

# مثال: چک‌کردن خیلی سریع وجود یک مقدار

```csharp
var set = new HashSet<string>
{
    "Ali",
    "Reza",
    "Sara"
};

if (set.Contains("Sara"))
    Console.WriteLine("Found!");
```

برخلاف List، این چک کردن در HashSet سریع‌تر است.

---

# مثال: عملیات مجموعه‌ای

```csharp
var a = new HashSet<int> { 1, 2, 3, 4 };
var b = new HashSet<int> { 3, 4, 5, 6 };

a.IntersectWith(b); // فقط اشتراک‌ها را نگه می‌دارد

foreach (var n in a)
    Console.WriteLine(n); // خروجی: 3 و 4
```

---

# سوال HashSet چه زمانی بهترین گزینه است؟

استفاده کن وقتی:

- می‌خواهی **تکراری‌ها حذف شوند**
- نیاز داری **سریع چک کنی** که آیتم موجود است یا نه
- عملیات مجموعه‌ای انجام می‌دهی
- داده زیاد داری

استفاده نکن وقتی:

- ترتیب عناصر مهم است → **List**  
- می‌خواهی آیتم‌ها قابل تکرار باشند → **List**  
- نیاز به دسترسی با Index داری → **List / Array**

---

# یک مثال واقعی از دنیای واقعی

مثلاً در یک API می‌خواهی چک کنی آیا کاربر قبلاً رأی داده یا نه:

```csharp
HashSet<int> votedUserIds = new HashSet<int>();

public bool TryVote(int userId)
{
    if (!votedUserIds.Add(userId))
        return false; // قبلاً رأی داده

    return true; // اولین بار است
}
```
