**مفهوم:** `init` به شما اجازه می‌دهد که یک ویژگی (Property) را **فقط در زمان ساخت آبجکت** (Object Initializer) مقداردهی کنید و بعد از آن، آن ویژگی `ReadOnly` می‌شود.

**مثال:**
```csharp

public class User {
    public string Username { get; init; }
}

var u = new User { Username = "Admin" }; // مجاز
// u.Username = "User"; // خطای کامپایل

```
