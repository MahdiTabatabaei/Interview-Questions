یک مجموعه [[1 - CSharp – Language Fundamentals/52|Thread-safe]] و غیرترتیبی (Unordered) است. برای سناریوهایی که چند Thread همزمان داده اضافه یا حذف می‌کنند (بدون نیاز به `lock` دستی) بهینه شده است.

**مثال:**
```csharp

var bag = new ConcurrentBag<int>();
Parallel.For(0, 100, i => bag.Add(i)); // ایمن در چندرشته‌ای

```
