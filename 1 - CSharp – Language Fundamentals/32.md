به‌صورت **پیش‌فرض نه**، چون Struct _Value Type_ است و روی Stack ذخیره می‌شود.

اما اگر داخل یک کلاس باشد، در Heap ذخیره می‌شود:
```csharp

struct Point { public int X; }

class Shape { public Point P; }

Shape s = new Shape(); // P داخل Heap چون متعلق به class است

```
✅ پس: مکان نگهداری بستگی به **Context (nested یا standalone)** دارد.
