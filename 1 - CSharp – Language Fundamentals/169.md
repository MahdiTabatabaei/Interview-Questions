این سه تا در یک سطح نیستند و همین باعث سردرگمی می‌شود.  
درواقع **SOAP و REST سبک/پروتکل ارتباطی هستند، اما WCF یک فریم‌ورک مایکروسافت است.**

بیایید دقیق تفکیک کنیم.

---

# 1. SOAP
درواقع **SOAP (Simple Object Access Protocol)** یک **پروتکل استاندارد برای وب‌سرویس‌ها** است.

ویژگی‌ها:
- مبتنی بر **XML**
- ساختار پیام مشخص دارد (Envelope, Header, Body)
- معمولاً روی **HTTP** کار می‌کند ولی می‌تواند روی **TCP، SMTP** هم باشد
- استانداردهای زیادی دارد مثل:
  - WS-Security
  - WS-ReliableMessaging
  - WS-AtomicTransaction

نمونه پیام SOAP:

```xml
<Envelope>
  <Body>
    <GetUser>
      <Id>10</Id>
    </GetUser>
  </Body>
</Envelope>
```

ویژگی مهم:
- بسیار **سنگین (Heavy)**  
- مناسب **سیستم‌های Enterprise**

مثال استفاده:
- بانک‌ها
- سیستم‌های قدیمی سازمانی
- سیستم ERPها

---

# 2. REST
درواقع **REST (Representational State Transfer)** یک **سبک معماری برای API** است، نه پروتکل.

ویژگی‌ها:
- معمولاً روی **HTTP**
- استفاده از متدهای HTTP:

```
GET
POST
PUT
DELETE
```

معمولاً داده‌ها:

```
JSON
```

مثال REST:

```
GET /users/10
```

پاسخ:

```json
{
  "id": 10,
  "name": "Ali"
}
```

ویژگی‌ها:
- سبک (Lightweight)
- سریع
- مناسب Web و Mobile
- ساده برای استفاده

امروزه **تقریباً تمام APIهای جدید REST هستند.**

---

# 3. WCF
درواقع **WCF (Windows Communication Foundation)** یک **فریم‌ورک مایکروسافت در .NET** برای ساخت سرویس‌ها است.

با WCF می‌توان چند نوع سرویس ساخت:

- SOAP services
- TCP services
- Named Pipes
- Message queues

ساختار معروف WCF:

```
ABC
```

- **A = Address**
- **B = Binding**
- **C = Contract**

مثال:

```
http://server/service
basicHttpBinding
IUserService
```

---

# رابطه بین این سه

```
WCF = Framework
SOAP = Protocol
REST = Architectural Style
```

یعنی:

- فریم‌ورک WCF می‌تواند **SOAP** پیاده‌سازی کند
- فرمت REST معمولاً با **ASP.NET Web API** ساخته می‌شود (نه WCF)

---

# مقایسه سریع

SOAP
- فرمت XML
- استانداردهای زیاد
- سنگین
- حالت enterprise

REST
- فرمت JSON
- ساده
- سریع
- مناسب web/mobile

WCF
- فریم‌ورک .NET
- می‌تواند SOAP / TCP / Pipes را پیاده کند

---

# وضعیت امروزی در .NET

تقریباً:

- **SOAP / WCF → قدیمی‌تر**
- **REST / ASP.NET Core API → استاندارد فعلی**
