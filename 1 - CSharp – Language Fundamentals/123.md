چون:

- حذف، افزودن، تغییر مقدار هم‌زمان باعث **race condition** می‌شود.
- resize داخلی آن (افزایش ظرفیت) در حالت چندنخی می‌تواند باعث **فساد حافظه** یا خطا شود.
- قفل داخلی ندارد.

## مثال خطای احتمالی:
```csharp

Dictionary<int, int> dict = new Dictionary<int, int>();

Parallel.For(0, 1000, i =>
{
    dict[i] = i; // احتمال کرش
});

```
