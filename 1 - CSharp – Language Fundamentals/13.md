## Deferred Execution

در این حالت Query **زمان استفاده اجرا می‌شود**.
```csharp

var result = numbers.Where(x => x > 10);

```
تا زمانی که iterate نشود اجرا نمی‌شود.

---

## Immediate Execution
در این حالت Query **فورا اجرا می‌شود**.
```csharp

var result = numbers.Where(x => x > 10).ToList();

```
