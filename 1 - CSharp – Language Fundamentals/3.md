هر دو برای **Query روی مجموعه داده** استفاده می‌شوند.

---

## IEnumerable

در این حالت Query در **Memory** اجرا می‌شود.
## مثال :
```csharp

var result = users.Where(x => x.Age > 20);

```
بعد از گرفتن داده از دیتابیس فیلتر می‌شود.

---

## IQueryable

در این حالت Query در **Database** اجرا می‌شود.
## مثال :
```csharp

IQueryable<User> users = db.Users;

var result = users.Where(x => x.Age > 20);

```
تبدیل به SQL می‌شود:
```markdown

SELECT * FROM Users WHERE Age > 20

```
