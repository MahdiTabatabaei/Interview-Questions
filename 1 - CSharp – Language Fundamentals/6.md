در واقع Task مستقیماً با OS کار نمی‌کند، بلکه مدیریت thread را به CLR می‌سپارد.

در مدیریت Exception در واقع Thread (بد) و Task (خوب)
```csharp

Thread t = new Thread(() =>
{
    throw new Exception("Error");
});
t.Start();

```
❌ ممکن است برنامه کرش کند یا exception گم شود.

```csharp

try
{
    await Task.Run(() =>
    {
        throw new Exception("Error");
    });
}
catch(Exception ex)
{
    Console.WriteLine(ex.Message);
}


```

✅ در هنگام exception قابل کنترل است.

در برگشت مقدار (Return Value) در واقع Thread (بد) و Task (خوب)

نوع Thread نمی‌تواند مقدار برگرداند (مستقیم).

```csharp

Task<int> t = Task.Run(() => 10);
int result = await t;

```
 ولی Task برمیگرداند
 
در Cancellation در واقع Thread (بد) و Task (خوب)

```csharp

t.Abort(); // ❌ deprecated و خطرناک

```

ولی Task (استاندارد) 


```csharp

var cts = new CancellationTokenSource();

Task.Run(() =>
{
    while (!cts.Token.IsCancellationRequested)
    {
        // do work
    }
}, cts.Token);

cts.Cancel();

```

خلاصه Thread یک واحد اجرایی سطح پایین و وابسته به سیستم‌عامل است که ساخت و مدیریت آن پرهزینه است  و Task یک abstraction سطح بالاتر است که معمولاً روی ThreadPool اجرا می‌شود، از async/await پشتیبانی می‌کند، مدیریت exception و cancellation بهتری دارد و برای برنامه‌های مدرن .NET انتخاب بهتری است.

# 1️⃣ ThreadPool

### تعریف

یک **مجموعه از Threadهای آماده** است که توسط **CLR** مدیریت می‌شود تا کارهای کوتاه را اجرا کند بدون اینکه هر بار Thread جدید ساخته شود.

### نحوه کار

کارها در یک **Queue** قرار می‌گیرند و یکی از Threadهای آزاد آن را اجرا می‌کند.

### مثال:
```csharp

ThreadPool.QueueUserWorkItem(_ =>
{
    Console.WriteLine("Work executed by ThreadPool");
});

```

### ویژگی‌ها

- مدیریت Threadها توسط CLR
- ساخت Thread جدید ندارد
- مناسب کارهای کوتاه
- کنترل کم

---

# 2️⃣ Task (TPL)

### تعریف

درواقع `Task` یک **abstraction سطح بالاتر** برای اجرای عملیات asynchronous یا parallel است.

معمولاً **پشت صحنه از ThreadPool استفاده می‌کند**.

### مثال :

```csharp

Task task = Task.Run(() =>
{
    Console.WriteLine("Task running");
});

```

یا با async:
```csharp

await Task.Run(() => DoWork());

```

### قابلیت‌ها

✅ async/await

✅ مدیریت exception

✅ cancellation

✅ chaining tasks

✅ return value

مثال برگشت مقدار:
```csharp

Task<int> task = Task.Run(() => 5 + 5);
int result = await task;

```

# 3️⃣ Parallel

### تعریف

استفاده `Parallel` برای **اجرای همزمان چند عملیات روی CPU (CPU-[[bound]])** استفاده می‌شود.

در واقع روی **چند Thread مختلف** اجرا می‌شود.

---

### مثال Parallel.For :
```csharp

Parallel.For(0, 10, i =>
{
    Console.WriteLine($"Processing {i}");
});

```
یا:
```csharp

Parallel.ForEach(list, item =>
{
    Process(item);
});

```

```csharp

foreach(var file in files)

    ThreadPool.QueueUserWorkItem(_ => Process(file));

Parallel.ForEach(files, file =>

    Process(file);

```

# پاسخ کوتاه 

 ابزار ThreadPool مجموعه‌ای از threadهای از پیش ساخته شده است که CLR آن‌ها را مدیریت می‌کند.
> 
 و Task یک abstraction سطح بالاتر برای اجرای عملیات asynchronous است که معمولاً از ThreadPool استفاده می‌کند.
> 
 و Parallel برای اجرای همزمان عملیات CPU-bound طراحی شده و از چند thread برای پردازش موازی استفاده می‌کند.
