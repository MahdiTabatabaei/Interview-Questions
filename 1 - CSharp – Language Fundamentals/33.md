متدی است که قبل از حذف object توسط **GC** اجرا می‌شود.

در C# با ~classname نوشته می‌شود:
```csharp

class FileHandler
{
    ~FileHandler()
    {
        Console.WriteLine("Finalizer called");
    }
}

```

 در واقع GC این تابع را هنگام حذف شیء به‌صورت خودکار فراخوانی می‌کند.

✅ معمولاً برای آزادسازی منابع unmanaged (مثل فایل یا handle‌ها).
