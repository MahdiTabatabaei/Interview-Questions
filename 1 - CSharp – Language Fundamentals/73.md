**مفهوم:** برای اطمینان از اینکه منابع (مانند فایل‌ها، ارتباطات دیتابیس) به محض اتمام کار **آزاد** می‌شوند. `using` در واقع یک بلوک `try/finally` تولید می‌کند که در قسمت `finally` متد `.Dispose()` را صدا می‌زند.

**مثال:**
```csharp

using (var stream = new FileStream("test.txt", FileMode.Open)) {
    // کار با فایل
} // اینجا فایل حتماً بسته می‌شود

```
