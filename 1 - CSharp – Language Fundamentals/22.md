✅ `StringBuilder`:
کلاسی برای **ساخت و تغییر رشته بدون ساخت object جدید**.

- متغییر **mutable** است
- داده‌ها را در buffer نگه می‌دارد
- حافظه جدید برای هر تغییر نمی‌سازد

مثال:

❌ string (بد)

```csharp

string text = "";

for(int i = 0; i < 1000; i++)
{
    text += i;
}

```

✅ StringBuilder (خوب)

```csharp

var sb = new StringBuilder();

for(int i = 0; i < 1000; i++)
{
    sb.Append(i);
}

string result = sb.ToString();


```
