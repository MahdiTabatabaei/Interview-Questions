ابزار Channel بهتر است وقتی:

- عملیات **async** داریم
- **backpressure** [[back‑pressure]]
- **producer-consumer pipeline** [[Producer‑Consumer Pipeline]]
- high throughput [[High Throughput]]

---

### مثال pipeline
```csharp

var channel = Channel.CreateUnbounded<string>();

Task.Run(async () =>
{
    await channel.Writer.WriteAsync("job1");
});

await foreach (var job in channel.Reader.ReadAllAsync())
{
    Console.WriteLine(job);
}

```
