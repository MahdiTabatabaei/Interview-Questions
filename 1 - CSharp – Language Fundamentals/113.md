ایجاد Caching برای بهبود سرعت دسترسی به داده‌ها است، بخصوص داده‌هایی که زیادی مورد نیاز هستند.

انواع:

- **In-memory cache:** استفاده از `MemoryCache` یا `ConcurrentDictionary`
- **Distributed cache:** Redis، SQL Server، NCache، AppFabric
- **Output caching:** در ASP.NET Core برای صفحات یا پاسخ‌ها

### نمونه:
```csharp

// MemoryCache
MemoryCache cache = MemoryCache.Default;
cache.Set("key", data, DateTimeOffset.Now.AddMinutes(10));
var data = cache["key"];

```
