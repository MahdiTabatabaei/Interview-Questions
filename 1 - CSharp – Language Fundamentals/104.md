### 🧩 نمونه استفاده سریع از هرکدام

#### 🔸 SemaphoreSlim
```csharp

using System.Threading;

var sem = new SemaphoreSlim(2); // حداکثر ۲ نخ هم‌زمان
await sem.WaitAsync();
try { Console.WriteLine("مرحله‌ی بحرانی"); }
finally { sem.Release(); }

```

🔸 Mutex

```csharp

using System.Threading;

using var mutex = new Mutex(false, "Global\\MyAppMutex");
if (!mutex.WaitOne(3000))
{
    Console.WriteLine("برنامه‌ی دیگری در حال اجراست!");
    return;
}
Console.WriteLine("در حال اجرا در حالت انحصاری...");

```

🔸 SpinLock
```csharp

using System.Threading;

SpinLock spin = new SpinLock();
bool taken = false;
spin.Enter(ref taken);
try
{
    // اجرای سریع (در حد نانوثانیه)، مناسب برای lockهای کوتاه
}
finally
{
    if (taken) spin.Exit();
}

```
