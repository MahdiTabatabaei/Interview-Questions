- حافظه **Managed Memory:** حافظه‌ای است که تحت کنترل **CLR (Common Language Runtime)** قرار دارد. یعنی تخصیص و آزادسازی توسط **Garbage Collector (GC)** انجام می‌شود.مثال: اشیاء کلاس‌ها، String، List و غیره.
- حافظه **Unmanaged Memory:** حافظه‌ای است که CLR درباره‌ی آن اطلاعی ندارد؛ باید **دستی** آزاد شود.مثال: فایل، Socket، هندل‌های Windows، نشانگرهای (Pointers) nativ‌ و داده‌های COM.

### مثال:
```csharp

// Managed object (با GC مدیریت می‌شود)
String s = "GapGPT"; 

// Unmanaged - باید Dispose شود
var bmp = new System.Drawing.Bitmap("image.png");
bmp.Dispose(); // آزادسازی دستی

```
💡 **نکته:** اشیائی که منابع Unmanaged دارند، معمولاً `IDisposable` را پیاده‌سازی می‌کنند تا بتوان با `using` آنها را مدیریت کرد.
