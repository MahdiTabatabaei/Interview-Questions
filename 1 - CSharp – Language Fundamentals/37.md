نشت حافظه یعنی:

برنامه **حافظه‌ای را می‌گیرد ولی دیگر آن را آزاد نمی‌کند**، حتی وقتی دیگر به آن نیاز ندارد.

در نتیجه:

- مصرف RAM برنامه کم‌کم زیاد می‌شود
- ممکن است برنامه کند شود
- یا حتی Crash کند.

زمانی که object دیگر نیازی نیست ولی **هنوز reference دارد و GC نمی‌تواند حذفش کند.**

یا وقتی objectهایی هنوز reference دارند ولی هرگز استفاده نمی‌شوند، GC نمی‌تواند حذفشان کند.

دلایل رایج:

- وجود event unsubscribed نشده در کد
- نوشتن static reference باقی مانده
- ایجاد cache بدون cleanup
### مثال خطا:
```csharp

public static List<byte[]> cache = new List<byte[]>();

void LoadData()
{
    cache.Add(new byte[1000000]); // هر بار اضافه ولی پاک نمی‌شود
}

```
در این حالت GC حذف نمی‌کند چون هنوز در `cache` نگهداری شده.

✅ نتیجه: مصرف حافظه پایدار یا افزایشی → Memory Leak
