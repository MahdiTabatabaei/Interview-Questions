فرقشان در **نقش** است: یکی **لغو را ایجاد می‌کند** و دیگری فقط **لغو را دریافت/مشاهده می‌کند**.

## CancellationTokenSource (CTS)
منبعِ لغو است.

یعنی این شیء می‌تواند بگوید عملیات‌ها **کنسل شوند**.

کارهایی که می‌کند:
- ایجاد `CancellationToken`
- صدا زدن `Cancel()`
- تعیین timeout
- کنترل lifecycle لغو

مثال:

```csharp
var cts = new CancellationTokenSource();

Task.Run(() =>
{
    while (!cts.Token.IsCancellationRequested)
    {
        Console.WriteLine("working...");
    }
});

Thread.Sleep(2000);
cts.Cancel();
```

اینجا:

```
cts → فرمان لغو را صادر می‌کند
```

---

## CancellationToken
فقط **سیگنال لغو را دریافت می‌کند**.

یعنی کدی که در حال اجراست می‌تواند بررسی کند:

```
آیا درخواست لغو آمده؟
```

ویژگی‌ها:

- `IsCancellationRequested`
- `ThrowIfCancellationRequested()`
- ثبت callback با `Register()`

مثال:

```csharp
void DoWork(CancellationToken token)
{
    for(int i = 0; i < 100; i++)
    {
        token.ThrowIfCancellationRequested();
        Thread.Sleep(100);
    }
}
```

---

## رابطه آنها

```
CancellationTokenSource
        ↓
   CancellationToken
        ↓
     Tasks / Operations
```

یعنی:

1. ابتدا `CancellationTokenSource` توکن می‌سازد
2. توکن به taskها داده می‌شود
3. اگر `Cancel()` صدا زده شود
4. همه توکن‌ها **سیگنال لغو دریافت می‌کنند**

---

## مثال واقعی

```csharp
var cts = new CancellationTokenSource();

Task task = Task.Run(() =>
{
    while (true)
    {
        cts.Token.ThrowIfCancellationRequested();
        Console.WriteLine("running...");
    }
}, cts.Token);

Thread.Sleep(2000);
cts.Cancel();
```

---

## خلاصه سریع

```
CancellationTokenSource → لغو را صادر می‌کند
CancellationToken → لغو را دریافت می‌کند
```

یا ساده‌تر:

```
CTS = cancel button
Token = signal listener
```
