ویژگی Profiling یعنی **تحلیل عملکرد (Performance)** برنامه برای کشف Bottleneckها در Memory یا CPU.

ابزارهای اصلی:

- 🔸 **dotnet-trace:** ردیابی عملکرد (Events, GC, Thread).
- 🔸 **dotnet-counters:** مشاهده شمارنده‌های زمان اجرا مانند GC، CPU usage.
- 🔸 **dotnet-dump:** استخراج Snapshot حافظه برای تحلیل Debug.
- 🔸 **PerfView, JetBrainsdotTrace, Visual Studio Profiler** — ابزارهای گرافیکی حرفه‌ای.

### مثال (اجرای ساده از ترمینال):
```markdown

dotnet trace collect --process-id 1234
dotnet-counters monitor --process-id 1234 System.Runtime

```
