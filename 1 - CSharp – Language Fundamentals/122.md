### زمانی که:

- چندین thread **به طور هم‌زمان** با یک collection کار می‌کنند.
- thread-safety لازم است.
- نمی‌خواهیم از lockهای زیاد استفاده کنیم.

### مثال‌ها:

- `ConcurrentDictionary`
- `ConcurrentQueue`
- `ConcurrentBag`
- `ConcurrentStack`
- `BlockingCollection`

## مثال:
```csharp

var dict = new ConcurrentDictionary<string, int>();
dict.TryAdd("A", 1);
dict.AddOrUpdate("A", 1, (_, old) => old + 1);

```
