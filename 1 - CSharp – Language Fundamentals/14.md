ویژگی **`IEnumerable`** یک **Interface برای پیمایش (Iteration)** مجموعه‌ها است، اما **`List`** یک **کلاس واقعی برای نگهداری داده‌ها در حافظه** است.

از لحاظ نوع :

```markdown

IEnumerable → Interface
List → Class

```

قابلیت تغییر
```markdown

IEnumerable → فقط خواندن
List → قابل تغییر

```

دسترسی با index

```markdown

IEnumerable → ندارد
List → دارد

```

مثال:
```csharp

numbers[0]

```

متدها

```markdown

IEnumerable → فقط iteration
List → Add, Remove, Insert, Count ...

```

### اجرا در LINQ

ویژگی `IEnumerable` معمولاً **LINQ to Objects** است.

مثال:

```csharp

IEnumerable<int> result = list.Where(x => x > 10);

```

## نکته مهم 

معمولاً گفته می‌شود:

✅ **در Method signature بهتر است از IEnumerable استفاده کنیم**

چرا؟

چون **Loose Coupling** ایجاد می‌کند.

مثال:

❌ بد

```csharp

public void Print(List<int> numbers)

```

✅ بهتر

```csharp

public void Print(IEnumerable<int> numbers)

```

حالا متد می‌تواند با:
```markdown

List
Array
HashSet
Collection

```

کار کند.

##  مثال مقایسه

```csharp

List<int> list = new List<int>() {1,2,3};

IEnumerable<int> numbers = list;

numbers = numbers.Where(x => x > 1);

```

اما:

```markdown

numbers.Add(5); ❌

```

## خلاصه 

ویژگی `IEnumerable` یک interface برای پیمایش مجموعه‌ها است و فقط امکان iteration دارد، در حالی که `List` یک کلاس برای ذخیره داده در حافظه است که عملیات‌هایی مثل Add، Remove و دسترسی با index را فراهم می‌کند. معمولاً در متدها از `IEnumerable` استفاده می‌شود تا وابستگی به implementation خاص کاهش پیدا کند.
