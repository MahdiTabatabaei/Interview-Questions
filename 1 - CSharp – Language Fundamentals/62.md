- کلاس **Dictionary:** برای محیط‌های تک‌رشته‌ای (Single-thread) طراحی شده است. اگر چند Thread همزمان در آن بنویسند، احتمال Crash یا فساد داده وجود دارد.
- کلاس **ConcurrentDictionary:** در فضای نام `System.Collections.Concurrent` قرار دارد. این کلاس **Thread-safe** است. یعنی چندین Thread می‌توانند همزمان بدون نیاز به `lock` دستی، در آن بنویسند یا از آن بخوانند.

**مثال کاربردی:**
```csharp

var dict = new ConcurrentDictionary<string, int>();
dict.TryAdd("Key", 1); // بدون نیاز به lock

```

درواقع **ConcurrentDictionary در ASP.NET Core زمانی مفید است که:**

- برای **shared state سراسری** بین همه requestها باشد
- داده‌ها کوچک و پایدار باشند
- برای cache / تنظیمات / metadata باشند
- همه کاربران باید به آن دسترسی داشته باشند
- به latency و performance نیاز داری
- نیاز به thread-safety داری

**و زمانی مضر است که:**

- وضعیت state کاربر در آن باشد
- داده همیشگی رشد کند
- بین سرورهای متعدد sync لازم باشد
- ویژگی scalable بودن مهم باشد
