ویژگی `CancellationToken` برای **لغو عملیات‌های در حال اجرا** در برنامه‌های async و کنترل جریان اجرای آن‌ها طراحی شده.

معمولاً وقتی کاری زمانبر است (مانند درخواست‌های شبکه، عملیات‌های طولانی یا درون سرور)، می‌خواهیم بتوانیم آن را در صورت نیاز متوقف کنیم.

### چطور کار می‌کند:

- یک **CancellationTokenSource** ساخته می‌شود و آن از طریق `Token`، یک `CancellationToken` را در اختیار می‌گذارد.
- عملیات‌های async یا بلندمدت باید `token` را استفاده کنند.
- وقتی نیاز است عملیات لغو شود، با `Cancel()` این منبع، `IsCancellationRequested` در توکن برابر با `true` می‌شود.
- عملیات باید این وضعیت را چک کند و در صورت نیاز، خاتمه یابد.

### مثال:
```csharp

CancellationTokenSource cts = new CancellationTokenSource();

async Task LongRunningOperationAsync(CancellationToken token)
{
    for (int i = 0; i < 10; i++)
    {
        token.ThrowIfCancellationRequested(); // چک کردن لغو
        await Task.Delay(500); // فرض عملیات طولانی
        Console.WriteLine($"مرحله {i+1}");
    }
}

try
{
    var task = LongRunningOperationAsync(cts.Token);
    // لغو عملیات پس از 2 ثانیه
    cts.CancelAfter(2000);
    await task;
}
catch (OperationCanceledException)
{
    Console.WriteLine("عملیات لغو شد");
}

```
