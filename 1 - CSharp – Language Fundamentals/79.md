- متد **`Equals`:** برای بررسی برابری دو شیء به کار می‌رود.
- متد **`GetHashCode`:** یک عدد صحیح (Hash) برمی‌گرداند که برای شناسایی سریع شیء در ساختارهایی مثل `Dictionary` و [[202 | HashSet]] استفاده می‌شود.

**قانون طلایی:** اگر دو شیء با `Equals` برابر هستند، **حتماً** باید `GetHashCode` یکسانی داشته باشند.

---

این دو متد برای **مقایسه اشیاء** استفاده می‌شوند، ولی نقششان فرق دارد.

## 1. `Equals`

متد `Equals` بررسی می‌کند **آیا دو شیء واقعاً با هم برابر هستند یا نه**.

مثال:
```csharp

string a = "hello";
string b = "hello";

Console.WriteLine(a.Equals(b)); // true

```
در اینجا محتویات رشته‌ها مقایسه می‌شود.

پس:

**Equals → مقایسه واقعی (logical equality)**

---

## 2. `GetHashCode`

متد `GetHashCode` یک **عدد (hash)** تولید می‌کند که نمایندهٔ آن شیء است.

```csharp

string a = "hello";
string b = "hello";

Console.WriteLine(a.GetHashCode());
Console.WriteLine(b.GetHashCode());

```
معمولاً برای اشیاء برابر، **hash برابر** تولید می‌شود.

اما نکته مهم:
```markdown

Hash برابر → لزوماً یعنی شیء برابر نیست

```
چون ممکن است [[collision]] اتفاق بیفتد. 

پس:

**GetHashCode → تولید یک کد سریع برای دسته‌بندی شیء**

---

## 3. چرا اصلاً `GetHashCode` وجود دارد؟

برای **ساختارهای داده سریع** مثل:

- `Dictionary`
- `HashSet`
- `ConcurrentDictionary`

این ساختارها اول از **HashCode** استفاده می‌کنند تا سریع بفهمند شیء در کدام [[Bucket]] قرار دارد،

بعد اگر لازم بود از **Equals** استفاده می‌کنند تا دقیقاً مقایسه کنند.

ترتیب کار:
```markdown

1️⃣ GetHashCode
2️⃣ اگر برابر بود → Equals

```
---

## 4. مثال واقعی

فرض کنید این کلاس را داریم:
```csharp

class Person
{
    public string NationalId { get; set; }
}

```
اگر بخواهیم افراد را در `HashSet` ذخیره کنیم باید بگوییم **برابری بر اساس NationalId است**.
```csharp

class Person
{
    public string NationalId { get; set; }

    public override bool Equals(object obj)
    {
        return obj is Person p &&
               NationalId == p.NationalId;
    }

    public override int GetHashCode()
    {
        return NationalId.GetHashCode();
    }
}

```

---
## 5. قانون مهم

اگر `Equals` را override کردی **حتماً باید `GetHashCode` را هم override کنی.**

قانون:
```markdown

اگر a.Equals(b) == true
باید
a.GetHashCode() == b.GetHashCode()

```
