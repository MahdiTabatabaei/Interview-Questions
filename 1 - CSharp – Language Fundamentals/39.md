### ✔ متغیر var در **compile time** مشخص می‌شود

یعنی کامپایلر با توجه به مقدار سمت راست، نوع واقعی را تعیین می‌کند.

مثال:
```csharp

var x = 10;       // int
var y = "hello";  // string
var z = new List<int>(); // List<int>

```

### ✔ مزایای var

## 1) قابلیت Type Safety

چون نوع در compile-time مشخص می‌شود، compiler **خطاها را قبل از اجرا** می‌گیرد.

مثال:
```csharp

var name = "Ali";
name = 10; // Error در compile-time

```

این موضوع:

- از خطاهای عجیب runtime جلوگیری می‌کند
- برنامه را پایدارتر و دیباگ را ساده‌تر می‌کند

---

## 2) از لحاظ Performance بهتر نسبت به dynamic

تا جایی که امکان دارد، همه چیز در compile-time مشخص می‌شود.

هیچ عملیات reflection / dynamic dispatch انجام نمی‌شود.

---

## 3) قابل استفاده برای Typeهای طولانی

مثال کلاس‌های generic سنگین:
```csharp

var customers = new Dictionary<int, List<Order>>();

```
نوشتن نوع واقعی خیلی سخت است.

---

## 4) پیشنهاد IntelliSense بهتر

چون compiler نوع را می‌فهمد، VS پیشنهادهای دقیق می‌دهد.

در واقع **IntelliSense** یعنی:

- پیشنهاد خودکار متدها، کلاس‌ها، پارامترها
- نمایش نوع داده، امضا (Signature)
- هشدار خطا قبل از اجرا
- تکمیل خودکار (Auto‑Complete)

---

## 5) مناسب LINQ

چون خروجی LINQ ممکن است anonymous type باشد:
```csharp

var result = items.Select(x => new { x.Id, x.Name });

```
بدون var اصلا قابل نوشتن نیست.
