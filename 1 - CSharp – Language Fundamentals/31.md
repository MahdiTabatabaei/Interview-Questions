### 🔹 Stack

- محل ذخیره **Value Type**ها و متغیرهای محلی است.
- ساخت و آزادسازی سریع دارد.
- به‌صورت **LIFO (Last In First Out)** کار می‌کند.
- حافظه به‌صورت خودکار هنگام خروج از scope آزاد می‌شود.
```csharp

void Test()
{
    int x = 10;  // روی Stack ذخیره می‌شود
}

```
---

### 🔹 Heap

- محل ذخیره **Reference Type**ها است.
- مدیریت حافظه توسط **Garbage Collector** انجام می‌شود.
- آزادسازی کند‌تر از Stack است.
```csharp

class Person { public int Age; }

var p = new Person(); // روی Heap ذخیره می‌شود

```
