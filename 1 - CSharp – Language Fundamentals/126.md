### راه‌ها:

- دیدن تبدیل **value type → object**
- استفاده از ابزارهایی مثل:
    - ILSpy یا ILDASM
    - BenchmarkDotNet
    - Visual Studio Analyzer

## مثال ساده:
```csharp

int x = 5;
object obj = x; // boxing
int y = (int)obj; // unboxing

```
تشخیص با BenchamrkDotNet

```csharp

[Benchmark]
public void Test()
{
    object o = 10; // boxing
}

```
