در زبان `#await`، C به‌صورت پیش‌فرض تلاش می‌کند بعد از پایان Task، ادامه‌ی متد را روی **Context اصلی Thread (مثلاً UI)** اجرا کند.

اگر بنویسیم `ConfigureAwait(false)`، می‌گوید:

> نیازی نیست روی همان Context برگردی؛ ادامه را روی Threadpool اجرا کن.

✅ باعث **افزایش Performance** و جلوگیری از **Deadlock** در برنامه‌های غیر UI.

### مثال:
```csharp

await DoSomethingAsync().ConfigureAwait(false);
// ادامه‌ی اجرای کد روی همان Context لازم نیست

```
