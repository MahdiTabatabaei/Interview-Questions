برای مدیریت صحیح منابع: 
```csharp

class ResourceHolder : IDisposable
{
    private bool disposed = false;

    public void Dispose()
    {
        Dispose(true);
        GC.SuppressFinalize(this);
    }

    protected virtual void Dispose(bool disposing)
    {
        if (disposed) return;

        if (disposing)
        {
            // آزادسازی منابع managed
        }

        // آزادسازی منابع unmanaged
        disposed = true;
    }

    ~ResourceHolder()
    {
        Dispose(false);
    }
}

```
✅ این الگو مانع می‌شود اگر Finalizer هم اجرا شد، دوباره Dispose شود.
