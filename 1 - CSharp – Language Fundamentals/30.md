تعریف Root reference یعنی **object هایی که هنوز قابل دسترسی هستند** و GC نمی‌تواند آنها را حذف کند.

---

## مثال Root :
- static variables
- local variables
- CPU registers
- active threads

```csharp

Person p = new Person();

```
تا وقتی `p` وجود دارد:

در این حالت GC نمی‌تواند object را پاک کند.

---

اگر:
```csharp

p = null;

```
دیگر root reference نیست.
