![[28_difference_Select_vs_SelectMany.png]]
مثال:
```csharp

// Select
var names = people.Select(p => p.Name);

// SelectMany
var allPhones = people.SelectMany(p => p.PhoneNumbers);

```

---
تفاوت اصلی **`Select`** و **`SelectMany`** در LINQ این است که:

- ساده **Select**: هر عنصر را به **یک مقدار** تبدیل می‌کند.  
- مجموعه **SelectMany**: هر عنصر را به **چند مقدار (collection)** تبدیل می‌کند و سپس همه را **Flatten (مسطح)** می‌کند.

---

# 1️⃣ Select

برای **تبدیل هر آیتم به یک نتیجه** استفاده می‌شود.

مثال:

```csharp
var numbers = new List<int> { 1, 2, 3 };

var result = numbers.Select(x => x * 2);

foreach (var n in result)
{
    Console.WriteLine(n);
}
```

خروجی:

```
2
4
6
```

اینجا:

```
1 → 2
2 → 4
3 → 6
```

هر ورودی → **یک خروجی**

---

# 2️⃣ SelectMany

وقتی هر آیتم **خودش یک مجموعه دارد** و می‌خواهیم همه را در یک لیست واحد جمع کنیم.

مثال:

```csharp
var list = new List<string>
{
    "Ali",
    "Sara"
};

var chars = list.SelectMany(name => name.ToCharArray());

foreach (var c in chars)
{
    Console.WriteLine(c);
}
```

خروجی:

```
A
l
i
S
a
r
a
```

چون:

```
"Ali"  → [A,l,i]
"Sara" → [S,a,r,a]
```

و `SelectMany` آنها را **در یک مجموعه واحد** ترکیب کرده است.

---

# 3️⃣ مثال خیلی واضح با کلاس

فرض کن:

```csharp
class Student
{
    public string Name { get; set; }
    public List<string> Courses { get; set; }
}
```

داده:

```csharp
var students = new List<Student>
{
    new Student { Name="Ali", Courses = new List<string>{"Math","Physics"} },
    new Student { Name="Sara", Courses = new List<string>{"Biology","Chemistry"} }
};
```

---

## با Select

```csharp
var result = students.Select(s => s.Courses);
```

خروجی:

```
[
 [Math, Physics],
 [Biology, Chemistry]
]
```

یعنی:

```
List<List<string>>
```

---

## با SelectMany

```csharp
var result = students.SelectMany(s => s.Courses);
```

خروجی:

```
[Math, Physics, Biology, Chemistry]
```

یعنی:

```
List<string>
```

---

# خلاصه خیلی سریع

| متد | خروجی |
|----|----|
| Select | هر آیتم → یک آیتم |
| SelectMany | هر آیتم → چند آیتم → flatten |

---

# یک قانون ساده برای یادآوری

اگر خروجی این شکلی شد:

```
List<List<T>>
```

احتمالاً باید از **SelectMany** استفاده کنی.
