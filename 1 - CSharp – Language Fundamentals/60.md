وضعیت Deadlock زمانی رخ می‌دهد که **دو یا چند thread منتظر منابع یکدیگر باشند و هیچکدام آزاد نشوند**.

---

### مثال
```csharp

lock(obj1)
{
    lock(obj2)
    {
    }
}

```
در Thread دیگر:
```csharp

lock(obj2)
{
    lock(obj1)
    {
    }
}

```
هر دو منتظر هم می‌مانند.

---

### مثال async deadlock
```csharp

var result = GetDataAsync().Result;

```
در UI thread ممکن است deadlock ایجاد کند.

---

✅ راه‌حل

- استفاده از `await`
- ترتیب ثابت lock
- استفاده از timeout
