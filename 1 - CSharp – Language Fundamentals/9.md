## 🧱 1. مفهوم Encapsulation (کپسوله‌سازی)

### تعریف

یعنی **پنهان کردن داده‌ها (Data Hiding)** و کنترل دسترسی به فیلدها یا پراپرتی‌ها از طریق متدها یا propertyها.

📦 در عمل یعنی:

- فیلدها `private` باشند
- دسترسی از طریق متدها (`get/set`) یا property انجام شود.

---

### مثال:
```csharp

public class BankAccount
{
    private decimal _balance;  // فیلد خصوصی

    public void Deposit(decimal amount)
    {
        if (amount > 0)
            _balance += amount;
    }

    public decimal GetBalance()
    {
        return _balance;
    }
}

```

در اینجا، داده‌ی `_balance` از بیرون کلاس قابل دسترسی نیست، فقط از طریق متدها.

### ✅ خلاصه 

 مفهوم Encapsulation یعنی پنهان کردن داده‌ها و اعمال محدودیت در دسترسی مستقیم به فیلدها.
> 
> این اصل باعث امنیت، کنترل و جلوگیری از تغییرات ناخواسته داده‌ها می‌شود.

## 🧩 2. مفهوم Abstraction (انتزاع)

### تعریف

یعنی **نمایش دادن فقط بخش ضروری از یک شئ و پنهان کردن جزئیات پیچیده‌ی داخلی.**

در C# معمولا با **`abstract class`** یا **`interface`** انجام می‌شود.

---

### مثال:
```csharp

public abstract class Shape
{
    public abstract double GetArea(); // هیچ جزئیاتی از نحوه‌ی محاسبه نمی‌داند
}

public class Circle : Shape
{
    public double Radius { get; set; }
    public Circle(double r) => Radius = r;

    public override double GetArea() => Math.PI * Radius * Radius;
}

```

کاربر فقط می‌داند که هر **Shape** متدی به نام `GetArea()` دارد؛

جزئیات داخلی هر نوع شکل را نمی‌بیند.

---

### ✅ خلاصه  

 مفهوم Abstraction یعنی پنهان کردن جزئیات پیاده‌سازی و نمایش دادن فقط ویژگی‌های ضروری یک شیء.
> 
> این اصل کد را ساده‌تر، منعطف‌تر و قابل توسعه‌تر می‌کند.

## 🧬 3.مفهوم  Inheritance (وراثت)

### تعریف

یعنی یک کلاس فرزند، می‌تواند از ویژگی‌ها و رفتارهای کلاس والد استفاده یا آنها را بازنویسی کند.

---

### مثال:

```csharp

public class Animal
{
    public void Eat() => Console.WriteLine("Eating...");
}

public class Dog : Animal
{
    public void Bark() => Console.WriteLine("Barking...");
}

```

```csharp

Dog d = new Dog();
d.Eat();  // از Animal ارث برده شده
d.Bark();

```

### ✅ خلاصه

 مفهوم Inheritance مکانیزمی است که به ما اجازه می‌دهد ویژگی‌ها و رفتارهای کلاس پدر در کلاس فرزند استفاده یا بازتعریف شوند.
> 
> هدف اصلی کاهش تکرار و استفاده مجدد از کد است.

---

## 🎭 4. مفهوم Polymorphism (چندریختی)

### تعریف

یعنی **یک متد واحد می‌تواند رفتارهای متفاوتی در کلاس‌های مختلف داشته باشد.**

در عمل یعنی:

- **Override در زمان اجرا (Runtime Polymorphism)**
- **Overload در زمان کامپایل (Compile-time Polymorphism)**

---

### مثال (Run‑Time Polymorphism):

```csharp

public class Animal
{
    public virtual void Speak()
    {
        Console.WriteLine("Animal sound");
    }
}

public class Dog : Animal
{
    public override void Speak()
    {
        Console.WriteLine("Woof!");
    }
}

public class Cat : Animal
{
    public override void Speak()
    {
        Console.WriteLine("Meow!");
    }
}

```

```csharp

Animal a1 = new Dog();
Animal a2 = new Cat();

a1.Speak(); // Woof!
a2.Speak(); // Meow!

```

### ✅ خلاصه

 مفهوم Polymorphism یعنی داشتن چند رفتار مختلف تحت یک Interface یا Base Class یکسان.
> 
> در C# می‌توان به صورت Compile-time (Overloading) یا Run-time (Overriding) پیاده‌سازی‌اش کرد.
