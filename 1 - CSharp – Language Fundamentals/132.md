### Span<T>

- اشاره به حافظه بدون کپی (zero-copy)
- سریع
- فقط stack-only
- نمی‌تواند در async استفاده شود

### ArraySegment<T>

- فقط یک view روی array
- روی heap است (نه stack-only)
- در async قابل استفاده است
- فقط روی array کار می‌کند

## مثال Span

```csharp

Span<int> span = stackalloc int[5];
span[0] = 10;

```

مثال ArraySegment

```csharp

int[] data = {1,2,3,4,5};
ArraySegment<int> segment = new ArraySegment<int>(data, 1, 3);

```
