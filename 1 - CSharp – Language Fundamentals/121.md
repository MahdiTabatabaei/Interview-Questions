## توضیح مفهومی

### lock

- مخصوص **دسترسی انحصاری** به یک بخش از کد است.
- فقط **یک** thread وارد بخش critical می‌شود.
- **Blocking** است و async را پشتیبانی نمی‌کند.

### SemaphoreSlim

- اجازه ورود **N** thread را می‌دهد (نه فقط 1).
- از **async/await** پشتیبانی می‌کند (`WaitAsync`).
- lightweight تر از Semaphore معمولی است.

## مثال lock
```csharp

private readonly object _lock = new object();
int counter = 0;

void Increment()
{
    lock (_lock)
    {
        counter++;
    }
}

```

مثال SemaphoreSlim
```csharp

private static SemaphoreSlim _sem = new SemaphoreSlim(2); // اجازه به ۲ ترد

async Task DownloadAsync()
{
    await _sem.WaitAsync();
    try
    {
        Console.WriteLine("Downloading...");
        await Task.Delay(1000);
    }
    finally
    {
        _sem.Release();
    }
}

```
