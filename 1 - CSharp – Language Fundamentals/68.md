- ویژگی **Delegate:** یک متغیر معمولی است. هر کسی از بیرون کلاس می‌تواند آن را مقداردهی مجدد کند (`=`) یا آن را Invoke کند.
- ویژگی **Event:** یک لایه محافظ روی دلیگیت است (Encapsulation). در بیرون از کلاس، شما فقط می‌توانید به آن متد اضافه (`+=`) یا کم (`-=`) کنید. فقط خودِ کلاسی که Event را تعریف کرده می‌تواند آن را Invoke (اجرا) کند.

## ویژگی Delegate (قابل دستکاری از بیرون → خطرناک)

```csharp

public class Button
{
    public Action OnClick; // Delegate معمولی
}

var btn = new Button();

// افزودن Listener
btn.OnClick += () => Console.WriteLine("Clicked!");

// اما مشکل: از بیرون قابل Override است!
btn.OnClick = () => Console.WriteLine("Hacked!");

// اجرا
btn.OnClick();

```
خروجی:
```markdown

Hacked!

```
مشکل: از بیرون می‌توان کل دلیگیت را جایگزین کرد.

## ویژگی Event (ایمن و استاندارد)

```csharp

public class Button
{
    public event Action OnClick;
    
    public void Click()
    {
        OnClick?.Invoke();
    }
}

var btn = new Button();

btn.OnClick += () => Console.WriteLine("Clicked!");
// btn.OnClick = null;   // خطا: event اجازه Override ندارد

btn.Click();

```
خروجی:
```markdown

Clicked!

```
اینجا فقط اضافه/حذف Listener مجاز است → **Encapsulation بهتر**.
