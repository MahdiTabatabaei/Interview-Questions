## مفهوم کلی

کلمه کلیدی **`async`** و **`await`** در #C برای نوشتن کد **غیرهمزمان (Asynchronous)** استفاده می‌شوند تا برنامه هنگام انجام عملیات طولانی (مثل I/O، دیتابیس، API) **بلاک نشود**.

اما این دو کلمه **نقش متفاوتی دارند**.

---

# 1️⃣ تعریف async چیست؟

درواقع`async` یک **modifier برای متد** است که به کامپایلر می‌گوید این متد می‌تواند شامل `await` باشد و به صورت asynchronous اجرا شود.

مثال:
```csharp

public async Task GetData()
{
    await Task.Delay(2000);
    Console.WriteLine("Done");
}

```

ویژگی‌های `async`:

- روی **متد** قرار می‌گیرد
- اجازه استفاده از `await` را می‌دهد
- معمولاً نوع بازگشتی متد را تبدیل می‌کند به:
    - `Task`
    - `Task<T>`
    - `void` (فقط برای event handler)

# 2️⃣ تعریف await چیست؟

تعریف `await` برای **منتظر ماندن غیر بلاک‌کننده (non‑blocking)** برای یک `Task` استفاده می‌شود.

وقتی `await` اجرا می‌شود:

1. اگر Task هنوز تمام نشده باشد
2. متد **موقتاً متوقف می‌شود**
3. و Thread آزاد می‌شود
4. و  وقتی Task تمام شد → ادامه متد اجرا می‌شود

---

# مثال ساده

### بدون async/await (Blocking)

```csharp

public void GetData()
{
    Thread.Sleep(3000);
    Console.WriteLine("Finished");
}

```

مشکل:

- در Thread برای 3 ثانیه **بلاک** می‌شود
- در UI یا Web باعث مشکل performance می‌شود

---

### با async/await
```csharp

public async Task GetData()
{
    await Task.Delay(3000);
    Console.WriteLine("Finished");
}

```

مزیت:

- در این حالت Thread بلاک نمی‌شود
- در این مدت می‌تواند کارهای دیگر انجام دهد

---

# مثال واقعی‌تر (Web API)

### بدون async
```csharp

public IActionResult GetUser()
{
    var user = repository.GetUser(); // query to database
    return Ok(user);
}

```

اگر دیتابیس کند باشد:

- در این حالت Thread درخواست **بلاک می‌شود**

---

### با async
```csharp

public async Task<IActionResult> GetUser()
{
    var user = await repository.GetUserAsync();
    return Ok(user);
}

```

مزیت:

- در این حالت Thread آزاد می‌شود
- و server می‌تواند requestهای بیشتری هندل کند

# تفاوت دقیق async و await
![[6_difference_async_vs_await.png]]
مثال کامل جریان اجرا

```csharp

public async Task Example()
{
    Console.WriteLine("Start");

    await Task.Delay(2000);

    Console.WriteLine("End");
}

```

جریان:

```markdown

Start
↓
Task.Delay شروع می‌شود
↓
متد pause می‌شود
↓
Thread آزاد می‌شود
↓
بعد از 2 ثانیه
↓
ادامه متد اجرا
↓
End

```


انواع Return در async

1️⃣ Task

```csharp

public async Task Save()
{
    await Task.Delay(1000);
}

```

2️⃣ Task<T>


```csharp

public async Task<int> Calculate()
{
    await Task.Delay(1000);
    return 10;
}

```

3️⃣ void (فقط Event)

```csharp

private async void Button_Click(object sender, EventArgs e)
{
    await Task.Delay(1000);
}

```

در بقیه موارد **نباید async void استفاده شود**.

# یک نکته مهم

### آیا async باعث ساخت Thread جدید می‌شود؟

❌ خیر

خیلی‌ها اشتباه می‌کنند.

تعریف `async/await` معمولاً **Thread جدید نمی‌سازد**.

فقط اجازه می‌دهد **Thread آزاد شود** تا کارهای دیگر انجام دهد.

---

# مثال برای فهم بهتر

فرض کن یک رستوران:

### بدون async

گارسون کنار میز می‌ایستد تا غذا آماده شود.

---

### با async

گارسون سفارش را می‌دهد و می‌رود به میزهای دیگر.

وقتی غذا آماده شد برمی‌گردد.

---

# جمع‌بندی 

> در `async` برای تعریف متدی است که عملیات asynchronous انجام می‌دهد و معمولاً `Task` یا `Task<T>` برمی‌گرداند.
> 
> در `await` برای منتظر ماندن غیر بلاک‌کننده روی یک `Task` استفاده می‌شود. وقتی await اجرا می‌شود، Thread آزاد می‌شود تا کارهای دیگر انجام دهد و پس از تکمیل Task ادامه متد اجرا می‌شود.
