در عملیات زیاد:

- هر بار object جدید ساخته می‌شود
- حافظه زیاد مصرف می‌شود
- در این وضعیت GC زیاد اجرا می‌شود

مثال بد:
```csharp

string s = "";

for(int i=0;i<10000;i++)
{
    s += i;
}

```
اینجا **10000 object ساخته می‌شود.**

❌ چه اتفاقی می‌افتد؟

- در هر iteration
- یک string جدید ساخته می‌شود
- فشار زیاد به GC
- افت performance
