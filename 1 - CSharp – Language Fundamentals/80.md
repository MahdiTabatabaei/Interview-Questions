- کلمه کلیدی **Array:** اندازه ثابت (Fixed size) دارد. سریع‌تر است و برای تعداد المان‌های مشخص عالی است.
- کلاس **List:** اندازه متغیر (Dynamic) دارد. در واقع یک Array در پشت صحنه دارد که با پر شدن، سایز آن را دو برابر می‌کند.

**مثال:**
```csharp

int[] arr = new int[3]; // ثابت
List<int> list = new List<int>(); // منعطف
list.Add(10);

```
