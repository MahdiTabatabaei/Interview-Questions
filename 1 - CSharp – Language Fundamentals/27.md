برای **pin کردن object در حافظه** استفاده می‌شود.

بخاطر اینکه GC ممکن است object را جابجا کند.

کار این است `fixed` مانع این کار می‌شود.

```csharp

unsafe
{
    int[] arr = {1,2,3};

    fixed(int* p = arr)
    {
        Console.WriteLine(*p);
    }
}

```
