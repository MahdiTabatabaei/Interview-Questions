مثال:
```csharp

// Async enumeration از دیتابیس یا API
await foreach (var item in GetDataAsync())
{
    Console.WriteLine(item);
}

async IAsyncEnumerable<string> GetDataAsync()
{
    yield return "A";
    await Task.Delay(100);
    yield return "B";
}

```
