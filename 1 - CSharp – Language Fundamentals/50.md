## await

روش مدرن async در C# است.

مزایا:

- خوانایی بالا
- مدیریت exception بهتر
- رفتار async flow طبیعی

مثال:
```csharp

var data = await GetDataAsync();

```
---

## ContinueWith

روش قدیمی‌تر برای chain کردن Task.
```csharp

GetDataAsync().ContinueWith(task =>
{
    Console.WriteLine(task.Result);
});

```
