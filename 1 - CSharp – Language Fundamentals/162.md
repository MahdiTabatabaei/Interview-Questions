خیر.

نوع Reference Type **به صورت پیشفرض Pass-by-Value ارسال می‌شود ولی مقدار آن Reference است.**
```csharp

void Test(Person p)
{
    p.Name = "Ali";
}

```
اگر بخواهیم **خود reference تغییر کند**:
```csharp

void Test(ref Person p)

```

---


می‌خواهیم دقیقاً بفهمیم:

1. چرا Reference Typeها «به صورت پیش‌فرض» **Pass‑by‑Value** هستند  
2. تفاوت دقیق "تغییر شیء" با "تغییر reference" چیست  
3. چرا `ref` لازمه اگر بخواهیم **خود reference** را تغییر بدهیم  

---

# مثال شماره 1  
## تغییر شیء کار می‌کند، حتی بدون `ref`

```csharp
class Person { public string Name { get; set; } }

void ChangeName(Person p)
{
    p.Name = "Ali";    // تغییر شیء
}

var person = new Person { Name = "Reza" };
ChangeName(person);

Console.WriteLine(person.Name);  // خروجی: Ali
```

### چرا؟
چون:

- کلاس `person` یک reference است (مثلاً آدرس 0xA112F)
- وقتی به متد می‌دهیم، **یک کپی از همین reference** داده می‌شود
- هر دو به یک شیء اشاره می‌کنند  

پس تغییر **داخل شیء** دیده می‌شود.

📌 *اما reference (آدرس) اصلی دست‌نخورده است.*

---

# مثال شماره 2  
## تغییر reference بدون `ref` کار نمی‌کند

```csharp
void Reassign(Person p)
{
    p = new Person { Name = "Sara" };  // تغییر reference
}

var person = new Person { Name = "Reza" };
Reassign(person);

Console.WriteLine(person.Name);  // خروجی: Reza
```

### چرا؟
چون:

- برای اینکه p **کپی reference** است
- وقتی می‌نویسی `p = new Person`، فقط **کپی** به شیء جدید اشاره می‌کند
- درواقع reference اصلی بیرون **اصلاً عوض نشده**

---

# مثال شماره 3  
## این بار تغییر reference با `ref` → اثر می‌کند

```csharp
void Reassign(ref Person p)
{
    p = new Person { Name = "Sara" };
}

var person = new Person { Name = "Reza" };
Reassign(ref person);

Console.WriteLine(person.Name);  // خروجی: Sara
```

### چرا؟
چون:

- این بار p **کپی نیست**
- خود reference اصلی پاس داده می‌شود
- و assignment روی reference اصلی اثر می‌گذارد

---

# خلاصه با تصویر ذهنی ساده

فرض کن:

```
person ───► [ Person(Name="Reza") ]
```

### حالت بدون ref
متد این را دریافت می‌کند:

```
p (copy of person) ───► همان شیء
```

اگر داخل شیء تغییری بدهی → همه می‌بینند  
اگر خود p را به چیز دیگری وصل کنی → فقط p جدید می‌شود، person نه!

---

### حالت با ref

```
p = alias به person
```

پس:

- هر تغییری روی p  
= دقیقاً همان تغییر روی person
