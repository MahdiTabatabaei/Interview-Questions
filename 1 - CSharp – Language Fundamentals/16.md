هر دو برای گرفتن **اولین عنصر یک collection** استفاده می‌شوند.

## First

اگر عنصری پیدا نشود **Exception** می‌دهد.
```csharp

var numbers = new List<int> { 2,4,6 };

var result = numbers.First(x => x > 10);

```
خروجی:
```markdown

InvalidOperationException

```
---

## FirstOrDefault

اگر چیزی پیدا نشود **مقدار پیش‌فرض type را برمی‌گرداند**.
```csharp

var numbers = new List<int> { 2,4,6 };

var result = numbers.FirstOrDefault(x => x > 10);

Console.WriteLine(result); // 0

```
برای reference type:
```markdown

null

```
---

✅ **خلاصه**

- `First` → Exception اگر پیدا نشود
- `FirstOrDefault` → مقدار پیش‌فرض
