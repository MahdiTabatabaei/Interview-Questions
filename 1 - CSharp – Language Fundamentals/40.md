متغیر ### ✔ dynamic در **runtime** تایپ را مشخص می‌کند

یعنی کامپایلر هیچ چکی انجام نمی‌دهد و همه‌چیز را به runtime می‌سپارد.

```csharp

dynamic obj = "hi";
obj = 10;
obj = new Person();

```

```csharp

dynamic x = 10;
x = "Text"; // OK
x = new Person(); // OK

```
✅ رفتار مثل زبان‌های پویا (Python, JS)

# مثال تفاوت رفتاری

## مثال var – امنیت بالا
```csharp

var name = "Ali";
name.DoSomething(); // Error در compile-time

```
قبل از اجرا خطا می‌دهد → عالی برای جلوگیری از خطاهای runtime.

مثال dynamic – خطا در runtime
```csharp

dynamic name = "Ali";
name.DoSomething(); // Error در runtime

```

خطر: برنامه ممکن است وسط اجرا کرش کند.
