- هر **`ToList()`** عملیات تمام داده‌های IEnumerable را اجرا می‌کند و در حافظه قرار می‌دهد.
- اگر این عملیات چند بار تکرار شود، Collectionهای بزرگ ساخته می‌شود.
- در حلقه‌ها و عملیات‌های زنجیره‌ای، این موضوع می‌تواند **کشش بیش از حد** بر حافظه و CPU باشد.

### نمونه:
```csharp

// بد
var list = data.Where(x => x > 10).ToList();
// هر بار این خط اجرا می‌شود، مجموعه جدید ساخته می‌شود

```
### راه حل:

- فقط زمانی که نیاز است، استفاده کنید؛ یا داده اولیه را قبل از حلقه در متغیر ذخیره کنید.
