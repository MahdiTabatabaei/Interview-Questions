**مفهوم:** وقتی شما متد `Dispose` را دستی صدا می‌زنید، یعنی منابع را آزاد کرده‌اید. دیگر نیازی نیست که Garbage Collector دوباره متد **Finalizer** (تخریب‌کننده) آن آبجکت را اجرا کند.

با فراخوانی `GC.SuppressFinalize(this)`، به GC می‌گویید: “این آبجکت قبلاً تمیز شده، لازم نیست دوباره برای Finalizer در صف قرار بگیرد”. این کار باعث بهبود عملکرد GC می‌شود.

این مثال برای کلاس‌هایی است که **Finalizer دارند**.

```csharp

public class ResourceHolder : IDisposable
{
    private IntPtr _handle;
    private bool _disposed;

    public ResourceHolder()
    {
        _handle = System.Runtime.InteropServices.Marshal.AllocHGlobal(100);
    }

    ~ResourceHolder()
    {
        // Finalizer (اگر Dispose دستی صدا نشود)
        Cleanup();
    }

    public void Dispose()
    {
        Cleanup();

        // می‌گوییم Finalizer دیگر لازم نیست اجرا شود
        GC.SuppressFinalize(this);
    }

    private void Cleanup()
    {
        if (!_disposed)
        {
            System.Runtime.InteropServices.Marshal.FreeHGlobal(_handle);
            _disposed = true;
        }
    }
}

```
استفاده:

```csharp

using (var r = new ResourceHolder())
{
    // استفاده از منابع unmanaged
}

```
مزیت:

- منابع unmanaged **بلافاصله** آزاد می‌شوند
- ابزار GC دیگر Finalizer را اجرا نمی‌کند → **بهبود عملکرد**
- صف Finalizer کمتر اشغال می‌شود و سرعت GC بالا می‌رود
