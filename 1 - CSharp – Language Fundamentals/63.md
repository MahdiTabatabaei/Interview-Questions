**مفهوم:** `yield` به ما اجازه می‌دهد که یک **Iterative Navigation** بسازیم بدون اینکه کل لیست را در حافظه لود کنیم. این دستور داده‌ها را به صورت “تنبل” (Lazy) تولید می‌کند. یعنی هر بار که حلقه `foreach` یک آیتم می‌خواهد، کد اجرا می‌شود تا آن آیتم را برگرداند و سپس وضعیت متد حفظ می‌شود تا درخواست بعدی.

**مثال:**
```csharp

public IEnumerable<int> GetNumbers() {
    yield return 1;
    yield return 2;
    yield return 3;
}
// هنگام فراخوانی، هر بار فقط یک عدد تولید و به حلقه فرستاده می‌شود.

```
