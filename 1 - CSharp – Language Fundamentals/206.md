
تعریف **Concurrency** و **Parallelism** هر دو به اجرای هم‌زمان کارها مربوط هستند، اما یکسان نیستند.

---

# ✅ تفاوت مفهومی

## 🔹 1. مفهوم Concurrency (هم‌روندی)

یعنی **چند کار بتوانند در یک بازه زمانی پیش بروند**،  
اما لزوماً هم‌زمان اجرا نمی‌شوند.

سیستم ممکن است بین کارها **سوییچ (Context Switch)** کند.

📌 حتی روی یک CPU تک‌هسته‌ای هم ممکن است.

### مثال ساده
فرض کنید:
- همزمان در حال دانلود فایل هستید
- و در همان برنامه، کاربر می‌تواند روی دکمه‌ها کلیک کند

دانلود در پس‌زمینه انجام می‌شود ولی CPU بین کارها جابه‌جا می‌شود.

---

## 🔹 2. مفهوم Parallelism (موازی‌سازی)

یعنی **چند کار واقعاً هم‌زمان اجرا شوند**  
(روی چند هسته CPU)

📌 نیازمند چند هسته پردازنده است.

---

# ✅ تفاوت کلیدی

| ویژگی | Concurrency | Parallelism |
|--------|------------|------------|
| اجرا همزمان واقعی | ❌ لزوماً نه | ✅ بله |
| نیاز به چند هسته | ❌ نه | ✅ بله |
| هدف اصلی | پاسخ‌گویی بهتر | افزایش سرعت پردازش |
| معمولاً با | async/await, Task | Parallel.For, PLINQ |

---

# ✅ مثال در#C

---

# 🔹 مثال Concurrency (async/await)

```csharp
using System;
using System.Threading.Tasks;

class Program
{
    static async Task Main()
    {
        Task task1 = DownloadFileAsync();
        Task task2 = DownloadFileAsync();

        await Task.WhenAll(task1, task2);

        Console.WriteLine("تمام دانلودها تمام شد");
    }

    static async Task DownloadFileAsync()
    {
        Console.WriteLine("شروع دانلود...");
        await Task.Delay(3000); // شبیه‌سازی عملیات I/O
        Console.WriteLine("دانلود تمام شد");
    }
}
```

### ✅ چه اتفاقی می‌افتد؟

- دو دانلود همزمان شروع می‌شوند
- در این حالت Thread بلاک نمی‌شود
- و CPU درگیر نیست (عملیات I/O)
- این **Concurrency** است نه Parallelism واقعی

---

# 🔹 مثال Parallelism (Parallel.For)

```csharp
using System;
using System.Threading.Tasks;

class Program
{
    static void Main()
    {
        Parallel.For(0, 5, i =>
        {
            Console.WriteLine($"Task {i} در Thread {Environment.CurrentManagedThreadId}");
            Thread.Sleep(2000);
        });

        Console.WriteLine("تمام شد");
    }
}
```

### ✅ چه اتفاقی می‌افتد؟

- چند iteration واقعاً همزمان اجرا می‌شوند
- از چند هسته CPU استفاده می‌شود
- این Parallelism واقعی است

---

# ✅ مثال واضح‌تر تفاوت

### 🔹 در Concurrency (تک هسته هم ممکن است)

```csharp
await Task.WhenAll(
    Task.Delay(2000),
    Task.Delay(2000)
);
```

زمان اجرا ≈ 2 ثانیه  
(چون عملیات I/O است)

---

### 🔹 در Parallelism (پردازش سنگین CPU)

```csharp
Parallel.Invoke(
    () => Compute(),
    () => Compute()
);
```

اگر سیستم چند هسته داشته باشد:
زمان اجرا تقریباً نصف می‌شود.

---

# ✅ تفاوت از نظر نوع کار

| نوع عملیات | مناسب برای |
|------------|------------|
| I/O (دانلود، دیتابیس، API) | Concurrency (async/await) |
| CPU Bound (محاسبات سنگین) | Parallelism |

---

# ✅ اشتباه رایج

خیلی‌ها فکر می‌کنند:

> async = اجرای موازی

❌ اشتباه است.

`async/await` بیشتر برای **Concurrency و non-blocking I/O** است  
نه اجرای موازی CPU.

---

# ✅ تشبیه ساده

### 🍳 Concurrency
آشپز تنها:
- برنج را می‌گذارد
- بین آن سالاد درست می‌کند
- بین آن غذا را هم می‌زند  
(سوییچ بین کارها)

---

### 👨‍🍳👩‍🍳 Parallelism
دو آشپز:
- یکی برنج
- یکی سالاد  
(واقعاً همزمان)
