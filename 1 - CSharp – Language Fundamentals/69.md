این‌ها دلیگیت‌های آماده و جنریک در .NET هستند که نیاز ما به تعریف دلیگیت‌های دستی را کم می‌کنند:

- تعریف **Action:** برای متدهایی که خروجی ندارند (`void`). می‌تواند تا ۱۶ ورودی بگیرد.
- تعریف **Func:** برای متدهایی که **خروجی دارند**. آخرین پارامتر جنریک همیشه نوع خروجی است.

**مثال:**
```csharp

Action<string> print = (s) => Console.WriteLine(s);
Func<int, int, int> add = (a, b) => a + b; // ورودی int، خروجی int

```

---

در C# دو نوع delegate بسیار پرکاربرد داریم: **Func** و **Action**

این‌ها ابزارهایی هستند برای اینکه بتوانیم **یک تکه کد را به عنوان ورودی** به یک متد بدهیم.

بیایید ساده و کاربردی توضیح دهیم.

---

# ✔ 1) کلمه کلیدی Action چیست؟

## درواقع Action: یک متد را نشان می‌دهد که **برگشتی ندارد**.

یعنی:
```markdown

Action = متدی که void برمی‌گرداند.

```
مثال ساده
```csharp

Action sayHello = () => Console.WriteLine("Hello");
sayHello();

```
کاربرد:

وقتی می‌خواهی یک کار انجام بدهی، بدون اینکه خروجی خاصی داشته باشد.

### تعریف Action با پارامتر

درواقع Action می‌تواند 1 تا 16 پارامتر داشته باشد:
```csharp

Action<string> print = (msg) => Console.WriteLine(msg);
print("Hi");

```
---

# ✔ 2) کلمه کلیدی Func چیست؟

## درواقع Func: یک متد را نشان می‌دهد که **یک مقدار برمی‌گرداند**.

فرمت Func همیشه این است:
```markdown

Func<پارامترها..., نوع_خروجی>

```
مثال ساده:
```csharp

Func<int, int> square = x => x * x;
Console.WriteLine(square(5)); // 25

```
مثال با چند پارامتر:
```csharp

Func<int, int, int> add = (a, b) => a + b;
Console.WriteLine(add(3, 4)); // 7

```

---
# ✔ 3) تفاوت Action و Func در یک جمله

- **Action:** کار انجام می‌دهد ولی خروجی ندارد (void).
- **Func:** کار انجام می‌دهد و خروجی دارد (هر نوعی).

```csharp

void Repeat(int times, Action action)
{
    for (int i = 0; i < times; i++)
        action();
}

Repeat(3, () => Console.WriteLine("Hi"));

```

### کاربرد ۲) صاف و ساده‌تر کردن LINQ

وقتی می‌نویسی:
```csharp

var numbers = list.Where(n => n > 10);

```
این `n => n > 10` یک **Func<int, bool>** است.

### کاربرد ۳) ساختن Factory، Strategy و Callback
```csharp

Func<int> generator = () => new Random().Next(1, 100);
int value = generator();

```

---

### کاربرد ۴) استفاده در Thread, Task
```csharp

Task.Run(() => DoSomething()); // Action
Task<int>.Run(() => Calculate()); // Func<int>

```

---

### کاربرد ۵) جلوگیری از تکرار کد
```csharp

T LogAndExecute<T>(Func<T> func)
{
    Console.WriteLine("Start");
    var result = func();
    Console.WriteLine("End");
    return result;
}

```
