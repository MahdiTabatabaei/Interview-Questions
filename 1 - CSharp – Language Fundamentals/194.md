مقادیر **Session** و **Cookie** هر دو برای نگهداری اطلاعات مربوط به کاربر در وب استفاده می‌شوند، اما تفاوت اصلی آن‌ها در **محل ذخیره‌سازی و نحوه مدیریت** است.

---

## تعریف Cookie چیست؟

درواقع **Cookie** یک قطعه داده کوچک است که **در مرورگر کاربر (Client)** ذخیره می‌شود.

وقتی سرور یک Cookie ارسال می‌کند، مرورگر آن را ذخیره می‌کند و در درخواست‌های بعدی دوباره برای سرور می‌فرستد.

مثال هدر HTTP:

```
Set-Cookie: username=ali; expires=Wed, 21 Oct 2026 07:28:00 GMT
```

در درخواست‌های بعدی:

```
Cookie: username=ali
```

### محل ذخیره

در **مرورگر کاربر (Client Side)**

### ویژگی‌ها
- حجم محدود (حدود 4KB)
- کاربر می‌تواند آن را ببیند یا حذف کند
- در هر درخواست به سرور ارسال می‌شود
- می‌تواند **Expiration** داشته باشد

### مثال کاربرد
- نگهداری **Remember Me**
- نگهداری **تنظیمات کاربر**
- ذخیره **Token**

---

## تعریف Session چیست؟

درواقع **Session** روشی برای نگهداری اطلاعات کاربر در **سمت سرور (Server)** است.

وقتی کاربر به سایت وارد می‌شود:

1. سرور یک **Session** ایجاد می‌کند
2. یک **Session ID** تولید می‌شود
3. این Session ID در قالب یک **Cookie** به مرورگر ارسال می‌شود
4. در درخواست‌های بعدی مرورگر همان Session ID را می‌فرستد

---

### محل ذخیره

اطلاعات Session در **سرور** ذخیره می‌شود، نه در مرورگر.

بسته به تنظیمات می‌تواند در اینجا ذخیره شود:

- Memory سرور
- Distributed Cache
- Redis
- SQL Server

---

### مثال

فرض کنیم اطلاعات کاربر در Session ذخیره شود:

```
Session["UserId"] = 25
Session["Role"] = "Admin"
```

در مرورگر فقط این ذخیره می‌شود:

```
ASP.NET_SessionId = X12345ABC
```

---

## تفاوت اصلی Session و Cookie

| ویژگی | Cookie | Session |
|------|------|------|
| محل ذخیره | مرورگر (Client) | سرور |
| امنیت | کمتر | بیشتر |
| حجم | محدود (~4KB) | تقریباً نامحدود |
| دسترسی کاربر | قابل مشاهده | قابل مشاهده نیست |
| ارسال در Request | بله | فقط SessionId در Cookie ارسال می‌شود |

---

## یک مثال ساده

فرض کن وارد یک سایت فروشگاهی می‌شوی.

### با Cookie
مرورگر ممکن است ذخیره کند:

```
theme=dark
language=fa
```

---

### با Session
سرور ذخیره می‌کند:

```
UserId = 15
CartItems = 3
```

در مرورگر فقط:

```
SessionId = ABC123
```

---

## نکته مهم

در **ASP.NET Core** معمولاً Session به این صورت فعال می‌شود:

```csharp
builder.Services.AddSession();
```

و در Pipeline:

```csharp
app.UseSession();
```

استفاده:

```csharp
HttpContext.Session.SetString("UserName", "Ali");
```

---

✅ خلاصه خیلی کوتاه:

- **Cookie** → در مرورگر ذخیره می‌شود  
- **Session** → در سرور ذخیره می‌شود و فقط SessionId در Cookie نگه‌داری می‌شود
