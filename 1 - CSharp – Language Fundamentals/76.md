برای **درخواست دیرهنگام (Lazy Initialization)** استفاده می‌شود. یعنی شیء فقط زمانی ساخته می‌شود که برای اولین بار به آن نیاز داریم. این کار برای اشیایی که ساختشان “هزینه‌بر” (از نظر حافظه یا CPU) است، عالی است.

**مثال:**

```csharp

public class BigData
{
    public BigData() { Console.WriteLine("BigData Initialized!"); }
}

var lazyData = new Lazy<BigData>(); // اینجا هنوز ساخته نشده

Console.WriteLine("Before accessing Value");
var data = lazyData.Value; // در این خط شیء ساخته می‌شود

```
