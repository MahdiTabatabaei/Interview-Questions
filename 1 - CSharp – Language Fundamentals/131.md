## تعریف JIT Compiler چیست؟

درواقع **JIT (Just-In-Time) Compiler** در .NET کامپایلری است که کد **IL (Intermediate Language)** را در زمان اجرا به **کد ماشین (Native Machine Code)** تبدیل می‌کند.

روند اجرای برنامه در .NET:

```
C# code
   ↓
C# Compiler
   ↓
IL (Intermediate Language)
   ↓
CLR
   ↓
JIT Compiler
   ↓
Native Machine Code
```

یعنی:

- کد C# ابتدا به **IL** تبدیل می‌شود.
- وقتی برنامه اجرا می‌شود، **JIT** هر متد را **در لحظه نیاز** به کد ماشین تبدیل می‌کند.

مثال:

اگر برنامه 100 متد داشته باشد ولی فقط 10 متد اجرا شوند،  
درواقع JIT فقط همان **10 متد** را کامپایل می‌کند.

این باعث می‌شود:

- شروع startup سریع‌تر شود
- کامپایل فقط برای کدهای مورد استفاده انجام شود

---

# تعریف RyuJIT چیست؟

درواقع **RyuJIT** موتور JIT مدرن .NET است.

مایکروسافت آن را جایگزین JITهای قدیمی کرد.

ویژگی‌ها:

- سریع‌تر در کامپایل
- تولید **کد ماشین بهینه‌تر**
- پشتیبانی بهتر از **64-bit**
- استفاده در **.NET Core / .NET 5+ / .NET 6+**

قبلاً:

```
Legacy JIT
x86 JIT
```

الان:

```
RyuJIT
```

درواقع RyuJIT در واقع **پیاده‌سازی JIT** است.

---

# تعریف Tiered JIT چیست؟

درواقع **Tiered Compilation** یک **استراتژی کامپایل** است، نه یک نوع JIT.

ایده آن این است:

ابتدا سریع کامپایل کن → بعداً اگر متد زیاد استفاده شد آن را **بهینه‌تر کامپایل کن**.

مراحل:

### Tier 0
کامپایل سریع

هدف:
```
startup سریع برنامه
```

بهینه‌سازی کم است.

---

### Tier 1
اگر متد زیاد اجرا شود:

ابزار CLR آن متد را دوباره کامپایل می‌کند با **optimization بیشتر**.

نتیجه:

```
performance بهتر در طول اجرای برنامه
```

---

### مثال ساده

فرض کن متدی ۱ میلیون بار اجرا می‌شود.

بدون Tiered JIT:

```
یک بار JIT
با optimization متوسط
```

با Tiered JIT:

```
Tier0 → سریع کامپایل
اگر Hot شد
Tier1 → دوباره با optimization بالا
```

---

# تفاوت اصلی

**RyuJIT**

- موتور JIT واقعی
- مسئول تبدیل IL → Native code
- یک implementation از JIT

**Tiered JIT**

- یک **strategy** برای کامپایل
- چند مرحله‌ای کامپایل می‌کند
- از **RyuJIT** برای کامپایل استفاده می‌کند

---

# رابطه آنها

در .NET جدید:

```
Tiered Compilation
        ↓
      RyuJIT
        ↓
   Native Code
```
