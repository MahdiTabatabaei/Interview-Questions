برای **تطبیق نوع پارامتر و خروجی delegate** استفاده می‌شود.

---

# Covariance

اجازه می‌دهد **نوع بازگشتی مشتق شده باشد**.
```csharp

class Animal {}
class Dog : Animal {}

delegate Animal GetAnimal();

Animal GetDog()
{
    return new Dog();
}

GetAnimal del = GetDog;

```
اینجا `Dog` به `Animal` تبدیل شده.

---

# Contravariance

اجازه می‌دهد **پارامتر پایه باشد**.
```csharp

class Animal {}
class Dog : Animal {}

delegate void Handler(Dog dog);

void HandleAnimal(Animal animal){}

Handler h = HandleAnimal;

```

بیاییم با یک مثال واقعی‌تر و شهودی‌تر جلو برویم. فرض کن کلاس‌ها این هستند:
```csharp

class Animal 
{
    public string Name;
}

class Dog : Animal 
{
}

```
مجود Dog یک نوع **مشتق‌شده از Animal** است.

---

# 1️⃣ تعریف Covariance (کوواریانس)

اینجا موضوع **نوع خروجی (return type)** است.

ایده ساده:

> اگر کدی انتظار **Animal** داشته باشد، برگرداندن **Dog** هم مشکلی ندارد.

چون **Dog خودش یک Animal است**.

### مثال

delegate:
```csharp

delegate Animal AnimalFactory();

```
متدی که **Dog** برمی‌گرداند:
```csharp

Dog CreateDog()
{
    return new Dog { Name = "Rex" };
}

```
اتصال:
```csharp

AnimalFactory factory = CreateDog;

```
استفاده:
```csharp

Animal a = factory();

```
چرا درست است؟

چون:
```markdown

Dog → Animal

```
یعنی:

“من Animal می‌خواهم، اگر Dog بدهی هم قبول است.”

این می‌شود **Covariance**.

خلاصه ذهنی:

```markdown

return type
Derived → Base
Dog → Animal

```
---

# 2️⃣ تعریف Contravariance (کانتراواریانس)

اینجا موضوع **پارامتر ورودی** است.

ایده ساده:

> اگر کدی قرار است **Dog** به متد بدهد، متدی که **Animal** می‌گیرد هم می‌تواند آن را پردازش کند.

چون **Dog یک Animal است**.

### delegate
```csharp

delegate void DogHandler(Dog dog);

```
متدی که **Animal** می‌گیرد:
```csharp

void HandleAnimal(Animal animal)
{
    Console.WriteLine(animal.Name);
}

```
اتصال:
```csharp

DogHandler handler = HandleAnimal;

```
استفاده:
```csharp

handler(new Dog { Name = "Rex" });

```

چرا درست است؟

چون متد:

```markdown

Animal

```
می‌گیرد و **Dog هم یک Animal است**.

پس مشکلی ندارد.

این می‌شود **Contravariance**.

---

# تصویر ذهنی خیلی ساده

## تعریف Covariance (برای خروجی)

```markdown

متد → Dog
delegate انتظار → Animal

Dog قابل تبدیل به Animal است ✅

```

```markdown

Dog → Animal

```
---

## تعریف Contravariance (برای ورودی)
```markdown

delegate می‌فرستد → Dog
متد می‌گیرد → Animal

Dog یک Animal است ✅

```

```markdown

Animal ← Dog

```

---
# یک مثال واقعی‌تر (که سریع در ذهن می‌ماند)

فرض کن:
```markdown

Animal = حیوان
Dog = سگ

```

### Covariance

تو می‌گویی:

> برایم یک **حیوان** بیاور.

دوستت **سگ** می‌آورد.

مشکلی نیست چون سگ هم حیوان است.

---

### Contravariance

تو می‌گویی:

> من به تو **سگ** می‌دهم، رسیدگی کن.

دوستت می‌گوید:

> من با **حیوان‌ها** کار می‌کنم.

باز هم مشکلی نیست چون سگ هم حیوان است.
