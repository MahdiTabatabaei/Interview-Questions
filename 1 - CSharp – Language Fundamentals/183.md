درواقع **Operator Overloading** یکی از قابلیت‌های قدرتمند C# است که اگر درست استفاده شود، کد را **خواناتر، طبیعی‌تر و دامنه‌محور (Domain‑Driven)** می‌کند؛ و اگر بد استفاده شود، می‌تواند کد را گیج‌کننده کند.  
بیایید دقیق، مرحله‌به‌مرحله و با مثال جلو برویم.

---

## 🔹 مفهوم Operator Overloading چیست؟

مفهوم **Operator Overloading** یعنی:
> تعریف رفتار **عملگرهای استاندارد** (`+ - * == > <` و …) برای **نوع‌های سفارشی (Class / Struct)**

به زبان ساده:
> کاری کنیم عملگرها برای کلاس‌های خودمان **معنای منطقی داشته باشند**

مثلاً:
```csharp
var c = a + b;
```
اگر `a` و `b` از نوع کلاس خودت باشند، با Operator Overloading می‌توانی مشخص کنی این `+` دقیقاً چه کاری انجام دهد.

---

## 🔹 چرا به آن نیاز داریم؟

بدون Operator Overloading:
```csharp
var result = vector1.Add(vector2);
```

با Operator Overloading:
```csharp
var result = vector1 + vector2;
```

✅ خواناتر  
✅ نزدیک‌تر به زبان ریاضی و دامنه مسئله  
✅ کاهش متدهای مصنوعی مثل `Add`, `Subtract`, `Compare`

---

## 🔹 مثال پایه: جمع دو Vector

```csharp
public struct Vector
{
    public int X { get; }
    public int Y { get; }

    public Vector(int x, int y)
    {
        X = x;
        Y = y;
    }

    public static Vector operator +(Vector a, Vector b)
    {
        return new Vector(a.X + b.X, a.Y + b.Y);
    }
}
```

استفاده:
```csharp
var v1 = new Vector(2, 3);
var v2 = new Vector(4, 1);

var v3 = v1 + v2; // (6, 4)
```

📌 نکته مهم:  
همه Operatorها **باید static باشند**.

---

## 🔹 Overload کردن Operatorهای مقایسه‌ای

مثلاً `==` و `!=`:

```csharp
public static bool operator ==(Vector a, Vector b)
{
    return a.X == b.X && a.Y == b.Y;
}

public static bool operator !=(Vector a, Vector b)
{
    return !(a == b);
}
```

⚠️ **قانون خیلی مهم**  
اگر `==` را overload کنی، **باید** این‌ها را هم پیاده‌سازی کنی:
```csharp
public override bool Equals(object obj)
public override int GetHashCode()
```

در غیر این صورت رفتار غیرمنتظره در Dictionary، HashSet و LINQ رخ می‌دهد.

---

## 🔹 مثال کامل Equality استاندارد

```csharp
public override bool Equals(object obj)
{
    if (obj is not Vector other)
        return false;

    return X == other.X && Y == other.Y;
}

public override int GetHashCode()
{
    return HashCode.Combine(X, Y);
}
```

## 🔹 Operator Unary و Binary

### Unary (یک operand)
```csharp
public static Vector operator -(Vector v)
{
    return new Vector(-v.X, -v.Y);
}
```

استفاده:
```csharp
var v = -v1;
```

---

### Binary (دو operand)
```csharp
public static Vector operator *(Vector v, int scalar)
{
    return new Vector(v.X * scalar, v.Y * scalar);
}
```

---

## 🔹 Overload + به همراه string

```csharp
public static string operator +(Vector v, string label)
{
    return $"{label}: ({v.X}, {v.Y})";
}
```

## 🔹 بهترین موارد استفاده (✅ Do)

✅ برای مفاهیم ریاضی (Vector، Matrix، Complex)  
✅ برای Value Objectها در DDD  
✅ زمانی که معنا کاملاً واضح است  
✅ برای افزایش خوانایی کد

---

## 🔹 مواردی که نباید استفاده شود (❌ Don’t)

❌ اگر رفتار operator غیرمنتظره باشد  
❌ اگر باعث گمراهی توسعه‌دهنده دیگر شود  
❌ برای منطق‌های تجاری پیچیده  
❌ وقتی متد نام‌دار خواناتر است

مثال بد:
```csharp
order1 + order2; // ❌ این یعنی چی؟
```

---

## 🔹 تفاوت Operator Overloading با Method Overloading

| ویژگی | Operator Overloading | Method Overloading |
|------|----------------------|--------------------|
| هدف | تعریف رفتار operatorها | تعریف متد با امضای مختلف |
| خوانایی | خیلی بالا (اگر درست باشد) | معمولی |
| محدودیت | فقط operatorهای خاص | بدون محدودیت |

---

## ✅ جمع‌بندی خیلی کوتاه

> **Operator Overloading** یعنی تعریف رفتار عملگرهای استاندارد C# برای کلاس‌های خودت  
> تا کد طبیعی‌تر، خواناتر و نزدیک‌تر به دامنه مسئله شود.  
> اما باید **با احتیاط** و فقط زمانی که معنا واضح است استفاده شود.

---

اگر دوست داری، می‌توانم:
- تفاوت Operator Overloading با **Implicit / Explicit Conversion**
- یا مثال حرفه‌ای با **Money Value Object**
- یا بررسی Performance و GC

را هم توضیح بدهم. کدامش را می‌خواهی؟
