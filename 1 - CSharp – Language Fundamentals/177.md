در یک جملهٔ خیلی ساده:

**Encryption** قابل **برگشت** است.  
**Hashing** قابل **برگشت نیست**.

اما برای اینکه موضوع کاملاً روشن شود، بگذار دقیق، فنی و خلاصه توضیح بدهم.

---

# تفاوت اصلی: برگشت‌پذیری (Reversibility)

## الگوی Encryption (رمزنگاری)

- یک متن ورودی (**plaintext**) را با یک **کلید** تبدیل به **ciphertext** می‌کند.
- **قابل بازگشت** است: با همان کلید یا یک کلید دیگر می‌توان متن اصلی را دوباره بدست آورد.
- هدف: **جلوگیری از خوانده شدن داده توسط غیرمجاز**.

نمونه:

```
Encrypt( "Hello", key ) → "A9D1X2..."
Decrypt( "A9D1X2...", key ) → "Hello"
```

**کاربرد:**

- ذخیره امن اطلاعات قابل بازیابی (tokenها، اتصال به بانک، config)
- انتقال امن داده (TLS/HTTPS)
- سیستم‌های پیام‌رسان

---

## الگوی Hashing (هش کردن)

- یک متن را تبدیل به یک مقدار هش (مثلاً 256 بیت) می‌کند.
- **غیرقابل برگشت** است: فقط یک‌طرفه (One-way).
- هدف: **تشخیص یکسان بودن داده**، نه بازیابی آن.

نمونه:

```
Hash("Hello") → "AAF4C61DDCC5E8A2..."
```

اگر ورودی حتی یک کاراکتر تغییر کند، هش کاملاً تغییر می‌کند.

**کاربرد:**

- ذخیره امن رمز عبور (Password hashing)
- یکپارچگی داده‌ها (Integrity)
- تشخیص تغییر فایل‌ها

---

# تفاوت‌های کلیدی دیگر

## 1. برگشت‌پذیری  
Encryption = Two-way  
Hashing = One-way

## 2. استفاده از کلید  
Encryption → نیاز به **کلید**  
Hashing → بدون کلید (ولی می‌توان SALT داشت)

## 3. طول خروجی  
Encryption → اندازه خروجی وابسته به ورودی  
Hashing → طول خروجی ثابت است (مثل SHA-256 همیشه 256 بیت)

## 4. هدف  
Encryption → محرمانگی (Confidentiality)  
Hashing → یکپارچگی (Integrity) و تأیید هویت

# مثال واقعی از کاربرد

## چرا رمز عبور را encrypt نمی‌کنیم؟

چون اگر encrypt کنیم، باید **کلید** را ذخیره کنیم، و اگر کسی کلید را بدزدد:

- تمام رمزها بازیابی می‌شوند  
→ فاجعه امنیتی

با hashing:

- حتی شما هم نمی‌توانید رمز را بازیابی کنید
- فقط می‌توانید مقایسه کنید

```
Hash(inputPassword) == storedHash
```

برای امنیت واقعی از الگوریتم‌های hashing مخصوص رمز عبور استفاده می‌شود:

- PBKDF2
- bcrypt
- scrypt
- Argon2

# خلاصه نهایی

Encryption:

- reversible
- uses keys
- protects data confidentiality
- example: AES, RSA

Hashing:

- irreversible
- one-way
- used for verification/integrity
- example: SHA256, SHA3, bcrypt
