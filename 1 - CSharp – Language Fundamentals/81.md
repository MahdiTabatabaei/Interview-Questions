- اینترفیس **`ICollection`:** امکاناتی مثل `Add`, `Remove`, `Clear` و `Count` را می‌دهد. (فقط مدیریت کلی مجموعه)
- اینترفیس **`IList`:** تمام امکانات `ICollection` را دارد + **دسترسی از طریق ایندکس `[]`** و متدهایی مثل `InsertAt`.
---
هر دو **اینترفیس (Interface)** هستند و کلاس نمی باشند.

یعنی خودشان **پیاده‌سازی ندارند**؛ فقط می‌گویند هر کلاسی که آن‌ها را implement کند باید این قابلیت‌ها را داشته باشد.

مثال:
```csharp

public interface ICollection<T>
{
    int Count { get; }
    void Add(T item);
    bool Remove(T item);
    void Clear();
}

```
پس `ICollection` فقط **قرارداد (contract)** است.

---

## چه کلاس‌هایی آن‌ها را پیاده‌سازی می‌کنند؟

مثلاً:
```csharp

List<T>

```
همه این‌ها را implement می‌کند:
```markdown

IEnumerable
ICollection
IList

```
مثال:
```csharp

List<int> numbers = new List<int>();
numbers.Add(5);
numbers.Add(10);

Console.WriteLine(numbers[0]);

```
اینجا:

- `Add` از **ICollection**
- `[]` از **IList**

می‌آید.
