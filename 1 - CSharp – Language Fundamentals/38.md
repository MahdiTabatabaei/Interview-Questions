کلاس Weak Reference اجازه می‌دهد شیء **در صورت نبود reference دیگر حذف شود** توسط GC،

ولی شما بتوانید تا زمان حذف به آن دسترسی داشته باشید.
```csharp

WeakReference<Person> wr = new WeakReference<Person>(new Person());

if (wr.TryGetTarget(out var p))
{
    Console.WriteLine("Object alive");
}

```
✅ برای **cache‌ها و data موقت** استفاده می‌شود.
