### نکات بهبود:

- **Avoid multiple enumerations:** فرض کنید از `ToList()` چند بار در حلقه یا چند جای مختلف استفاده کنید، این باعث تکرار عملیات می‌شود.
- **Use deferred execution:** دقت کنید که LINQ در صورت نیاز lazy اجرا می‌شود ولی وقتی `ToList()` یا `ToArray()` بکار ببرید، eager می‌شود.
- **Reduce data early:** قبل از عملیات‌های سنگین، داده‌های غیر ضروری را فیلتر کنید (`Where`) در ابتدا.
- **Use compiled queries:** در مواردی که چندبار استفاده می‌شود، می‌توانید LINQ را **کامپایل** کنید.
- **Avoid unnecessary copies:** مثلا `[data].Where(...).ToList()` را فقط وقتی لازم است، استفاده کنید؛ در غیر این صورت، ترجیح دهید به صورت lazy باقی بماند.

### چرا زیاد استفاده از LINQ باعث کاهش Performance می‌شود:

- هر `ToList()` یا `ToArray()` باعث اجرای کامل و ساخت Collection می‌شود.
- عملیات زنجیره‌ای بیشتر، عملیات اضافی در مراحل مختلف ایجاد می‌کند.

### مثال:
```csharp

// بد
var result = data.Where(x => x > 10).ToList();
foreach (var item in result)
{
    // عملیات
}

// خوب
foreach (var item in data.Where(x => x > 10))
{
    // عملیات
}

```
