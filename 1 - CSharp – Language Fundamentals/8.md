## خلاصه :

boxing

تبدیل value type به object

unboxing

برعکس آن

# 1️⃣ عمل Boxing چیست؟

عمل **Boxing** یعنی تبدیل یک **Value Type** به **object (Reference Type)**.

وقتی Boxing انجام می‌شود:

1. مقدار Value Type
2. در **Heap** کپی می‌شود
3. و به صورت **object reference** ذخیره می‌شود

---

### مثال
```csharp

int number = 10;

object obj = number;   // Boxing

```

جریان در حافظه:

```markdown

Stack: number = 10
Heap:  object → 10

```

در اینجا مقدار `10` از Stack به Heap کپی شده است.

---

# 2️⃣ عمل Unboxing چیست؟

عمل **Unboxing** یعنی تبدیل دوباره **object** به **Value Type**.

اما باید **Cast** انجام شود.

---

### مثال

```csharp

object obj = 10;   // Boxing

int number = (int)obj;   // Unboxing

```

جریان:

```markdown

Heap: object → 10
Stack: number = 10

```

مثال کامل

```csharp

int x = 5;

object obj = x;     // Boxing

int y = (int)obj;   // Unboxing

Console.WriteLine(y);

```

# چرا Boxing بد است؟

عمل Boxing باعث **کاهش Performance** می‌شود چون:

1️⃣ در این حالت Allocation در Heap انجام می‌شود

2️⃣ در این حالت Garbage Collector درگیر می‌شود

3️⃣ عملیات Copy انجام می‌شود

به همین دلیل در کدهای Performance‑Sensitive باید از آن اجتناب کرد.

---

# مثال رایج Boxing

```csharp

ArrayList list = new ArrayList();

list.Add(10);  // Boxing
list.Add(20);  // Boxing

```

چون `ArrayList` از `object` استفاده می‌کند.

---

# راه‌حل بهتر (Generics)

```csharp

List<int> list = new List<int>();

list.Add(10);
list.Add(20);

```

در اینجا **Boxing اتفاق نمی‌افتد**.

---

# یک نکته مهم 

عمل Boxing معمولاً در این موارد اتفاق می‌افتد:

- استفاده از `object`
- استفاده از `ArrayList`
- استفاده از Interface روی Value Type

مثال:
```csharp

int x = 10;
IComparable c = x;  // Boxing

```

# جمع‌بندی 

 عمل Boxing تبدیل یک Value Type به Reference Type (object) است که باعث کپی شدن مقدار در Heap می‌شود.
> 
 عمل Unboxing تبدیل object به Value Type است که نیاز به cast دارد.
> 
 عمل Boxing می‌تواند باعث کاهش performance شود چون allocation در Heap و درگیر شدن Garbage Collector را ایجاد می‌کند.
