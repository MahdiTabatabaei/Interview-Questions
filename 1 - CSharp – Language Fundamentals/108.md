در .NET، **Memory Leak هنگامی رخ می‌دهد** که اشیاء یا منابعی که دیگر به آن‌ها نیاز نیست، همچنان توسط مرجع‌های قوی در حافظه نگه داشته شوند، در نتیجه علاوه بر اشغال حافظه، **نمی‌توانند GC جمع‌آوری شوند**.

### علل رایج:
- نگه داشتن مرجع‌های هرگز آزاد نشده (مثل cacheهای بی‌پایان، رویدادهای ثبت‌شده ولی حذف نشده، یا حلقه‌های مرجع)
- اشتباه در مدیریت منابع Unmanaged (فراموشی Dispose)
- نگهداری بی‌پایان در Collection ها، مثلاً List ثابت

### مثال:
```csharp

class LeakExample
{
    static List<string> cache = new List<string>();

    static void AddToCache(string data)
    {
        cache.Add(data); // همه چیز نگه داشته می‌شود
    }
}

```
برای رفع این مشکل معمولا باید:

- **رویدادها** را **لغو یا حذف** کنیم.
- از **WeakReference** استفاده کنیم.
- در پایان، **Dispose** را برای اشیای unmanaged فراخوانی کنیم.
