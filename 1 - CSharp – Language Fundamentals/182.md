
درواقع **Lambda Expression** یکی از مهم‌ترین و زیباترین مفاهیم C# مدرن است؛ ابزار اصلی برای کدنویسی مختصر، خوانا و تابعی (Functional) محسوب می‌شود.  
بیایید مفهومش را گام‌به‌گام و با مثال واضح توضیح دهم 👇

---

## 🔹 مفهوم کلی

مفهوم **Lambda Expression** در واقع یک **تابع بدون نام (Anonymous Function)** است که می‌توان آن را مثل یک مقدار (Value) به متغیر، پارامتر، یا متدها پاس داد.  
یعنی تو می‌توانی یک تکه منطق را مثل داده ذخیره و منتقل کنی!

شکل کلی آن:

```csharp
(parameters) => expression or statement block
```

علامت `=>` را «Lambda Operator» می‌نامند و به معنی «می‌فرستد به» (goes to) است.

---

## 🔹 مثال ساده

مثلاً برای مربعی کردن عددها:

```csharp
x => x * x
```

یعنی:  
«تابعی با ورودی `x` که خروجی‌اش `x * x` است»

اگر بخواهیم آن را در عمل بنویسیم:

```csharp
Func<int, int> square = x => x * x;

Console.WriteLine(square(5)); // خروجی: 25
```

اینجا:
- درواقع `Func<int, int>` یعنی تابعی که `int` می‌گیرد و `int` برمی‌گرداند  
- سمت راست، Lambda Expression است  
- بدون هیچ نامی مثل `MyFunction`

---

## 🔹 Lambda با چند پارامتر

```csharp
Func<int, int, int> add = (a, b) => a + b;
Console.WriteLine(add(3, 4)); // خروجی: 7
```

---

## 🔹 Lambda با بدنه چندخطی (نه فقط یک عبارت)
اگر بدنه چند خط کد دارد، باید از `{ }` استفاده کنی:

```csharp
Action<string> greet = name =>
{
    var message = $"سلام {name}";
    Console.WriteLine(message);
};

greet("مریم"); // خروجی: سلام مریم
```

اینجا از نوع `Action` استفاده کردیم چون مقدار برنمی‌گرداند (`void`).

---

## 🔹 استفاده واقعی — LINQ

تز Lambda تقریباً همه‌جا در LINQ استفاده می‌شود.
به عنوان مثال فیلتر کردن لیست:

```csharp
var numbers = new[] { 1, 2, 3, 4, 5, 6 };

var evens = numbers.Where(x => x % 2 == 0);
```

عبارت `x => x % 2 == 0` تابعی‌ست که به متد `Where` پاس داده شده تا تصمیم بگیرد کدام عنصرها را نگه دارد.  

در پس‌زمینه:
شرط `Where` یک delegate از نوع `Func<int, bool>` می‌پذیرد،  
و Lambda دقیقاً همین را ارائه می‌دهد.

---

## 🔹 نکات مهم

| نکته | توضیح |
|------|--------|
| **Lambda** جایگزین متدهای کوچک است | سریع‌تر، کوتاه‌تر، خواناتر |
| **می‌تواند مقدار برگشتی داشته باشد یا نداشته باشد** | `Func` برای تابع‌های با خروجی – `Action` برای بدون خروجی |
| **می‌تواند درون یک متد تعریف شود** | حتی می‌تواند به متغیرهای خارجی دسترسی داشته باشد (Closure) |
| **در LINQ، Event Handling و Parallel Tasks بسیار کاربرد دارد** | چون راحت می‌شود کدهای کوچک را به عنوان منطق پاس داد |

## 🔹 مثال کامل‌تر

فرض کن بخواهی از لیست فقط اسم‌هایی را بگیری که طولشان بیشتر از ۳ حرف است:

```csharp
var names = new List<string> { "Ali", "Sara", "Amir", "Zahra" };

var result = names.Where(name => name.Length > 3);

foreach(var n in result)
    Console.WriteLine(n);
```

خروجی:
```
Sara
Amir
Zahra
```

## 🔹 پشت پرده

پشت پرده Lambda در واقع به یک **delegate** تبدیل می‌شود.  
مثلاً `x => x * x` تبدیل می‌شود به چیزی شبیه:

```csharp
delegate(int x) { return x * x; }
```

بنابراین در زمان کامپایل، هیچ جادو خاصی نیست — فقط دسترسی سطح بالا و کوتاه‌تر به delegateها.

## 🔹 خلاصه تفاوتی نگاه‌محور:

| ویژگی | Lambda Expression | متد معمولی |
|--------|--------------------|-------------|
| نام دارد؟ | ❌ ندارد | ✅ دارد |
| جای استفاده | داخل متدها، LINQ، Delegate | معمولاً در کلاس |
| طول و سادگی | کوتاه و مختصر | بلندتر |
| قابلیت Closure | دارد | دارد (اما پیچیده‌تر) |

✅ **جمع‌بندی خیلی کوتاه**

> عبارت **Lambda Expression** یعنی یک تابع بدون نام که با علامت `=>` تعریف می‌شود،  
> معمولاً برای نوشتن منطق کوتاه داخل LINQ، Delegate، Event و غیره استفاده می‌شود.  
> به کدها خوانایی، سادگی و قابلیت تابعی می‌دهد.
