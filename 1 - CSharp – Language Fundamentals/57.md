## async Task

قابل await است.
```csharp

async Task Run()
{
    await Task.Delay(1000);
}

```
---

## async void

نمی‌توان await کرد.
```csharp

async void Run()
{
    await Task.Delay(1000);
}

```
---

### مشکل async void

- رخداد exception قابل catch نیست
- مدیریت سخت

✅ فقط برای **event handler**
