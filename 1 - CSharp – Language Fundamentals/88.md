با استفاده از کلمه کلیدی `dynamic`. در این حالت، کامپایلر چک کردن نوع داده را نادیده می‌گیرد و آن را به **DLR (Dynamic Language Runtime)** می‌سپارد تا در زمان اجرا بررسی شود.

**مثال:**
```csharp

dynamic val = "Hello";
Console.WriteLine(val.Length); // در زمان اجرا چک می‌شود
val = 10; // تغییر نوع به راحتی انجام می‌شود

```
