در C# مدیریت اجرای **Taskها (در Task Parallel Library / TPL)** برای کنترل همزمانی، زمان‌بندی و هماهنگی کارهای asynchronous استفاده می‌شود. چند دسته روش مهم وجود دارد.

---

# 1. اجرای ساده Task

ساده‌ترین روش برای اجرای یک کار در ThreadPool.
```csharp

Task task = Task.Run(() =>
{
    Console.WriteLine("Task running");
});

```
یا
```csharp

Task.Factory.StartNew(() =>
{
    // code
});

```
تفاوت:

- `Task.Run` ساده‌تر و مدرن‌تر است
- `StartNew` گزینه‌های بیشتری برای scheduling دارد

---

# 2. Await / Async

رایج‌ترین روش مدیریت Task در برنامه‌های مدرن.
```csharp

public async Task GetData()
{
    await Task.Delay(1000);
    Console.WriteLine("Done");
}

```
مزایا:

- non-blocking
- خواناتر
- مدیریت خطا ساده‌تر

---

# 3. Task.WhenAll

اجرای چند Task به صورت همزمان و صبر تا همه تمام شوند.
```csharp

Task t1 = Task.Run(() => Work1());
Task t2 = Task.Run(() => Work2());

await Task.WhenAll(t1, t2);

```
کاربرد:

- parallel API calls
- اجرای چند عملیات I/O

---

# 4. Task.WhenAny

منتظر اولین Task که تمام شود.
```csharp

Task t1 = Work1();
Task t2 = Work2();

Task finished = await Task.WhenAny(t1, t2);

```
کاربرد:

- race بین چند منبع داده
- timeout logic

---

# 5. ContinueWith

اجرای Task بعد از پایان Task دیگر.
```csharp

Task.Run(() => Work())
    .ContinueWith(t =>
    {
        Console.WriteLine("Task finished");
    });

```
اما امروزه بیشتر از `await` استفاده می‌شود چون خواناتر است.

---

# 6. Parallel Programming

برای پردازش موازی روی CPU.

### Parallel.For
```csharp

Parallel.For(0, 10, i =>
{
    Console.WriteLine(i);
});

```
Parallel.ForEach
```csharp

Parallel.ForEach(list, item =>
{
    Process(item);
});

```
برای **CPU-bound tasks** مناسب است.

---

# 7. Task.Delay (Scheduling)

اجرای با تاخیر.
```csharp

await Task.Delay(2000);

```
مثلاً برای retry یا polling.

---

# 8. CancellationToken

برای **لغو Task**.
```csharp

var cts = new CancellationTokenSource();

Task task = Task.Run(() =>
{
    while (!cts.Token.IsCancellationRequested)
    {
        // work
    }
}, cts.Token);

cts.Cancel();

```
---

# 9. Task.Wait / Result (Blocking)

منتظر تمام شدن Task می‌ماند.
```csharp

task.Wait();

```
یا
```csharp

var result = task.Result;

```
اما در برنامه‌های async ممکن است **Deadlock** ایجاد کند.

---

# 10. Task Scheduler

کنترل اینکه Task روی چه Threadی اجرا شود.
```csharp

TaskScheduler scheduler = TaskScheduler.Default;

```
یا custom scheduler.
