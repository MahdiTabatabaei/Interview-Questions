در برنامه‌های با عملکرد بالا، ایجاد و حذف مکرر اشیاء هزینه‌بر است.

پس، **Object Pooling** یعنی نگهداری تعداد محدودی از نمونه‌های اشیاء و استفاده مجدد از آن‌ها، به جای ساختن چندباره.

### مزایا:

- کاهش هزینه‌های تخصیص حافظه
- کاهش فشار روی GC
- افزایش عملکرد و پاسخگویی

### مثال:
```csharp

var pool = new ObjectPool<MyObject>(() => new MyObject(), 10);

var obj = pool.Get();
// استفاده از obj
pool.Return(obj);

```
در **.NET Core 2.0+**، کلاس `System.Buffers.ArrayPool<T>` برای استقرارِ آرایه‌هاست.
