

# خلاصه سریع
■ **Race Condition:**  
وقتی *چند Thread همزمان* به یک داده مشترک دسترسی می‌گیرند و به خاطر زمان‌بندی غیرقابل‌پیش‌بینی، نتیجه نهایی **غیرقابل‌پیش‌بینی و اشتباه** می‌شود.

■ **Deadlock:**  
وقتی *چند Thread* به خاطر گرفتن Lockهای اشتباه **همدیگر را بلوکه می‌کنند** و برنامه برای همیشه منتظر می‌ماند و پیش نمی‌رود.

---

# 1) معنای Race Condition  

وقتی دو یا چند Thread همزمان به یک **منبع مشترک** دسترسی دارند و ترتیب اجرای آن‌ها تعیین‌کننده نتیجه است.

نتیجه:  
- داده خراب می‌شود  
- رفتار غیرقابل پیش‌بینی است  
- برنامه قفل نمی‌کند، فقط خروجی اشتباه می‌دهد

### مثال ساده با داده مشترک:

```
int counter = 0;

Parallel.For(0, 1000, _ =>
{
    counter++;   // عملیات غیراتمیک → Race Condition
});
```

هر بار خروجی ممکن است:
- 1000  
- 950  
- 700  
- حتی 300  
- یا هر عددی!

به این دلیل که `counter++` یک عملیات چندمرحله‌ای است:
1. خواندن مقدار  
2. افزایش  
3. نوشتن مقدار جدید

اگر دو Thread همزمان انجامش دهند، یکی از تغییرات گم می‌شود.

### خلاصه
 درواقع [[1 - CSharp – Language Fundamentals/61| race condition]]  یعنی:
- دیتای اشتباه  
- نتیجه غیرقابل پیش‌بینی  
- برنامه گیر نمی‌کند، فقط خراب می‌شود

# 2) معنای Deadlock  

وقتی دو Thread (یا بیشتر) **برای همیشه منتظر یکدیگر می‌مانند** و هیچ‌وقت ادامه نمی‌دهند.

### مثال کلاسیک Deadlock:

```
object lockA = new();
object lockB = new();

void T1()
{
    lock(lockA)
    {
        Thread.Sleep(100);
        lock(lockB) { }
    }
}

void T2()
{
    lock(lockB)
    {
        Thread.Sleep(100);
        lock(lockA) { }
    }
}
```

در این سناریو:

- Thread1 → lockA را گرفته، منتظر lockB است  
- Thread2 → lockB را گرفته، منتظر lockA است  

هیچ‌کدام آزاد نمی‌کنند چون منتظر همدیگرند.

نتیجه:
- برنامه **هنگ می‌کند**  
- هیچ کاری پیش نمی‌رود  
- 100% قابل بازتولید

### خلاصه
تعریف Deadlock یعنی:
- توقف کامل برنامه  
- در نتیجه Threadها forever منتظر هم هستند  
- هیچ خروجی تولید نمی‌شود  
- برنامه Freeze می‌کند

# 3) تفاوت‌ها به شکل خیلی کوتاه

■ **[[1 - CSharp – Language Fundamentals/61|Race Condition]] **  
- مشکلِ داده است  
- روش غلط اشتراک داده  
- نتیجه اشتباه  
- برنامه پیش می‌رود ولی غلط  
- رفع: lock ، Interlocked ، Channel ، [[196 | Immutable]] data

■ **Deadlock**  
- مشکلِ ساختار قفل‌گذاری است  
- و Threadها همدیگر را block می‌کنند  
- برنامه پیش نمی‌رود  
- رفع: ترتیب یکسان Lockها، timeout، عدم نگه داشتن Lock بیش از حد
