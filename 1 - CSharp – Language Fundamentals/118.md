- متد `First()` اگر هیچ عنصری پیدا نکند، **یک استثنا** (`InvalidOperationException`) پرتاب می‌کند.
- متد `FirstOrDefault()`، اگر چیزی نباشد، **مقدار پیش‌فرض** را برمی‌گرداند (مثل `null` برای reference types).

### مثال:
```csharp

var data = new List<int>();

// این خط استثنا می‌دهد
var first = data.First();

// این خط مقدار پیش‌فرض که 0 است، برمی‌گرداند
var firstOrDefault = data.FirstOrDefault();

```
