### 🔹 Mutable Struct

می‌تواند بعد از ساخت تغییر کند:
```csharp

struct Point { public int X; public int Y; }

```
---

### 🔹 Immutable Struct

مقدار فقط در سازنده تعیین می‌شود؛ بعداً قابل تغییر نیست:
```csharp

readonly struct Point
{
    public int X { get; }
    public int Y { get; }

    public Point(int x, int y)
    {
        X = x; Y = y;
    }
}

```
✅ مزیت: thread-safe و قابل پیش‌بینی.

---

### 🔸 نکته:

در طراحی Struct ترجیح داده می‌شود **immutable باشد**.
