این دو مفهوم درباره **انعطاف‌پذیری نوع‌ها (type compatibility)** در inheritance هستند.

فرض کنیم:

```
Animal
   ↑
  Dog
```

یعنی `Dog` زیرکلاس `Animal` است.

---

# Covariance

یعنی اجازه داریم **نوع مشتق‌شده‌تر (Derived)** را **به جای نوع پایه (Base)** برگردانیم.

به زبان ساده:

```
Dog → Animal
```

یعنی چیزی که `Dog` برمی‌گرداند می‌تواند به عنوان `Animal` استفاده شود.

### مثال

```csharp
class Animal {}
class Dog : Animal {}

Func<Dog> dogFactory = () => new Dog();

Func<Animal> animalFactory = dogFactory; // covariance
```

چرا مجاز است؟

چون:

```
Dog یک Animal است
```

پس مشکلی ندارد.

---

# Contravariance

برعکس covariance است.

اجازه می‌دهد **پارامتر ورودی عمومی‌تر (Base)** را جای **مشتق‌تر (Derived)** استفاده کنیم.

به زبان ساده:

```
Animal ← Dog
```

### مثال

```csharp
class Animal {}
class Dog : Animal {}

Action<Animal> animalHandler = a => Console.WriteLine("handle animal");

Action<Dog> dogHandler = animalHandler; // contravariance
```

چرا؟

چون متدی که می‌تواند **Animal** را پردازش کند، قطعاً **Dog** را هم می‌تواند پردازش کند.

---

# تصویر ذهنی ساده

### Covariance (برای return)

```
Dog → Animal
```

یعنی:

```
نوع خاص‌تر قابل تبدیل به نوع عمومی‌تر
```

---

### Contravariance (برای parameter)

```
Animal ← Dog
```

یعنی:

```
متدی که عمومی‌تر است می‌تواند خاص‌تر را هم بگیرد
```

---

# قانون ساده‌ای که خیلی کمک می‌کند

در اکثر موارد در C#:

```
Covariance → return types
Contravariance → parameter types
```

---

# مثال واقعی در .NET

### IEnumerable (covariant)

```csharp
IEnumerable<Dog> dogs = new List<Dog>();

IEnumerable<Animal> animals = dogs; // covariance
```

چون فقط **می‌خوانیم**.

---

### IComparer (contravariant)

```csharp
IComparer<Animal> animalComparer = ...

IComparer<Dog> dogComparer = animalComparer; // contravariance
```

چون **پارامتر می‌گیرد**.

---

# در generic ها در C#

با این کلمات مشخص می‌شود:

```
out → covariance
in  → contravariance
```

مثال:

```csharp
interface IEnumerable<out T> {}
interface IComparer<in T> {}
```

---

# خلاصه کوتاه 

**Covariance**

```
اجازه می‌دهد نوع مشتق شده
به جای نوع پایه استفاده شود
(معمولاً در return)
```

**Contravariance**

```
اجازه می‌دهد نوع پایه
به جای نوع مشتق شده استفاده شود
(معمولاً در parameter)
```
