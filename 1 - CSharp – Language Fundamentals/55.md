## override

متد والد را **بازنویسی می‌کند**.
```csharp

class Animal
{
    public virtual void Speak() {}
}

class Dog : Animal
{
    public override void Speak()
    {
        Console.WriteLine("Bark");
    }
}

```
---

## new

متد والد را **مخفی می‌کند**.
```csharp

class Dog : Animal
{
    public new void Speak()
    {
        Console.WriteLine("Dog Speak");
    }
}

```
