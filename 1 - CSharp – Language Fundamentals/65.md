**مفهوم:** `record` یک نوع مرجع (Reference Type) است (مشابه کلاس) اما با تمرکز بر **Immutable بودن** و **برابری بر اساس مقدار (Value-based Equality)**.

در کلاس‌ها، دو آبجکت با مقادیر یکسان برابر نیستند (چون رفرنس متفاوت دارند)، اما در رکوردها برابر هستند.

**مثال:**
```csharp

public record Person(string Name, int Age);

var p1 = new Person("Ali", 20);
var p2 = new Person("Ali", 20);
Console.WriteLine(p1 == p2); // True

```
