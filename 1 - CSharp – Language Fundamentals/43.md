زمانی که با `fixed` یا `GCHandle` شیء را **در حافظه قفل (pin)** می‌کنیم تا GC آن را **جابجا نکند**.

```csharp

byte[] data = new byte[10];
GCHandle handle = GCHandle.Alloc(data, GCHandleType.Pinned);

```
✅ کاربرد: ارتباط با APIهای unmanaged.

⚠️ **اثر جانبی:**

- مانع فشرده‌سازی Heap → **fragmentation**
- کاهش کارایی → **GC سخت‌تر کار می‌کند**
