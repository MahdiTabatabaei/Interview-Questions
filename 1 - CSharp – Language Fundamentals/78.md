- عملکرد **`==` (Operator):** معمولاً برای مقایسه هویت (Reference Equality) در Reference Typeها استفاده می‌شود (به جز رشته‌ها که اورلود شده‌اند). در زمان **Compile-time** بررسی می‌شود.
- متد **`Equals` (Method):** یک متد مجازی است که برای مقایسه محتوا (Value Equality) بازنویسی (Override) می‌شود. در زمان **Runtime** عمل می‌کند.

**مثال:**
```csharp

object s1 = new string("Gap");
object s2 = new string("Gap");

Console.WriteLine(s1 == s2);      // False (چون دو جای مختلف حافظه هستند)
Console.WriteLine(s1.Equals(s2)); // True (چون محتوای هر دو Gap است)

```
