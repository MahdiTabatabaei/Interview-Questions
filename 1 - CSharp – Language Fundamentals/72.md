- کلمه کلیدی**ref:** متغیر به صورت رفرنس می‌رود و متد **می‌تواند** آن را تغییر دهد.
- کلمه کلیدی**in:** متغیر به صورت رفرنس می‌رود اما متد **اجازه تغییر آن را ندارد** (Read-only reference). این برای بهبود Performance در زمان ارسال استراکت‌های بزرگ (Struct) استفاده می‌شود تا کپی نشوند.

---

فرض کنیم یک struct سنگین داریم:
```csharp

public struct BigStruct
{
    public int A, B, C, D, E, F;
}

```

برای  ref → امکان تغییر وجود دارد
```csharp

void Modify(ref BigStruct s)
{
    s.A = 100; // قابل تغییر
}

var item = new BigStruct();
Modify(ref item);
Console.WriteLine(item.A); // 100

```

---

## کلمه کلیدی in → فقط خواندنی (Read-only) است و سریع‌تر (بدون کپی)

```csharp

void Print(in BigStruct s)
{
    // s.A = 200;  // خطا: فقط خواندنی
    Console.WriteLine(s.A);
}

var item2 = new BigStruct { A = 50 };
Print(item2); // کپی نمی‌شود → عملکرد بهتر

```

مزیت: بدون کپی شدن struct → **Performance بهتر**.
