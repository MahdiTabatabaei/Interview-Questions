 ✅ متغیر `DateTime` در ‎C# یک **Value Type** است

---

## چرا؟

زیرا `DateTime` به صورت **struct** در .NET تعریف شده است و همه `struct` ها **Value Type** هستند.

تعریف آن در .NET:
```csharp

public struct DateTime

```
پس:

```markdown

DateTime → struct → Value Type

```

## رفتار در حافظه

وقتی استفاده می‌کنیم:
```markdown

DateTime d1 = DateTime.Now;
DateTime d2 = d1;

```

یک **کپی کامل از مقدار** ساخته می‌شود.

```markdown

d1 = 2026-03-16
d2 = 2026-03-16

```

اگر `d2` تغییر کند، `d1` تغییر نمی‌کند.

---

## مثال

```csharp

DateTime d1 = DateTime.Now;
DateTime d2 = d1;

d2 = d2.AddDays(1);

Console.WriteLine(d1);
Console.WriteLine(d2);

```

نتیجه:

```markdown

d1 = 16 Mar
d2 = 17 Mar

```

چون **Value Copy** اتفاق افتاده است.

---

## نکته مهم مصاحبه‌ای

با اینکه `DateTime` **Value Type** است ولی:

✅ متغیر **Immutable** هم هست.

یعنی متدهایی مثل:

```markdown

AddDays
AddMonths
AddYears

```

مقدار جدید برمی‌گردانند و مقدار قبلی را تغییر نمی‌دهند.

## پاسخ کوتاه 

 متغیر `DateTime` در .NET یک Value Type است چون به صورت struct پیاده‌سازی شده است. بنابراین مقدار آن هنگام assignment کپی می‌شود. همچنین DateTime immutable است و متدهای آن مقدار جدید برمی‌گردانند.
