این کلاس مدل نحوه‌ی اجرای async را تعریف می‌کند. هر محیط (مثلاً WPF یا ASP.NET Context خاص خود را دارد:

- در WPF → اجرای کد در Thread UI.
- در ASP.NET → اجرای کد در Request Thread.

### مثال:
```csharp

var context = SynchronizationContext.Current;
context.Post(_ => Console.WriteLine("Run inside context"), null);

```
