- باید **struct** زمانی استفاده شود که:
    - مقادیر کوچک، سبک و **immutable** هستند.
    - نیاز به **کپی سریع** و بدون نیاز به heap allocation دارند.
    - در مواردی که **کپی** سریع و ارزان است، وعدم نیاز به inheritance.
    - بیشتر در سناریوهای **high-performance** و **پروسسینگ داده** کاربرد دارد.

### نکات:

- اطمینان حاصل کنید که struct **Immutable** باشد (مثل `DateTime`، `Color`)
- نباید بنایی از struct در پایین‌ترین سطح باشد و عملیات‌های پیچیده در آن انجام شود.

### نمونه:
```csharp

struct Point
{
    public int X { get; }
    public int Y { get; }

    public Point(int x, int y)
    {
        X = x;
        Y = y;
    }
}

var p1 = new Point(10, 20);
var p2 = p1; // کپی سریع

```
