در واقع `Thread` یک **thread واقعی سیستم‌عامل (OS Thread)** است.

یعنی وقتی Thread می‌سازید، مستقیماً از منابع سیستم‌عامل استفاده می‌کنید.

واحد اجرایی مستقل در برنامه.

هر Thread مسیر جداگانه‌ای از کد را اجرا می‌کند.

```csharp

using System.Threading;

void DoWork()
{
    Console.WriteLine("Thread running");
}

Thread t = new Thread(DoWork);
t.Start();

```

### ویژگی‌های Thread

- سنگین (heavy)
- هزینه ساخت بالا
- مدیریت دستی
- کنترل مستقیم (Priority، Abort، Sleep و…)

✅ کاربرد:

– اجرای موازی،
– عملیات سنگین بدون مسدود کردن UI.
