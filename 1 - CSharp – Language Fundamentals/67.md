**مفهوم:** دلیگیت در واقع یک **Type-safe Function Pointer** است. یعنی متغیری است که به یک یا چند متد اشاره می‌کند. دلیگیت امضای متد (نوع ورودی و خروجی) را تعریف می‌کند.

**مثال:**
```csharp

public delegate void MyDelegate(string msg);

void ShowMessage(string m) => Console.WriteLine(m);

MyDelegate del = ShowMessage;
del("Hello!"); // متد اجرا می‌شود

```
