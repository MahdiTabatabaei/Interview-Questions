مجموعه‌هایی هستند که پس از ساخت، **تغییر نمی‌کنند**. هر تغییری (مثل Add) یک نسخه **جدید** از مجموعه برمی‌گرداند. این برای امنیت داده در Threadهای مختلف عالی است.

**مثال:**
```csharp

var list = ImmutableList.Create<int>(1, 2);
var newList = list.Add(3); // list تغییر نمی‌کند، newList شامل ۳ عضو است

```
