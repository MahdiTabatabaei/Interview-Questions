در C# هر دو برای تعریف نوع داده استفاده می‌شوند اما تفاوت اصلی در **Reference Type و Value Type بودن** است.

## Class

- نوع **Reference Type** است
- در **Heap** ذخیره می‌شود
- می‌تواند **inheritance** داشته باشد
- مقدار آن با **reference** کپی می‌شود
- می‌تواند `null` باشد

### مثال :

```csharp

class Person
{
    public string Name;
}

Person p1 = new Person();
p1.Name = "Ali";

Person p2 = p1;
p2.Name = "Reza";

Console.WriteLine(p1.Name); // Reza

```
چون reference کپی شده، هر دو به یک آبجکت اشاره می‌کنند.

---

## Struct

- نوع**Value Type** است
- معمولا در **Stack** ذخیره می‌شود
- ارث بری inheritance ندارد (فقط از `ValueType`)
- مقدار آن **copy** می‌شود
- نمی‌تواند null باشد (مگر nullable)

### مثال :
```csharp

struct Point
{
    public int X;
}

Point p1;
p1.X = 10;

Point p2 = p1;
p2.X = 20;

Console.WriteLine(p1.X); // 10

```
اینجا مقدار کپی شده است.

# مرحله‌به‌مرحله چه اتفاقی می‌افتد؟

فرض کن این کد داخل یک متد نوشته شده:

```csharp
void Test()
{
    Person p = new Person();
}
```

## ✅ مرحله 1 — ورود به متد
وقتی متد `Test` اجرا می‌شود:

- یک **Stack Frame** روی Stack ساخته می‌شود.
- همه متغیرهای محلی این متد داخل همین Frame ذخیره می‌شوند.

پس متغیر `p` یک **متغیر محلی** است →  
بنابراین داخل Stack قرار می‌گیرد.

اما دقت کن:

🔹 داخل Stack فقط **یک آدرس (reference)** ذخیره می‌شود، نه خود شیء.

---

## ✅ مرحله 2 — اجرای `new Person()`

وقتی `new` اجرا می‌شود:

1. ابتدا CLR در Heap مقداری حافظه رزرو می‌کند.
2. فضای کافی برای فیلدهای کلاس + اطلاعات متادیتا ایجاد می‌شود.
3. آدرس آن برگردانده می‌شود.

مثلاً فرض کنیم:

```
Heap:
آدرس 0x5000 → شیء Person
```

---

## ✅ مرحله 3 — مقداردهی به p

حالا آن آدرس در متغیر `p` ذخیره می‌شود.

پس وضعیت حافظه می‌شود:

```
Stack:
p → 0x5000

Heap:
0x5000:
   Age = 0
   (Type Metadata)
```

---

# خیلی مهم 🔥

### درواقع p خودش شیء نیست  

مقدار p فقط یک **آدرس** است.

می‌توانی این را مثل یک برگه کاغذ در نظر بگیری که رویش نوشته:

```
شیء در آدرس 0x5000 قرار دارد
```

---

# اگر چند رفرنس بسازیم چه می‌شود؟

```csharp
Person p1 = new Person();
Person p2 = p1;
```

حافظه:

```
Stack:
p1 → 0x5000
p2 → 0x5000

Heap:
0x5000 → Person Object
```

✅ فقط یک شیء داریم  
✅ دو رفرنس به همان شیء

اگر تغییر بدهی:

```csharp
p2.Age = 30;
```

از طریق `p1` هم مقدار 30 دیده می‌شود  
چون هر دو به یک آدرس اشاره می‌کنند.

---

# حالا تفاوت با Struct را ببین 👇

```csharp
Point p1 = new Point();
Point p2 = p1;
```

اینجا:

```
Stack:
p1 → { X=0 , Y=0 }
p2 → { X=0 , Y=0 }
```

✅ دو کپی مستقل ساخته می‌شود  
✅ هیچ Heap در کار نیست (اگر local باشد)

---

# چرا اصلاً این طراحی وجود دارد؟

### Stack:
- سریع
- الگوریتم LIFO
- عمر کوتاه
- مناسب متغیرهای محلی

### Heap:
- عمر نامشخص
- مدیریت توسط GC
- مناسب objectهای پیچیده

---

# یک تصور ذهنی قوی

درواقع Stack = دفترچه آدرس  
و Heap = ساختمان‌ها  

متغیر Reference Type = آدرس ساختمان  
خود Object = ساختمان

---

# یک نکته مهم پیشرفته (خیلی مهم)

اگر این کد داخل کلاس باشد:

```csharp
class A
{
    Person p = new Person();
}
```

اینجا دیگر `p` در Stack نیست.

چرا؟

چون `p` فیلد یک شیء است.  
شیء A در Heap است.  
پس `p` هم داخل همان Heap ذخیره می‌شود.

---

# جمع‌بندی نهایی دقیق

در این کد:

```csharp
Person p = new Person();
```

| بخش | محل ذخیره |
|------|------------|
| p (رفرنس) | اگر local باشد → Stack |
| خود Person | همیشه → Heap |
