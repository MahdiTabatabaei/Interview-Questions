هر دو برای بررسی وجود داده استفاده می‌شوند.

---

## Any

بررسی می‌کند **آیا حداقل یک عنصر وجود دارد یا نه**
```csharp

bool result = users.Any(x => x.Age > 18);

```
به محض پیدا شدن اولین مورد **متوقف می‌شود**.

---

## Count

تعداد کل عناصر را می‌شمارد.
```csharp

int count = users.Count(x => x.Age > 18);

```
کل collection را پیمایش می‌کند.

---

✅ **Performance**

برای چک کردن وجود داده:

✅ بهتر است از **Any()**
