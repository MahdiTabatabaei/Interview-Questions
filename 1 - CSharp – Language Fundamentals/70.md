**مفهوم:** زمانی که یک عبارت Lambda از متغیرهای **بیرون از دامنه خود** (Local variables) استفاده می‌کند، یک Closure ایجاد می‌شود. کامپایلر یک کلاس مخفی می‌سازد تا آن متغیر را “زنده” نگه دارد، حتی اگر متد اصلی تمام شده باشد.

**مثال:**
```csharp

int factor = 5;
Func<int, int> multiplier = n => n * factor; // factor کپچر شده است

```
