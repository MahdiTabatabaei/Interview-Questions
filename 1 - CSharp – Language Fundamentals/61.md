**مفهوم:** Race Condition زمانی رخ می‌دهد که دو یا چند Thread به‌طور همزمان سعی کنند داده‌های مشترکی را تغییر دهند. نتیجه نهایی به **ترتیب اجرای Threadها** بستگی پیدا می‌کند (که غیرقابل پیش‌بینی است) و باعث بروز باگ‌های منطقی می‌شود.

**مثال:**

فرض کنید یک متغیر `Count` داریم که مقدارش ۰ است. دو Thread همزمان می‌خواهند آن را ++ کنند.

1. گام اول : Thread A مقدار ۰ را می‌خواند.
2. گام دوم : Thread B مقدار ۰ را می‌خواند.
3. گام سوم : Thread A مقدار را ۱ کرده و ذخیره می‌کند.
4. گام چهارم : Thread B هم مقدار را ۱ کرده و ذخیره می‌کند.

**نتیجه:** به جای ۲، مقدار ۱ ذخیره شد!

**راه حل:** استفاده از `lock` یا کلاس `Interlocked`.
