## Task

در این حالت Object در Heap ساخته می‌شود.
```csharp

Task<int> GetNumber()
{
    return Task.FromResult(5);
}

```
---

## ValueTask

در این حالت Value type است و allocation کمتر دارد.
```csharp

ValueTask<int> GetNumber()
{
    return new ValueTask<int>(5);
}

```
