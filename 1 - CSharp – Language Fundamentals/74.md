**مفهوم:** این یک اینترفیس است که متد `Dispose()` را دارد. کلاس‌هایی که از منابع **Unmanaged** (مثل هندل‌های سیستم‌عامل، فایل‌ها، سوکت‌ها) استفاده می‌کنند، باید این اینترفیس را پیاده‌سازی کنند تا کاربر بتواند دستی حافظه یا منبع را آزاد کند و منتظر Garbage Collector نماند.

برای کار با منابع unmanaged مثل فایل، دیتابیس، Socket و …

```csharp

public class FileWriter : IDisposable
{
    private FileStream _stream;
    private bool _disposed;

    public FileWriter(string path)
    {
        _stream = new FileStream(path, FileMode.Create);
    }

    public void Write(string text)
    {
        if (_disposed) throw new ObjectDisposedException("FileWriter");

        var bytes = System.Text.Encoding.UTF8.GetBytes(text);
        _stream.Write(bytes, 0, bytes.Length);
    }

    public void Dispose()
    {
        if (!_disposed)
        {
            _stream.Dispose();
            _disposed = true;
        }
    }
}

```

استفاده:
```csharp

using (var writer = new FileWriter("test.txt"))
{
    writer.Write("Hello!");
}

```
