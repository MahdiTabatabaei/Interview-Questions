### توضیح ساده:

وقتی متدی را async می‌نویسیم، کامپایلر آن را تبدیل می‌کند به یک **State Machine** که شامل:

- وضعیت state ها (مراحل)
- و continuation ها (بازگشت پس از await)
- مدیریت exception
- ذخیره متغیرهای محلی

### مثال:
این:
```csharp

async Task Test()
{
    await Task.Delay(1000);
    Console.WriteLine("Done");
}

```

تبدیل می‌شود به کدی بسیار پیچیده با state machine.

(ولی برنامه‌نویس آن را نمی‌بیند.)
