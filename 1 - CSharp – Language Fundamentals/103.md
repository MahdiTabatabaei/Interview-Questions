نوع خاصی از Lock است که برای **Performance بالا در سناریوهای کوتاه** استفاده می‌شود.

به جای خوابیدن Thread، یک حلقه سریع می‌چرخد تا منتظر آزاد شدن قفل بماند.

### مثال:
```csharp

SpinLock spin = new SpinLock();
bool taken = false;
spin.Enter(ref taken); // سعی در گرفتن قفل
try
{
    // عملیات کوتاه
}
finally
{
    if (taken) spin.Exit();
}

```
