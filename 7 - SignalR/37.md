
# 1. نصب SignalR

اگر پروژه ASP.NET Core دارید، معمولاً SignalR داخل آن هست. اگر نبود:

```bash
dotnet add package Microsoft.AspNetCore.SignalR
```

---

# 2. ساخت Hub

یک کلاس بسازید که از `Hub` ارث‌بری کند.

```csharp
using Microsoft.AspNetCore.SignalR;
using System.Threading.Tasks;

public class ChatHub : Hub
{
    public async Task SendMessage(string user, string message)
    {
        await Clients.All.SendAsync("ReceiveMessage", user, message);
    }
}
```

توضیح کوتاه:

- `SendMessage` متدی است که کلاینت‌ها صدا می‌زنند.
- `Clients.All` یعنی پیام برای همه کلاینت‌ها ارسال شود.
- `"ReceiveMessage"` نام متدی است که در کلاینت اجرا می‌شود.

---

# 3. ثبت Hub در Program.cs

در ASP.NET Core:

```csharp
var builder = WebApplication.CreateBuilder(args);

builder.Services.AddSignalR();

var app = builder.Build();

app.MapHub<ChatHub>("/chatHub");

app.Run();
```

حالا Hub در آدرس زیر در دسترس است:

```
/chatHub
```

# 4. فراخوانی Hub از سمت کلاینت (JavaScript)

اگر کلاینت وب دارید:

```javascript
const connection = new signalR.HubConnectionBuilder()
    .withUrl("/chatHub")
    .build();

connection.on("ReceiveMessage", (user, message) => {
    console.log(user + ": " + message);
});

connection.start();

connection.invoke("SendMessage", "Ali", "Hello world");
```

# 5. فراخوانی Hub از C# Client

ابتدا پکیج:

```
Microsoft.AspNetCore.SignalR.Client
```

سپس:

```csharp
using Microsoft.AspNetCore.SignalR.Client;

var connection = new HubConnectionBuilder()
    .WithUrl("https://localhost:5001/chatHub")
    .Build();

connection.On<string, string>("ReceiveMessage", (user, message) =>
{
    Console.WriteLine($"{user}: {message}");
});

await connection.StartAsync();

await connection.InvokeAsync("SendMessage", "Ali", "Hello");
```

# 6. فراخوانی Hub از داخل سرور (بدون کلاینت)

گاهی می‌خواهید از داخل سرویس‌ها پیام بفرستید. از `IHubContext` استفاده می‌شود.

```csharp
public class NotificationService
{
    private readonly IHubContext<ChatHub> _hub;

    public NotificationService(IHubContext<ChatHub> hub)
    {
        _hub = hub;
    }

    public async Task Send(string msg)
    {
        await _hub.Clients.All.SendAsync("ReceiveMessage", "Server", msg);
    }
}
```

---

✅ خلاصه:

- Hub = کلاس مرکزی ارتباط realtime  
- کلاینت → متد Hub را صدا می‌زند  
- Hub → پیام را به کلاینت‌ها می‌فرستد  
- `Clients.All`, `Clients.Caller`, `Clients.Group` برای کنترل مقصد پیام استفاده می‌شود
