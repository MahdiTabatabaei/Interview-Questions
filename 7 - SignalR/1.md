درواقع  **SignalR** یک کتابخانه در ASP.NET Core است که امکان **ارتباط Real‑Time بین سرور و کلاینت** را فراهم می‌کند.

یعنی سرور می‌تواند **بدون درخواست جدید از سمت کاربر، بلافاصله اطلاعات را به کلاینت ارسال کند.**

مشکلی که حل می‌کند:

در HTTP معمولی:

Client → Request → Server → Response

اما در برنامه‌هایی مثل:

- چت آنلاین
- قیمت لحظه‌ای بورس
- بازی آنلاین
- نوتیفیکیشن زنده

نیاز داریم سرور **خودش پیام ارسال کند**.

در این حالت SignalR این مشکل را حل می‌کند.

مثال زندگی واقعی:

فرض کنید در یک **تابلو فرودگاه** هستید.

اگر هر مسافر بخواهد مرتب سؤال کند:

“پرواز من کی است؟”

این شبیه HTTP است.

اما اگر تابلو **خودش تغییر کند و همه ببینند** → این شبیه SignalR است.
