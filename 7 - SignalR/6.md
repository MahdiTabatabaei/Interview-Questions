ویژگی **Hub یک کلاس مرکزی برای مدیریت ارتباط بین Client و Server است.**

کلاینت‌ها به Hub متصل می‌شوند و متدهای آن را صدا می‌زنند.

مثال:
```csharp

using Microsoft.AspNetCore.SignalR;

public class ChatHub : Hub
{
    public async Task SendMessage(string user, string message)
    {
        await Clients.All.SendAsync("ReceiveMessage", user, message);
    }
}

```
در اینجا Hub مثل **یک مرکز مخابراتی** است که پیام‌ها را هدایت می‌کند.
