احراز هویت در **SignalR** معمولاً با همان مکانیزم احراز هویتی انجام می‌شود که در **ASP.NET Core** استفاده می‌کنی؛ مثل **JWT Token، Cookie Authentication یا Identity**. بعد از اینکه اتصال برقرار شد، SignalR هویت کاربر را از `HttpContext.User` می‌گیرد.

در عمل مراحل این‌گونه است:

---

## 1. فعال کردن Authentication در برنامه

در `Program.cs` یا `Startup` باید احراز هویت را اضافه کنی. مثال با **JWT**:

```csharp
builder.Services.AddAuthentication("Bearer")
    .AddJwtBearer("Bearer", options =>
    {
        options.Authority = "https://example.com";
        options.TokenValidationParameters = new TokenValidationParameters
        {
            ValidateAudience = false
        };

        options.Events = new JwtBearerEvents
        {
            OnMessageReceived = context =>
            {
                var accessToken = context.Request.Query["access_token"];
                var path = context.HttpContext.Request.Path;

                if (!string.IsNullOrEmpty(accessToken) &&
                    path.StartsWithSegments("/chat"))
                {
                    context.Token = accessToken;
                }

                return Task.CompletedTask;
            }
        };
    });
```

سپس:

```csharp
builder.Services.AddAuthorization();
builder.Services.AddSignalR();
```

و در Pipeline:

```csharp
app.UseAuthentication();
app.UseAuthorization();
```

---

## 2. محافظت از Hub با Authorization

روی Hub از attribute استفاده می‌کنیم:

```csharp
[Authorize]
public class ChatHub : Hub
{
    public async Task SendMessage(string message)
    {
        var user = Context.User.Identity.Name;
        await Clients.All.SendAsync("ReceiveMessage", user, message);
    }
}
```

در این حالت فقط کاربران **احراز هویت‌شده** می‌توانند وصل شوند.

---

## 3. ارسال Token از سمت کلاینت

مثال در JavaScript:

```javascript
const connection = new signalR.HubConnectionBuilder()
    .withUrl("/chat", {
        accessTokenFactory: () => token
    })
    .build();
```

در اینجا:
- کلاینت **JWT token** را می‌فرستد
- سرور آن را اعتبارسنجی می‌کند
- اگر معتبر باشد اتصال برقرار می‌شود

---

## 4. دسترسی به اطلاعات کاربر در Hub

در Hub می‌توان اطلاعات کاربر را گرفت:

```csharp
var userId = Context.UserIdentifier;
var username = Context.User.Identity.Name;
```

---

## خلاصه

احراز هویت در SignalR این‌گونه انجام می‌شود:

1. فعال کردن Authentication در ASP.NET Core  
2. محافظت از Hub با `[Authorize]`  
3. ارسال Token یا Cookie از کلاینت  
4. دسترسی به اطلاعات کاربر از `Context.User`

به این شکل فقط کاربران **مجاز** می‌توانند به Hub وصل شوند و پیام ارسال یا دریافت کنند.
