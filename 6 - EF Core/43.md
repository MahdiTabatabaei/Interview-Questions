در **EF Core** گزینه‌های **Delete Behavior** مشخص می‌کنند وقتی یک **رکورد والد (Principal)** حذف شود، با **رکوردهای وابسته (Dependent)** چه اتفاقی بیفتد.

سه حالت رایج: **Cascade ،Restrict ،SetNull**

---

# 1. Cascade

وقتی رکورد والد حذف شود، **تمام رکوردهای وابسته هم حذف می‌شوند**.

مثال:

```
Author
  └── Books
```

اگر Author حذف شود:

```
Books مربوط به آن Author هم حذف می‌شوند
```

### Fluent API

```csharp
modelBuilder.Entity<Book>()
    .HasOne(b => b.Author)
    .WithMany(a => a.Books)
    .HasForeignKey(b => b.AuthorId)
    .OnDelete(DeleteBehavior.Cascade);
```

نتیجه:

```
DELETE Author
↓
DELETE Books
```

کاربرد رایج:

- Order → OrderItems  
- Blog → Posts  

جایی که وابسته‌ها بدون والد معنی ندارند.

---

# 2. Restrict

اجازه نمی‌دهد والد حذف شود **اگر رکورد وابسته وجود داشته باشد**.

مثال:

```
Author
  └── Books
```

اگر Author کتاب داشته باشد:

```
DELETE Author → ERROR
```

باید اول Book ها حذف شوند.

### Fluent API

```csharp
.OnDelete(DeleteBehavior.Restrict)
```

نتیجه:

```
Cannot delete because dependent rows exist
```

کاربرد:

- User → Orders  
- Category → Products  

جایی که حذف تصادفی داده خطرناک است.

---

# 3. SetNull

وقتی والد حذف شود، **Foreign Key در رکوردهای وابسته null می‌شود**.

مثال:

```
Book.AuthorId
```

اگر Author حذف شود:

```
AuthorId = NULL
```

Book باقی می‌ماند.

### Fluent API

```csharp
.OnDelete(DeleteBehavior.SetNull)
```

اما یک شرط مهم دارد:

```
FK باید nullable باشد
```

مثال:

```csharp
public int? AuthorId { get; set; }
```

---

# مثال واقعی

فرض کنیم:

```
Teacher
   └── Students
```

### Cascade

```
Delete Teacher
↓
Students also deleted
```

### Restrict

```
Delete Teacher
↓
Error if Students exist
```

### SetNull

```
Delete Teacher
↓
Students.TeacherId = NULL
```

---

# مقایسه سریع

| DeleteBehavior | نتیجه |
|---|---|
| Cascade | حذف خودکار رکوردهای وابسته |
| Restrict | جلوگیری از حذف والد |
| SetNull | FK رکوردهای وابسته NULL می‌شود |

---

✅ **نکته مهم در EF Core**

برای **Required Relationship** معمولاً پیش‌فرض:

```
Cascade
```

برای **Optional Relationship** معمولاً پیش‌فرض:

```
ClientSetNull
```
