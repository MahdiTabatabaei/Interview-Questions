## Shadow Property Relation

مثال:

Order دارای UserId در DB است

ولی در کلاس وجود ندارد.

تعریف:
```csharp

modelBuilder.Entity<Order>()
.Property<int>("UserId");

```
Relation:
```csharp

modelBuilder.Entity<Order>()
.HasOne<User>()
.WithMany()
.HasForeignKey("UserId");

```
Query:
```csharp

var orders = context.Orders
.Where(o => EF.Property<int>(o, "UserId") == 5)
.ToList();


```
