## همیشه Eager Load شدن Relation

در EF Core می‌توان **AutoInclude** تعریف کرد.
```csharp

modelBuilder.Entity<Order>()
    .Navigation(o => o.OrderItems)
    .AutoInclude();

```
مدل:
```csharp

public class Order
{
    public int Id { get; set; }

    public List<OrderItem> OrderItems { get; set; }
}

```
حال:
```csharp

var orders = context.Orders.ToList();

```
OrderItems **خودکار لود می‌شود**.

نیازی به Include نیست.
