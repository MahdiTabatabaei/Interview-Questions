## حذف Navigation ولی باقی بودن FK

اگر فقط FK وجود داشته باشد:

درواقع EF هنوز رابطه را می‌فهمد.

اما:

- استفاده از Include ممکن نیست
- و Lazy Loading از بین می‌رود
- پیمایش شیء به شیء نداریم

مثال:
```csharp

public class Order
{
    public int Id { get; set; }

    public int UserId { get; set; }
}

```
