رابطه Many-to-Many یعنی هر Entity در جدول اول می‌تواند با چندین Entity در جدول دوم مرتبط باشد، و بالعکس.

در **EF (و EF Core) این رابطه را با استفاده از یک جدول واسط (Junction/Linking Table) پیاده‌سازی می‌کند.**

**مثال: `Student` و `Course`**

هر دانشجو می‌تواند در چندین درس ثبت‌نام کند، و هر درس می‌تواند چندین دانشجو داشته باشد.

**با Data Annotations:**
```csharp

public class Student
{
    public int Id { get; set; }
    public string Name { get; set; }
    public ICollection<StudentCourse> CourseEnrollments { get; set; } // Navigation to junction table
}

public class Course
{
    public int Id { get; set; }
    public string Title { get; set; }
    public ICollection<StudentCourse> StudentEnrollments { get; set; } // Navigation to junction table
}

// Junction Table Entity
public class StudentCourse
{
    public int StudentId { get; set; } // Foreign Key to Student
    public Student Student { get; set; } // Navigation to Student

    public int CourseId { get; set; } // Foreign Key to Course
    public Course Course { get; set; } // Navigation to Course

    // Optional: You can add additional properties to the junction table
    public DateTime EnrollmentDate { get; set; }
}

```
با Fluent API:
```csharp

protected override void OnModelCreating(ModelBuilder modelBuilder)
{
    modelBuilder.Entity<StudentCourse>()
        .HasKey(sc => new { sc.StudentId, sc.CourseId }); // Composite Primary Key for junction table

    modelBuilder.Entity<StudentCourse>()
        .HasOne(sc => sc.Student)
        .WithMany(s => s.CourseEnrollments)
        .HasForeignKey(sc => sc.StudentId);

    modelBuilder.Entity<StudentCourse>()
        .HasOne(sc => sc.Course)
        .WithMany(c => c.StudentEnrollments)
        .HasForeignKey(sc => sc.CourseId);
}

```
**تفاوت با نسخه‌های قدیمی EF:**

در EF Core 5.0 به بعد، روش تعریف Many-to-Many کمی ساده‌تر شده است. شما می‌توانید **بدون نیاز به تعریف کلاس Entity برای جدول واسط**، رابطه را تعریف کنید. EF Core خودش جدول واسط را مدیریت می‌کند.

**مثال Many-to-Many بدون تعریف Entity واسط (EF Core 5.0+):**
```csharp

public class Student
{
    public int Id { get; set; }
    public string Name { get; set; }
    public List<Course> Courses { get; set; } // Direct navigation to Course
}

public class Course
{
    public int Id { get; set; }
    public string Title { get; set; }
    public List<Student> Students { get; set; } // Direct navigation to Student
}

```
در `DbContext.OnModelCreating`:
```csharp

protected override void OnModelCreating(ModelBuilder modelBuilder)
{
    modelBuilder.Entity<Student>()
        .HasMany(s => s.Courses)
        .WithMany(c => c.Students)
        // EF Core automatically creates a junction table (e.g., StudentCourses)
        // You can configure the junction table name and keys if needed
        .UsingEntity<StudentCourse>( // Optional: To configure the junction table itself
            j => j.HasOne(sc => sc.Course).WithMany().HasForeignKey(sc => sc.CourseId),
            j => j.HasOne(sc => sc.Student).WithMany().HasForeignKey(sc => sc.StudentId)
        );
}

```
در این حالت، EF Core به صورت خودکار یک جدول واسط (مثلاً `StudentCourses`) ایجاد می‌کند که شامل Foreign Key های `StudentId` و `CourseId` است. اگر بخواهید این جدول واسط را پیکربندی کنید یا پراپرتی‌های اضافی (مثل `EnrollmentDate`) داشته باشید، باید از روش اول (با تعریف `StudentCourse` Entity) استفاده کنید.
