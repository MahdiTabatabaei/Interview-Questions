چون:

- Joinهای زیاد تولید می‌کند
- حجم داده سنگین می‌شود
- کوئری پیچیده‌تر و کندتر می‌شود

مثال بد:
```csharp

var data = context.Users
    .Include(u => u.Orders)
    .Include(u => u.Address)
    .Include(u => u.Roles)
    .Include(u => u.Permissions)
    .ToList();

```
شاید بهتر باشد داده‌ها را جداگانه و هدفمند بگیریم.
