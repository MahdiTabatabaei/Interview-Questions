ویژگی Navigation Property راهی است برای پیمایش بین Entityها، مثل:
```csharp

public Customer Customer { get; set; }
public List<Order> Orders { get; set; }

```
نقش:

- و EF از آن برای تشخیص روابط استفاده می‌کند.
- داده‌های مرتبط را از طریق آن لود می‌کنیم (`Include`).
- برای Update/Delete cascade بر اساس رابطه انجام می‌شود.
