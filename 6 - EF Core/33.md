یک Entity می‌تواند به چندین Entity دیگر مرتبط باشد، اما هر Entity مرتبط فقط به یک Entity اصلی مرتبط است.

**مثال: `Customer` و `Order`**

یک `Customer` می‌تواند چندین `Order` داشته باشد، اما هر `Order` فقط متعلق به یک `Customer` است.

**با Data Annotations:**
```csharp

public class Customer
{
    public int Id { get; set; }
    public string Name { get; set; }
    public List<Order> Orders { get; set; } // Navigation Property (Collection)
}

public class Order
{
    public int Id { get; set; }
    public int CustomerId { get; set; } // Foreign Key Property
    public Customer Customer { get; set; } // Navigation Property (Single)
}

```
با Fluent API:
```csharp

modelBuilder.Entity<Customer>()
    .HasMany(c => c.Orders) // Customer has many Orders
    .WithOne(o => o.Customer) // Order belongs to one Customer
    .HasForeignKey(o => o.CustomerId); // The FK on Order table is CustomerId

```
