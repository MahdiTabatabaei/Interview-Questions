متد `HasForeignKey` در Fluent API برای **مشخص کردن نام ستون کلید خارجی (Foreign Key Column)** در دیتابیس استفاده می‌شود.

وقتی EF Core یک رابطه را بین دو Entity تشخیص می‌دهد، معمولاً نام ستون کلید خارجی را بر اساس نام Navigation Property یا نام Primary Key جدول والد حدس می‌زند (مثلاً `CustomerId` برای رابطه با `Customer`). اما گاهی اوقات نیاز دارید نام ستون را به صورت دلخواه تعیین کنید، یا نام convention شده با نام مورد نظر شما در دیتابیس مطابقت ندارد.

**نحوه استفاده:**
```csharp

modelBuilder.Entity<Order>()
    .HasOne(o => o.Customer) // Navigation property on Order
    .WithMany(c => c.Orders) // Navigation property on Customer
    .HasForeignKey(o => o.CustomerFK); // Specify the FK property in Order

```
در این مثال، `CustomerFK` نام پراپرتی در کلاس `Order` است که به عنوان کلید خارجی استفاده می‌شود. EF Core اطمینان حاصل می‌کند که ستون متناظر در جدول `Orders` به `Customers.Id` اشاره کند.

اگر نام پراپرتی کلید خارجی در کلاس Entity با نامی که می‌خواهید در دیتابیس باشد متفاوت است، می‌توانید آن را در `HasForeignKey` مشخص کنید:
```csharp

modelBuilder.Entity<Order>()
    .HasOne(o => o.Customer)
    .WithMany(c => c.Orders)
    .HasForeignKey("OrderCustomerID"); // Use a specific column name in the database

```
در این حالت، EF Core ستونی به نام `OrderCustomerID` در جدول `Orders` ایجاد یا استفاده خواهد کرد.
