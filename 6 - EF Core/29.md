ویژگی **Query Batching (دسته‌بندی کوئری):**

- در این حالت EF Core به طور خودکار چندین کوئری مستقل (مانند `SELECT`, `INSERT`, `UPDATE`, `DELETE`های جداگانه) را که در یک `DbContext` انجام می‌شوند، در **یک دستور SQL دسته‌بندی شده** (Batched SQL command) به دیتابیس ارسال می‌کند.
- این قابلیت به صورت پیش‌فرض در EF Core فعال است (برای اکثر دیتابیس‌ها).

**مزیت:**

- **کاهش تعداد رفت و برگشت بین اپلیکیشن و دیتابیس:** به جای ارسال N دستور، یک یا چند دستور دسته‌بندی شده ارسال می‌شود.
- **بهبود عملکرد:** سربار ارتباط با دیتابیس را کاهش می‌دهد.

**مثال:**

اگر شما چند عملیات `Add` و `Update` انجام دهید:
```csharp

context.Products.Add(new Product { Name = "A" });
context.Products.Add(new Product { Name = "B" });
context.Orders.Add(new Order { CustomerId = 1 });

await context.SaveChangesAsync(); // این دستور ممکن است به صورت یک Batch SQL ارسال شود

```
در این حالت EF Core این عملیات را جمع کرده و به صورت یک دستور SQL بزرگتر به دیتابیس می‌فرستد.
