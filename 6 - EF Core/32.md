یک Entity حداکثر به یک Entity دیگر مرتبط است و بالعکس.

**مثال: `User` و `UserProfile`**

هر `User` یک `UserProfile` دارد و هر `UserProfile` فقط متعلق به یک `User` است.

**با Data Annotations:**
```csharp

public class User
{
    public int Id { get; set; }
    public string Username { get; set; }
    public UserProfile Profile { get; set; } // Navigation Property
}

public class UserProfile
{
    public int Id { get; set; } // Primary Key for UserProfile
    public string Bio { get; set; }

    // Foreign Key Property pointing to User.Id
    public int UserId { get; set; }
    public User User { get; set; } // Navigation Property
}

```
در `DbContext.OnModelCreating`:
```csharp

modelBuilder.Entity<User>()
    .HasOne(u => u.Profile)
    .WithOne(p => p.User)
    .HasForeignKey<UserProfile>(p => p.UserId); // UserProfile foreign key points to User Id

```
کلید خارجی `UserId` باید هم Primary Key در `UserProfile` و هم Foreign Key به `User.Id` باشد.

برای این کار:
```csharp

modelBuilder.Entity<User>()
    .HasOne(u => u.Profile)
    .WithOne(p => p.User)
    .HasForeignKey<UserProfile>(p => p.UserId);

// برای اطمینان که UserId هم Primary Key است:
modelBuilder.Entity<UserProfile>()
    .HasKey(p => p.UserId);

```
اگر `UserProfile.Id` همان `UserProfile.UserId` باشد، تنظیم بالا کافی است.
