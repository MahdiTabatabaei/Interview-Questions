در واقع Interceptor روی عملیات SaveChanges قبل و بعد از اجرای آن عمل می‌کند.

مثال:
```csharp

public class LogSaveInterceptor : SaveChangesInterceptor
{
    public override int SavedChanges(SaveChangesCompletedEventData eventData, int result)
    {
        Console.WriteLine($"Saved {result} changes at {DateTime.Now}");
        return base.SavedChanges(eventData, result);
    }
}

```
ثبت در DBContext:
```csharp

options.AddInterceptors(new LogSaveInterceptor());

```
