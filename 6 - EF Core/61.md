## جلوگیری از حذف Review هنگام حذف Product

هدف:

- حذف Product → **نباید Reviewها حذف شوند**
- وجود Review → **مانع حذف Product شود**

باید از **Restrict** استفاده کنیم.
```csharp

modelBuilder.Entity<Review>()
    .HasOne(r => r.Product)
    .WithMany(p => p.Reviews)
    .HasForeignKey(r => r.ProductId)
    .OnDelete(DeleteBehavior.Restrict);

```
مدل:
```csharp

public class Product
{
    public int Id { get; set; }
    public List<Review> Reviews { get; set; }
}

public class Review
{
    public int Id { get; set; }
    public int ProductId { get; set; }
    public Product Product { get; set; }
}

```
مثال زندگی:

اگر محصولی در فروشگاه **Review داشته باشد**، سیستم اجازه حذف آن را نمی‌دهد.
