Up():

- اعمال تغییرات دیتابیس (ایجاد جدول، اضافه‌کردن ستون)

Down():

- بازگرداندن (Rollback) Up (حذف ستون، حذف جدول)

مثال:
```csharp

protected override void Up(MigrationBuilder migrationBuilder)
{
    migrationBuilder.AddColumn<string>("Title", "Books");
}

protected override void Down(MigrationBuilder migrationBuilder)
{
    migrationBuilder.DropColumn("Title", "Books");
}

```
