ابتدا باید NuGet Package `EFCore.BulkExtensions` را اضافه کنید:

`Install-Package EFCore.BulkExtensions`

**مثال Insert:**
```csharp

var usersToInsert = new List<User>();
for (int i = 0; i < 1000; i++)
{
    usersToInsert.Add(new User { Name = $"User {i}", Email = $"user{i}@example.com" });
}

await using (var context = new AppDbContext()) // Assuming AppDbContext is your DbContext
{
    await context.BulkInsertAsync(usersToInsert);
}

```
مثال Update:
```csharp

var usersToUpdate = await context.Users.Where(u => u.Name.StartsWith("User ")).ToListAsync();
foreach (var user in usersToUpdate)
{
    user.Email = user.Email.Replace("@example.com", "@updated.com");
}

await context.BulkUpdateAsync(usersToUpdate);

```
