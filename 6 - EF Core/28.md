استفاده **Compiled Queries (کوئری‌های کامپایل شده):**

- در این حالت EF Core یک نسخه از کوئری شما را از قبل کامپایل و ذخیره می‌کند.
- این کار باعث می‌شود که دفعه بعد که همان کوئری اجرا می‌شود، EF Core نیازی به parsing و ترجمه مجدد LINQ به SQL نداشته باشد.

**تأثیر بر Performance:**

- **افزایش سرعت:** برای کوئری‌هایی که **بسیار زیاد و مکرر** اجرا می‌شوند، Compiled Queries می‌توانند بهبود قابل توجهی در عملکرد ایجاد کنند.
- **کاهش سربار:** سربار ترجمه LINQ به SQL را از بین می‌برد.

**نحوه استفاده (EF Core 3.0 به بعد):**
```csharp

// تعریف کوئری کامپایل شده
var getPostById = EF.CompileQuery((AppDbContext context, int id) =>
    context.Posts.FirstOrDefault(p => p.Id == id));

// استفاده از آن
using (var context = new AppDbContext())
{
    var post = getPostById(context, 5);
}

```
**ملاحظات:**

- در واقع Compiled Queries برای کوئری‌های ساده که پارامترهای ثابت دارند، بیشترین تأثیر را دارند.
- برای کوئری‌های پویا یا پیچیده، ممکن است سربار پیاده‌سازی آن بیشتر از سودش باشد.
