در **Fluent API در EF Core** متدهای **`HasOne`** و **`WithMany`** برای تعریف رابطه **One‑to‑Many** بین دو Entity استفاده می‌شوند، اما هرکدام **سمت متفاوتی از رابطه** را مشخص می‌کنند.

به طور خلاصه:

- **HasOne** → این Entity به **یک Entity دیگر** اشاره می‌کند  
- **WithMany** → Entity مقابل می‌تواند **چندین نمونه از این Entity** داشته باشد

---

## مثال

فرض کنیم هر **Book** یک **Author** دارد و هر **Author** می‌تواند چند **Book** داشته باشد.

### Entity ها

```csharp
public class Book
{
    public int Id { get; set; }
    public int AuthorId { get; set; }

    public Author Author { get; set; }
}

public class Author
{
    public int Id { get; set; }

    public ICollection<Book> Books { get; set; }
}
```

---

## تعریف رابطه با Fluent API

```csharp
modelBuilder.Entity<Book>()
    .HasOne(b => b.Author)
    .WithMany(a => a.Books)
    .HasForeignKey(b => b.AuthorId);
```

---

## معنی هر بخش

### HasOne

```csharp
.HasOne(b => b.Author)
```

یعنی:

- هر **Book** فقط **یک Author** دارد
- این سمت رابطه یک **reference navigation** است

---

### WithMany

```csharp
.WithMany(a => a.Books)
```

یعنی:

- هر **Author** می‌تواند **چند Book** داشته باشد
- این سمت رابطه یک **collection navigation** است

---

### HasForeignKey

```csharp
.HasForeignKey(b => b.AuthorId)
```

مشخص می‌کند که:

- کلید خارجی در جدول **Book** قرار دارد

---

## نتیجه در دیتابیس

```
Authors
-------
Id

Books
-------
Id
AuthorId (FK)
```

رابطه:

```
Author (1) ---- (Many) Books
```

---

✅ **جمع‌بندی**

- **HasOne**: مشخص می‌کند این Entity به **یک Entity دیگر** وابسته است  
- **WithMany**: مشخص می‌کند Entity مقابل می‌تواند **چندین مورد از این Entity** داشته باشد  
- این ترکیب معمولاً برای تعریف **One‑to‑Many relationship** در EF Core استفاده می‌شود.
