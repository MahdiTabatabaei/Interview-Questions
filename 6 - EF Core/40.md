دو راه اصلی برای مشخص کردن دستی نام Foreign Key در EF Core وجود دارد:

1. **استفاده از Data Annotations:**

با استفاده از `[ForeignKey("RelatedEntityName")]` روی Navigation Property.
```csharp

    public class Order
    {
        public int Id { get; set; }

        // Navigation Property
        [ForeignKey("CustomerRef")] // Specify the FK property name
        public Customer Customer { get; set; }

        // Foreign Key Property
        public int CustomerRef { get; set; }
    }

```
در این حالت، EF Core از پراپرتی `CustomerRef` به عنوان Foreign Key استفاده می‌کند.

2. **استفاده از Fluent API (پیشنهادی و قدرتمندتر):**

در متد `OnModelCreating` دیتابیس کانکست.

**الف) با مشخص کردن نام پراپرتی Foreign Key در کلاس Entity:**
```csharp

    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        modelBuilder.Entity<Order>()
            .HasOne(o => o.Customer) // Navigation property
            .WithMany(c => c.Orders)
            .HasForeignKey(o => o.CustomerFK); // Specify the FK property in the Order entity
    }

```
اگر `CustomerFK` نام پراپرتی شماست، EF Core ستونی به همین نام در جدول `Orders` ایجاد یا استفاده می‌کند.

**ب) با مشخص کردن نام دلخواه ستون در دیتابیس (بدون نیاز به پراپرتی مجزا در Entity):**

اگر نمی‌خواهید یک پراپرتی جداگانه برای Foreign Key در کلاس Entity داشته باشید، می‌توانید مستقیماً نام ستون در دیتابیس را مشخص کنید. این کار معمولاً با تعریف یک Shadow Property یا با استفاده از `HasForeignKey()` همراه با نام رشته‌ای انجام می‌شود:
```csharp

    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        modelBuilder.Entity<Order>()
            .HasOne(o => o.Customer)
            .WithMany(c => c.Orders)
            .HasForeignKey("CustomOrderCustomerID"); // Specify the FK column name directly
                                                  // EF Core will create this column if it doesn't exist
    }

```
در این سناریو، EF Core خودش یک ستون به نام `CustomOrderCustomerID` در جدول `Orders` ایجاد یا مدیریت خواهد کرد، حتی اگر پراپرتی‌ای به این نام در کلاس `Order` وجود نداشته باشد (Shadow Property).
