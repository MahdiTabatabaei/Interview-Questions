Tracking:

- عملکرد EF روی موجودیت‌ها نظارت می‌کند (State = Modified, Added …)
- ویژگی ChangeTracker فعال می‌شود
- مناسب عملیات Update/Delete

NoTracking:

- عملکرد EF موجودیت ها را ردیابی نمی‌کند
- سریع‌تر و مناسب خواندن داده‌ها (Read-only)

مثال:
```csharp

var tracked = context.Users.ToList(); // Tracking

var noTracked = context.Users.AsNoTracking().ToList(); // No Tracking

```
