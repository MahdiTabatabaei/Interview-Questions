فرض: Address یک ستون IsPrimary دارد و تنها Primary حذف شود.

راه بهتر: **DeleteBehavior.Restrict** بگذارید که User حذف شود ولی Address ها دست‌نخورده بمانند.
```csharp

.Select(x => new UserDto { Name = x.Name, OrdersCount = x.Orders.Count })
modelBuilder.Entity<Address>()
    .HasOne(a => a.User)
    .WithMany(u => u.Addresses)
    .OnDelete(DeleteBehavior.Restrict);

```
اگر می‌خواهی فقط Primary حذف شود:
```csharp

var primary = user.Addresses.First(a => a.IsPrimary);
context.Remove(primary);
context.Remove(user);

```
نه EF، بلکه **منطق خودت** انتخاب می‌کند کدام حذف شود.
