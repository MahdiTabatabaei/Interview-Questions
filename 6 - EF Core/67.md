## Global Query Filter در MultiTenant
[[Tenant]]

تعریف:
```csharp

modelBuilder.Entity<Order>()
.HasQueryFilter(o => o.TenantId == _tenantId);

```
مشکل:

وقتی Navigation Property داریم:
```markdown

User → Orders

```
اگر Orders فیلتر شود:

- در Include ممکن است داده ناقص برگرداند
- و Join ها پیچیده می‌شوند
- بعضی Navigationها empty برمی‌گردند

راه حل:

- ایجاد Filter روی همه Entityها
- یا استفاده از **TenantId در همه جدول‌ها**
