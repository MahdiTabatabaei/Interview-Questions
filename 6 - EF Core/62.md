## One-to-One Optional / Required

فرض:

- درواقع Invoice وابسته به Order است
- اما ممکن است Order هنوز Invoice نداشته باشد

یعنی

Order → Optional Invoice

Invoice → Required Order

مدل:
```csharp

public class Order
{
    public int Id { get; set; }

    public Invoice Invoice { get; set; }
}

public class Invoice
{
    public int Id { get; set; }

    public int OrderId { get; set; }
    public Order Order { get; set; }
}

```
Fluent API
```csharp

modelBuilder.Entity<Order>()
    .HasOne(o => o.Invoice)
    .WithOne(i => i.Order)
    .HasForeignKey<Invoice>(i => i.OrderId)
    .IsRequired();

```
در این حالت:

Order ممکن است Invoice نداشته باشد

ولی Invoice حتما Order دارد.

مثال زندگی:

سفارش ثبت شده اما **فاکتور هنوز صادر نشده است.**
