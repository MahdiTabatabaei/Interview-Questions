
## هدف چیست؟

می‌خواهیم بررسی کنیم که آیا دو رشته **دقیقاً شامل همان کاراکترها با همان تعداد** هستند یا نه.  
ترتیب مهم نیست. یعنی:

- "aabc" و "abca" → درست  
- "aabc" و "abcc" → غلط  
- "aabc" و "abc" → غلط (طول متفاوت)

------------------------------------

## ایدهٔ اصلی

برای اینکه بدانیم دو رشته شامل همان کاراکترها هستند، کافی است:

1. **تعداد هر کاراکتر در s1 را بشماریم**
2. **به‌ازای هر کاراکتر در s2 یکی از آن تعداد کم کنیم**
3. اگر در پایان همه تعدادها صفر شدند ⇒ رشته‌ها یکسان‌اند  
   اگر یکی از تعدادها منفی شد یا کاراکتری وجود نداشت ⇒ رشته‌ها یکسان نیستند

این روش:

- فقط **یک بار** روی هر رشته حلقه می‌زند  
- **پیچیدگی زمانی O(n)** دارد  
- بدون Regex  
- بهینه‌ترین روش ممکن است

------------------------------------

## مثال شفاف

### مثال ۱  
S1 = "abcabc"  
S2 = "bbacac"

ابتدا از روی S1 یک شمارش می‌سازیم:

| کاراکتر | تعداد |
|--------|--------|
| a      | 2      |
| b      | 2      |
| c      | 2      |

حال روی S2 پیمایش می‌کنیم و از شمارش کم می‌کنیم:

- b → تعداد b از 2 به 1  
- b → از 1 به 0 (حذف می‌شود)  
- a → از 2 به 1  
- c → از 2 به 1  
- a → از 1 به 0 (حذف)  
- c → از 1 به 0 (حذف)

در پایان دیکشنری **خالی** می‌شود  
پس دو رشته دقیقاً یکسان‌اند.

### خروجی:  
`true`

------------------------------------

### مثال ۲  
S1 = "hello"  
S2 = "llheo"

شمارش s1:

| کاراکتر | تعداد |
|--------|--------|
| h      | 1      |
| e      | 1      |
| l      | 2      |
| o      | 1      |

پیمایش s2:

- l → 2 → 1  
- l → 1 → 0  
- h → 1 → 0  
- e → 1 → 0  
- o → 1 → 0  

دیکشنری خالی → True

------------------------------------

### مثال ۳  
S1 = "test"  
S2 = "tess"

شمارش s1:

| t | 2 |
| e | 1 |
| s | 1 |

پیمایش s2:

- t → 2 → 1  
- e → 1 → 0  
- s → 1 → 0  
- s → ❌ وجود ندارد → false

پس این دو رشته یکسان نیستند.

------------------------------------

## کد نهایی #C

```csharp
public static bool HaveSameCharacters(string s1, string s2)
{
    if (s1.Length != s2.Length)
        return false;

    var counts = new Dictionary<char, int>();

    // Count characters in s1
    foreach (char c in s1)
    {
        if (counts.ContainsKey(c))
            counts[c]++;
        else
            counts[c] = 1;
    }

    // Decrease counts for characters in s2
    foreach (char c in s2)
    {
        if (!counts.ContainsKey(c))
            return false;

        counts[c]--;

        if (counts[c] == 0)
            counts.Remove(c);
    }

    return counts.Count == 0;
}
```
