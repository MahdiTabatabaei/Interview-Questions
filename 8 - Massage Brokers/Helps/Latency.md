مفهوم **Latency** یعنی **مدت زمانی که طول می‌کشه یک کار از ابتدا تا انتها انجام بشه.**

به زبان خیلی ساده:

> **Latency = مدت انتظار برای دریافت نتیجه**

---

# مثال‌های واضح

## 1) اینترنت  

وقتی یک سایت را باز می‌کنی:

```
Latency = زمان بین درخواست شما تا دریافت اولین پاسخ
```

اگر 50ms باشد یعنی:

> در ۵۰ میلی‌ثانیه جواب می‌گیرد.

---

## 2) Message Broker (Kafka / RabbitMQ)

```
Latency = زمان ارسال یک پیام تا زمانی که Consumer آن را دریافت می‌کند
```

مثلاً:

- ابزار Kafka معمولاً چند میلی‌ثانیه تا چند ده میلی‌ثانیه
- و ابزار RabbitMQ معمولاً از Kafka سریع‌تر = چند میلی‌ثانیه

---

## 3) دیتابیس

```
Latency = زمان اجرای یک Query
```

مثلاً:

- SELECT ساده = 1 ms  
- JOIN پیچیده = 50 ms

---

# تفاوت Latency با Throughput

خیلی مهمه این‌ها را قاطی نکنیم:

| مفهوم | تعریف |
|------|-------|
| **Latency** | زمان انجام یک کار (می‌خواهی جواب با تأخیر کم باشد) |
| **Throughput** | تعداد کارهایی که در یک ثانیه انجام می‌شود |

### مثال:

```
Latency = 10 ms
Throughput = 100,000 msg/sec
```

این یعنی:
- هر پیام 10ms طول می‌کشد
- اما چون سیستم موازی‌سازی دارد، هر ثانیه 100,000 پیام پردازش می‌شود

---

# مثال سوپرمارکت (خیلی ساده و قابل فهم)

فرض کن یک صندوق فروشگاه داری.

### Latency:
زمانی که یک مشتری جلوی صندوق می‌ایستد تا کارش تمام شود.

```
Latency = 30 ثانیه
```

### Throughput:
در هر دقیقه چند مشتری را می‌توانی رد کنی؟

```
Throughput = 2 مشتری در دقیقه
```

اگر صندوق دوم اضافه کنی:

- Latency = همان 30 ثانیه  
- Throughput = بیشتر (4 مشتری در دقیقه)

---

# خلاصه نهایی

```
Latency = زمان انجام یک کار
Throughput = تعداد کارهای انجام‌شده در واحد زمان
```
