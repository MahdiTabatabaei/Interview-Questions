در **RabbitMQ** اینکه یک پیام به چند consumer برسد، به **نوع exchange و نحوه bind شدن queueها** بستگی دارد. به طور پیش‌فرض اگر چند consumer روی **یک queue** باشند، پیام فقط به یکی از آن‌ها می‌رسد (load balancing). ولی اگر بخواهی **همه consumerها پیام را بگیرند** باید ساختار را عوض کنی.

### حالت پیش‌فرض (یک Queue، چند Consumer)
```
Producer → Queue → Consumer1
                 → Consumer2
                 → Consumer3
```
- هر پیام فقط به **یکی از consumerها** می‌رسد.
- ابزار RabbitMQ بین consumerها **round-robin** توزیع می‌کند.
- این حالت برای **load balancing** استفاده می‌شود.

### حالت ارسال به چند Consumer (Fanout / Pub-Sub)

برای اینکه **همه consumerها پیام را بگیرند** باید:

1. یک **exchange** بسازی (مثلاً `fanout`)
2. برای هر consumer یک **queue جدا** داشته باشی
3. همه queueها را به exchange **bind** کنی

```
                → Queue1 → Consumer1
Producer → Exchange
                → Queue2 → Consumer2
                → Queue3 → Consumer3
```

در این حالت:
- تولید کننده Producer پیام را به **exchange** می‌فرستد.
- در Exchange پیام را **کپی می‌کند** و به همه queueها می‌دهد.
- هر consumer پیام خودش را دریافت می‌کند.

### مثال ساده (Fanout)

Producer:

```csharp
using RabbitMQ.Client;
using System.Text;

var factory = new ConnectionFactory()
{
    HostName = "localhost"
};

using var connection = factory.CreateConnection();
using var channel = connection.CreateModel();

// ساخت exchange از نوع fanout
channel.ExchangeDeclare(
    exchange: "logs",
    type: ExchangeType.Fanout,
    durable: true,
    autoDelete: false,
    arguments: null
);

// پیام
var message = "Hello";
var body = Encoding.UTF8.GetBytes(message);

// ارسال پیام
channel.BasicPublish(
    exchange: "logs",
    routingKey: "",
    basicProperties: null,
    body: body
);

Console.WriteLine("Message sent");

```

Consumer:

```csharp
using RabbitMQ.Client;
using System;

var factory = new ConnectionFactory()
{
    HostName = "localhost"
};

using var connection = factory.CreateConnection();
using var channel = connection.CreateModel();

// ساخت Fanout Exchange
channel.ExchangeDeclare(
    exchange: "logs",
    type: ExchangeType.Fanout,
    durable: false,
    autoDelete: false,
    arguments: null
);

// ساخت یک Queue موقتی و Exclusive مشابه queue='' در پایتون
var queueDeclareOk = channel.QueueDeclare(
    queue: "",
    durable: false,
    exclusive: true,
    autoDelete: true,
    arguments: null
);

var queueName = queueDeclareOk.QueueName;
Console.WriteLine($"Temporary Queue created: {queueName}");

// Bind کردن صف موقتی به exchange
channel.QueueBind(
    queue: queueName,
    exchange: "logs",
    routingKey: ""
);

```

### جمع‌بندی

- چند consumer روی **یک queue** → هر پیام فقط به **یکی** می‌رسد.
- چند **queue** bind شده به exchange → پیام به **همه consumerها** می‌رسد.
