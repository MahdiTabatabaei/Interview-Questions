تعریف **Message Broker** یک نرم‌افزار واسطه است که پیام‌های ارسال‌شده از یک سرویس (Producer) را دریافت کرده و آن را به سرویس موردنظر (Consumer) تحویل می‌دهد.

در معماری Microservices نقش اصلی آن **عدم وابستگی سرویس‌ها به هم (Decoupling)** و **ارتباط Async** است.

نقش‌ها:

- کاهش وابستگی سرویس‌ها
- امکان تحمل خطا
- جلوگیری از overload سرویس‌ها
- مدیریت صف‌ها، retries، acknowledgment
- افزایش scalability

**مثال واقعی:**

سرویس ثبت سفارش پیام “OrderCreated” را به بروکر می‌فرستد؛ سرویس فاکتورگیری و سرویس انبار هر دو مصرف‌کننده‌اند.

**مثال C#:**
```csharp

var factory = new ConnectionFactory() { HostName = "localhost" };
using var conn = factory.CreateConnection();
using var channel = conn.CreateModel();

var message = "OrderCreated";
var body = Encoding.UTF8.GetBytes(message);

channel.BasicPublish("", "orders", null, body);

```
